---

Open **Partner → Organizations**. Each row is a client workspace.

## What each row shows

| Column | Meaning |
| --- | --- |
| **Workspace** | Name and address. Click it for the [client detail](/partners/clients/client-detail) |
| Plan and status | The client's plan, subscription status, and whether it's suspended or cancels at period end |
| Balance | What the client can still spend. See [Balances](#balances) |
| **Renews** | Next renewal date |
| Usage | Contacts, channels, seats, WhatsApp, AI, automations and marketing emails |
| **Activation** | Setup steps the workspace has done, such as adding a payment method, connecting a channel or inviting the team |

## Queues

Use **Queue** to jump to the clients that need attention:

| Queue | Shows |
| --- | --- |
| **Needs money** | Low balance or open invoices |
| **Trusted and low** | Clients allowed to run into credit whose balance is low |
| **Least activated** | Clients that haven't finished setting up |
| **High spenders ($100+)** | Clients that paid the most so far |

You can also search, filter by status, plan or setup step, and sort by any column. The Overview page counts each queue so you see them at a glance.

## Balances

| Value | Meaning |
| --- | --- |
| **Spendable** | Credit left after usage already consumed this period and pending one-time items. This is the number that decides whether a client gets restricted |
| Metered | Usage consumed this period that will be billed against the wallet |
| Pending | One-time items waiting on the next invoice |
| Subscription | The plan amount for this cycle. Shown for context |
| Open invoices | Unpaid invoices that still need payment or your cover |
| Lifetime paid | What the client paid in total: card top-ups and paid invoices. Your transfers aren't counted |

The list uses balances checked recently; the detail page reads the wallet live.
