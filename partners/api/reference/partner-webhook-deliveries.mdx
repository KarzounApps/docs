---
title: "partnerWebhookDeliveries"
description: "Your partner webhook delivery log."
---

Query · Scope `partner:read`

Events sent to your [partner webhook](/partners/webhook) in the last 30 days, newest first.

## Arguments

| Argument | Type | Notes |
| --- | --- | --- |
| `state` | `String` | `pending`, `success` or `failed` |
| `page` | `Int` | Default 1 |
| `perPage` | `Int` | Default 20, at most 100 |

## Example

```graphql
query {
  partnerWebhookDeliveries(state: "failed") {
    list { eventId event subdomain state attempts lastStatus lastError nextAttemptAt canResend createdAt }
    totalCount
  }
}
```
