---
title: "partnerOrganizationDetail"
description: "One client, with a live wallet read, invoices and usage."
---

Query · Scope `partner:read`

Everything on the [client detail](/partners/clients/client-detail) page. The wallet is read live.

## Arguments

| Argument | Type | Notes |
| --- | --- | --- |
| `organizationId` | `ID!` | The client's `_id` |

## Example

```graphql
query {
  partnerOrganizationDetail(organizationId: "665f1c…") {
    planName
    organization { name spendableBalanceCents meteredCents pendingItemsCents }
    openInvoices { id amountRemaining dueDate hostedInvoiceUrl }
    upcomingLines { description amountCents }
    usageRecords { meterName quantity }
  }
}
```
