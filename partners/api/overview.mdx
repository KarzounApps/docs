The Partner API does from your system what the Partner portal does by hand: add clients, fund them, follow their numbers and issue their API keys.

## Endpoint and authentication

The Partner API is part of the Karzoun GraphQL API. Call your **partner workspace**:

```
POST https://YOUR_PARTNER_SUBDOMAIN.api.karzoun.chat/graphql
Authorization: Bearer kz_live_YOUR_API_KEY
Content-Type: application/json
```

Create the key in your partner workspace under **Developer → API keys** with these scopes:

| Scope | Grants |
| --- | --- |
| `partner:read` | Your profile and wallet, clients and their balances, numbers across clients, earnings, partner webhook deliveries |
| `partner:write` | Create, fund and suspend clients, issue and revoke number API keys, test and resend the partner webhook |

## A typical flow

<Steps>
  <Step title="Pick a plan">
    [`partnerPlans`](/partners/api/reference/partner-plans) lists your plans and their IDs.
  </Step>
  <Step title="Create the client">
    [`partnerRegisterOrganization`](/partners/api/reference/partner-register-organization), with an optional initial balance.
  </Step>
  <Step title="Connect a WhatsApp number">
    Send the client a [connect link](/partners/connect-links). It works without a Karzoun login.
  </Step>
  <Step title="Issue an API key">
    When [`channel.connected`](/partners/webhook) arrives, call [`partnerChannelApiKeyCreate`](/partners/api/reference/partner-channel-api-key-create).
  </Step>
  <Step title="Keep it running">
    Watch balances with [`partnerOrganizationMonitor`](/partners/api/reference/partner-organization-monitor) or the `wallet.low_balance` event, and top up with [`partnerTransferBalance`](/partners/api/reference/partner-transfer-balance).
  </Step>
</Steps>

## Operations

| Operation | Type | Scope | Use |
| --- | --- | --- | --- |
| [`partner`](/partners/api/reference/partner) | Query | read | Your partner profile and workspace wallet |
| [`partnerPlans`](/partners/api/reference/partner-plans) | Query | read | Plans you can assign to clients |
| [`partnerOrganizationMonitor`](/partners/api/reference/partner-organization-monitor) | Query | read | Clients with balances, usage and status |
| [`partnerOrganizationDetail`](/partners/api/reference/partner-organization-detail) | Query | read | One client, with a live wallet read |
| [`partnerChannels`](/partners/api/reference/partner-channels) | Query | read | WhatsApp numbers across clients |
| [`partnerWallet`](/partners/api/reference/partner-wallet) | Query | read | Your earnings balance |
| [`partnerWebhookDeliveries`](/partners/api/reference/partner-webhook-deliveries) | Query | read | Partner webhook delivery log |
| [`partnerRegisterOrganization`](/partners/api/reference/partner-register-organization) | Mutation | write | Create a client workspace |
| [`partnerTransferBalance`](/partners/api/reference/partner-transfer-balance) | Mutation | write | Move credit from your wallet to a client |
| [`partnerSuspendOrganizations`](/partners/api/reference/partner-suspend-organizations) | Mutation | write | Suspend or reactivate clients |
| [`partnerChannelApiKeyCreate`](/partners/api/reference/partner-channel-api-key-create) | Mutation | write | Issue the API key for a client's number |
| [`partnerChannelApiKeyRevoke`](/partners/api/reference/partner-channel-api-key-revoke) | Mutation | write | Revoke it |
| [`partnerTestWebhook`](/partners/api/reference/partner-test-webhook) | Mutation | write | Send a test event to your partner webhook |
| [`partnerWebhookResend`](/partners/api/reference/partner-webhook-resend) | Mutation | write | Resend a failed partner webhook event |

Settings like branding, plans and domains are managed in the Partner portal only.

## Errors

Errors come back in GraphQL's `errors` array with a message, for example `initialBalance must be a non-negative number`. A missing scope or an organization that isn't yours returns a permission error.
