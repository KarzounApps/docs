---
title: "Numbers and API keys"
description: "List your clients' WhatsApp numbers and issue WhatsApp API keys for them."
---

## List numbers

```graphql
query {
  partnerChannels {
    organizationId
    subdomain
    integrationId
    phoneNumber
    status
    qualityRating
    messagingLimitTier
    apiKeyHint
    webhookUrl
    error
  }
}
```

Pass `organizationId` to list one client's numbers only.

| Field | Meaning |
| --- | --- |
| `integrationId` | The number's ID in Karzoun. Use it for API keys |
| `phoneNumber`, `phoneNumberId`, `wabaId` | The number, and Meta's IDs for it |
| `status`, `qualityRating`, `messagingLimitTier`, `nameStatus` | Live from Meta, for example `CONNECTED`, `GREEN`, `TIER_1K` |
| `accountMode` | `cloud_api`, or `coexistence` when the number is also used in the WhatsApp Business app |
| `apiKeyHint` | First characters of the active API key, or `null` |
| `webhookUrl` | The number's webhook URL, or `null` |
| `error` | Set when Meta couldn't be reached for this number |

## Create an API key

```graphql
mutation {
  partnerChannelApiKeyCreate(organizationId: "ORG_ID", integrationId: "INTEGRATION_ID") {
    token
    hint
  }
}
```

`token` is the full key, returned **once**. Store it in your secret manager and use it as `Karzoun-API-Key` with the [WhatsApp API](/whatsapp-api/authentication). Creating a key replaces the number's previous key.

Create the key when the [`channel.connected`](/partners/webhook) event arrives, so onboarding finishes without anyone opening the dashboard.

## Revoke a key

```graphql
mutation {
  partnerChannelApiKeyRevoke(organizationId: "ORG_ID", integrationId: "INTEGRATION_ID")
}
```

Requests with the key fail with `401` from that moment.

## Set the number's webhook

Use the new key to point the number's events at your platform:

```bash
curl -X POST https://waba.karzoun.chat/webhook \
  -H "Karzoun-API-Key: THE_NEW_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://platform.example/whatsapp/acme" }'
```

See [Webhooks](/whatsapp-api/webhooks/overview).
