## Pick a plan

```graphql
query {
  partnerPlans {
    _id
    name
    type
  }
}
```

Use a plan of type `api` for clients that only use the WhatsApp API.

## Create a client

```graphql
mutation {
  partnerRegisterOrganization(input: {
    name: "Acme Trading"
    email: "owner@acme.example"
    subdomain: "acme"
    planId: "PLAN_ID"
    initialBalance: 50
  }) {
    _id
    subdomain
    name
  }
}
```

| Field | Notes |
| --- | --- |
| `name`, `email` | The workspace name and its owner. The owner receives an invitation |
| `subdomain` | The client's address: `acme.karzoun.chat`, or `acme.yourdomain.com` on your whitelabel domain |
| `planId` | From `partnerPlans` |
| `initialBalance` | Optional. Dollars moved from your wallet right after creation. Rejected up front if your wallet can't cover it |
| `phone`, `source`, `customFields` | Optional |

Store `_id`: it is the `organizationId` for every other partner call. A `client.created` event also goes to your [partner webhook](/partners/webhook).

## Read balances

```graphql
query {
  partnerOrganizationMonitor(page: 1, perPage: 50, sortBy: "spendableBalanceCents", sortOrder: "asc") {
    data {
      _id
      name
      subdomain
      spendableBalanceCents
      isRestricted
      isSuspended
      balanceCheckedAt
    }
    pagination { totalCount }
  }
}
```

`spendableBalanceCents` is what the client can spend now. The list reads cached balances (see `balanceCheckedAt`). For a live read of one client, use `partnerOrganizationDetail(organizationId: …)`.

Your own wallet:

```graphql
query {
  partner {
    wallet { availableBalance currency }
  }
}
```

## Top up a client

```graphql
mutation {
  partnerTransferBalance(input: {
    organizationId: "ORG_ID"
    amount: 25
    description: "November top-up"
  }) {
    success
    transferredAmount
    partnerBalanceAfter
    organizationBalanceAfter
  }
}
```

`amount` is in dollars. It must be covered by your wallet. Top up your own wallet by card in **Partner → Wallet**.

## Know when a client runs low

When a client's balance drops below $20, your [partner webhook](/partners/webhook) receives `wallet.low_balance` once. It fires again only after the balance has recovered and dropped again.

```json
{
  "event": "wallet.low_balance",
  "partner": "agency",
  "organization_id": "665f1c…",
  "subdomain": "acme",
  "data": { "available_balance": 14.2, "threshold": 20, "currency": "usd" },
  "occurred_at": "2026-11-18T10:00:00.000Z"
}
```

If you fund client wallets (**You fund customer wallets**), your support email also gets a notice.

## Suspend a client

```graphql
mutation {
  partnerSuspendOrganizations(input: { organizationIds: ["ORG_ID"], suspend: true }) {
    successCount
    errorCount
  }
}
```

Pass `suspend: false` to lift it. Suspended workspaces can't send messages.
