**Automations** (`/automations`) run sequences across Inbox, contacts, segments, Karzoun Pixel, campaigns, and installed apps. Ready-made apps (Salla, Zid, Shopify, Sheets, …) are the fast path. **HTTP request** is the open path to any API.

## Building blocks

| Piece | Role |
| --- | --- |
| Trigger | The event that starts the run (new conversation, segment join, store order, page view, …) |
| Node | A step on the canvas — nine types (message, question, email, condition, A/B split, action, go-to, AI agent, sticky note) |

Action nodes include tagging, assignment, **handoff to a human**, and outbound HTTP / GraphQL / JavaScript.

## Do not start here on day one

If the channel is not tested and the team cannot reply from Inbox, fix that first ([Get started](/help-center/guides/getting-started/overview)). Store **initial sync** can fire a “new customer” automation thousands of times — disable those automations before sync: [Ecommerce apps (Arabic)](/ar/help-center/guides/automations/apps/ecommerce).
