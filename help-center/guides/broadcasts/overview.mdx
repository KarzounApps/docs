**Broadcasts** (`/broadcast`) is where you launch campaigns to a defined audience — usually from [segments (Arabic)](/ar/help-center/guides/contacts/segments/overview). In Help Center Arabic we call this **marketing campaigns**; the product sidebar says **Broadcasts**.

<Info>
**Canonical (Arabic):** [Campaigns overview](/ar/help-center/guides/broadcasts/overview) · [Marketer path](/ar/help-center/guides/broadcasts/path-marketer)
</Info>

## Five channels

| Channel | Use it for |
| --- | --- |
| WhatsApp | Highest engagement; requires an **approved Meta template** |
| Email | Longer content; separate email templates |
| Live chat | Visitor-triggered message on your site widget |
| Automation | **Starts a workflow** for each person in the audience — you do not write the message inside the campaign |
| Web and app push | Native notification for contacts with device tokens |

Do not describe the product as “WhatsApp + email only”.

## Three run modes

| Mode | Meaning |
| --- | --- |
| Manual, one-time | Send now or once at a scheduled time |
| Recurring | Time-based schedule; audience is recalculated each cycle |
| Visitor hook | Visitor rules, no classic timetable — live chat is forced into this mode |

<Warning>
A **recurring** campaign is not “send when someone enters a segment”. Segment enter/leave is an **automation** trigger. You can use both; they are not the same control.
</Warning>

## Launch sequence

Setup → audience (segments **or** tags **or** specific contacts) → content → schedule → review. Then save draft or publish. Steps: [Create a campaign (Arabic)](/ar/help-center/guides/broadcasts/create).

First week discipline (small audience, then report): [Marketer week 1 (Arabic)](/ar/help-center/guides/use-cases/marketer-week-1).
