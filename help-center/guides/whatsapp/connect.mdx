WhatsApp is connected from **Inbox → Channels**, not from a separate “WhatsApp product” install. After the number is live, **WhatsApp Manager** is where you run Meta-side settings (profile, QR, templates, ads, calls, catalog).

<Info>
**Canonical (Arabic):** [Connect the channel](/ar/help-center/guides/channels/whatsapp) · [Manage the number](/ar/help-center/guides/whatsapp/connect)
</Info>

Karzoun is a **Meta Business Partner** and WhatsApp Solution Partner. Signup follows the official Cloud API embedded path.

## What to do

1. Run the WhatsApp wizard from **Inbox → Channels → Create → WhatsApp** (or `/channels?add=whatsapp`). Full click-path, coexistence, and Meta errors: [WhatsApp channel (Arabic)](/ar/help-center/guides/channels/whatsapp).
2. Send a test message and confirm it appears in [Inbox](/help-center/guides/inbox/overview).
3. Open **WhatsApp Manager** (Inbox → Channels → edit WhatsApp → WhatsApp Manager) for profile, QR, templates, and the rest — index: [Manage the number (Arabic)](/ar/help-center/guides/whatsapp/connect).

Karzoun channel settings (department, bot, **assignment**) are separate from WhatsApp Manager (Meta account settings).

## Moving a number from another provider

Disable two-factor on the number in Meta **before** cutover day: [Disable 2FA (Arabic)](/ar/help-center/guides/whatsapp/disable-2fa), then finish transfer from the channel guide. Ordered cutover: [Migrate from another tool (Arabic)](/ar/help-center/guides/use-cases/migrate-from-other-tool).
