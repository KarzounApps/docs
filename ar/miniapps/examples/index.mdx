تعريفات ميني أب مرجعية حسب أسلوب التكامل. هذه **أنماط لتقديمك** — احذف علامات الحذف (`// ...`) قبل إرسال JSON الكامل إلى كرزون.

| المثال                             | المصادقة         | أبرز النقاط                                              |
| -------------------------------------- | ------------ | ----------------------------------------------------------- |
| [Dropbox](/ar/miniapps/examples/dropbox) | Bearer token | إجراءات الملفات ومشغّلات بسيطة                              |
| [Slack](/ar/miniapps/examples/slack)     | Bearer token | مصادر RPC واستجابة التحدي وطلبات متسلسلة          |
| [GitHub](/ar/miniapps/examples/github)   | Bearer token | أحداث قائمة على الترويسة والتحقق بـ HMAC                     |
| [Salla](/ar/miniapps/examples/salla)     | OAuth 2.0    | مزامنة التجارة الإلكترونية واستخراج العملاء ومعالجات الطلبات        |

<Info>
  **الأصول** — تشير الأمثلة إلى `https://cdn.karzoun.com/miniapps/...` للتطبيقات المدمجة. استخدم **روابط HTTPS الخاصة بك** لـ `icon` و`logo` في التقديمات.
</Info>

## اختر نقطة بداية

- **الإنتاجية / SaaS** → Dropbox أو GitHub
- **الرسائل** → Slack
- **شريك تجارة إلكترونية** → Salla + [دليل المزامنة](/ar/miniapps/guides/sync)

بعد تكييف مثال، اتبع [التقديم للمراجعة](/ar/miniapps/guides/submission).
