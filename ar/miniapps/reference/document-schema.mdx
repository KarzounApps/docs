---

كل ميني أب هو مستند واحد بهذه الحقول العلوية:

| الحقل              | النوع   | مطلوب | الوصف                                                                                                                          |
| ------------------ | ------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `ns`               | string | ✅       | معرّف مساحة أسماء فريد (حروف صغيرة، kebab)                                                                                       |
| `name`             | string | ✅       | الاسم الداخلي (عادة نفس `ns`)                                                                                                 |
| `type`             | string | ✅       | معرّف النوع (عادة نفس `ns`)                                                                                               |
| `title`            | string | ✅       | عنوان العرض في السوق                                                                                                     |
| `label`            | string | ✅       | تسمية قصيرة                                                                                                                          |
| `description`      | string | ✅       | وصف كامل (يدعم markdown)                                                                                                 |
| `shortDescription` | string | ✅       | ملخص بسطر واحد                                                                                                                     |
| `status`           | string | ✅       | `'public'` أو `'private'`                                                                                                            |
| `version`          | string | ✅       | إصدار دلالي (مثل `'1.0.0'`)                                                                                                   |
| `category`         | string | ✅       | الفئة لتصفية السوق                                                                                                   |
| `icon`             | string | ✅       | رابط الأيقونة (يُفضَّل SVG)                                                                                                           |
| `logo`             | string | ✅       | رابط الشعار                                                                                                                             |
| `docsUrl`          | string | ✅       | رابط إلى وثائقك                                                                                                           |
| `youtubeId`        | string | —        | معرّف فيديو تعليمي على YouTube                                                                                                            |
| `auth`             | object | ✅       | إعدادات المصادقة                                                                                                         |
| `actions`          | array  | —        | إجراءات قابلة للتنفيذ (استدعاءات API + خطوات دوال التطبيق اختيارياً)                                                                         |
| `triggers`         | array  | —        | مشغّلات أحداث الويب هوك                                                                                                               |
| `webhook`          | object | —        | معالجة الويب هوك الواردة — انظر [الويب هوك](/ar/miniapps/guides/webhooks)                                                               |
| `sync`             | object | —        | الاستيراد الجماعي + مزامنة فورية عبر `sync.webhooks` — انظر [المزامنة](/ar/miniapps/guides/sync)                                                      |
| `source`           | object | —        | تعريفات مصادر البيانات الديناميكية (RPC) — انظر [مصادر البيانات الديناميكية](/ar/miniapps/guides/dynamic-data-sources)                            |
| `functions`        | object | —        | دوال تطبيق معزولة تُستدعى كخطوات في المسار — انظر [الإجراءات → دوال التطبيق](/ar/miniapps/guides/actions#app-functions-pipeline-steps) |
| `dashboardApps`    | array  | —        | لوحات اختيارية في الشريط الجانبي للبريد الوارد. يثبّتها المستأجر من **الإعدادات ← التطبيقات ← {التطبيق}** (لا تثبيت تلقائي). كل عنصر: `key`، `name`، `iframeUrl`، واختياريًا `description`، `icon`، `allowedActions`، `defaultStatus`. انظر [Dashboard SDK](/ar/sdk/dashboard-sdk). |

<Info>
  **حقول فريق كرزون** — قد تتضمن بذور السوق من الطرف الأول حقول `webhook` إضافية (`merchantExtraction` و`uninstallEvents`) وكتلة `provisioning` علوية. هذه **ليست** جزءاً من مخطط تقديم الشركاء وتُوثَّق بشكل منفصل للاستخدام الداخلي.
</Info>

### الفئات

استخدم إحدى قيم الفئات التالية:

| الفئة        | الوصف                       |
| --------------- | ---------------------------------- |
| `ecommerce`     | منصات التجارة الإلكترونية               |
| `productivity`  | الإنتاجية وإدارة المشاريع  |
| `communication` | الدردشة والرسائل والبريد             |
| `marketing`     | التسويق والتحليلات              |
| `developer`     | أدوات المطوّرين وDevOps           |
| `payment`       | بوابات الدفع                   |
| `social`        | منصات التواصل الاجتماعي             |
| `storage`       | تخزين الملفات وإدارتها          |
| `analytics`     | التحليلات والتقارير              |
| `crm`           | إدارة علاقات العملاء          |
