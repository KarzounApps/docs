---
title: "البداية السريعة"
description: "اربط رقم واتساب، أنشئ مفتاح API، وأرسل أول رسالة."
---

ستربط رقماً، تشحن محفظتك، تنشئ مفتاح API، ترسل قالباً، ثم تستقبل الرد على خادمك.

<Steps>
  <Step title="اربط رقم واتساب">
    ادخل حسابك في كرزون واضغط **أضف رقماً**. سجّل الدخول بحساب ميتا الذي يدير نشاطك، وأكمل خطوات التسجيل في ميتا.

    تحتاج إلى:
    - صلاحية مسؤول (Admin) في حساب Meta Business الخاص بنشاطك،
    - رقم يستقبل رسالة SMS أو مكالمة، أو رقم شغّال على تطبيق واتساب للأعمال (اختر **استخدام تطبيق واتساب للأعمال**)،
    - موقع إلكتروني فعّال لنشاطك، لأن ميتا تراجعه.
  </Step>
  <Step title="اشحن محفظتك">
    افتح **الفوترة** وأضف رصيداً أو بطاقة. ميتا تحاسب على كل رسالة، وكل طلب مدفوع يحجز تكلفته من المحفظة قبل الإرسال. إذا لم يكفِ الرصيد يرجع الطلب `402`. التفاصيل في [الأسعار والمحفظة](/ar/whatsapp-api/pricing-and-wallet).
  </Step>
  <Step title="أنشئ مفتاح API">
    افتح الرقم، ثم تبويب **واجهة API**، واضغط **إنشاء مفتاح**. انسخ المفتاح الآن، فهو يظهر مرة واحدة فقط.

    شكل المفتاح مثل `acme_9f2c…` وهو خاص بهذا الرقم وحده.

    <Warning>
      احفظ المفتاح على خادمك فقط. من يملكه يستطيع الإرسال من رقمك والصرف من محفظتك.
    </Warning>
  </Step>
  <Step title="أرسل قالباً">
    خارج نافذة الـ 24 ساعة، واتساب لا يسمح لك ببدء المحادثة إلا بقالب معتمد. كل حساب جديد فيه قالب `hello_world`.

    ```bash
    curl -X POST https://waba.karzoun.chat/messages \
      -H "Content-Type: application/json" \
      -H "Karzoun-API-Key: YOUR_API_KEY" \
      -d '{
        "messaging_product": "whatsapp",
        "to": "966500000000",
        "type": "template",
        "template": { "name": "hello_world", "language": { "code": "en_US" } }
      }'
    ```

    إذا نجح الإرسال يرجع لك:

    ```json
    {
      "messaging_product": "whatsapp",
      "contacts": [{ "input": "966500000000", "wa_id": "966500000000" }],
      "messages": [{ "id": "wamid.HBgMOTY2NTAwMDAwMDAwFQIAERgS..." }]
    }
    ```
  </Step>
  <Step title="استقبل الرد">
    في تبويب **واجهة API**، ضع رابط خادمك في **عنوان نقطة الاستقبال** واضغط **حفظ**. كرزون ترسل أولاً حدثاً تجريبياً موقّعاً، ولازم يرد خادمك بـ `2xx` خلال 5 ثوانٍ.

    ردّ على الرسالة من جوالك. سيصل الحدث إلى خادمك:

    ```json
    {
      "object": "whatsapp_business_account",
      "entry": [{
        "id": "102290129340398",
        "changes": [{
          "field": "messages",
          "value": {
            "messaging_product": "whatsapp",
            "metadata": { "display_phone_number": "15550783881", "phone_number_id": "106540352242922" },
            "contacts": [{ "profile": { "name": "Sara" }, "wa_id": "966500000000" }],
            "messages": [{ "from": "966500000000", "id": "wamid.HBgM...", "timestamp": "1731916800", "type": "text", "text": { "body": "Hi!" } }]
          }
        }]
      }]
    }
    ```

    خلال الـ 24 ساعة التالية تستطيع الرد بأي نوع رسالة، وليس بالقوالب فقط.
  </Step>
</Steps>
