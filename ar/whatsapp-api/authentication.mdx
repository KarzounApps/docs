كل طلب إلى `https://waba.karzoun.chat` يحمل ترويسة واحدة:

```
Karzoun-API-Key: YOUR_API_KEY
```

## مفتاح لكل رقم

مفتاح API مربوط برقم واتساب واحد. المفتاح هو الذي يحدد من أي رقم تخرج الرسالة، ولأي حساب واتساب للأعمال يتبع القالب أو الـ Flow، لذلك لا تحتاج الـ endpoints أبداً إلى معرّف الرقم أو الحساب: `POST /messages` يرسل من رقم المفتاح، و`GET /message_templates` يعرض قوالب هذا الرقم.

إذا عندك أكثر من رقم، أنشئ مفتاحاً لكل رقم واختر المفتاح المناسب في كل طلب.

## الإنشاء والاستبدال والإبطال

افتح الرقم في حسابك، ثم تبويب **واجهة API**.

| الإجراء | النتيجة |
| --- | --- |
| **إنشاء مفتاح** | يظهر المفتاح مرة واحدة. احفظه في مدير الأسرار (Secret Manager) عندك. |
| **استبدال المفتاح** | يصدر مفتاحاً جديداً ويبطل القديم فوراً. إعدادات الـ Webhook تبقى كما هي. |
| **إبطال** | كل طلب بهذا المفتاح يرجع `401` من تلك اللحظة. |

كرزون تحفظ نسخة مشفّرة (Hash) من المفتاح فقط. إذا ضاع منك، استبدله.

## الأخطاء

| الحالة | المعنى |
| --- | --- |
| `401` | المفتاح غير موجود، أو بصيغة خاطئة، أو مُبطل. |
| `402` | المحفظة لا تكفي لهذا الإرسال. راجع [الأسعار والمحفظة](/ar/whatsapp-api/pricing-and-wallet). |

أخطاء كرزون لها هذا الشكل، حتى تفرّقها عن أخطاء ميتا:

```json
{ "error": { "message": "Invalid API key", "type": "Karzoun", "code": 401 } }
```

## قائمة أمان سريعة

- المفاتيح على الخادم فقط. لا تضعها أبداً في تطبيق جوال أو في المتصفح.
- مفتاح منفصل لكل رقم ولكل بيئة.
- استبدل المفتاح فوراً إذا احتمل أنه تسرّب.
