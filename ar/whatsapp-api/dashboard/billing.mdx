صفحة **الفوترة** تعرض محفظتك وخطتك وتكلفة رسائل واتساب.

## المحفظة

رسائل واتساب تُخصم من محفظتك. كل طلب مدفوع يحجز تكلفته أولاً؛ وإذا لم تغطّها المحفظة يرد الـ API بـ `402` ولا يُرسل شيء.

- اضغط **شحن المحفظة** وادفع بالبطاقة.
- فعّل **الشحن التلقائي** لتُشحن المحفظة عندما يقل رصيدها.

راجع [التسعير والمحفظة](/ar/whatsapp-api/pricing-and-wallet) لطريقة الحجز.

## الخطة الحالية

خطتك وسعرها الشهري والمقاعد المشمولة. استهلاك واتساب ليس ضمن سعر الخطة؛ يُخصم من المحفظة.

## استهلاك واتساب

**استهلاك واتساب** يعرض تكلفة أرقامك يومياً أو أسبوعياً، مقارنة بالفترة السابقة. استخدمه لمتابعة تكلفة الحملات واكتشاف أي ارتفاع غير متوقع.

## رسوم البطاقة

**رسوم البطاقة** تعرض إيصالات شحن المحفظة ودفعات الخطة. تكلفة إرسال واتساب في قائمة الاستهلاك، لا هنا.

## الاسترداد

رسوم الاشتراك قابلة للاسترداد خلال 7 أيام من الدفع. استهلاك واتساب الذي أُرسل لا يُسترد.

## الانتقال لمنصة كرزون

من **قارن الخطط** تقدر تنتقل لخطة على منصة كرزون فيها صندوق وارد للفريق وحملات وأتمتة ووكلاء ذكاء اصطناعي. أرقامك وقوالبك ومحفظتك ومفتاح API تستمر في العمل.
