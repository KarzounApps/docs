تبويب **القوالب** يعرض كل قوالب حساب واتساب للأعمال الخاص بالرقم، وهي نفس القوالب التي ترجعها [الـ API](/ar/whatsapp-api/templates/manage).

## القائمة

| العمود | المعنى |
| --- | --- |
| **الاسم** | اسم القالب المستخدم في طلبات الـ API |
| **الفئة** | تسويقية أو خدمية أو مصادقة |
| **اللغة** | صف لكل لغة |
| **الحالة** | معتمد، قيد المراجعة، مرفوض، موقوف، أو معطّل. راجع [الحالات](/ar/whatsapp-api/templates/overview#الحالات) |
| **الجودة** | [تقييم جودة](/ar/whatsapp-api/templates/overview#جودة-القالب) القالب |

فلتر حسب الفئة والحالة، أو ابحث بالاسم.

## إنشاء قالب

1. اضغط **إنشاء قالب**.
2. اختر الفئة والاسم واللغة.
3. ابنِ المحتوى: الترويسة، والنص مع المتغيرات، والتذييل، والأزرار. المعاينة تعرض شكله في واتساب.
4. أضف مثالاً لكل متغير.
5. اضغط **إنشاء القالب**. يذهب لمراجعة ميتا.

راجع [عناصر القالب](/ar/whatsapp-api/templates/elements) لمحتوى كل جزء، و[أسباب الرفض الشائعة](/ar/whatsapp-api/templates/overview#أسباب-الرفض-الشائعة).

## التعديل والحذف

افتح قائمة خيارات القالب:

- **تعديل** يغيّر قالباً معتمداً أو مرفوضاً ويعيده للمراجعة. ميتا تسمح بتعديل واحد يومياً و10 تعديلات خلال 30 يوماً.
- **حذف** يحذف القالب بتلك اللغة. حدد عدة صفوف لحذفها معاً.

لا يمكن استخدام اسم قالب محذوف قبل 30 يوماً.

## التحليلات

**عرض التحليلات** يفتح **تحليلات القالب**: أعداد الإرسال والتسليم والقراءة والنقر عبر الوقت، وتكلفته. حدد عدة قوالب واضغط **تحليلات** لتقارن بينها.
