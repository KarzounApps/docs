---

تبويب **التحليلات** يعرض ما حدث للرسائل التي أرسلها الرقم، من بيانات ميتا.

## ماذا ترى

| الرسم | يعرض |
| --- | --- |
| مسار التسليم | الإرسال ← التسليم ← القراءة ← النقر |
| الحجم عبر الوقت | الرسائل يومياً أو أسبوعياً |
| التكلفة عبر الوقت | تكلفة الرسائل |
| التكلفة لكل رسالة مسلَّمة ولكل نقرة رابط | كفاءة الإرسال |
| النقرات حسب الزر | أي أزرار القوالب يضغطها الناس |
| التقسيم | نفس المقاييس حسب الدولة أو الفئة أو القالب |

اختر الفترة من الأعلى. بيانات ميتا قد تتأخر بضع ساعات.

## استخدمها لـ

- **اكتشاف مشاكل الجودة مبكراً.** القالب الذي تنخفض نسبة قراءته غالباً لا يريده الناس. أصلحه قبل أن [يُوقف](/ar/whatsapp-api/templates/overview#الإيقاف-المؤقت).
- **مقارنة القوالب.** حدد القوالب في تبويب **القوالب** واضغط **تحليلات**.
- **تخطيط الميزانية.** التكلفة حسب الدولة والفئة توضح أين يذهب إنفاقك.

لسحب مقاييس القوالب لتقاريرك، استخدم [واجهة تحليلات القوالب](/ar/whatsapp-api/templates/analytics). ولما يُخصم من محفظتك، راجع [الفوترة](/ar/whatsapp-api/dashboard/billing).
