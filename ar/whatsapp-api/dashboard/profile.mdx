تبويب **الملف الشخصي** يعرض كيف يظهر الرقم للعملاء ومدى صحته.

## رقم هاتف العمل

| الحقل | المعنى |
| --- | --- |
| **الاسم الموثق** | [اسم العرض](/ar/whatsapp-api/account/display-names) المعتمد |
| **تقييم الجودة** | أخضر أو أصفر أو أحمر. راجع [تقييم الجودة](/ar/whatsapp-api/account/quality-rating) |
| **حد المراسلة** | عدد الأشخاص المختلفين الذين تقدر تراسلهم يومياً. راجع [حدود المراسلة](/ar/whatsapp-api/account/messaging-limits) |
| **وضع الحساب** | هل الرقم فعّال أم ما زال في وضع التجربة |
| **مستوى الإنتاجية** | كم رسالة في الثانية يقدر الرقم يرسل. ترفعه ميتا تلقائياً للأرقام ذات الحجم الكبير والجودة الجيدة |
| **اسم مستخدم واتساب** | [اسم مستخدم النشاط](/ar/whatsapp-api/account/usernames-and-bsuid#اسم-المستخدم-الخاص-بنشاطك) إن وُجد |

### تغيير اسم العرض

1. اضغط **تعديل اسم العرض**، اكتب الاسم الجديد واضغط **إرسال للمراجعة**.
2. انتظر مراجعة ميتا، ولا ترسل طلباً آخر خلالها.
3. بعد الموافقة اضغط **تطبيق الاسم** خلال 14 يوماً. هذا يعيد تسجيل الرقم بالاسم الجديد.

### حجز اسم مستخدم

اضغط **حجز اسم المستخدم**، اختر اسماً متاحاً وأرسله. وتقدر تغيّره لاحقاً من **تغيير اسم المستخدم**. مالك مساحة العمل فقط يقدر يفعل ذلك.

## الملف التجاري

ما يراه العملاء عند فتح معلومات نشاطك في واتساب:

| الحقل | الحد |
| --- | --- |
| الصورة (**تغيير الصورة**) | صورة مربعة، 192×192 بكسل على الأقل |
| **حول** | حتى 139 حرفاً |
| **الوصف** | حتى 512 حرفاً |
| **العنوان** | حتى 256 حرفاً |
| **البريد الإلكتروني** | حتى 128 حرفاً |
| **الفئة** | إحدى فئات الأنشطة في ميتا |
| المواقع (**+ إضافة موقع**) | حتى موقعين |

اضغط **حفظ الملف الشخصي** لنشر التغييرات. وتقدر تدير الملف عبر الـ API أيضاً: راجع [إعدادات الرقم](/ar/whatsapp-api/messaging/number-settings).

في أرقام [التشغيل المشترك](/ar/whatsapp-api/account/coexistence) عدّل الملف من تطبيق واتساب للأعمال.

## الإرسال المباشر

**الإرسال المباشر** (Direct Send) يتيح لك إرسال رسائل خدمية يبدأها نشاطك بدون إنشاء قالب أولاً. فعّله من هنا، ثم استخدم `"category": "utility"` في طلباتك. راجع [Direct Send](/ar/whatsapp-api/messaging/send-messages#direct-send).
