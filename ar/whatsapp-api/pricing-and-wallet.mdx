رسائل واتساب تُحسب لكل رسالة، بسعر واتساب حسب دولة المستلم وفئة الرسالة، وتُخصم التكلفة من محفظة حسابك.

## الحجز قبل كل إرسال

كل طلب مدفوع يحجز تكلفته المتوقعة من محفظتك قبل إرسال الرسالة:

| الطلب | يحجز من المحفظة؟ |
| --- | --- |
| `POST /messages` | نعم |
| `POST /marketing_messages` | نعم |
| `POST /calling/calls` | نعم |
| باقي الطلبات (القوالب، الوسائط، الملف التجاري…) | لا |

- المبلغ يُحسب حسب دولة المستلم (`to`، أو دولة `recipient`).
- إذا رفض واتساب الرسالة، يُلغى الحجز فوراً.
- إذا قُبلت، يبقى الحجز حتى يصل الخصم النهائي إلى محفظتك، ثم يحلّ مكانه.

**الرصيد المتاح** = رصيد المحفظة ناقص الحجوزات المفتوحة.

## الخطأ 402

إذا لم يكفِ الرصيد المتاح لإرسال ما، ترد الـ API بـ `402` ولا يُرسل شيء:

```json
{
  "error": {
    "message": "Wallet can cover 120 cents, 300 cents are already held, this send needs 45",
    "type": "Karzoun",
    "code": 402
  }
}
```

اشحن المحفظة من **الفوترة**، أو فعّل الشحن التلقائي، ثم أعد المحاولة.

<Tip>
  عندك حملة كبيرة؟ تأكد من الرصيد المتاح أولاً وأرسل على دفعات. كل طلب يحجز تكلفته، فالإرسال الكثيف قد يصل إلى الحد في منتصف الحملة.
</Tip>

## الاستهلاك

من **الفوترة ← استهلاك واتساب** تشوف تكلفة أرقامك يومياً أو أسبوعياً، مقارنةً بالفترة السابقة.

## للشركاء

يستطيع الشريك تمويل محفظة عميله من محفظته، ويصله تنبيه عندما يقترب رصيد العميل من النفاد. راجع [العملاء والتمويل](/ar/partners/api/clients-and-funding).
