ترجع WhatsApp API نوعين من الأخطاء:

| المصدر | كيف تعرفه |
| --- | --- |
| **كرزون** | `error.type` قيمته `"Karzoun"`: المصادقة، المحفظة، صيغة الطلب، أو إعدادات الـ Webhook. |
| **واتساب** | أي شكل آخر، ومعه كود الخطأ `code` من واتساب (مثل `131047`). |

```json
{ "error": { "message": "Invalid API key", "type": "Karzoun", "code": 401 } }
```

## أخطاء كرزون

| الحالة | الرسالة | ماذا تفعل |
| --- | --- | --- |
| `400` | `Upload body was not received. Send multipart/form-data.` | أرسل `/media` وملفات الـ Flows بصيغة `multipart/form-data`. |
| `400` | `Upload body was not received. Send the file bytes with its Content-Type.` | أرسل الملف خاماً إلى `/upload:{id}`، وليس multipart. |
| `400` | رسالة عن رابط الـ Webhook أو الترويسات | صحّح الرابط أو الترويسات. راجع [شروط الرابط](/ar/whatsapp-api/webhooks/overview#شروط-الرابط). |
| `400` | `Your endpoint did not accept the test event (…)` | اجعل خادمك يرد بـ `2xx` خلال 5 ثوانٍ، ثم احفظ مرة ثانية. |
| `401` | `Invalid API key` | المفتاح غير موجود، أو بصيغة خاطئة، أو مُبطل. |
| `402` | `Wallet can cover … cents, … cents are already held, this send needs …` | اشحن المحفظة. راجع [الأسعار والمحفظة](/ar/whatsapp-api/pricing-and-wallet). |
| `404` | `No such path {METHOD} {path}` | الـ endpoint أو الـ method غير متوفر. راجع [مرجع الـ API](/whatsapp-api/reference/send-a-message). |
| `404` | `No such template on this number` (أو `flow`، `group`) | المعرّف يتبع حساباً آخر. |
| `415` | `This path accepts JSON bodies` | أرسل `Content-Type: application/json`. |
| `502` | `Meta request failed` / `Media download failed` | تعذّر الوصول إلى واتساب. أعد المحاولة مع backoff. |
| `503` | `Uploads are not configured` | تواصل مع الدعم. |

<Note>
  عند `502` في إرسال مدفوع، يبقى الحجز في المحفظة لأن الرسالة ربما أُرسلت فعلاً. تحقّق من حالتها على الـ Webhook قبل أن تعيد الإرسال.
</Note>

## أخطاء واتساب

أخطاء واتساب تحتفظ بأكوادها: في جسم الرد للأخطاء الفورية، وفي مصفوفة `errors` داخل [أحداث الحالة](/ar/whatsapp-api/webhooks/events#فشل-الإرسال) `failed` لأخطاء التسليم. اعتمد على `code` في منطقك، وسجّل `error_data.details` و`fbtrace_id` لأن الدعم يحتاجهما.

### الإرسال والتسليم

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `131026` | تعذر التسليم | الرقم ليس على واتساب، أو لم يوافق المستخدم على شروط واتساب الأخيرة، أو تطبيقه قديم. لا تعد المحاولة |
| `131047` | مرّت أكثر من 24 ساعة على آخر رسالة من العميل | أرسل [قالباً](/ar/whatsapp-api/templates/sending) |
| `131049` | لم تُرسل حفاظاً على تجربة المستخدم | [حد التسويق لكل مستخدم](/ar/whatsapp-api/templates/sending#حدود-التسويق-لكل-مستخدم). انتظر 24 ساعة |
| `131050` | المستخدم أوقف رسائلك التسويقية | لا ترسل له تسويقاً. الرسائل الخدمية ما زالت تعمل |
| `130472` | المستخدم ضمن تجربة من ميتا | لا تعد إرسال التسويق له |
| `131051` | نوع رسالة غير مدعوم | راجع `type` |
| `131052` / `131053` | تعذر تنزيل وسائط المستخدم / رفع وسائطك | اطلب إعادة الإرسال، أو راجع [الصيغة والحجم](/ar/whatsapp-api/messaging/media) |
| `131062` | قالب مصادقة أُرسل إلى BSUID | أرسله لرقم الجوال |
| `131061` | قالب بسعر أقصى أُرسل إلى `/messages` | أرسله إلى [`/marketing_messages`](/ar/whatsapp-api/templates/marketing) |
| `131070` | مزوّد آخر يتحكم بالمحادثة | انظر [أدناه](#مزود-آخر-يتحكم-بالمحادثة) |

### القوالب

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `132000` | عدد المعاملات لا يطابق القالب | معامل واحد لكل متغير |
| `132001` | القالب غير موجود بهذه اللغة أو غير معتمد | راجع الاسم واللغة والحالة |
| `132005` / `132007` | النص طويل أو يخالف السياسة بعد تعبئة المتغيرات | راجع القيم |
| `132012` | صيغة المعامل غير مطابقة | مثل نص بدل صورة في الترويسة |
| `132015` / `132016` | القالب موقوف مؤقتاً / معطّل | راجع [الإيقاف المؤقت](/ar/whatsapp-api/templates/overview#الإيقاف-المؤقت) |
| `132068` / `132069` | الـ Flow محظور / مقيّد | أصلح الـ Flow وانشره من جديد |

### حدود السرعة

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `130429` | حد سرعة الإرسال للرقم | أعد المحاولة مع exponential backoff |
| `131056` | رسائل كثيرة لنفس المستخدم | خفّف الإرسال لهذا المستلم |
| `131048` | حد الإزعاج: رسائل كثيرة حُظرت أو أُبلغ عنها | حسّن الجودة وخفّف الإرسال |
| `4` / `80007` | طلبات API كثيرة للحساب | وزّع الطلبات |

### الحساب والرقم

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `368` | إيقاف مؤقت بسبب مخالفة | راجع [حالة الحساب](/ar/whatsapp-api/account/account-status) |
| `131031` | الحساب مقفل | راجع [قفل حساب الأعمال](/ar/whatsapp-api/account/account-status#قفل-حساب-الأعمال) |
| `131037` | اسم العرض يحتاج موافقة | انتظر [مراجعة الاسم](/ar/whatsapp-api/account/display-names) |
| `131042` | مشكلة فوترة على الحساب | تواصل مع دعم كرزون |
| `133010` / `133006` | الرقم غير مسجّل / يحتاج تحقق من جديد | أعد ربط الرقم |
| `133005` / `133008` / `133009` | رمز التحقق بخطوتين خاطئ أو محاولات كثيرة | راجع [التحقق بخطوتين](/ar/whatsapp-api/account/phone-numbers#التحقق-بخطوتين) |

### الطلب والخادم

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `100` / `131008` / `131009` | معامل غير صالح أو ناقص | اقرأ `error_data.details` |
| `131000` / `131016` / `133004` / `1` / `2` | خطأ مؤقت من واتساب | أعد المحاولة مع backoff |

### مزود آخر يتحكم بالمحادثة

الخطأ `131070`، أو عدم وصول رسائل واردة رغم أن الرقم مربوط، يعني أن الرقم مشترك مع مزوّد آخر وهذا المزوّد ما زال يستقبل المحادثات. يحدث هذا بعد إضافة كرزون إلى رقم كان مستخدماً عند مزوّد آخر.

الحل في Meta Business Suite: **الإعدادات ← حسابات واتساب ←** حسابك **← توجيه المحادثات (Conversation routing) ← إدارة**، اختر **Karzoun** في كل القوائم واضغط **تطبيق**. هذا الإجراء متاح لمسؤول حساب Meta Business فقط.

## متى تعيد المحاولة

| الحالة | أعيد المحاولة؟ |
| --- | --- |
| `2xx` | لا |
| `400`، `401`، `404`، `415` | لا. صحّح الطلب |
| `402` | بعد شحن المحفظة |
| `429`، `130429` | نعم، مع exponential backoff |
| `5xx` | نعم، مع backoff. في الإرسال، تحقّق من الـ Webhook أولاً حتى لا تكرّر الرسالة |
