كل طلب Webhook يحمل هذه الترويسات:

| الترويسة | القيمة |
| --- | --- |
| `X-Karzoun-Signature-256` | `sha256=` + قيمة HMAC-SHA256 بصيغة hex لجسم الطلب الخام بمفتاح التوقيع |
| `X-Karzoun-Event-Id` | فريد لكل حدث، ويبقى نفسه في كل إعادة محاولة أو إعادة إرسال |
| `X-Karzoun-Delivery-Attempt` | `1` للمحاولة الأولى، ثم `2`، `3`… |
| `X-Karzoun-Signature-256-Previous` | لمدة 24 ساعة فقط بعد تغيير المفتاح: نفس التوقيع بالمفتاح القديم |
| `User-Agent` | `Karzoun-Webhooks/1.0` |

هذه نفس طريقة `X-Hub-Signature-256` عند Meta، ونفس طريقة كل Webhooks كرزون الأخرى.

## مفتاح التوقيع

افتح تبويب **واجهة API** للرقم. في بطاقة **عنوان الويب هوك**، اضغط أيقونة العين بجانب **مفتاح التوقيع**.

## التحقق من الطلب

1. اقرأ جسم الطلب **الخام** كـ bytes قبل أي تحليل للـ JSON.
2. احسب `HMAC-SHA256(secret, rawBody)` وحوّله إلى hex.
3. قارن `sha256=` + الناتج مع `X-Karzoun-Signature-256` بمقارنة ثابتة الزمن (constant-time).
4. خزّن `X-Karzoun-Event-Id` وتجاهل الأحداث التي عالجتها من قبل. هذا يمنع أيضاً إعادة استخدام طلب ملتقَط.

<CodeGroup>
```js Node.js (Express)
import crypto from "crypto";
import express from "express";

const app = express();
const SECRET = process.env.KARZOUN_WEBHOOK_SECRET;

app.post("/whatsapp/webhook", express.raw({ type: "application/json" }), (req, res) => {
  const signature = req.get("X-Karzoun-Signature-256") || "";
  const expected = "sha256=" + crypto.createHmac("sha256", SECRET).update(req.body).digest("hex");

  const valid = signature.length === expected.length &&
    crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected));
  if (!valid) return res.sendStatus(401);

  res.sendStatus(200); // رد أولاً ثم عالج
  const event = JSON.parse(req.body);
  queue.push({ id: req.get("X-Karzoun-Event-Id"), event });
});
```

```python Python (Flask)
import hashlib, hmac, os
from flask import Flask, request, abort

app = Flask(__name__)
SECRET = os.environ["KARZOUN_WEBHOOK_SECRET"].encode()

@app.post("/whatsapp/webhook")
def webhook():
    signature = request.headers.get("X-Karzoun-Signature-256", "")
    expected = "sha256=" + hmac.new(SECRET, request.get_data(), hashlib.sha256).hexdigest()

    if not hmac.compare_digest(signature, expected):
        abort(401)
    enqueue(request.headers["X-Karzoun-Event-Id"], request.get_json())
    return "", 200
```

```php PHP
<?php
$secret = getenv('KARZOUN_WEBHOOK_SECRET');
$raw = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_KARZOUN_SIGNATURE_256'] ?? '';
$expected = 'sha256=' . hash_hmac('sha256', $raw, $secret);

if (!hash_equals($expected, $signature)) {
    http_response_code(401);
    exit;
}
http_response_code(200);
enqueue($_SERVER['HTTP_X_KARZOUN_EVENT_ID'], json_decode($raw, true));
```
</CodeGroup>

## تغيير المفتاح

اضغط **تغيير المفتاح** في بطاقة **عنوان الويب هوك**. المفتاح الجديد يبدأ التوقيع فوراً، والقديم يستمر بالتوقيع في `X-Karzoun-Signature-256-Previous` لمدة 24 ساعة، حتى تنشر المفتاح الجديد بدون أن تفقد أي حدث. خلال هذه الفترة اقبل أيّاً من الترويستين.

<Warning>
  تحقّق من التوقيع في كل طلب. بدونه، أي شخص يعرف رابطك يستطيع إرسال رسائل مزيّفة إليه.
</Warning>
