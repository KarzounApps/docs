## تحقق من الحالة أولاً

| الصفحة | تغطي |
| --- | --- |
| [status.karzoun.chat](https://status.karzoun.chat/) | خدمات كرزون، ومنها واتساب |
| [metastatus.com](https://metastatus.com/whatsapp-business-api) | واتساب نفسه: تسليم الرسائل وخوادم ميتا وWhatsApp Manager |

إذا ظهر عطل في أي منهما، تابع التحديثات هناك. لا داعي لفتح بلاغ لعطل معروف.

## كرزون أم واتساب؟

| ما تراه | غالباً يعني |
| --- | --- |
| خطأ فيه `"type": "Karzoun"` | كرزون: المفتاح أو المحفظة أو صيغة الطلب أو إعدادات الـ Webhook. راجع [الأخطاء](/ar/whatsapp-api/reference/errors#أخطاء-كرزون) |
| كود خطأ من واتساب (مثل `131026`) | واتساب استلم الطلب ورد بسبب. راجع [أخطاء واتساب](/ar/whatsapp-api/reference/errors#أخطاء-واتساب) |
| `502 Meta request failed` | تعذر الوصول لواتساب. أعد المحاولة مع backoff وراجع حالة ميتا |
| أحداث قيد إعادة المحاولة في **عرض سجل الإرسال** | خادمك لا يرد بـ `2xx`. راجع [التسليم وإعادة المحاولة](/ar/whatsapp-api/webhooks/delivery) |

## التواصل مع الدعم

| أنت | تواصل عبر |
| --- | --- |
| مطوّر تربط الـ API | [developers@karzoun.chat](mailto:developers@karzoun.chat) |
| صاحب نشاط أو فريق تشغيل | [تواصل معنا](https://karzoun.chat/contact) |

### أرفق في أول رسالة

- نطاق مساحة عملك، مثل `yourbrand.karzoun.chat`، والرقم المعني.
- الطلب (الطريقة والمسار) وجسم الرد كاملاً، ومعه `fbtrace_id` لأخطاء واتساب.
- معرّف الرسالة (`wamid…`) أو معرّف حدث الـ Webhook (`X-Karzoun-Event-Id`) إن وُجد.
- وقت حدوث المشكلة مع المنطقة الزمنية.

<Warning>
  لا ترسل مفتاح الـ API أو مفتاح التوقيع أو كلمات المرور أبداً. إذا احتاج الدعم معرفة أي مفتاح، أرسل آخر أربعة أحرف منه.
</Warning>
