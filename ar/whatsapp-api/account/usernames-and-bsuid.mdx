title: "أسماء المستخدمين وBSUID"
description: "أسماء مستخدمي واتساب تخفي أرقام الجوال. استخدم المعرّف الخاص بنشاطك لتعرف الناس وتراسلهم."
---

يقدر مستخدمو واتساب يضعون **اسم مستخدم**. عندها يُظهر واتساب الاسم بدل رقم الجوال، وقد يصلك **معرّف المستخدم الخاص بنشاطك (BSUID)** بدل الرقم.

## مصطلحات

| المصطلح | المعنى |
| --- | --- |
| **BSUID** | معرّف ثابت للمستخدم، فريد لحافظة أعمالك، في الحقل `user_id`. صيغته: رمز الدولة ثم نقطة ثم أرقام، مثل `SA.13491208655302741918` |
| **Parent BSUID** | معرّف واحد مشترك بين عدة حافظات لنفس المؤسسة، ويحتوي `ENT` |
| **دفتر جهات الاتصال** | تحتفظ ميتا بأزواج الرقم ↔ BSUID للأشخاص الذين تبادلت معهم رسائل أو مكالمات منذ أبريل 2026. ما دام الشخص فيه، يستمر وصول رقمه لك |
| **ذاكرة الـ 30 يوماً** | إذا راسل رقمك مستخدماً أو اتصل به خلال آخر 30 يوماً، يستمر ظهور رقم ذلك المستخدم لرقمك |
| **اسم مستخدم النشاط** | اسم لرقم نشاطك للبحث والاكتشاف. لا يخفي رقمك |

## ماذا يصلك

**الرسائل الواردة**

| المستخدم | يصلك |
| --- | --- |
| ليس لديه اسم مستخدم | `wa_id` و`from` و`user_id` و`from_user_id` |
| لديه اسم مستخدم | `user_id` و`from_user_id` و`username`. و`wa_id` و`from` فقط إذا كان رقمه في دفتر جهات الاتصال أو ذاكرة الـ 30 يوماً |

**تحديثات الحالة**

| أرسلت إلى | يصلك |
| --- | --- |
| رقم جوال | `recipient_id` (و`wa_id`) |
| BSUID | `recipient_user_id` (و`user_id`). والرقم فقط إذا كان في دفتر جهات الاتصال أو الذاكرة |

الحالات الفاشلة لا تحتوي مصفوفة `contacts`. ويظهر `username` في حالتي delivered وread إذا كان للمستخدم اسم.

<Tip>
  خزّن `user_id` لكل جهة اتصال، بجانب الرقم إذا توفر. هو المعرّف الذي لا يختفي.
</Tip>

## راسل BSUID

استخدم `recipient` بدل `to`:

```json
{
  "messaging_product": "whatsapp",
  "recipient": "SA.13491208655302741918",
  "type": "template",
  "template": { "name": "order_shipped", "language": { "code": "ar" } }
}
```

- أرسل الـ BSUID كاملاً مع رمز الدولة.
- إذا أرسلت `to` و`recipient` معاً، يُعتمد `to`.
- خارج نافذة الـ 24 ساعة ما زلت تحتاج قالباً (وإلا يصلك `131047`).
- قوالب المصادقة (نسخ الرمز، اللمسة الواحدة، بدون لمس) لا تُرسل إلى BSUID (`131062`).
- خزّن دائماً `wamid` الراجع؛ هو المفتاح الموثوق لربط الحالات.

## اطلب رقم الجوال

عندما يكون لديك BSUID فقط، اطلب من المستخدم مشاركة رقمه بزر **طلب معلومات الاتصال**.

في قالب خدمي أو تسويقي، أضف الزر:

```json
{ "type": "BUTTONS", "buttons": [{ "type": "REQUEST_CONTACT_INFO" }] }
```

داخل محادثة مفتوحة، أرسله كرسالة تفاعلية:

```json
{
  "messaging_product": "whatsapp",
  "recipient": "SA.13491208655302741918",
  "type": "interactive",
  "interactive": {
    "type": "request_contact_info",
    "body": { "text": "شاركنا رقمك لنرسل لك تحديثات التوصيل." },
    "action": { "name": "request_contact_info" }
  }
}
```

عند الضغط، يصل للـ Webhook رسالة من نوع `contacts` فيها `origin: "contact_request"` والرقم في `phones`. ويُضاف الرقم لدفتر جهات الاتصال، فتعود الأحداث اللاحقة تحمله.

## حذف مستخدم من دفتر جهات الاتصال

إذا لم تعد تريد وصول رقم مستخدم عبر دفتر جهات الاتصال، احذف قيده:

```bash
curl -X DELETE "https://waba.karzoun.chat/contact_book?messaging_product=whatsapp&bsuid=SA.13491208655302741918" \
  -H "Karzoun-API-Key: YOUR_API_KEY"
```

```json
{ "messaging_product": "whatsapp", "success": true, "deleted": true }
```

تكون `deleted` بقيمة `false` إذا لم يكن هناك قيد. ذاكرة الـ 30 يوماً لا تتأثر، والـ Parent BSUID غير مدعوم.

## اسم المستخدم الخاص بنشاطك

احجز اسم مستخدم لنشاطك أو غيّره من تبويب **الملف الشخصي** للرقم، أو عبر الـ API:

| الإجراء | الطلب |
| --- | --- |
| الاسم الحالي وحالته | `GET /username` |
| الأسماء المحجوزة لك من واتساب | `GET /username_suggestions` |
| حجز أو تغيير | `POST /username` مع `{ "username": "acme" }` |
| حذف | `DELETE /username` |

```bash
curl -X POST https://waba.karzoun.chat/username \
  -H "Karzoun-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "username": "acme" }'
```

اسم المستخدم من 3 إلى 35 حرفاً: حروف إنجليزية وأرقام ونقاط وشرطة سفلية، وفيه حرف واحد على الأقل. لا يبدأ أو ينتهي بنقطة، ولا يحتوي نقطتين متتاليتين، ولا يبدأ بـ `www` ولا ينتهي بنطاق مثل `.com`. تغييرات الاسم تصلك على الـ Webhook كأحداث اسم مستخدم النشاط.
