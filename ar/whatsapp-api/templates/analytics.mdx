تحليلات القوالب تعطيك مقاييس يومية لكل قالب: كم رسالة أُرسلت وسُلّمت وقُرئت، وأي الأزرار ضُغطت، وكم كلّفت. تبويب **التحليلات** يعرض نفس البيانات، والـ API يتيح لك سحبها لتقاريرك.

## التفعيل

تحتاج ميتا تفعيل تحليلات القوالب مرة واحدة لكل حساب واتساب للأعمال. تُجمع البيانات من لحظة التفعيل، لا بأثر رجعي.

```bash
curl -X POST https://waba.karzoun.chat/template_analytics \
  -H "Karzoun-API-Key: YOUR_API_KEY"
```

رد `200` يعني أنها فُعّلت. وتكرار الطلب لا يضر.

## جلب المقاييس

```bash
curl "https://waba.karzoun.chat/template_analytics?start=1731888000&end=1732492800&granularity=DAILY&template_ids=[1689556908129832]&metric_types=[SENT,DELIVERED,READ,CLICKED,COST]" \
  -H "Karzoun-API-Key: YOUR_API_KEY"
```

| المعامل | إلزامي | المعنى |
| --- | --- | --- |
| `start` و`end` | نعم | بداية ونهاية الفترة كـ Unix timestamps |
| `granularity` | نعم | `DAILY`. البيانات بالساعة غير متاحة |
| `template_ids` | لا | مصفوفة JSON من معرّفات القوالب، حتى 10 |
| `metric_types` | لا | مصفوفة JSON: `SENT` و`DELIVERED` و`READ` و`CLICKED` و`COST`. كلها إذا لم تحددها |
| `use_waba_timezone` | لا | `true` لعرض الأيام بتوقيت حسابك بدل UTC. عندها يكون `start` و`end` بصيغة `YYYY-MM-DD` |

## معنى الأرقام

| المقياس | المعنى |
| --- | --- |
| `sent` | الرسائل المرسلة بالقالب |
| `delivered` | الرسائل التي وصلت للجهاز |
| `read` | الرسائل المقروءة. تُحسب فقط لمن فعّل إشعار القراءة، فهي حد أدنى |
| `clicked` | الضغطات لكل زر، للقوالب التسويقية والخدمية |
| `cost` | المبلغ المصروف، والتكلفة لكل رسالة مسلَّمة ولكل نقرة رابط |

المقاييس تشمل فقط الرسائل التي بدأها نشاطك بالقالب، وقد تتأخر البيانات بضع ساعات.

## استخدمها لـ

- مقارنة نسب القراءة بين القوالب والتخلص من الضعيف قبل أن تنخفض [جودته](/ar/whatsapp-api/templates/overview#جودة-القالب).
- معرفة أي زر يضغطه الناس أكثر، ووضعه أولاً.
- متابعة تكلفة الحملة لكل قالب بجانب بيانات التحويل عندك.
