القالب عبارة عن قائمة **مكوّنات** (components). النص (`BODY`) هو الوحيد الإلزامي.

| المكوّن | إلزامي | الحد |
| --- | --- | --- |
| `HEADER` | لا | واحد لكل قالب: نص، صورة، فيديو، مستند، أو موقع |
| `BODY` | نعم | 1,024 حرفاً |
| `FOOTER` | لا | 60 حرفاً، بدون متغيرات |
| `BUTTONS` | لا | حتى 10 أزرار |

## المتغيرات

المتغيرات أماكن فارغة تملؤها عند الإرسال. كل متغير يحتاج مثالاً في `example`، وإلا يُرفض القالب.

<Tabs>
  <Tab title="بالترتيب">
    ```json
    {
      "type": "BODY",
      "text": "مرحباً {{1}}، طلبك {{2}} جاهز للاستلام.",
      "example": { "body_text": [["سارة", "#1042"]] }
    }
    ```
  </Tab>
  <Tab title="بالاسم">
    ```json
    {
      "type": "BODY",
      "text": "مرحباً {{first_name}}، طلبك {{order_id}} جاهز للاستلام.",
      "example": {
        "body_text_named_params": [
          { "param_name": "first_name", "example": "سارة" },
          { "param_name": "order_id", "example": "#1042" }
        ]
      }
    }
    ```
    أضف `"parameter_format": "NAMED"` في أعلى القالب. أسماء المتغيرات حروف إنجليزية صغيرة وأرقام وشرطة سفلية.
  </Tab>
</Tabs>

استخدم أسلوباً واحداً في القالب. مع المتغيرات المسمّاة تنتهي مفاتيح المثال بـ `_named_params`: `body_text_named_params` و`header_text_named_params`.

القواعد:

- المتغيرات المرقّمة تبدأ من `{{1}}` وتتسلسل بدون فجوات.
- لا يبدأ النص أو ينتهي بمتغير.
- لا يأتي متغيران متجاوران.
- حافظ على نسبة معقولة بين النص الثابت والمتغيرات.

## الترويسة

### نص

```json
{
  "type": "HEADER",
  "format": "TEXT",
  "text": "بدأ {{1}}!",
  "example": { "header_text": ["موسم التخفيضات"] }
}
```

60 حرفاً، ومتغير واحد كحد أقصى.

### صورة أو فيديو أو مستند

```json
{
  "type": "HEADER",
  "format": "IMAGE",
  "example": { "header_handle": ["4::aW1hZ2UvanBlZw==:ARb…"] }
}
```

قيمة `format` هي `IMAGE` أو `VIDEO` أو `DOCUMENT`. المثال عبارة عن handle من [رفع عيّنة قالب](/ar/whatsapp-api/messaging/media#رفع-عيّنة-قالب). عند الإرسال تمرّر الملف الفعلي لكل رسالة (معرّف وسائط أو رابط). راجع [الوسائط المدعومة](/ar/whatsapp-api/messaging/media).

### موقع

```json
{ "type": "HEADER", "format": "LOCATION" }
```

تعرض خريطة، وتمرّر الإحداثيات والاسم والعنوان عند الإرسال. للقوالب الخدمية والتسويقية فقط.

## النص

```json
{
  "type": "BODY",
  "text": "موعدك مع {{1}} يوم {{2}} الساعة {{3}}.",
  "example": { "body_text": [["د. عمر", "12 مايو", "10:30"]] }
}
```

حتى 1,024 حرفاً، مع التنسيق: `*عريض*` و`_مائل_` و`~يتوسطه خط~` و`` `كود` ``. الإيموجي مسموح في القوالب التسويقية والخدمية.

## التذييل

```json
{ "type": "FOOTER", "text": "أرسل إيقاف لإلغاء الاشتراك" }
```

حتى 60 حرفاً، بدون متغيرات.

## الأزرار

القالب يحتوي حتى **10 أزرار** إجمالاً، ونص كل زر حتى 25 حرفاً.

| النوع | ماذا يفعل | الحد الأقصى |
| --- | --- | --- |
| `QUICK_REPLY` | يرسل نص الزر لك كرسالة | 10 |
| `URL` | يفتح موقعاً. متغير واحد مسموح في آخر الرابط | 2 |
| `PHONE_NUMBER` | يتصل برقم هاتف | 1 |
| `VOICE_CALL` | يبدأ مكالمة واتساب مع رقمك ([المكالمات](/ar/whatsapp-api/messaging/calling)) | 1 |
| `COPY_CODE` | ينسخ كود خصم ([قوالب الكوبونات](/ar/whatsapp-api/templates/commerce#أكواد-الخصم)) | 1 |
| `OTP` | زر رمز التحقق ([المصادقة](/ar/whatsapp-api/templates/authentication)) | 1 |
| `FLOW` | يفتح [WhatsApp Flow](/ar/whatsapp-api/messaging/flows) | 1 |
| `CATALOG` و`MPM` و`SPM` | يفتح الكتالوج أو المنتجات ([التجارة](/ar/whatsapp-api/templates/commerce)) | 1 |
| `REQUEST_CONTACT_INFO` | يطلب من المستخدم مشاركة رقمه ([BSUID](/ar/whatsapp-api/account/usernames-and-bsuid#اطلب-رقم-الجوال)) | 1 |

إذا جمعت أزرار الرد السريع مع أزرار أخرى، رتّبها كمجموعات: كل الردود السريعة معاً، ثم البقية. يعرض واتساب أول ثلاثة أزرار، والباقي يظهر تحت "عرض كل الخيارات".

### رد سريع

```json
{ "type": "QUICK_REPLY", "text": "إيقاف العروض" }
```

عند الضغط يصل للـ Webhook رسالة من نوع `button` فيها نص الزر، و`payload` إذا حددته عند الإرسال.

### رابط

```json
{
  "type": "URL",
  "text": "تتبع الطلب",
  "url": "https://example.com/track/{{1}}",
  "example": ["https://example.com/track/1042"]
}
```

المتغير يكون في آخر الرابط فقط. استخدم نطاقك أنت، لا خدمة اختصار روابط.

### رقم هاتف

```json
{ "type": "PHONE_NUMBER", "text": "اتصل بنا", "phone_number": "+966112345678" }
```

حتى 20 حرفاً، مع رمز الدولة.

## مثال كامل

```json
{
  "name": "appointment_reminder",
  "language": "ar",
  "category": "UTILITY",
  "components": [
    { "type": "HEADER", "format": "TEXT", "text": "تذكير بالموعد" },
    {
      "type": "BODY",
      "text": "مرحباً {{1}}، نذكّرك بموعدك يوم {{2}} الساعة {{3}}.",
      "example": { "body_text": [["سارة", "12 مايو", "10:30"]] }
    },
    { "type": "FOOTER", "text": "عيادة النور" },
    {
      "type": "BUTTONS",
      "buttons": [
        { "type": "QUICK_REPLY", "text": "تأكيد" },
        { "type": "QUICK_REPLY", "text": "تغيير الموعد" },
        { "type": "PHONE_NUMBER", "text": "اتصل بالعيادة", "phone_number": "+966112345678" }
      ]
    }
  ]
}
```

أنشئه عبر [`POST /message_templates`](/ar/whatsapp-api/templates/manage#الإنشاء)، ثم [أرسله](/ar/whatsapp-api/templates/sending).
