القوالب الخدمية (Utility) ترسل تحديثات عن شيء بدأه المستخدم معك: طلب، حجز، دفعة، أو تغيير في الحساب. سعرها أقل من التسويقية.

## ما الذي يُعتبر خدمياً

القالب الخدمي لازم يكون:

- **خاصاً بالمستخدم.** يشير لطلبه أو حجزه أو حسابه، غالباً عبر متغيرات مثل رقم الطلب.
- **بسبب تصرّفه.** يأتي بعد إجراء أو طلب قام به المستخدم، أو يتعلق باتفاق بينكما.
- **غير ترويجي.** لا عروض ولا خصومات ولا بيع إضافي ولا دعوة للشراء.

| خدمي | ليس خدمياً |
| --- | --- |
| "تم شحن طلبك #1042. تتبعه من هنا." | "تم شحن طلبك #1042. خصم 10% على طلبك القادم!" |
| "موعدك غداً الساعة 10:30." | "احجز موعدك القادم ووفّر 20%." |
| "استلمنا دفعتك بقيمة 250 ريال. الفاتورة مرفقة." | "شكراً على الدفع! شاهد مجموعتنا الجديدة." |
| "تم تغيير كلمة المرور. لست أنت؟ تواصل معنا." | "أهلاً بعودتك! هذا الجديد هذا الأسبوع." |

إذا وجدت ميتا محتوى ترويجياً، تنقل القالب إلى التسويق أثناء المراجعة أو لاحقاً، وترسل حدث `template_category_update`.

## استخدامات شائعة

- تأكيد الطلب وتحديثات الشحن والتوصيل
- تأكيد المواعيد والحجوزات والتذكير بها
- إيصالات الدفع والفواتير والمدفوعات الفاشلة والتجديد
- تنبيهات الحساب: تغيير كلمة المرور، تنبيهات أمنية، تحديث الملف
- استبيانات رضا عن عملية شراء أو خدمة محددة
- تحديثات على طلب دعم

## مثال

```json
{
  "name": "delivery_update",
  "language": "ar",
  "category": "UTILITY",
  "components": [
    { "type": "HEADER", "format": "LOCATION" },
    {
      "type": "BODY",
      "text": "مرحباً {{1}}، طلبك {{2}} في الطريق ويصلك اليوم بين {{3}}.",
      "example": { "body_text": [["سارة", "#1042", "4 و6 مساءً"]] }
    },
    {
      "type": "BUTTONS",
      "buttons": [
        { "type": "URL", "text": "تتبع الطلب", "url": "https://example.com/track/{{1}}", "example": ["https://example.com/track/1042"] },
        { "type": "QUICK_REPLY", "text": "تغيير موعد التوصيل" }
      ]
    }
  ]
}
```

## بدون قالب: Direct Send

للرسائل الخدمية المفردة، تجاوز إنشاء القالب. أرسل رسالة عادية مع `"category": "utility"` وواتساب ينشئ القالب ويديره عنك. راجع [Direct Send](/ar/whatsapp-api/messaging/send-messages#direct-send).

## التدرج في الإرسال

القوالب الخدمية لا تخضع للتدرج افتراضياً. بعد أن يُوقف أحد قوالبك الخدمية لانخفاض الجودة، قد تخضع القوالب الخدمية الجديدة أو منخفضة التقييم لـ [التدرج](/ar/whatsapp-api/templates/sending#التدرج-في-الإرسال) مثل التسويقية.
