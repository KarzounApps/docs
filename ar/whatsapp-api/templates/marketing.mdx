القوالب التسويقية تشمل كل ما هو ترويجي: العروض والإطلاقات والتذكيرات والنشرات وإعادة التفاعل. أرسلها عبر **Marketing Messages API** (`POST /marketing_messages`) لتستفيد من تحسين ميتا للتسليم.

## Marketing Messages API مقابل `/messages`

| | `/marketing_messages` | `/messages` |
| --- | --- | --- |
| التسليم | تحسّنه ميتا لمن احتمال تفاعلهم أعلى | عادي |
| مدة الصلاحية | قابلة للضبط، من 12 ساعة إلى 30 يوماً | ثابتة |
| السعر الأقصى | مدعوم | غير مدعوم |
| المقاييس والتحليلات | مقارنات النقر والقراءة في WhatsApp Manager | أساسية |
| التوفر | في طريقه ليصبح الافتراضي للتسويق | ميتا توقف القوالب التسويقية على `/messages` |

<Warning>
  ستتوقف ميتا عن قبول القوالب التسويقية على `/messages` في **13 أكتوبر 2027**. ابنِ حملاتك الجديدة على `/marketing_messages` من الآن.
</Warning>

## التفعيل

يُفعّل Marketing Messages API مرة واحدة لكل حافظة أعمال ميتا، بموافقة مسؤول الحافظة على شروطه:

<Steps>
  <Step title="افتح WhatsApp Manager">
    في Meta Business Suite اذهب إلى **WhatsApp Manager → Overview**.
  </Step>
  <Step title="وافق على الشروط">
    في قسم **Alerts** اضغط **Accept terms to get started** الخاص بـ Marketing Messages API واتبع الخطوات.
  </Step>
</Steps>

الشروط تنطبق على كل حسابات واتساب المؤهلة في الحافظة. إذا عندك أكثر من حافظة، كرّرها لكل واحدة. وقبل الموافقة يرجع `/marketing_messages` خطأ.

## الإرسال

جسم الطلب رسالة قالب عادية:

```bash
curl -X POST https://waba.karzoun.chat/marketing_messages \
  -H "Karzoun-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messaging_product": "whatsapp",
    "to": "966500000000",
    "type": "template",
    "template": {
      "name": "spring_sale",
      "language": { "code": "ar" },
      "components": [
        { "type": "body", "parameters": [{ "type": "text", "text": "سارة" }] }
      ]
    },
    "message_activity_sharing": true
  }'
```

| الحقل | المعنى |
| --- | --- |
| `message_activity_sharing` | اختياري. `true` يشارك إشارات التفاعل، مثل النقر، مع ميتا لتحسين التسليم والتقارير |

الحالات والردود تصلك على [الـ Webhook](/ar/whatsapp-api/webhooks/events) تماماً مثل `/messages`. ويُقبل هنا فقط قوالب `MARKETING`.

## مدة الصلاحية

حدد `message_send_ttl_seconds` على القالب، من `43200` (12 ساعة) إلى `2592000` (30 يوماً، الافتراضي). تخفيض ينتهي الليلة لا يصح أن يصل غداً: اعطه مدة قصيرة. الرسائل غير المسلَّمة لا تُحتسب.

## السعر الأقصى

السعر الأقصى (Max price) يحدد أعلى مبلغ تدفعه مقابل كل رسالة تسويقية مُسلَّمة، لكل قالب. ميتا تحتسب سقفك أو أقل، وتحسّن التسليم ضمنه. القوالب بدون سعر أقصى تستخدم السعر المعتاد.

اضبطه عبر `optimization_spec`، كعدد صحيح بأصغر وحدة من عملة حسابك **لكل 1,000 رسالة مُسلَّمة**. مثلاً 0.05 دولار للرسالة = `5000`.

```json
{
  "name": "spring_sale",
  "language": "ar",
  "category": "MARKETING",
  "components": [{ "type": "BODY", "text": "تخفيضات الربيع بدأت اليوم!" }],
  "optimization_spec": {
    "bid_strategy": "LOWEST_COST_WITH_BID_CAP",
    "bid_amount": 5000
  }
}
```

- أضفه عند [إنشاء](/ar/whatsapp-api/templates/manage#الإنشاء) القالب، أو [عدّل](/ar/whatsapp-api/templates/manage#التعديل) قالباً معتمداً بإرسال `optimization_spec` فقط. التعديل لا يعيد القالب للمراجعة.
- هذه القوالب تُقبل فقط على `/marketing_messages`. على `/messages` تفشل بالخطأ `131061`.
- الأهلية تعتمد على دولة المستلم. المستلمون في أوروبا والمملكة المتحدة غير مؤهلين.
- الميزة في مرحلة تجريبية مفتوحة، وقد تغيّر ميتا تفاصيلها.

## التوفر

Marketing Messages API غير متاح لكل الأنشطة:

- بعض الدول مستثناة من تحسين التسليم، منها أوروبا والمملكة المتحدة. الرسائل لهؤلاء المستلمين تُرسل بالتسليم العادي.
- أنشطة في بعض الدول لا تقدر تفعّله بعد. ميتا تخبرك بذلك عند محاولة الموافقة على الشروط.

## الأخطاء

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `131049` | حد التسويق لكل مستخدم | لا تعد المحاولة قبل 24 ساعة. راجع [حدود كل مستخدم](/ar/whatsapp-api/templates/sending#حدود-التسويق-لكل-مستخدم) |
| `130472` | المستخدم ضمن تجربة من ميتا | لا تعد المحاولة |
| `131061` | قالب بسعر أقصى أُرسل إلى `/messages` | أرسله إلى `/marketing_messages` |
| `132001` | القالب غير موجود | تحقق من الاسم واللغة |

ويُرفض الطلب أيضاً إذا لم تُفعَّل الحافظة ([التفعيل](#التفعيل))، أو إذا كان الجسم ليس قالب `MARKETING` (رسائل حرة، أو قوالب خدمية أو مصادقة).

## قوالب تسويقية تحقق نتائج

- ابدأ بالفائدة: ماذا يستفيد القارئ، من أول سطر.
- استخدم دعوة واحدة واضحة لاتخاذ إجراء، كزر.
- خصّص بالمتغيرات، بشكل طبيعي.
- أضف زر رد سريع "إيقاف العروض". من يقدر يلغي بسهولة يحظر أقل.
- استخدم الصيغ الغنية حيث تناسب: [الكاروسيل والكوبونات والعروض المحدودة](/ar/whatsapp-api/templates/commerce).
