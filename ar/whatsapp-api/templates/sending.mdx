أرسل القالب عبر `POST /messages` مع `"type": "template"`. القوالب ذات الحالة `APPROVED` فقط تُرسل.

## الإرسال

```bash
curl -X POST https://waba.karzoun.chat/messages \
  -H "Karzoun-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messaging_product": "whatsapp",
    "to": "966500000000",
    "type": "template",
    "template": {
      "name": "order_shipped",
      "language": { "code": "ar" },
      "components": [
        {
          "type": "header",
          "parameters": [{ "type": "image", "image": { "link": "https://example.com/box.jpg" } }]
        },
        {
          "type": "body",
          "parameters": [
            { "type": "text", "text": "سارة" },
            { "type": "text", "text": "#1042" }
          ]
        },
        {
          "type": "button",
          "sub_type": "url",
          "index": "0",
          "parameters": [{ "type": "text", "text": "1042" }]
        }
      ]
    }
  }'
```

```json
{
  "messaging_product": "whatsapp",
  "contacts": [{ "input": "966500000000", "wa_id": "966500000000" }],
  "messages": [{ "id": "wamid.HBgMOTY2NTAwMDAwMDAwFQIAERgS...", "message_status": "accepted" }]
}
```

`components` تحمل فقط الأجزاء التي فيها متغيرات أو وسائط. القالب بدون متغيرات يكفيه `name` و`language`.

## المعاملات

| المكوّن | أنواع المعاملات |
| --- | --- |
| `header` | `text` و`image` و`video` و`document` و`location` |
| `body` | `text` و`currency` و`date_time` |
| `button` | `text` لنهاية الرابط، `payload` للرد السريع، `coupon_code` لزر نسخ الكود، `action` لأزرار الـ Flow والكتالوج |

للمتغيرات المسمّاة أضف `parameter_name`:

```json
{ "type": "text", "parameter_name": "first_name", "text": "سارة" }
```

ترويسة الوسائط تأخذ `id` من [الرفع](/ar/whatsapp-api/messaging/media) أو `link` عاماً. ترويسة المستند تقبل `filename` أيضاً.

### بيانات أزرار الرد السريع

حدد payload لكل زر رد سريع لتعرف أي زر ضُغط بدون تحليل النص:

```json
{
  "type": "button",
  "sub_type": "quick_reply",
  "index": "1",
  "parameters": [{ "type": "payload", "payload": "STOP_PROMOS" }]
}
```

`index` هو ترتيب الزر في القالب، ويبدأ من `0`.

## حالة الرسالة

القيمة `messages[0].message_status` في الرد تخبرك بما حدث فوراً:

| القيمة | المعنى |
| --- | --- |
| `accepted` | أُرسلت بشكل طبيعي |
| `held_for_quality_assessment` | محجوزة بسبب [التدرج في الإرسال](#التدرج-في-الإرسال). تُسلَّم أو تُلغى لاحقاً |

بعدها تابع `sent` و`delivered` و`read` أو `failed` على [الـ Webhook](/ar/whatsapp-api/webhooks/events#حالات-الرسائل) بنفس معرّف الرسالة.

## التدرج في الإرسال

التدرج (Pacing) يعطي الناس وقتاً ليتفاعلوا مع القالب قبل أن يصل للجميع. إذا كانت ردود الفعل الأولى سيئة، توقف ميتا القالب قبل أن يضر رقمك.

**أي قوالب قد تخضع له:** القوالب التسويقية الجديدة، أو التي رُفع عنها الإيقاف للتو، أو التي تقييمها ليس مرتفعاً. والقوالب الخدمية تخضع له بنفس الطريقة بعد أن يُوقف أحد قوالبك الخدمية.

**أي أنشطة:** الحافظات التي أرسلت أقل من 500,000 رسالة قالب خلال آخر 365 يوماً، والحافظات قيد المراجعة بسبب نشاط مشبوه.

**كيف يعمل:**

1. تُرسل الرسائل عادي حتى عتبة تحددها ميتا لكل قالب.
2. بعدها يرجع الإرسال `held_for_quality_assessment`.
3. تراقب ميتا ردود الفعل، ثم تطلق الرسائل المحجوزة على دفعات.

| ردود الفعل | النتيجة |
| --- | --- |
| جيدة | تُسلَّم الرسائل المحجوزة، مع حالات `sent` و`delivered` المعتادة |
| سيئة | يُوقف القالب، وكل رسالة محجوزة تفشل بالخطأ `132015` |
| غير كافية خلال المهلة | تُطلق الرسائل المحجوزة بشكل طبيعي |

تهدف ميتا لتسليم الحملات حتى مع التدرج خلال ساعة تقريباً. والإرسال الصغير تحت العتبة لا يخضع للتدرج أصلاً.

<Tip>
  تطلق حملة كبيرة بقالب جديد؟ أرسل أولاً لشريحة صغيرة متفاعلة. ردود الفعل الجيدة المبكرة تعني أن البقية لن تُحجز.
</Tip>

## حدود التسويق لكل مستخدم

يحدّ واتساب من عدد القوالب التسويقية التي يستقبلها الشخص من كل الأنشطة مجتمعة، بدءاً بمن احتمال تفاعلهم أقل. عندما لا تُسلَّم رسالة تسويقية لهذا السبب:

- تفشل الرسالة بالخطأ `131049` ("not delivered to maintain healthy ecosystem engagement")،
- لا تُحتسب عليك،
- بقية المستلمين لا يتأثرون.

لا تعد المحاولة فوراً: ستفشل مرة أخرى. انتظر 24 ساعة على الأقل، أو حتى يراسلك الشخص.

الحد ينطبق فقط على القوالب التسويقية التي ستبدأ محادثة جديدة. إذا ردّ عليك الشخص مؤخراً، يمر قالبك التسويقي التالي.

هذا الحد لا ينطبق في المنطقة الاقتصادية الأوروبية والمملكة المتحدة واليابان وكوريا الجنوبية.

وبشكل منفصل، تحجب ميتا الرسائل التسويقية عن نسبة صغيرة من المستخدمين كتجربة مستمرة (الخطأ `130472`). لا تُحتسب عليك؛ لا تعد إرسالها.

## ترتيب الوصول

الرسائل المرسلة وراء بعض قد تصل بترتيب مختلف. إذا كان الترتيب مهماً، مثل صورة ثم شرحها، انتظر حالة `delivered` للأولى قبل إرسال التالية.

## مدة الصلاحية (TTL)

إذا تعذر تسليم الرسالة فوراً، مثلاً لأن الجوال مغلق، يستمر واتساب بالمحاولة حتى 30 يوماً. القوالب تقدر تحدد مدة أقصر عبر `message_send_ttl_seconds` عند إنشائها:

| الفئة | المسموح |
| --- | --- |
| المصادقة | من 30 إلى 900 ثانية (الافتراضي 10 دقائق) |
| الخدمية | من 30 إلى 43,200 ثانية (12 ساعة) |
| التسويقية | من 43,200 إلى 2,592,000 ثانية (من 12 ساعة إلى 30 يوماً)، عبر Marketing Messages API فقط |

الرسائل التي لا تُسلَّم خلال المدة تفشل ولا تُحتسب.

## أخطاء شائعة

| الكود | المعنى | ماذا تفعل |
| --- | --- | --- |
| `132000` | عدد المعاملات لا يطابق القالب | أرسل معاملاً واحداً لكل متغير |
| `132001` | القالب غير موجود بهذه اللغة | تحقق من `name` و`language.code` |
| `132005` | النص طويل بعد تعبئة المتغيرات | اختصر قيم المتغيرات |
| `132007` | المحتوى يخالف السياسة بعد تعبئة المتغيرات | راجع قيم المتغيرات |
| `132012` | صيغة المعامل لا تطابق القالب | مثلاً ترويسة صورة أُرسلت كنص |
| `132015` | القالب موقوف لانخفاض الجودة | انتظر انتهاء الإيقاف، أو استخدم قالباً آخر |
| `132016` | القالب معطّل | أنشئ قالباً جديداً |
| `131049` | حد التسويق لكل مستخدم | لا تعد المحاولة قبل 24 ساعة |
| `131026` | تعذر التسليم | الرقم ليس على واتساب، أو لا يستطيع استقبال هذه الرسالة |

كل الأكواد في [الأخطاء](/ar/whatsapp-api/reference/errors).
