الأداة الواحدة هي عملية GraphQL عامة واحدة. `tags` تشغّل `query tags`. `customersAdd` تشغّل `mutation customersAdd`. لا توجد واجهة ثانية خلف MCP.

1. يختار التطبيق أداة ويمرّر الوسائط. تلك الوسائط هي وسائط GraphQL.
2. يبني خادم MCP الاستعلام ويرسله POST إلى عنوان GraphQL مع `Authorization: Bearer`.
3. يُعاد JSON إلى التطبيق كنص.

إن لم يستطع مفتاح API تشغيل تلك العملية، فلن تستطيعها الأداة. جرّب العملية نفسها في [ساحة التجربة](https://karzoun.chat/developer/playground) قبل أن تلوم النموذج. النطاقات مشروحة في [المصادقة](/ar/developers/getting-started/authentication).

توثيق حقول كل عملية في [مرجع GraphQL](/api-reference). الأسماء في [كتالوج الأدوات](/ar/mcp-server/tools/catalog).

## أظهر للوكيل أدواتاً أقل

الحزمة هي القائمة التي تريدها. اضبط `KARZOUN_MCP_PACK` محلياً، أو استدعِ `/mcp/customer-support` عبر HTTP.

```json
"env": {
  "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
  "KARZOUN_API_KEY": "kz_live_YOUR_API_KEY",
  "KARZOUN_MCP_PACK": "customer-support"
}
```

`KARZOUN_MCP_TOOL_PREFIX` يقصّ تلك القائمة أكثر. `customers` يبقي `customers` و`customersAdd` و`customerDetail` ويسقط ما عداها. استخدم حزمة أولاً. استخدم البادئة عندما تبقى الحزمة أوسع مما تحتاج.

## القراءة والكتابة

الاستعلامات معلَّمة للقراءة فقط. التعديلات معلَّمة للكتابة. هذه علامات للتطبيق. لا تمنع الحذف. نطاقات مفتاح API هي التي تمنعه.

## عندما يفشل الطلب

تعيد الأداة JSON فيه نص `error`. فشل الصلاحية وفشل التحقق والردود الأكبر من **512 كيلوبايت** كلها بهذا الشكل. خفّض `perPage` أو أضف مرشحاً عندما تقول الرسالة إن الرد أكبر من اللازم. انظر [ترقيم الصفحات](/ar/developers/guides/pagination).

MCP لا يبث رسائل الوارد الجديدة. استخدم [Webhooks](/ar/developers/guides/webhooks) لذلك. وهو لا يثبّت MiniApps.

## المحلي والمستضاف

على جهازك تحتفظ عملية `npx` بـ `KARZOUN_API_KEY` وتستدعي GraphQL بنفسها. MCP المستضاف هو `POST https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp`. يرسل خادمك `Authorization: Bearer` في كل طلب، أو يسجّل Claude.ai وChatGPT دخول المستخدم. التفاصيل: [MCP عبر HTTP](/ar/mcp-server/setup/hosted).
