يستخدم Claude Desktop نفس حزمة `@karzounchat/mcp-server` مع مسار ملف إعداد مختلف.

## ملف الإعداد

| النظام | المسار |
| ------ | ------ |
| macOS  | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

## الإعداد

```json
{
  "mcpServers": {
    "karzoun-customer-support": {
      "command": "npx",
      "args": ["-y", "@karzounchat/mcp-server"],
      "env": {
        "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
        "KARZOUN_APP_TOKEN": "YOUR_APP_TOKEN",
        "KARZOUN_MCP_PACK": "customer-support"
      }
    }
  }
}
```

أنشئ رمزاً من **المطور → التطبيقات**. عيّن `KARZOUN_MCP_PACK` لحزمة مركّزة أو `full`. انظر [الحزم](/mcp-server/setup/hosted#packs-tool-subsets).

## التحقق

1. أغلق Claude Desktop وأعد فتحه
2. ابحث عن مؤشر الأدوات — يجب أن تظهر أدوات Karzoun
3. اسأل: _"Using Karzoun tools, list my first 5 tags"_

## Claude على الويب؟

استخدم موصّل HTTP وليس هذا الملف: [موصّلات الذكاء الاصطناعي](/mcp-server/setup/ai-connectors#claudeai).
