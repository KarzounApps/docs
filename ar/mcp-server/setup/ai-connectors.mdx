استخدم هذه الصفحة عندما يكون تطبيق الذكاء الاصطناعي على الإنترنت لا على جهازك. عنوانك هو:

```
https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp/customer-support
```

`customer-support` هي حزمة الأدوات. احذفها، أو استبدلها بحزمة أخرى من [نظرة MCP](/ar/mcp-server)، عندما تريد قائمة مختلفة.

**Claude.ai وChatGPT** يسجّلان دخولك. الصق العنوان وانتقل إلى القسم أدناه. لا تلصق مفتاح API.

**Manus وCursor عن بُعد وClaude Code وخادمك** يستطيعون ضبط ترويسة. أرسل `Authorization: Bearer kz_live_…` مع [مفتاح API](/ar/developers/getting-started/authentication). لا تضع ذلك المفتاح في إضافة متصفح أو محادثة مشتركة.

**المطوّر ← إعداد MCP** (`/developer/mcp-setup`) يعبّئ العنوان لحسابك.

بعد الاتصال، جرّب:

- _"اعرض أحدث 10 عملاء ولخّص وسومهم."_
- _"جد المحادثات المفتوحة التي تحتاج رداً."_
- _"ابحث في قاعدة المعرفة عن سياسة الإرجاع واكتب رداً قصيراً."_
- _"اعرض قوالب واتساب المعتمدة لحسابي."_
- _"جد المحادثة مع alice@example.com ولخّص آخر 5 رسائل."_

اطلب من النموذج أن يقرأ قبل أن يعدّل شيئاً. المزيد من الأوامر: [أنماط الوكلاء](/ar/mcp-server/guides/agent-patterns). أسماء العمليات في [كتالوج الأدوات](/ar/mcp-server/tools/catalog).

## Claude.ai

يدعم Claude على الويب **موصّلات MCP عن بُعد مخصصة** (Settings → Connectors → Add custom connector).

<Steps>

  <Step title="أضف الموصّل">
    1. افتح [Claude Connectors](https://claude.ai/settings/connectors) (أو **Admin → Connectors** على Team/Enterprise).
    2. انقر **Add custom connector**.
    3. **Server URL:** `https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp/customer-support`
    4. يكتشف Claude خادم التفويض في كرزون. سجّل الدخول بحساب كرزون ووافق على النطاقات. لا تلصق مفتاح API في هذا الموصّل.
  </Step>

  <Step title="فعّل في المحادثة">
    استخدم قائمة **+** في محادثة → **Connectors** → فعّل كرزون لتلك المحادثة.

    اختبر: _"Using Karzoun tools, run currentUser and list my first 5 tags."_
  </Step>
</Steps>

<Info title="Claude Desktop مقابل Claude.ai">
  **Claude Desktop** للبرمجة المحلية ما زال الأفضل مع [stdio](/ar/mcp-server/setup/claude-desktop). **الموصّلات عن بُعد** في Claude.ai لجلسات السحابة — لا تضف عنوان HTTPS إلى `claude_desktop_config.json`؛ استخدم واجهة Connectors بدلًا من ذلك.
</Info>

## Manus

يدعم [Manus](https://manus.im/) **خوادم MCP مخصصة** عبر HTTP — ملاءمة قوية لكرزون المستضاف لأنك تستطيع الإشارة إلى عنوان `/mcp` عام وتزويد بيانات الاعتماد.

<Steps>
  <Step title="افتح Custom MCP">
    **Settings → Integrations → Custom MCP** (أو **+ Add custom MCP → Direct configuration**).
  </Step>

  <Step title="أدخل تفاصيل الخادم">
    | الحقل              | القيمة                                                                                    |
    | ------------------ | ------------------------------------------------------------------------------------------ |
    | **Name**           | `Karzoun` (أو اسم حسابك)                                                       |
    | **Transport**      | `HTTP` / Streamable HTTP                                                                 |
    | **Server URL**     | `https://{subdomain}.api.karzoun.chat/mcp`                                               |
    | **Authentication** | API key / Bearer — الصق `kz_live_…`. إن وُجد حقل ترويسة مخصصة فاستخدم `Authorization`. |

    إذا كان Manus يرسل `Authorization: Bearer` من حقل مفتاح واحد، الصق مفتاح API الخاص بكرزون. بلا وكيل وسيط.
  </Step>

  <Step title="اختبر واستخدم">
    يتحقق Manus من الخادم ويعرض الأدوات المكتشفة. اذكر كرزون في الأوامر:

    _"Pull my top 10 customers by last updated date and create a Manus doc summarizing their tags."_

    المرجع الرسمي: [وثائق Manus custom MCP](https://manus.im/docs/integrations/custom-mcp).
  </Step>
</Steps>

## ChatGPT Apps والموصّلات

تدعم OpenAI **MCP عن بُعد** عبر **Apps / Connectors** (وضع المطوّر في إعدادات ChatGPT). يتصل ChatGPT من سحابة OpenAI — **stdio المحلي لا يعمل**.

<Steps>
  <Step title="فعّل وصول المطوّر">
    في ChatGPT: **Settings → Apps & Connectors** (أو **Connectors → Advanced**) → فعّل **Developer mode** إن كان متاحًا في خطتك.
  </Step>

  <Step title="أضف عنوان MCP">
    أنشئ تطبيقًا/موصّلًا جديدًا والصق:

    ```
    https://{subdomain}.api.karzoun.chat/mcp
    ```

    راجع الأدوات المكتشفة قبل تفعيل التطبيق في المحادثات.
  </Step>
</Steps>

<Warning title="OAuth، وليس مفتاحاً ملصوقاً">
  موصّلات ChatGPT تسجّل الدخول عبر **OAuth**. الصق رابط MCP، ثم سجّل الدخول إلى كرزون ووافق على النطاقات. لا تلصق مفتاح API في هذا المسار.

  العملاء الذين يعتمدون الترويسات ([Manus](#manus)، [Cursor عن بُعد](#cursor-remote)، [Claude Code](#claude-code)، أو خلفيتك) يرسلون `Authorization: Bearer kz_live_…` بدل ذلك.
</Warning>

## Cursor (عن بُعد)

للفرق التي تفضّل **عدم** تشغيل `npx` محليًا، يدعم Cursor **MCP عن بُعد** عبر `url` + `headers` في `mcp.json`.

```json
{
  "mcpServers": {
    "karzoun-hosted": {
      "url": "https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp",
      "headers": {
        "Authorization": "Bearer ${env:KARZOUN_API_KEY}"
      }
    }
  }
}
```

صدّر `KARZOUN_API_KEY` في ملف تعريف الصدفة (تطبيقات سطح المكتب قد لا تحمّل `.zshrc` — استخدم بيئة النظام أو أنماط الأسرار المدعومة في Cursor).

يجب أن يظهر **إعدادات Cursor ← MCP** بحالة **connected** مع نحو 75 أداة. فضّل [stdio المحلي](/ar/mcp-server/setup/cursor) للتطوير دون اتصال؛ واستخدم **المستضاف** عندما يكون `npx` محظورًا أو تريد نقطة نهاية مشتركة واحدة.

الوثائق: [Cursor MCP — remote servers](https://cursor.com/docs/mcp).

## Claude Code

يمكن لـ [Claude Code](https://docs.anthropic.com/en/docs/claude-code) تسجيل خوادم MCP عبر HTTP من سطر الأوامر:

```bash
claude mcp add --transport http karzoun \
  https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp \
  --header "Authorization: Bearer kz_live_YOUR_API_KEY"
```

استخدم `.mcp.json` للمشروع للوصول على مستوى المستودع. ألغِ المفتاح من **المطوّر ← مفاتيح API** إذا شارك إعداد CLI.

## ابنِ وكيلك الخاص

أي مكدس يتحدث **Streamable HTTP MCP** يمكنه استدعاء كرزون:

```mermaid
flowchart LR
  User[User / trigger] --> Agent[Your agent runtime]
  Agent -->|POST /mcp + Authorization Bearer| Karzoun[Karzoun gateway]
  Karzoun --> GQL[GraphQL API]
```

المضيفات النموذجية: LangGraph، عمال Node/Python مخصصون، أتمتة بأسلوب Zapier، بوتات Slack داخلية.

1. `POST initialize`
2. `POST tools/list` → اكتشف العمليات
3. `POST tools/call` → نفّذ بحجج بشكل GraphQL

MCP المستضاف لا يطلب `mcp-session-id` بين هذه الطلبات.

أمثلة وcurl: [MCP المستضاف](/ar/mcp-server/setup/hosted). تصميم الأوامر: [أنماط الوكلاء](/ar/mcp-server/guides/agent-patterns).

## ضيّق نطاق الرموز لوكلاء أكثر أمانًا

قبل ربط عميل قوي:

| الهدف                    | نطاقات المفتاح                     | بيئة اختيارية                            |
| ------------------------ | ------------------------------------- | ------------------------------------------ |
| مساعد CRM للقراءة فقط | قراءة العملاء، الوسوم، الشركات    | `KARZOUN_MCP_TOOL_PREFIX` على stdio فقط |
| فرز الدعم          | المحادثات + قراءة قاعدة المعرفة | ضيّق نطاقات المفتاح                  |
| إدارة التكامل       | كتابة خطافات الويب           | مفتاح منفصل، لا مفتاح القراءة فقط           |

ابدأ بمفتاح **للقراءة فقط**، تحقّق من الأوامر، ثم أصدر مفتاحاً أوسع عند الحاجة.

## استكشاف أخطاء الموصّلات

| العرض                        | السبب المحتمل                          | الإصلاح                                           |
| -------------------------------- | ---------------------------------------- | ------------------------------------------------ |
| 401 مطلوب تفويض            | لا مفتاح API ولا تسجيل دخول OAuth        | أرسل `Authorization: Bearer`، أو أكمل الموافقة |
| أدوات فارغة / خطأ صلاحية | نطاقات المفتاح ضيقة جدًا               | وسّع النطاقات؛ اختبر في ساحة التجربة         |
| العميل لا يصل إلى العنوان        | شبكة خاصة / localhost           | استخدم `*.api.karzoun.chat` العام فقط          |
| فشل مصادقة ChatGPT أو Claude | عنوان الموصّل ليس رابط MCP العام | استخدم `https://{subdomain}.api.karzoun.chat/mcp` وسجّل الدخول |

المزيد: [استكشاف الأخطاء](/ar/mcp-server/guides/troubleshooting).
