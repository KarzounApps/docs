استدعِ كرزون MCP عبر **Streamable HTTP** من الخلفية — أو اربط **تطبيقات الذكاء الاصطناعي السحابية** (Claude، Manus، ChatGPT، Cursor عن بُعد) بنفس نقطة النهاية.

**جديد:** دليل الموصّلات خطوة بخطوة → [موصّلات تطبيقات الذكاء الاصطناعي](/ar/mcp-server/setup/ai-connectors)

```
https://{subdomain}.api.karzoun.chat/mcp
https://{subdomain}.api.karzoun.chat/mcp/{pack}
```

<Warning title="من جهة الخادم فقط">
  لا تستدعِ `/mcp` من JavaScript في المتصفح أبدًا. سيتعرّض رمز التطبيق للمستخدمين النهائيين. استخدم الخلفية أو عاملًا موثوقًا.
</Warning>

## متى تستخدم المستضاف

| استخدم المستضاف | استخدم stdio بدلًا منه |
| --- | --- |
| وكيل ذكاء اصطناعي منشور على بنيتك | البرمجة المحلية في Cursor / Claude |
| مهمة Cron أو عامل خلفي يحتاج أدوات CRM | استكشاف لمرة واحدة |
| وكيل SaaS متعدد المستأجرين يمرّر رموزًا لكل عميل | جهاز التطوير الشخصي |

## المصادقة

```
x-app-token: YOUR_APP_TOKEN_JWT
```

اختياري: `x-subdomain` عندما توجّه بوابتك المستأجرين عبر الترويسة.

## الحزم (packs)

فضّل **حزمة** حتى يحصل الوكيل على قائمة أدوات مركّزة:

| الحزمة | المسار |
| --- | --- |
| دعم العملاء | `/mcp/customer-support` |
| التسويق | `/mcp/marketing` |
| العمليات | `/mcp/operations` |
| واتساب | `/mcp/whatsapp` |
| الأتمتة | `/mcp/automations` |
| التكاملات | `/mcp/integrations` |
| الذكاء الاصطناعي | `/mcp/ai` |
| كامل الواجهة العامة | `/mcp` أو `/mcp/full` |

```bash
curl -s 'https://YOUR.api.karzoun.chat/mcp/packs'
```

يمكنك أيضًا تمرير `?pack=customer-support` أو الترويسة `x-mcp-pack: customer-support` على `/mcp`.

## النقل

MCP المستضاف **عديم الحالة** (stateless) عبر Streamable HTTP. يرسل العميل `initialize` ثم `tools/list` / `tools/call` كطلبات POST منفصلة — دون الحاجة إلى `mcp-session-id` ثابت عبر نسخ البوابة.

## مثال initialize

```bash
curl -s -X POST 'https://YOUR.api.karzoun.chat/mcp/customer-support' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'x-app-token: YOUR_TOKEN' \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {
      "protocolVersion": "2024-11-05",
      "capabilities": {},
      "clientInfo": { "name": "my-agent", "version": "1.0.0" }
    }
  }'
```
