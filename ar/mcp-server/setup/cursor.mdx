شغّل كرزون MCP محليًا ليتمكن وكيل Cursor من استدعاء واجهة GraphQL لمساحة عملك كأدوات.

<Tip title="شرح بالفيديو">
  **قريبًا:** _تثبيت كرزون MCP في Cursor_ — من رمز التطبيق إلى أول استعلام `tags`. _(مكان مخصص لتضمين الفيديو)_
</Tip>

## قبل البدء

- [رمز التطبيق](/ar/developers/getting-started/authentication) من **المطوّر ← التطبيقات**
- عنوان GraphQL: `https://{subdomain}.api.karzoun.chat/graphql`

## إعداد MCP

<Steps>
  <Step title="افتح إعدادات MCP">
    **إعدادات Cursor ← MCP ← Add new global MCP server**

    أو عدّل `~/.cursor/mcp.json` مباشرة.
  </Step>

  <Step title="أضف خادم كرزون">
    ```json
    {
      "mcpServers": {
        "karzoun": {
          "command": "npx",
          "args": ["-y", "@karzounchat/mcp-server"],
          "env": {
            "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
            "KARZOUN_APP_TOKEN": "YOUR_APP_TOKEN"
          }
        }
      }
    }
    ```

    استبدل `YOUR_SUBDOMAIN` والصق JWT من `appsAdd` (يُعرض مرة واحدة).

    <Warning title="أبقِ الرموز خارج Git">
      لا ترفع `mcp.json` إلى Git إذا كان يحتوي رموزًا حقيقية. استخدم متغيرات البيئة أو تخزين الأسرار في Cursor حيث يتوفر.
    </Warning>
  </Step>

  <Step title="اختياري: تقييد الأدوات">
    لتسريع التشغيل وتقليل السياق، اعرض أدوات CRM فقط:

    ```json
    "env": {
      "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
      "KARZOUN_APP_TOKEN": "YOUR_APP_TOKEN",
      "KARZOUN_MCP_TOOL_PREFIX": "customers"
    }
    ```
  </Step>

  <Step title="أعد التشغيل وتحقق">
    1. **إعدادات Cursor ← MCP** — أوقف/شغّل الخادم أو انقر تحديث
    2. يجب أن تظهر الحالة **connected** مع عدد أدوات (~75 بدون بادئة)
    3. في المحادثة: _"Use Karzoun to run currentUser"_

    المتوقع: ملف JSON لملف مستخدم مساحة العمل المرتبط بالتطبيق.
  </Step>
</Steps>

## صفحة الإعداد داخل التطبيق

يوفّر كرزون أيضًا تدفقًا موجّهًا في **المطوّر ← إعداد MCP** في تطبيق الويب (`/developer/mcp-setup`) مع مقاطع إعداد جاهزة للنسخ.

## إعداد على مستوى المشروع

لمستودعات الفريق، أضف `.cursor/mcp.json` (بنفس المخطط) حتى يستخدم الجميع نفس اسم الخادم — ويظل كل مطوّر يزوّد رمزه الخاص عبر البيئة المحلية إن رغب.

للفرق التي تفضّل عدم تشغيل `npx`، استخدم [MCP المستضاف](/ar/mcp-server/setup/hosted) أو [موصّلات تطبيقات الذكاء الاصطناعي](/ar/mcp-server/setup/ai-connectors) (Claude.ai، Manus، ChatGPT، Cursor عن بُعد).
