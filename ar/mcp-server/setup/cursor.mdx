شغّل Karzoun MCP محلياً ليمكّن وكيل Cursor من استدعاء واجهة GraphQL العامة كمساحة عملك.

## قبل البدء

- [رمز تطبيق](/developers/getting-started/authentication) من **المطور → التطبيقات**
- رابط GraphQL: `https://{subdomain}.api.karzoun.chat/graphql`

## إعداد MCP

<Steps>
  <Step title="افتح إعدادات MCP">
    **Cursor Settings → MCP → Add new global MCP server**

    أو عدّل `~/.cursor/mcp.json` / `.cursor/mcp.json` في المشروع.
  </Step>

  <Step title="أضف خادم Karzoun">
    ```json
    {
      "mcpServers": {
        "karzoun-customer-support": {
          "command": "npx",
          "args": ["-y", "@karzounchat/mcp-server"],
          "env": {
            "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
            "KARZOUN_APP_TOKEN": "YOUR_APP_TOKEN",
            "KARZOUN_MCP_PACK": "customer-support"
          }
        }
      }
    }
    ```

    استبدل النطاق الفرعي والصق JWT من **المطور → التطبيقات**.

    <Warning title="لا تضع الرموز في git">
      لا ترفع `mcp.json` إذا احتوى رموزاً حقيقية.
    </Warning>
  </Step>

  <Step title="اختر حزمة">
    يحدّ `KARZOUN_MCP_PACK` الأدوات الظاهرة للوكيل. ابدأ بـ `customer-support`. الجدول الكامل: [حزم HTTP MCP](/mcp-server/setup/hosted#packs-tool-subsets).
  </Step>

  <Step title="أعد التشغيل وتحقق">
    حدّث الخادم من **Cursor Settings → MCP** ثم اسأل: _"Use Karzoun to list my first 5 tags"_
  </Step>
</Steps>

**المطور → إعداد MCP** (`/developer/mcp-setup`) — مقتطفات جاهزة لـ Cursor و VS Code و Claude Desktop.
