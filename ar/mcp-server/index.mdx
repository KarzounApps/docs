يتيح MCP لتطبيق ذكاء اصطناعي أن يستدعي حسابك في كرزون: يعرض العملاء، ويقرأ الوارد، ويبحث عن قالب واتساب. كل أداة هي عملية GraphQL عامة واحدة. اسم الأداة هو اسم العملية.

افتح **المطوّر ← إعداد MCP** (`/developer/mcp-setup`) إن أردت العنوان والإعداد معبّأين لحسابك.

## اختر التطبيق

- **Cursor أو VS Code أو Claude Desktop على جهازك.** اتبع [Cursor](/ar/mcp-server/setup/cursor). [VS Code](/ar/mcp-server/setup/vscode) و[Claude Desktop](/ar/mcp-server/setup/claude-desktop) يستخدمان البرنامج نفسه وملف إعداد مختلف. تلصق [مفتاح API](/ar/developers/getting-started/authentication) في ذلك الملف.
- **Claude.ai أو ChatGPT.** اتبع [التطبيقات السحابية](/ar/mcp-server/setup/ai-connectors). الصق عنوان MCP. التطبيق يسجّل دخولك. لا تلصق مفتاحاً.
- **خادم تشغّله أنت.** اتبع [MCP عبر HTTP](/ar/mcp-server/setup/hosted) وأرسل `Authorization: Bearer` مع مفتاح API.

إن كان التطبيق لا يحتاج نموذج لغة، استدعِ [GraphQL](/ar/developers/getting-started/quickstart) أو [Webhooks](/ar/developers/guides/webhooks) مباشرة.

## ابدأ بحزمة

الحزمة قائمة أدوات قصيرة. `full` هي كل العمليات العامة وبداية سيئة.

| الحزمة | أعطها لوكيل يفترض أن |
| --- | --- |
| `customer-support` | يقرأ الوارد وجهات الاتصال والشركات والوسوم |
| `marketing` | يعمل على الحملات والشرائح والنماذج والمنتجات |
| `operations` | يعمل على المهام ودردشة الفريق والمستخدمين |
| `whatsapp` | يعمل على رسائل واتساب والقوالب والتدفقات |
| `automations` | يقرأ تدفقات الأتمتة ويعدّلها |
| `integrations` | يقرأ التطبيقات وWebhooks وMiniApps |
| `ai` | يبحث في قاعدة المعرفة |
| `full` | يرى الواجهة العامة كلها |

على جهازك، اضبط `KARZOUN_MCP_PACK` على أحد هذه المعرّفات. عبر HTTP، استدعِ `/mcp/customer-support` بدل `/mcp`.

بعد الاتصال، اسأل: «استخدم كرزون لعرض أول 5 وسوم.» إن غابت الأداة أو رُفضت، انظر [استكشاف الأخطاء](/ar/mcp-server/guides/troubleshooting).

## الإعداد المحلي

```json
{
  "mcpServers": {
    "karzoun-customer-support": {
      "command": "npx",
      "args": ["-y", "@karzounchat/mcp-server"],
      "env": {
        "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
        "KARZOUN_API_KEY": "kz_live_YOUR_API_KEY",
        "KARZOUN_MCP_PACK": "customer-support"
      }
    }
  }
}
```

| المتغير | مطلوب | ماذا تضع |
| --- | --- | --- |
| `KARZOUN_API_URL` | نعم | عنوان GraphQL |
| `KARZOUN_API_KEY` | نعم | المفتاح من **المطوّر ← مفاتيح API** |
| `KARZOUN_MCP_PACK` | لا | معرّف حزمة. الافتراضي `full` |
| `KARZOUN_MCP_FETCH_TIMEOUT_MS` | لا | مدة استدعاء GraphQL الواحد. الافتراضي 30000 |
| `KARZOUN_MCP_MAX_RESPONSE_BYTES` | لا | أكبر رد لأداة. الافتراضي 524288 (512 كيلوبايت) |

ما زال `KARZOUN_APP_TOKEN` القديم يُقرأ عندما يكون `KARZOUN_API_KEY` فارغاً، حتى 31 مارس 2027. الإعدادات الجديدة تضع مفتاح API.

يسمح `/mcp` المستضاف بـ 120 طلب POST في الدقيقة لكل مفتاح. `MCP_RATE_LIMIT_PER_MIN=0` على البوابة يوقف ذلك.
