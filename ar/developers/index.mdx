## أيها يناسبك

استدعِ **GraphQL** عندما يحتاج خادمك البيانات الآن. استخدم **webhook** عندما تريد أن يخبرك كرزون أن شيئاً تغيّر. استخدم **MCP** عندما يستدعي تطبيق ذكاء اصطناعي الواجهة. استخدم **Dashboard SDK** عندما تدمج لوحة داخل الوارد. استخدم **MiniApps** عندما تشحن موصّلاً يثبّته الآخرون.

## طلب

```bash
curl -X POST 'https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer kz_live_YOUR_API_KEY' \
  -d '{"query":"query { tags(page: 1, perPage: 3) { data { name } pagination { totalCount } } }"}'
```

الرد الناجح فيه كائن `data`. الرد الفاشل فيه مصفوفة `errors`. انظر [الأخطاء](/ar/developers/guides/errors).

## قبل النشر

- أبقِ مفتاح API على خادمك. لا تضعه في JavaScript للمتصفح ولا في مستودع عام.
- تحقق من `X-Karzoun-Signature-256` على كل webhook قبل أن تثق بالمحتوى. انظر [Webhooks](/ar/developers/guides/webhooks).
- امنح المفتاح النطاقات التي تحتاجها تلك المهمة فقط، مثل `contacts:read`.
- ألغِ المفتاح من **المطوّر ← مفاتيح API** عندما يغادر صاحبه أو يتوقف التكامل.
