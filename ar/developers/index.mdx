مرحباً بك في توثيق **GraphQL API** لكرزون — أدلة وساحة تجربة ومخطط لمطوّري تطبيقات الشركاء، ومهندسي التكامل، والفرق التي تربط وكلاء الذكاء وتحتاج وصولاً حياً بصلاحيات إلى بيانات مساحة العمل.

المبيعات والدعم والتسويق تعمل أصلاً على مساحة عمل واحدة في كرزون. يستفيد تكاملك من هذا التوحيد: نموذج رموز واحد، وقصة صلاحيات واحدة، وسجل عميل واحد عبر القنوات.

</Info>

## متى تستخدم ماذا

| الحاجة | فضّل | لماذا |
| --- | --- | --- |
| قراءة/كتابة عند الطلب | **GraphQL** | مخطط كامل، ساحة تجربة، استعلامات دقيقة |
| التفاعل عند حدوث شيء | **Webhooks** | دفع الأحداث لخادمك مع التوقيعات |
| عميل ذكاء يحتاج أدوات | **MCP** | أدوات بصلاحيات على نفس بيانات مساحة العمل |
| واجهة داخل الوارد | **Dashboard SDK** | تطبيقات iframe تستدعي `executeMiniAppAction` |
| موصل قابل لإعادة الاستخدام | **MiniApps** | تعريف JSON للسوق + مراجعة |

## قائمة أمان سريعة

- خزّن رموز التطبيقات على الخادم — لا في JavaScript للمتصفح أو المستودعات العامة
- تحقق من توقيعات Webhooks (`x-karzoun-signature-256`) قبل الوثوق بالمحتوى
- امنح كل تطبيق أقل صلاحيات يحتاجها التكامل
- بدّل الرموز عند مغادرة أشخاص أو إيقاف تكاملات

## جرّب

```bash
curl -X POST 'https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql' \
  -H 'Content-Type: application/json' \
  -H 'x-app-token: YOUR_APP_TOKEN' \
  -d '{"query":"query { tags(page: 1, perPage: 3) { data { name } } }"}'
```

<Tip>
  تفضّل محرراً مرئياً؟ افتح [ساحة GraphQL](/ar/api-reference/playground).
</Tip>

## ما الذي يصل إليه تكاملك

| المجال | أمثلة |
| --- | --- |
| البريد الوارد المشترك | محادثات متعددة القنوات — واتساب، البريد، الدردشة، Messenger، Instagram |
| CRM والشرائح | العملاء، الشركات، الوسوم، الحقول المخصصة، الشرائح الديناميكية |
| الأتمتة | المحفّزات والشروط والإجراءات عبر الوارد والقنوات |
| الذكاء | Copilot ووكلاء مبنيون على سياق CRM والمحادثة |
| التسويق | الحملات والقوالب وتحليلات البث |
| العمليات | المهام، الطلبات، الاجتماعات، الملفات، دردشة الفريق |
