---
title: "ترقيم الصفحات"
description: "اقرأ قائمة في كرزون صفحةً صفحة."
---

استعلامات القوائم مثل `tags` و`customers` و`conversations` تأخذ `page` و`perPage`. تبدأ `page` من **1**. `tags` يعيد أول 20 صفاً إذا تركتهما فارغين. القوائم الأخرى توثّق افتراضها، لذا مرّر الاثنين كلما كان يهمك أي صفحة تحصل عليها.

اطلب كائن `pagination` وتوقف عندما تكون `hasNextPage` خطأ.

```graphql
query {
  customers(page: 1, perPage: 20) {
    data {
      _id
      firstName
    }
    pagination {
      totalCount
      currentPage
      totalPages
      hasNextPage
      hasPreviousPage
    }
  }
}
```

مرّر الصفحة التالية كمتغير بدل تعديل الاستعلام:

```json
{ "page": 2, "perPage": 20 }
```

```graphql
query Customers($page: Int, $perPage: Int) {
  customers(page: $page, perPage: $perPage) {
    data { _id firstName }
    pagination { currentPage hasNextPage }
  }
}
```

أبقِ `perPage` صغيراً. MCP يتجاهل نتيجة أداة أكبر من 512 كيلوبايت، والصفحة الضخمة أبطأ لكل عميل. أضف وسيط بحث أو ترشيح عندما يظهر في المرجع، بدل تصفح الحساب كله.
