النصوص والخوادم تستدعي الواجهة العامة بمفتاح **API**. أنشئه من **المطوّر ← مفاتيح API** (`/developer/api-keys`). انسخ السر عند ظهوره. لن تستطيع قراءته مرة أخرى.

أرسله مع كل طلب:

```bash
-H "Authorization: Bearer kz_live_YOUR_API_KEY"
```

`x-api-key: kz_live_YOUR_API_KEY` هو الشيء نفسه. مفاتيح الإنتاج تبدأ بـ `kz_live_`. البيئات الأخرى تستخدم `kz_test_`.

## أي مفتاح تنشئ

أنشئ مفتاحاً **شخصياً** عندما يجب أن يعمل التكامل بصفتك ويتوقف إذا عُطّل مستخدمك. المهمة على الخادم التي يجب أن تستمر بعد مغادرتك تحتاج مفتاح **حساب**. مفتاح الحساب ملك للحساب. يمكنك تقييده بمجموعة مستخدمين. إن لم تكن المالك فذلك إلزامي.

كلا النوعين ينتهي. الافتراضي سنة. أطول مدة سنتان. ألغِ المفتاح من الصفحة نفسها. يسري الإلغاء في الطلب التالي.

لا يستدعي المفتاح إلا النطاقات التي تختارها. `contacts:read` يعرض جهات الاتصال. `inbox:write` يقرأ الوارد ويعدّله، لأن الكتابة تشمل القراءة. النطاقات الحساسة، مثل إدارة التطبيقات أو Webhooks، للمالك فقط. مفتاح API لا يستطيع إنشاء مفتاح آخر.

`currentUser` يتأكد أن المفتاح يعمل. مع المفتاح الشخصي يعيدك أنت. مع مفتاح الحساب يعيد مستخدم المفتاح نفسه، لا زميلاً في الفريق.

<CodeGroup>
```graphql
query {
  currentUser {
    _id
    email
  }
}
```

```bash
curl -X POST 'https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer kz_live_YOUR_API_KEY' \
  -d '{"query":"query { currentUser { _id email } }"}'
```
</CodeGroup>

[ساحة التجربة](https://karzoun.chat/developer/playground) تعمل بصفتك وأنت مسجّل الدخول. ضع الترويسة أعلاه في لوحة الترويسات عندما تريد تجربة المفتاح.

## إن كنت تربط Claude أو ChatGPT

هذان التطبيقان لا يقبلان مفتاحاً ملصوقاً. أعطه عنوان MCP: `https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp`. يمرّرك بتسجيل الدخول المعتاد وشاشة الموافقة. الرمز الذي يحتفظ به لا يستدعي إلا النطاقات التي وافقت عليها. افصله من **الإعدادات ← التطبيقات المتصلة**.

الأدوات المحلية مثل Cursor تستخدم مفتاح API. انظر [MCP](/ar/mcp-server).

## أبقِ المفتاح آمناً

خزّنه في مدير أسرار أو متغير بيئة على الخادم. لا تضعه في JavaScript للمتصفح ولا في مستودع Git ولا في محادثة. عند فقدان جهاز أو مغادرة شخص، ألغِ ذلك المفتاح وأنشئ مفتاحاً جديداً. لا تعِد استخدام السر القديم.

## رموز التطبيقات الموجودة

`x-app-token` يبقى مقبولاً حتى **31 مارس 2027**. الردود تحمل ترويستي `Deprecation` و`Sunset`. لا تبدأ شيئاً جديداً بهذه الطريقة.

الرموز التي لديك أصلاً معروضة في **المطوّر ← التطبيقات**. حوّل أحدها إلى مفتاح API للحساب من هناك. المنتج لم يعد يسمح بإنشاء رمز تطبيق جديد.
