---
title: "البداية السريعة"
description: "نفّذ أول طلب لواجهة GraphQL في كرزون."
---

ستنشئ مفتاحاً، وتستدعي حسابك، وتقرأ قائمة وسوم.

<Steps>
  <Step title="أنشئ مفتاح API">
    افتح **المطوّر ← مفاتيح API** (`/developer/api-keys`). أنشئ مفتاحاً **شخصياً**، واترك النطاقات التي يسمح بها حسابك، وانسخ السر. يبدأ بـ `kz_live_` ويُعرض مرة واحدة.

    <Warning>
      لا ترفع المفتاح إلى Git ولا تلصقه في شيفرة الواجهة.
    </Warning>
  </Step>
  <Step title="انسخ عنوان الواجهة">
    استبدل `YOUR_SUBDOMAIN` بالنطاق الفرعي لحسابك. إن كنت تدخل من `acme.karzoun.chat` فالعنوان هو:

    ```
    https://acme.api.karzoun.chat/graphql
    ```
  </Step>
  <Step title="شغّل هذا الاستعلام">
    الاستعلام وأمر curl أدناه هما الطلب نفسه.

    <CodeGroup>
    ```graphql
    query {
      tags(page: 1, perPage: 5) {
        data {
          _id
          name
        }
        pagination {
          totalCount
        }
      }
    }
    ```

    ```bash
    curl -X POST 'https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer kz_live_YOUR_API_KEY' \
      -d '{"query":"query { tags(page: 1, perPage: 5) { data { _id name } pagination { totalCount } } }"}'
    ```
    </CodeGroup>

    المفتاح السليم يعيد JSON بهذا الشكل:

    ```json
    {
      "data": {
        "tags": {
          "data": [{ "_id": "…", "name": "VIP" }],
          "pagination": { "totalCount": 12 }
        }
      }
    }
    ```

    قد تكون `data` قائمة فارغة. هذا يعني أن الطلب نجح. إذا ظهر `errors` فالمفتاح مفقود أو ملغى، أو الاستعلام لا يطابق المخطط. انظر [الأخطاء](/ar/developers/guides/errors).
  </Step>
</Steps>

الطلب نفسه يعمل في [ساحة التجربة](https://karzoun.chat/developer/playground) وأنت مسجّل الدخول. أضف ترويسة `Authorization` هناك فقط عندما تريد تجربة المفتاح لا جلستك.

- [ترقيم الصفحات](/ar/developers/guides/pagination) — اقرأ بقية القائمة
