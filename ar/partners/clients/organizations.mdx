افتح **بوابة الشريك ← المؤسسات**. كل صف مساحة عميل.

## ماذا يعرض كل صف

| العمود | المعنى |
| --- | --- |
| المساحة | الاسم والعنوان. اضغطه لفتح [تفاصيل العميل](/ar/partners/clients/client-detail) |
| الخطة والحالة | خطة العميل، وحالة الاشتراك، وهل هو معلّق أو سيُلغى في نهاية الفترة |
| الرصيد | ما يستطيع العميل إنفاقه. راجع [الأرصدة](#الأرصدة) |
| التجديد | تاريخ التجديد القادم |
| الاستهلاك | جهات الاتصال، والقنوات، والمقاعد، وواتساب، والذكاء الاصطناعي، والأتمتة، والرسائل التسويقية |
| **التفعيل** | خطوات الإعداد التي أنجزتها المساحة، مثل إضافة وسيلة دفع أو ربط قناة أو دعوة الفريق |

## قوائم المتابعة

استخدم **قائمة المتابعة** للوصول مباشرة للعملاء الذين يحتاجون انتباهك:

| القائمة | تعرض |
| --- | --- |
| **يحتاج إلى رصيد** | رصيد منخفض أو فواتير مفتوحة |
| **موثوق ورصيده منخفض** | عملاء مسموح لهم بالاستمرار على الائتمان ورصيدهم منخفض |
| **الأقل تفعيلًا** | عملاء لم يكملوا الإعداد |
| **الأكثر إنفاقاً (+$100)** | العملاء الذين دفعوا أكثر حتى الآن |

وتستطيع البحث، والتصفية حسب الحالة أو الخطة أو خطوة الإعداد، والترتيب حسب أي عمود. وصفحة **نظرة عامة** تعرض عدد كل قائمة لتراها بنظرة.

## الأرصدة

| القيمة | المعنى |
| --- | --- |
| **القابل للإنفاق** | الرصيد المتبقي بعد الاستهلاك المستخدم في هذه الفترة والبنود المعلقة لمرة واحدة. هذا الرقم هو ما يحدد إن كان العميل سيُقيَّد |
| المحسوب بالاستهلاك | استهلاك هذه الفترة الذي سيُخصم من المحفظة |
| المعلّق | بنود لمرة واحدة بانتظار الفاتورة القادمة |
| الاشتراك | مبلغ الخطة لهذه الدورة، للاطلاع |
| الفواتير المفتوحة | فواتير غير مدفوعة تحتاج دفعاً أو تغطية منك |
| إجمالي المدفوع | كل ما دفعه العميل: شحن بالبطاقة وفواتير مدفوعة. تحويلاتك لا تُحسب |

القائمة تعتمد على أرصدة فُحصت مؤخراً، أما صفحة التفاصيل فتقرأ المحفظة مباشرة.
