---
title: "حل المشاكل"
description: "حلول لمشاكل شائعة في بوابة الشريك وPartner API."
---

| المشكلة | الحل |
| --- | --- |
| **لا أستطيع حفظ الهوية البصرية** | الهوية المخصصة غير مفعّلة لحسابك. اطلبها من مدير حسابك |
| **شاشة النطاقات تعرض "اطلب فتح هذه الميزة"** | النطاقات المخصصة غير مفعّلة لحسابك. اطلبها من مدير حسابك |
| **النطاق يبقى قيد الانتظار** | سجل CNAME لم يظهر بعد. تحقق منه عند مزوّد الـ DNS، وانتظر التحديث، ثم اضغط **تحقق** مجدداً |
| **"Partner price cannot be below system cost"** | ارفع السعر إلى التكلفة الظاهرة للخطة الأساسية على الأقل |
| **"Only one … plan is allowed per partner"** | لديك خطة على نفس الخطة الأساسية. عدّلها بدل إنشاء جديدة |
| **"Feature overrides cannot grant features…"** | حاولت تفعيل ميزة غير موجودة في الخطة الأساسية. اختر خطة أساسية أعلى |
| **رُفض الرصيد الابتدائي أو التحويل** | محفظة مساحتك لا تغطي المبلغ. اشحنها من **الفوترة** أولاً |
| **العميل لا يستطيع إرسال رسائل واتساب** | محفظته فارغة أو مقيّدة. راجع **القابل للإنفاق** في صفحة تفاصيله وأضف رصيداً |
| **لم تصل الدعوة للعميل** | تحقق من البريد. وإذا كنت تستخدم SMTP خاصاً، شغّل **اختبار الاتصال** من **الإعدادات ← البريد الإلكتروني** |
| **بريد المرسل لا يُستخدم** | المرسل المخصص يعمل فقط مع خادم SMTP خاص بك. اضبطه من **الإعدادات ← البريد الإلكتروني** |
| **رابط الربط يعرض "غير صالح"** | تحقق من رمز الشريك، و`organization_id` الخاص بالعميل، وأنك توقّع بمفتاح المنصّة الحالي |
| **Webhook الشريك لا يُحفظ** | يجب أن يكون خادمك `https` عاماً ويرد بـ `2xx` خلال 10 ثوانٍ |
| **الـ API ترجع خطأ صلاحيات** | مفتاح الـ API يحتاج صلاحية `partner:read` أو `partner:write`، ويجب أن يكون العميل من عملائك |

## ما زالت المشكلة قائمة؟

تواصل مع مدير حسابك في كرزون، واذكر عنوان مساحة العميل وما جرّبته.
