افتح **بوابة الشريك ← الأرباح**.

## كيف تكسب

تكسب عمولة عندما يدفع عملاؤك فواتير اشتراكاتهم، بالنسب المحددة في اتفاقية الشراكة. كل فاتورة مدفوعة تُنشئ سجل عمولة.

وفي صفحة [الخطط](/ar/partners/plans/plans)، يعرض **هامشك** الفرق بين سعرك وتكلفة النظام لكل خطة.

## ماذا ترى

| | يعرض |
| --- | --- |
| **إجمالي الأرباح** و**المبلغ المعلق** و**المبلغ المدفوع** | عمولتك حتى الآن، وما لم يُدفع لك بعد، وما دُفع |
| **ملخص العمولات** | الإجماليات، ومتوسط العمولة، والنمو الشهري |
| **توقع الإيرادات** | العمولة المتوقعة للأشهر الثلاثة القادمة بناءً على التجديدات |
| **آخر العمولات** | أحدث السجلات، و**عرض الكل** يفتح القائمة كاملة |

## قائمة العمولات

كل سجل يعرض العميل والخطة وفترة الفوترة والمبلغ الأساسي والنسبة والعمولة. صفِّ حسب الحالة:

| الحالة | المعنى |
| --- | --- |
| **قيد الانتظار** | مكتسبة ولم تُدفع بعد |
| **قيد المعالجة** | ضمن دفعة قيد التجهيز |
| **مدفوع** | دُفعت لك |
| **مسترجع** | استُرجعت، مثلاً بعد استرداد مبلغ |
| **ملغاة** | غير مستحقة الدفع |

اضغط على أي سجل لترى بنوده.

## الدفعات

دفع أرباحك يتم حسب اتفاقية الشراكة. تواصل مع مدير حسابك لترتيب دفعة.
