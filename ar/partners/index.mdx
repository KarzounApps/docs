برنامج شركاء كرزون يتيح لك بناء نشاطك الخاص فوق كرزون. تنشئ مساحة عمل لكل عميل، بعلامتك وأسعارك، وتدير الجميع من بوابة شريك واحدة.

## لمن البرنامج

- **الوكالات** التي تجهّز واتساب وصندوق الوارد والأتمتة لعملائها وتديرها لهم.
- **الموزّعون** الذين يبيعون باقات كرزون في سوقهم بأسعارهم.
- **منصات البرمجيات** (المتاجر، وأنظمة CRM والحجوزات وERP) التي تقدّم واتساب لمستخدميها عبر [WhatsApp API](/ar/whatsapp-api).

## ماذا تبيع

| | يحصل عليه عملاؤك |
| --- | --- |
| **منصة كرزون** | صندوق وارد مشترك، واتساب وقنوات أخرى، أتمتة، حملات، ذكاء اصطناعي، جهات اتصال وتقارير، كلها بعلامتك |
| **WhatsApp API** | مفاتيح API وWebhooks لأرقامهم، لربط واتساب بأنظمتهم أو بنظامك |
| **الاثنين** | أي مزيج، عميلاً عميلاً. كل عميل على الخطة التي تختارها له |
