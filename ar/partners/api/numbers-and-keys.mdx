## اعرض الأرقام

```graphql
query {
  partnerChannels {
    organizationId
    subdomain
    integrationId
    phoneNumber
    status
    qualityRating
    messagingLimitTier
    apiKeyHint
    webhookUrl
    error
  }
}
```

مرّر `organizationId` لتعرض أرقام عميل واحد فقط.

| الحقل | المعنى |
| --- | --- |
| `integrationId` | معرّف الرقم في كرزون، تستخدمه للمفاتيح |
| `phoneNumber`، `phoneNumberId`، `wabaId` | الرقم، ومعرّفاته عند ميتا |
| `status`، `qualityRating`، `messagingLimitTier`، `nameStatus` | مباشرة من ميتا، مثل `CONNECTED` و`GREEN` و`TIER_1K` |
| `accountMode` | `cloud_api`، أو `coexistence` إذا كان الرقم يعمل أيضاً على تطبيق واتساب للأعمال |
| `apiKeyHint` | أول أحرف المفتاح الفعّال، أو `null` |
| `webhookUrl` | رابط Webhook الرقم، أو `null` |
| `error` | يظهر إذا تعذّر الوصول إلى ميتا لهذا الرقم |

## أنشئ مفتاح API

```graphql
mutation {
  partnerChannelApiKeyCreate(organizationId: "ORG_ID", integrationId: "INTEGRATION_ID") {
    token
    hint
  }
}
```

`token` هو المفتاح كاملاً، ويرجع **مرة واحدة فقط**. احفظه في مدير الأسرار عندك واستخدمه كـ `Karzoun-API-Key` مع [WhatsApp API](/ar/whatsapp-api/authentication). إنشاء مفتاح جديد يستبدل مفتاح الرقم السابق.

الأفضل أن تنشئ المفتاح لحظة وصول حدث [`channel.connected`](/ar/partners/webhook)، فيكتمل ربط العميل بدون أن يفتح أحد لوحة التحكم.

## أبطل مفتاحاً

```graphql
mutation {
  partnerChannelApiKeyRevoke(organizationId: "ORG_ID", integrationId: "INTEGRATION_ID")
}
```

كل طلب بهذا المفتاح يرجع `401` من تلك اللحظة.

## اضبط Webhook الرقم

استخدم المفتاح الجديد لتوجيه أحداث الرقم إلى منصتك:

```bash
curl -X POST https://waba.karzoun.chat/webhook \
  -H "Karzoun-API-Key: THE_NEW_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://platform.example/whatsapp/acme" }'
```

راجع [Webhooks](/ar/whatsapp-api/webhooks/overview).
