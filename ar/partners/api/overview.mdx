Partner API تنفّذ من نظامك ما تفعله بوابة الشريك يدوياً: إضافة العملاء، وتمويلهم، ومتابعة أرقامهم، وإصدار مفاتيحهم.

## الـ Endpoint والمصادقة

Partner API جزء من واجهة GraphQL في كرزون. الطلبات تذهب إلى **مساحة الشريك**:

```
POST https://YOUR_PARTNER_SUBDOMAIN.api.karzoun.chat/graphql
Authorization: Bearer kz_live_YOUR_API_KEY
Content-Type: application/json
```

أنشئ المفتاح من مساحة الشريك عبر **المطوّر ← مفاتيح API** بهذه الصلاحيات:

| الصلاحية | تتيح |
| --- | --- |
| `partner:read` | ملفك ومحفظتك، والعملاء وأرصدتهم، والأرقام عبر العملاء، والأرباح، وسجل Webhook الشريك |
| `partner:write` | إنشاء العملاء وتمويلهم وتعليقهم، وإصدار مفاتيح الأرقام وإبطالها، واختبار Webhook الشريك وإعادة إرساله |

## مسار نموذجي

<Steps>
  <Step title="اختر خطة">
    [`partnerPlans`](/ar/partners/api/reference/partner-plans) تعرض خططك ومعرّفاتها.
  </Step>
  <Step title="أنشئ العميل">
    [`partnerRegisterOrganization`](/ar/partners/api/reference/partner-register-organization)، مع رصيد ابتدائي اختياري.
  </Step>
  <Step title="اربط رقم واتساب">
    أرسل للعميل [رابط ربط](/ar/partners/connect-links). يعمل بدون تسجيل دخول إلى كرزون.
  </Step>
  <Step title="أصدر مفتاح API">
    عندما يصل [`channel.connected`](/ar/partners/webhook)، استدعِ [`partnerChannelApiKeyCreate`](/ar/partners/api/reference/partner-channel-api-key-create).
  </Step>
  <Step title="حافظ على التشغيل">
    راقب الأرصدة عبر [`partnerOrganizationMonitor`](/ar/partners/api/reference/partner-organization-monitor) أو حدث `wallet.low_balance`، واشحن عبر [`partnerTransferBalance`](/ar/partners/api/reference/partner-transfer-balance).
  </Step>
</Steps>

## العمليات

| العملية | النوع | الصلاحية | الاستخدام |
| --- | --- | --- | --- |
| [`partner`](/ar/partners/api/reference/partner) | Query | read | ملف الشريك ومحفظة المساحة |
| [`partnerPlans`](/ar/partners/api/reference/partner-plans) | Query | read | الخطط التي تعيّنها للعملاء |
| [`partnerOrganizationMonitor`](/ar/partners/api/reference/partner-organization-monitor) | Query | read | العملاء مع الأرصدة والاستهلاك والحالة |
| [`partnerOrganizationDetail`](/ar/partners/api/reference/partner-organization-detail) | Query | read | عميل واحد مع قراءة مباشرة للمحفظة |
| [`partnerChannels`](/ar/partners/api/reference/partner-channels) | Query | read | أرقام واتساب عبر العملاء |
| [`partnerWallet`](/ar/partners/api/reference/partner-wallet) | Query | read | رصيد أرباحك |
| [`partnerWebhookDeliveries`](/ar/partners/api/reference/partner-webhook-deliveries) | Query | read | سجل Webhook الشريك |
| [`partnerRegisterOrganization`](/ar/partners/api/reference/partner-register-organization) | Mutation | write | إنشاء مساحة عميل |
| [`partnerTransferBalance`](/ar/partners/api/reference/partner-transfer-balance) | Mutation | write | تحويل رصيد من محفظتك لعميل |
| [`partnerSuspendOrganizations`](/ar/partners/api/reference/partner-suspend-organizations) | Mutation | write | تعليق العملاء أو إعادة تفعيلهم |
| [`partnerChannelApiKeyCreate`](/ar/partners/api/reference/partner-channel-api-key-create) | Mutation | write | إصدار مفتاح API لرقم عميل |
| [`partnerChannelApiKeyRevoke`](/ar/partners/api/reference/partner-channel-api-key-revoke) | Mutation | write | إبطاله |
| [`partnerTestWebhook`](/ar/partners/api/reference/partner-test-webhook) | Mutation | write | إرسال حدث تجريبي لـ Webhook الشريك |
| [`partnerWebhookResend`](/ar/partners/api/reference/partner-webhook-resend) | Mutation | write | إعادة إرسال حدث فاشل |

الإعدادات مثل الهوية البصرية والخطط والنطاقات تُدار من بوابة الشريك فقط.

## الأخطاء

الأخطاء تصل في مصفوفة `errors` الخاصة بـ GraphQL مع رسالة، مثل `initialBalance must be a non-negative number`. وغياب الصلاحية، أو استخدام مؤسسة ليست من عملائك، يرجع خطأ صلاحيات.
