Query · الصلاحية `partner:read`

أرباحك من العمولات، بنفس إجماليات **بوابة الشريك ← الأرباح**. أما الرصيد الذي تموّل به العملاء فهو حقل `wallet` في [`partner`](/ar/partners/api/reference/partner). راجع [الأرباح](/ar/partners/money/earnings).

بدون وسائط.

## مثال

```graphql
query {
  partnerWallet { availableBalance pendingBalance totalPaidOut currency }
}
```

```json
{
  "data": {
    "partnerWallet": { "availableBalance": 310.4, "pendingBalance": 95, "totalPaidOut": 1200, "currency": "usd" }
  }
}
```
