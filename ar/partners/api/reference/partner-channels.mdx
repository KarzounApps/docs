Query · الصلاحية `partner:read`

راجع [أرقام عملائك](/ar/partners/whatsapp/numbers) لمعنى كل حقل.

## الوسائط

| الوسيط | النوع | ملاحظات |
| --- | --- | --- |
| `organizationId` | `ID` | اختياري. أرقام هذا العميل فقط |

## مثال

```graphql
query {
  partnerChannels {
    organizationId
    subdomain
    integrationId
    phoneNumber
    status
    qualityRating
    messagingLimitTier
    apiKeyHint
    error
  }
}
```
