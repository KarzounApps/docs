Query · الصلاحية `partner:read`

الأحداث المرسلة إلى [Webhook الشريك](/ar/partners/webhook) خلال آخر 30 يوماً، الأحدث أولاً.

## الوسائط

| الوسيط | النوع | ملاحظات |
| --- | --- | --- |
| `state` | `String` | `pending` أو `success` أو `failed` |
| `page` | `Int` | الافتراضي 1 |
| `perPage` | `Int` | الافتراضي 20، وبحد أقصى 100 |

## مثال

```graphql
query {
  partnerWebhookDeliveries(state: "failed") {
    list { eventId event subdomain state attempts lastStatus lastError nextAttemptAt canResend createdAt }
    totalCount
  }
}
```
