Query · الصلاحية `partner:read`

يعرض [خططك](/ar/partners/plans/plans). استخدم `_id` الخطة كقيمة `planId` عند [إنشاء عميل](/ar/partners/api/reference/partner-register-organization).

## الوسائط

| الوسيط | النوع | ملاحظات |
| --- | --- | --- |
| `page` | `Int` | الافتراضي 1 |
| `perPage` | `Int` | الافتراضي 20 |
| `status` | `PlanStatus` | تصفية حسب الحالة |
| `type` | `PlanType` | `API`، `BASIC`، `PRO`، `BUSINESS`، `ENTERPRISE`… |
| `billingCycle` | `BillingCycle` | تصفية حسب الدورة |
| `search` | `String` | بحث في الاسم |

## مثال

```graphql
query {
  partnerPlans(type: API) {
    data { _id name type amount currency billingCycle features }
    pagination { totalCount }
  }
}
```

```json
{
  "data": {
    "partnerPlans": {
      "data": [
        { "_id": "6651bb…", "name": "WhatsApp API", "type": "API", "amount": 49, "currency": "usd", "billingCycle": "MONTHLY", "features": ["API keys per number", "Webhooks"] }
      ],
      "pagination": { "totalCount": 1 }
    }
  }
}
```

استخدم خطة من نوع `API` للعملاء الذين يستخدمون WhatsApp API فقط.
