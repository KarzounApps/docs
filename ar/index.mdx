مكان واحد يشغّل محادثات عملائك — بقوة منصة، ببساطة يفهمها فريقك.

## ماذا تفعل بكروزون؟

ستة أنظمة تتشارك ملف عميل واحداً ووارداً واحداً والسياق نفسه — عميقة بما يكفي لتعمل وحدها، وأقوى معاً.

| المحور | ماذا يعني لفريقك |
| --- | --- |
| **البريد الوارد** | واتساب وإنستغرام وتيك توك وماسنجر والبريد ودردشة الموقع في وارد واحد — مع سياق العميل بجانب كل محادثة |
| **واتساب للأعمال** | الواجهة الرسمية، القوالب، الفلو، التجارة داخل المحادثة، والمكالمات من نفس الحوار |
| **الأتمتة** | مسارات مرئية بلا كود: ترحيب، متابعة، إسناد، استرداد سلة، وربط بالمتجر |
| **النمو** | Karzoun Pixel والشرائح والحملات على واتساب والبريد وPush — وصول للشخص الصحيح |
| **الذكاء الاصطناعي** | Copilot لفريقك ووكلاء للعملاء — بمعرفة ومهارات وتصعيد واضح |
| **مساحة عمل الفريق** | مهام، شات داخلي، اجتماعات، حضور، أدوار، وتقارير كلما كبرت |
