---
title: "ساحة GraphQL"
description: "افتح ساحة GraphQL التفاعلية لكرزون لاستكشاف الواجهة العامة."
---

استخدم الساحة المستضافة لتشغيل الاستعلامات والطفرات على حسابك في كرزون. تستدعي الواجهة بصفتك وأنت مسجّل الدخول. لتجربة مفتاح API، أضف `Authorization: Bearer kz_live_…` في لوحة الترويسات.

<Card title="فتح الساحة" icon="terminal" href="https://karzoun.chat/developer/playground">
  محرر GraphQL تفاعلي داخل لوحة مطوّري كرزون.
</Card>

## قبل أن تبدأ

1. سجّل الدخول، أو أنشئ [مفتاح API](/ar/developers/getting-started/authentication) إن أردت تجربة مفتاح بدل جلستك
2. اعرف عنوانك: `https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql`
3. نزّل مخطط SDL العام في أي وقت: `https://YOUR_SUBDOMAIN.api.karzoun.chat/public-api.graphql`
4. راجع مرجع المخطط في هذا التبويب لتوثيق الحقول والأنواع

<Tip>
  لا تلصق مفاتيح API الإنتاجية في شاشات مشتركة أو تسجيلات.
</Tip>
