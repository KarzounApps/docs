عندما تحتاج اتجاهات الأسبوع لا مراقبة كل محادثة لحظة بلحظة، قائمة الوارد وحدها لا تكفي لاجتماع التشغيل.

توفّر **الرؤى** في كرزون (`/insights`) لوحات تحكم تبنيها من رسوم بيانية جاهزة — لمراقبة **الاتجاهات** لا للمتابعة اللحظية للمحادثات. المتابعة اليومية من [البريد الوارد](/ar/help-center/guides/inbox/supervise-queue).

يشرح هذا الدليل ماذا تتابع، وكيف تُبنى اللوحة، ومتى تستخدم الرؤى مقابل تقارير أخرى.

## ماذا يمكنك متابعته؟

| المجال | أمثلة رسوم |
| --- | --- |
| **المحادثات** | حجم الوارد، سرعة الرد، SLA، معدل الإغلاق، خريطة حرارة الذروة، انتظار العميل للرد الآن |
| **رضا العملاء (CSAT)** | اتجاه الرضا، حسب الموظف/القسم، توزيع التقييمات |
| **جهات الاتصال** | نمو العملاء، حسب الدولة/الحالة/الاشتراك |
| **المهام** | قوالب مهام في منتقي مصدر الرسم (عدد، حسب الحالة/المسند إليه، متأخرة…) إن كانت إضافة المهام مفعّلة |

## البنية

| المكوّن | الوظيفة |
| --- | --- |
| **لوحة تحكم** | مجموعة رسوم على شبكة — تبويبات متعددة ممكنة |
| **مجلد (مجموعة)** | تنظيم اللوحات في الشريط الجانبي |
| **رسم بياني** | مصدر بيانات + نوع (خط، عمود، جدول…) + **فلاتر خاصة بالرسم** |
| **إنشاء سريع** | `/insights/quick-create` — معالج قالب → رسوم → تفاصيل |

<Note>
لا تعتمد على فلتر تاريخ/قناة/مقارنة **على مستوى اللوحة** لتغيير كل الرسوم — الضبط الفعّال اليوم من [فلاتر كل رسم](/ar/help-center/guides/insights/charts-and-filters).
</Note>

## الرؤى مقابل تقارير أخرى

| السطح | متى |
| --- | --- |
| **الرؤى** | لوحات مخصصة، اتجاهات، CSAT، قوالب محادثات/عملاء/مهام |
| **تحليلات الحملات** | `/broadcast/analytics` — تسليم واتساب/بريد |
| **ملف العميل** | CSAT لعميل واحد |
| **الصفحة الرئيسية** | لمحة سريعة — ليست بديل لوحة كاملة |

## الخطوة التالية

تعلّمت أن الرؤى للاتجاهات لا للمراقبة اللحظية. بعد ذلك:

- أنشئ أول لوحة من [إنشاء لوحة تحكم](/ar/help-center/guides/insights/create-dashboard).
- أو ابدأ بقوالب التشغيل من [تقارير المحادثات](/ar/help-center/guides/insights/conversation-reports).
