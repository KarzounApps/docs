**الرؤى** (`/insights`) هي لوحات تحكم تبنيها من رسوم بيانية جاهزة — لمراقبة **الاتجاهات** لا للمراقبة اللحظية للمحادثات. المتابعة اليومية من [البريد الوارد](/ar/help-center/guides/inbox/supervise-queue).

## ماذا يمكنك متابعته؟

| المجال | أمثلة رسوم |
| --- | --- |
| **المحادثات** | حجم الوارد، سرعة الرد، SLA، معدل الإغلاق، خريطة حرارة الذروة |
| **رضا العملاء (CSAT)** | اتجاه الرضا، حسب الموظف/القسم، توزيع التقييمات |
| **جهات الاتصال** | نمو العملاء، حسب الدولة/الحالة/الاشتراك |

<Info>
**وسائط مطلوبة:** شاشة **الرؤى** مع شريط جانبي «لوحات التحكم»، لوحة مفتوحة بعدة رسوم، ومحدّد نطاق التاريخ.  
المسار المقترح: `/images/help/insights/overview-dashboard.webp`
</Info>

## البنية

| المكوّن | الوظيفة |
| --- | --- |
| **لوحة تحكم** | مجموعة رسوم على شبكة — تبويبات متعددة ممكنة |
| **مجلد (مجموعة)** | تنظيم اللوحات في الشريط الجانبي |
| **رسم بياني** | مصدر بيانات + نوع (خط، عمود، جدول…) + فلاتر |
| **إنشاء سريع** | `/insights/quick-create` — معالج قالب → رسوم → تفاصيل |

## الرؤى مقابل تقارير أخرى

| السurface | متى |
| --- | --- |
| **الرؤى** | لوحات مخصصة، مقارنة فترات، CSAT، اتجاهات |
| **تحليلات الحملات** | `/broadcast/analytics` — تسليم واتساب/بريد |
| **ملف العميل** | CSAT لعميل واحد |
| **الصفحة الرئيسية** | لمحة سريعة — ليست بديل لوحة كاملة |
