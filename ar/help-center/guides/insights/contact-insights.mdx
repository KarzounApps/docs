لوحة التشغيل تركز على **المحادثات**؛ قبل الحملة أو مراجعة الشرائح تحتاج صورة عن **من في قاعدتك** وكيف تتغيّر.

**رؤى جهات الاتصال** قوالب رسوم في **الرؤى** — البيانات من [جهات الاتصال](/ar/help-center/guides/contacts/overview) وليس من تقارير منفصلة.

يشرح هذا الدليل قوالب النمو والتركيبة والـ Pivot، ومتى تستخدمها قبل حملة أو استيراد.

> مفيد قبل [حملة تسويقية](/ar/help-center/guides/broadcasts/overview) أو مراجعة [شرائح](/ar/help-center/guides/segments/overview).

## نظرة عامة على القاعدة

| القالب | ماذا يجيب |
| --- | --- |
| **إجمالي عدد العملاء** | حجم القاعدة الآن |
| **العملاء المُنشأون حسب السنة / الشهر / اليوم** | وتيرة النمو |
| **العملاء حسب الحالة** | عميل / عميل محتمل / … |
| **العملاء حسب مرحلة العميل المحتمل** | خط الأنابيب (إن استخدمت المراحل) |

## التركيبة الديموغرافية والجودة

| القالب | الاستخدام |
| --- | --- |
| **حسب البلد / المنطقة (State)** | توزيع جغرافي |
| **حسب الجنس** | عند اكتمال الحقل |
| **حسب سلة/نقاط الملف** | جودة البيانات أو engagement |
| **حسب صلاحية البريد / الهاتف** | نظافة القاعدة قبل حملة (تحقق البريد/الهاتف) |
| **حسب الاشتراك في التسويق** | من يصلح لـ [الرسائل الجماعية](/ar/help-center/guides/broadcasts/overview) |

<Note>
قالب **العملاء حسب الصلاحية** / `customersByHasAuthority` **غير متاح** في كتالوج الرسوم النشط اليوم — لا تبحث عنه في المنتقي.
</Note>

## تواريخ الميلاد (إن وُجدت)

| القالب | فكرة |
| --- | --- |
| **حسب العمر** | شرائح عمرية |
| **حسب شهر / يوم الميلاد** | حملات موسمية |

## Pivot: تقاطعات زمنية

| القالب | مثال سؤال |
| --- | --- |
| **Pivot: الحالة × الشهر** | هل التحويل ل«عميل» يتسارع؟ |
| **Pivot: المنطقة × الشهر** | أي سوق ينمو؟ |

## متى تستخدم هذه الرسوم؟

| الموقف | الرسم |
| --- | --- |
| اجتماع تسويق شهري | إنشاء حسب الشهر + حسب الاشتراك |
| قبل استيراد CSV | حسب صلاحية البريد |
| مراجعة CRM | حسب الحالة + Pivot |

<Warning>
الرسوم تعكس **ما في السجل** — استيراد مكرر أو [دمج](/ar/help-center/guides/contacts/merge) ناقص يشوّه النمو. نظّف القاعدة قبل قرارات كبيرة.
</Warning>

## الفرق عن صفحة جهات الاتصال

| سطح | دور |
| --- | --- |
| **قائمة جهات الاتصال** | بحث، تعديل، جماعي |
| **الشرائح** | جمهور ديناميكي |
| **رؤى جهات الاتصال** | اتجاهات وتركيبة — لا تعديل سجل |

## الخطوة التالية

تعلّمت كيف تقرأ نمو القاعدة قبل الحملة. بعد ذلك:

- ابنِ جمهوراً من [الشرائح](/ar/help-center/guides/segments/overview).
- اضبط فلاتر الرسم من [الرسوم والفلاتر](/ar/help-center/guides/insights/charts-and-filters).
