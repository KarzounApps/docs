عندما ينتهي التفاعل، يبقى سؤال الجودة: هل كان العميل راضياً — وهل المشكلة في قسم أو وقت أو موظف؟

**رضا العملاء (CSAT)** في كرزون يُتابَع من **قوالب رسوم الرضا** داخل **الرؤى** — وليس من مسار `/csat` مستقل.

يشرح هذا الدليل أين تُجمع التقييمات، وأي قوالب تستخدم، وكيف تقرأ CSAT بمسؤولية.

> **شرط:** جمع التقييمات مفعّل في حسابك (بعد المحادثة أو عبر أتمتة/إجراء).

## أين تُجمع التقييمات؟

| المصدر | ماذا يحدث |
| --- | --- |
| **طلب تقييم بعد إغلاق** | رسالة للعميل بتقييم (حسب إعداد القناة/الأتمتة) |
| **إجراء «إدراج تقييم»** في الأتمتة | يضيف سجل رضا برمجياً |
| **ملاحظة يدوية** | نادر — للتصحيح لا للتقرير اليومي |

التقييمات الفردية تظهر أيضاً في [ملف جهة الاتصال](/ar/help-center/guides/contacts/profile) — مكمّل للوحة، لا بديلاً عنها.

## قوالب CSAT في الرؤى

| القالب | الاستخدام |
| --- | --- |
| **رضا العملاء (مختصر/متقدم)** | نظرة عامة + اتجاه |
| **تقييمات العملاء (رضا العميل)** | اتجاه التقييمات |
| **اتجاه متوسط الرضا مقابل عدد التقييمات** | جودة vs حجم — حذر من متوسط مضلل بعينة صغيرة |
| **رضا العملاء حسب القسم** | أي قسم يحتاج دعماً |
| **رضا العملاء حسب الموظف** | مراجعة أداء — استخدمها للتدريب لا للعقاب العشوائي |
| **اتجاه توزيع رضا العملاء (متقدم)** | تفصيل توزيع الدرجات |
| **رضا العملاء حسب يوم الأسبوع / ساعة اليوم** | توقيت ضعف الخدمة |
| **مخطط حرارة رضا العملاء (اليوم × الساعة)** | ذروة سوء التجربة |
| **رضا العملاء حسب تقييم سرعة الاستجابة** | هل البطء = رضا أقل؟ |
| **اتجاه حجم التقييمات المنخفضة** | تنبيه مبكر |

## كيف تقرأ CSAT بمسؤولية

| المبدأ | التطبيق |
| --- | --- |
| **حجم العينة** | متوسط ٤.٨ من ٣ تقييمات ≠ حقيقة |
| **قارن فترات** | اضبط **نطاق تاريخ** مختلفاً على رسمين متجاورين، أو صدّر CSV — لا تعتمد على «مقارنة لوحة» عامة (غير مفعّلة على الرسوم اليوم) |
| **اربط بالتشغيل** | رسم CSAT + [تقارير المحادثات](/ar/help-center/guides/insights/conversation-reports) بنفس فلتر التاريخ على كل رسم |
| **لا تعزل الموظف** | راجع القسم والقناة من فلاتر الرسم قبل الحكم |

## لوحة CSAT مقترحة

1. **رضا العملاء (مختصر/متقدم)** — KPI  
2. **حسب القسم** — أين المشكلة تنظيمية  
3. **حسب الموظف** — تدريب محدد  
4. **مخطط حرارة** — متى يحدث سوء التجربة  
5. **اتجاه التقييمات المنخفضة** — تنبيه

## عندما لا تظهر بيانات

| السبب | ماذا تفعل |
| --- | --- |
| لا طلبات تقييم | فعّل الإرسال بعد الإغلاق أو عبر [أتمتة](/ar/help-center/guides/automations/overview) |
| فترة فارغة | وسّع **نطاق التاريخ** من فلاتر الرسم |
| قناة واحدة بلا تقييم | اضبط فلتر القناة/التكامل على الرسم إن وُجد |

## أسئلة شائعة

**هل يوجد مسار `/csat` مستقل؟**  
لا. القوالب داخل الرؤى، والتفاصيل الفردية في ملف جهة الاتصال.

**هل قارن الفترات من أعلى اللوحة؟**  
لا تعتمد على مقارنة لوحة عامة اليوم — اضبط نطاق التاريخ على كل رسم أو صدّر CSV.

## الخطوة التالية

تعلّمت كيف تقرأ الرضا دون عقاب عشوائي. بعد ذلك:
