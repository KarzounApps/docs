عندما تبحث عن صورة أو مرفقاً ظهر أثناء حملة أو أتمتة، لن تجده دائماً داخل شجرة مجلدات الفريق.

تعرض **مكتبة الرفع** (`/filemanager/uploads`) ملفات رُفعت من البث والأتمتة وخدمات أخرى في الحساب — للتصفح والبحث والتنزيل. ليست شجرة مجلدات الفريق؛ تلك في [جميع الملفات](/ar/help-center/guides/file-manager/folders).

يشرح هذا الدليل ماذا ترى هنا، خطوات التصفح اليومية، ومتى تعود لسطح المجلدات.

في الشريط غالباً: **مدير الملفات** ← **الملفات المرفوعة**.

## ماذا ترى هنا؟

| العنصر | دوره |
| --- | --- |
| قائمة/شبكة الملفات | أصول جاءت من خدمات المنصة |
| بحث | تضييق بالاسم |
| فلاتر النوع | الكل · الصور · الفيديوهات · المستندات |
| تنزيل | حفظ نسخة محلية |

لا تنشئ مجلدات من هذه الصفحة ولا ترفع إليها كما في `/filemanager`. للتنظيم والمشاركة استخدم سطح المجلدات.

## خطوات يومية

1. افتح `/filemanager/uploads`.
2. ابحث أو صفِّ حسب النوع إن كثرت الملفات.
3. بدّل بين عرض الشبكة والقائمة حسب راحتك.
4. نزّل ما تحتاجه للمراجعة أو لإعادة الاستخدام خارج كرزون.

إن ظهرت قائمة فارغة بعد بحث أو فلتر: امسح البحث أو اختر **الكل** ثم أعد المحاولة.

## متى تستخدم المجلدات بدل هذه المكتبة؟

- تريد هيكل سياسات/أصول للفريق مع مجلدات ومشاركة → `/filemanager`
- تبحث عن مرفق ظهر أثناء حملة أو أتمتة → هذه المكتبة أولاً

## الخطوة التالية

وجدتَ الملف في مكتبة الرفع أو عرفتَ أنها ليست للمجلدات. بعد ذلك:

- للتنظيم والمشاركة: [المجلدات](/ar/help-center/guides/file-manager/folders) ثم [المشاركة](/ar/help-center/guides/file-manager/sharing).
- لسياق الحملات: [الحملات التسويقية](/ar/help-center/guides/broadcasts/overview).
