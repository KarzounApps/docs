عندما تحتاج متابعة بعنوان ومسؤول واستحقاق، الاكتفاء برد في المحادثة لا يكفي كسجل عمل.

المهمة بطاقة العمل الفردية داخل مرحلة مسار — وتُسمَّى **بطاقة دعم** حين ترتبط بعميل أو محادثة.

يشرح هذا الدليل كيف تنشئ مهمة، وحقولها، وبطاقة التفاصيل، وفرق الإكمال عن المرحلة.

## إنشاء مهمة

1. من **المهام** اختر اللوحة والمسار، ثم **مهمة جديدة** (أو من عمود المرحلة).
2. املأ الحقول الإلزامية على الأقل: **العنوان** و**المرحلة**.
3. أضف الأولوية والاستحقاق والمعيَّنين إن لزم.
4. وسّع **خيارات أكثر** للوصف وتاريخ البدء والتصنيفات والحقول المخصصة.
5. **إنشاء مهمة**.

## حقول الإنشاء والتعديل

| الحقل | إلزامي؟ | المعنى والاستخدام |
| --- | --- | --- |
| **العنوان** (ما الذي يجب إنجازه؟) | نعم | فعل واضح: «متابعة تأخير طلب 1055» لا اسم العميل فقط |
| **اللوحة** | عند الحاجة | الحساب |
| **المسار** | عند الحاجة | خط السير داخل اللوحة |
| **المرحلة** | نعم | العمود الابتدائي |
| **الأولوية** | لا | انظر الجدول أدناه |
| **تاريخ الاستحقاق** | لا | يُحفظ كـ `closeDate` — موعد الإنجاز المتوقع |
| **المُعيَّنون** | لا | من ينفّذ أو يتابع |
| **الوصف** | لا | تفاصيل داخلية للفريق |
| **تاريخ البدء** | لا | متى يبدأ العمل فعلياً |
| **التصنيفات** | لا | ألوان/أسماء سريعة على البطاقات |
| **خصائص مخصصة** | حسب إعدادكم | حقول مربوطة بلوحة/مسار من **الإعدادات ← الحقول المخصصة** (نوع **المهام**)؛ قد تكون إلزامية — انظر التحذير أسفل الجدول |

### الأولوية (قيم الواجهة الحالية)

| القيمة | التسمية العربية |
| --- | --- |
| `Critical` | **حرجة** |
| `High` | **مرتفعة** |
| `Normal` | **عادية** |
| `Low` | **منخفضة** |
| (فارغ) | بدون أولوية |

لا تستخدم مسميات قديمة مثل «عاجلة / متوسطة / عالية» في التدريب الداخلي إن كانت الواجهة تعرض الجدول أعلاه. وحّدوا لغة الفريق على هذه الأربع.

<Warning>
**تعريف** الخصائص المخصصة للمهام يتم من **الإعدادات** ← **الحقول المخصصة** (`/settings/properties`) مع نوع المحتوى **المهام**، بعد اختيار اللوحة والمسار. تبويب «الخصائص» داخل نافذة إعدادات المهام في `/tasks` **غير ظاهر حالياً** في الواجهة (معلّق في المنتج) — لا توجّه الفريق إليه. على بطاقة المهمة تملأ **قيم** الحقول فقط إن كانت معرّفة مسبقاً؛ إن ظهرت رسالة فارغة فالحقول غير مضبوطة لهذا المسار بعد.
</Warning>

<Tip>
تاريخ الاستحقاق هو `closeDate` في النظام — فلتر «متأخرة» و«غداً» يعتمد عليه. بلا تاريخ لن تظهر المهمة في عروض التقويم المعتمدة على الاستحقاق بنفس الوضوح.
</Tip>

## بطاقة التفاصيل

عند فتح مهمة تظهر لوحة بتفاصيل كاملة تقريباً:

| المنطقة | ماذا تفعل بها |
| --- | --- |
| **رأس البطاقة** | العنوان، الرقم المرجعي من ترقيم المسار، المسار/اللوحة، قائمة إجراءات (نسخ رابط، أرشفة، حذف، نقل…) |
| **خصائص** | المرحلة، المعيَّنون، الاستحقاق، الأولوية، التصنيفات، الوسوم، الأقسام/الفروع إن لزم |
| **الوصف** | نص غني للتفاصيل |
| **خصائص مخصصة** | قيم حقولكم |
| **قوائم التحقق** | بنود داخل المهمة دون إنشاء مهام منفصلة |
| **مهام فرعية** | مهام مرتبطة بأب (`parentId`) لها مراحلها وإكمالها |
| **مهام مرتبطة** | ربط ندّي بمهام أخرى في نفس اللوحة تقريباً |
| **المرفقات** | ملفات على البطاقة |
| **عملاء / شركات** | ربط جهة الاتصال أو الشركة |
| **محادثة مصدر** | إن وُلدت من الوارد أو رُبطت لاحقاً — للعودة للسياق |
| **تتبع الوقت** | تشغيل/إيقاف مؤقت للعمل على المهمة |
| **متابعة (Watch)** | تلقي تحديثات دون أن تكون المعيَّن الوحيد |
| **النشاط** | سجل النقل والتعديلات والملاحظات |

### قوائم التحقق مقابل الفرعية مقابل المرتبطة

| الأداة | متى |
| --- | --- |
| **قائمة تحقق** | خطوات قصيرة داخل نفس المهمة («اتصلت»، «بانتظار فاتورة») |
| **مهمة فرعية** | عمل يحتاج مسؤولاً أو تتبعاً منفصلاً تحت الأب |
| **مهمة مرتبطة** | اعتماد أو علاقة بين بطاقتين دون علاقة أب/ابن |

## الإكمال مقابل المرحلة

{/* MEDIA: /images/help/tasks/task-complete-gif.webp | GIF 4ث: تعليم المهمة مكتملة على البطاقة مع بقاء المرحلة ظاهرة */}
<Frame caption="GIF 4ث: تعليم المهمة مكتملة على البطاقة مع بقاء المرحلة ظاهرة">
  <img src="/images/help/tasks/task-complete-gif.webp" alt="تعليم المهمة مكتملة من بطاقة التفاصيل" />
</Frame>

| إجراء | النتيجة |
| --- | --- |
| نقل المرحلة إلى عمود «مكتملة» / `Done` | تغيّر موقع السير فقط — راجع [المرحلة](/ar/help-center/guides/tasks/stages) |
| تعليم المهمة مكتملة (`isComplete`) | تُحسب مكتملة في المقاييس والفلاتر التي تعتمد الإكمال |
| أرشفة المهمة | تخرج من اللوحة النشطة إلى **المهام المؤرشفة** ويمكن استعادتها |

<Warning>
لا تخلط «وصلت لعمود النهاية» مع «علّمتها مكتملة». القاعدة الآمنة للفريق: عند إنهاء العمل انقل للمرحلة النهائية **و** علّم الإكمال إن كان تقريركم يعتمد المكتملة.
</Warning>

## أرشفة وحذف

| الإجراء | قابلية التراجع |
| --- | --- |
| **أرشفة** | نعم عبر عرض المؤرشفة ثم الاستعادة للوحة |
| **حذف** | لا — تأكيد قبل التنفيذ |
