title: "العروض والفلاتر"
description: "كانبان وقائمة وتقويم ولوحة التحكم والخط الزمني والمؤرشفة: متى تستخدم كل عرض، وما تفعله الفلاتر."
---

نفس المسار يمكن قراءته بأكثر من **عرض**. العروض لا تغيّر هيكل اللوحة؛ تغيّر كيف ترى المهام وتفرزها. الفلاتر تضيّق المجموعة الظاهرة في العرض الحالي.

في `/tasks`: بدّل العرض من شريط أدوات المسار، وافتح الفلاتر من أيقونة التصفية. تُحفظ الفلاتر غالباً في رابط الصفحة (`f=…`) فيسهل مشاركة نفس المنظور.

## العروض المتاحة

| العرض | ماذا يظهر | متى تستخدمه |
| --- | --- | --- |
| **كانبان** | أعمدة = مراحل؛ بطاقات قابلة للسحب | التشغيل اليومي ونقل الحالة بسرعة |
| **قائمة** | جدول بأعمدة (عنوان، أولوية، مرحلة، استحقاق، معيَّنون…) | حجم كبير، فرز ومراجعة دفعة واحدة |
| **تقويم** | مهام حسب التواريخ (الاستحقاق أساساً) | التخطيط الأسبوعي والالتزامات الزمنية |
| **لوحة التحكم** | مؤشرات: إجمالي، مكتملة، متأخرة، مستحقة هذا الأسبوع… | نظرة مدير سريعة على صحة المسار |
| **الخط الزمني** | تخطيط زمني (واجهة غانت) | تتابع المهام والمدد على مدى أيام |
| **المهام المؤرشفة** | طبقة أرشيف فوق المسار (ليست وضع عرض كالباقي) | استعادة أو مراجعة ما أُخرج من اللوحة النشطة |

<Info>
**وسائط مطلوبة:** شريط تبديل العروض (كانبان · قائمة · تقويم · لوحة التحكم · الخط الزمني) مع كانبان نشط وشارة فلاتر.  
المسار المقترح: `/images/help/tasks/views-switcher.webp`  
**فيديو (مستحسن):** 20 ثانية للتبديل بين كانبان وقائمة وتقويم لنفس المسار.
</Info>

### ملاحظات دقة من المنتج

- **المؤرشفة** ليست قيمة ضمن `kanban|list|calendar|dashboard|timeline`؛ تُفتح كطبقة/وضع أرشيف على المسار ثم تُغلق للعودة للعمل.
- **لوحة التحكم** تعتمد مقاييس من المهام الظاهرة في المسار (مثل المكتملة عبر `isComplete` والمتأخرة عبر تاريخ الاستحقاق) — إن لم يعلّم الفريق الإكمال، عمود «مكتملة» في الكانبان وحده لا يكفي لكل البطاقات.
- **التقويم والخط الزمني** يضعف نفعهما بلا `closeDate` / تواريخ على البطاقات.
- الفلاتر تُطبَّق فوق ما تسمح به [خصوصية المسار والمرحلة](/ar/help-center/guides/tasks/visibility)؛ إن كان المسار «عرض المُسند فقط» فلن ترى بطاقات زملائك حتى بلا فلتر.

## الفلاتر الشائعة

| الفلتر | الاستخدام |
| --- | --- |
| **بحث نصي** | عنوان أو محتوى ظاهر في البحث |
| **الأولوية** | حرجة / مرتفعة / عادية / منخفضة (متعدد) |
| **أعضاء الفريق** | معيَّن محدد، غير مُعيَّن، أو مُسندة إليّ |
| **التصنيفات** | بطاقات بوسم لوني/اسم |
| **أُنشئت بواسطة** | بما فيه خيار يميّز إنشاًء من بوت إن وُجد |
| **فروع / أقسام** | تنظيم جغرافي أو إداري |
| **شركات / عملاء** | مهام مربوطة بجهة اتصال أو شركة |
| **تواريخ سريعة** | متأخرة · غداً · الأسبوع/الشهر القادم · بلا تاريخ استحقاق |
| **نطاق مخصص / تاريخ إنشاء** | نافذة زمنية أدق |
| **خصائص مخصصة** | فلاتر متقدمة على حقولكم |

<Tip>
احفظ رابط المتصفح بعد ضبط الفلاتر كـ«عرض جاهز» لوردية الدعم (مثلاً: مُسندة إليّ + متأخرة + أولوية حرجة/مرتفعة).
</Tip>

## متى أي عرض؟ (دليل سريع)

| هدفك | العرض |
| --- | --- |
| أنقل البلاغات بين حالات السير | كانبان |
| أراجع 80 مهمة وأرتّبها | قائمة |
| أخطّط أسبوع الاستحقاقات | تقويم |
| أسأل: كم متأخر؟ كم اكتمل؟ | لوحة التحكم |
| أرى تداخل المدد بين مهام مترابطة | الخط الزمني |
| أسترجع مهمة أُرشفت بالخطأ | المهام المؤرشفة |
