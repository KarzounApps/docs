يُعد **مركز المطور** في كرزون الواجهة الأساسية التي تتيح لك توسيع قدرات المنصة، وربطها بأنظمتك الخارجية، وبناء حلول مخصصة تلبي احتياجات عملك الدقيقة.

يوفر لك هذا القسم مجموعة متكاملة من الأدوات التي تسمح بالتكامل العميق بين كرزون وأي نظام آخر تستخدمه.

## أدوات مركز المطور

يحتوي مركز المطور على عدة أدوات رئيسية مصممة لتغطية مختلف سيناريوهات التكامل:

| الأداة                      | الوظيفة الأساسية                                                                          |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| **رموز API**                | إنشاء وإدارة رموز مصادقة آمنة للوصول البرمجي لبيانات كرزون وإجراء العمليات عن بُعد.       |
| **خطافات الويب (Webhooks)** | استقبال إشعارات فورية في نظامك عند حدوث أحداث معينة داخل كرزون (مثل استلام رسالة جديدة).  |
| **GraphQL Playground**      | بيئة تفاعلية لاختبار وبناء استعلامات وتعديلات GraphQL مباشرة على بيانات حسابك في كرزون.       |
| **تطبيقات لوحة التحكم**     | بناء واجهات مخصصة (iFrame) تظهر داخل شاشة المحادثة للوكلاء، لعرض بيانات من أنظمتك الخاصة. |
| **خادم MCP**                | ربط مساعدي الذكاء الاصطناعي الخارجيين (مثل Claude و Cursor) ببيانات كرزون.                |
| **مدير السكريبتات**         | إنشاء وتخصيص كود التضمين (Pixel) الخاص بكرزون لتتبّع زوار موقعك الإلكتروني.               |

## الموارد والتوثيق

في أسفل صفحة مركز المطور، ستجد قسماً مخصصاً للموارد والأدلة التي تساعدك على البدء:

- **مرجع API:** استعراض شامل لجميع استعلامات (Queries) وتعديلات (Mutations) الـ GraphQL المتاحة.

- **أحداث خطافات الويب:** قائمة مرجعية بكافة الأحداث التي يمكنك الاشتراك بها عبر الويب هوكس.

- **حزم SDK والمكتبات:** مكتبات برمجية جاهزة للغات الشائعة لتسريع عملية التطوير.

- **سجل التغييرات:** تحديثات دورية توضح الميزات الجديدة والتغييرات على الـ API.
