تُستخدم **رموز API (API Tokens)** في كرزون كوسيلة آمنة لمصادقة تطبيقاتك وأنظمتك الخارجية، مما يتيح لها التخاطب برمجياً مع منصة كرزون عبر الـ GraphQL API.

بفضل هذه الرموز، يمكنك قراءة البيانات، إرسال الرسائل، تحديث جهات الاتصال، وأتمتة المهام من خارج المنصة.

## كيفية إنشاء رمز API جديد

لإنشاء رمز وصول لتطبيقك:

1. من القائمة الجانبية، اذهب إلى **المطور** ثم اختر **رموز API**.![صفحة رموز API](/images/help/api-2279059/01-40b71fcbe8d8.webp)

1. انقر على زر **إنشاء رمز API** أو **تطبيق لوحة تحكم جديد**.![نموذج إنشاء رمز API](/images/help/api-2279059/02-9259fd109c5b.webp)

1. قم بتسمية التطبيق/الرمز باسم واضح يعكس الغرض منه (مثلاً: "تكامل نظام المحاسبة").

1. حدد الصلاحيات (Scopes) التي يحتاجها هذا الرمز. من الأفضل دائماً منح الصلاحيات الضرورية فقط لأسباب أمنية.

1. بمجرد الإنشاء، سيظهر لك الرمز السري. **قم بنسخه وحفظه في مكان آمن فوراً**، حيث لن يظهر لك مرة أخرى لأسباب أمنية.

## إدارة الرموز الحالية

من خلال صفحة التطبيقات ورموز API، يمكنك:

- رؤية قائمة بجميع الرموز النشطة والمنتهية الصلاحية.

- معرفة تاريخ الإنشاء وتاريخ آخر نشاط لكل رمز.

- مراجعة الصلاحيات الممنوحة لكل رمز.

- حذف الرموز التي لم تعد بحاجة إليها (باستخدام أيقونة سلة المهملات).

## توثيق API والبدء السريع

أسفل قائمة التطبيقات في صفحة رموز API، ستجد قسماً مخصصاً للبدء السريع (Quickstart) والتوثيق.

![قسم التوثيق والبدء السريع](/images/help/api-2279059/03-851c849968cc.webp)

يوضح لك هذا القسم كيفية المصادقة وإجراء طلبات API باستخدام رمز التطبيق الذي أنشأته للتو. جميع طلبات API تمر عبر نقطة GraphQL واحدة، ويتم المصادقة عبر تمرير رمز التطبيق في ترويسة (Header) الطلب باسم `x-app-token`.

يوفر كرزون أمثلة شفرة (Code Snippets) جاهزة للاستخدام بثلاث لغات مختلفة لتسهيل البدء:

- **cURL:** لتنفيذ الطلبات مباشرة من سطر الأوامر.

- **JavaScript:** لاستخدامها في تطبيقات الويب أو Node.js.

- **Python:** للاستخدام في سكربتات تحليل البيانات أو الباك إند.

![مثال كود JavaScript](/images/help/api-2279059/04-4a12abeabf75.webp)

يمكنك ببساطة نسخ الكود المناسب للغتك البرمجية، استبدال `YOUR_APP_TOKEN` بالرمز السري الخاص بك، والبدء فوراً في التخاطب مع المنصة.
