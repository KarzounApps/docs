عندما تكثر الحملات، تحتاج إيجاد المسودة أو المتكرّر النشط بسرعة ثم إيقافاً أو نسخاً دون فتح كل سجل يدوياً.

من **الرسائل الجماعية** (`/broadcast`) ترى كل الحملات: الاسم، القناة، النوع، الحالة، التواريخ، وأحياناً ملخص أرقام سريع — مع إجراءات من الصف أو التفاصيل.

يشرح هذا الدليل البحث والتصفية، الإجراءات الشائعة، وما تجده في صفحة التفاصيل.

## البحث والتصفية

- ابحث بالاسم
- صفِّ بالقناة (واتساب، بريد، …) أو النوع (يدوي / متكرر / مشغّل زائر) أو الحالة
- رتّب حسب تاريخ الإنشاء أو الإرسال حسب أعمدة الجدول

## إجراءات شائعة

من صف الحملة أو صفحة التفاصيل (حسب ما يظهر في الواجهة):

| الإجراء | متى |
| --- | --- |
| **فتح التفاصيل** | متابعة التسليم والأخطاء والجمهور |
| **إيقاف مؤقت / استئناف** | حملات نشطة أو متكررة متوقفة مؤقتاً |
| **إيقاف نهائي / إلغاء** | إيقاف قبل أو أثناء الإرسال عند توفره — حالة طرفية |
| **إعادة المحاولة** | حملات بحالة **فشل** لإعادة التشغيل بعد الإصلاح |
| **تكرار / نسخ** | بناء حملة جديدة من إعدادات قديمة (مسودة) |
| **تعديل** | غالباً للمسودات؛ بعد النشر قد تكون الحقول مقفلة جزئياً |
| **حذف** | إزالة حملة لم تعد تحتاجها (بحذر) |

## صفحة التفاصيل

غالباً تجد: معلومات الإعداد، الجمهور، المحتوى، حالة التنفيذ، جداول التسليم أو الأخطاء، وروابط للتقارير.  
من تقارير واتساب قد يتوفر فتح المحادثة في الوارد — راجع [ردود الحملات والتسليم](/ar/help-center/guides/broadcasts/replies-handoff).  
للأرقام عبر عدة حملات: [التحليلات](/ar/help-center/guides/broadcasts/analytics).  
لعرض مواعيد **مرة واحدة** (وليس كل دورات المتكرر): [التقويم](/ar/help-center/guides/broadcasts/calendar).

## إعدادات سريعة

قد تظهر صفحة **إعدادات** تحت الرسائل الجماعية لاختبار البريد أو خيارات محدودة — لا تخلطها بإعدادات القنوات العامة (واتساب، SMTP…).

## أسئلة شائعة

**ما الفرق بين الإيقاف المؤقت والنهائي؟**  
المؤقت يمكن استئنافه غالباً. النهائي يوقف الحملة كحالة طرفية؛ للعمل مجدداً انسخ حملة أو أعد المحاولة إن كانت فاشلة وسمح الزر بذلك.

**متى أنسخ بدل إعادة المحاولة؟**  
عندما تحتاج تغيير الجمهور أو المحتوى أو القناة — النسخ يعطيك مسودة جديدة بأمان.
