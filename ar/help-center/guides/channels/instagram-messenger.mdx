عندما تصل رسائل إنستغرام المباشرة إلى التطبيق وحده، ينفصل الدعم عن بقية القنوات.

تربط قناة **رسائل إنستغرام** (في الإضافة: **ماسنجر إنستغرام**) حساب الأعمال ليظهر الـ DM في **البريد الوارد**.

يشرح هذا الدليل كيف تفوّض ميتا وتختار الحساب حتى رسالة اختبار.

المسار السريع: `/channels?add=instagram-messenger`.

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | تكامل `instagram-messenger` عبر حساب ميتا وحساب إنستغرام للأعمال/المحترفين المرتبط |
| **متى تظهر الرسائل** | بعد إكمال المعالج ووصول رسالة مباشرة جديدة |
| **الاستخدام** | دعم ومبيعات عبر DM من صندوق الفريق |
| **متى لا** | تريد تعليقات الريلز والمنشورات — استخدم [تعليقات إنستغرام](/ar/help-center/guides/channels/instagram-comments) |
| **الأثر** | محادثات إنستغرام داخل الوارد مع رد آلي اختياري |

## قبل أن تبدأ

- حساب إنستغرام مربوط بصفحة فيسبوك وفق متطلبات ميتا الحالية.  
- صلاحية على الحساب التجاري في ميتا.  
- قسم في كرزون لاختياره عند الإنشاء.

## بعد الربط

| المهمة | المكان |
| --- | --- |
| تعديل الاسم/القسم | `/channels/:id/edit` |
| الرد اليومي | [القنوات في البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) |
| بوت القناة | [الرد الآلي](/ar/help-center/guides/automations/channel-bots) |
| DM من مسار أتمتة | [رسالة مباشرة](/ar/help-center/guides/automations/nodes/actions/send-dm) |

<Warning>
نافذة المراسلة في ميتا وحدود الـ 24 ساعة تنطبق على كثير من الردود الاستباقية. خطط القوالب/الأزرار عبر الأتمتة عندما تحتاج خروجاً عن النافذة — التفاصيل في أدلة الأتمتة وواتساب/ميتا ذات الصلة.
</Warning>

## أخطاء شائعة

| العَرَض | التصرف |
| --- | --- |
| لا يظهر حساب إنستغرام | الحساب غير مربوط بصفحة وفق متطلبات ميتا، أو بلا صلاحية |
| الحساب «مستخدم» | قناة رسائل أخرى تستخدمه — عدّلها أو افصلها |
| لا تصل الرسائل | القناة غير نشطة، أو الرسالة خارج نوع الـ DM المدعوم |
