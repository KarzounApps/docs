عندما يريد العملاء الكتابة من واتساب والبريد والموقع، يتشتت الفريق إن بقيت كل قناة في تطبيقها.

تجمع **قنوات التواصل** في كرزون (`/channels`) الرسائل الواردة إلى **البريد الوارد** مع جهات الاتصال والأتمتة.

يشرح هذا الدليل أنواع القنوات المتاحة اليوم، وكيف تختار نقطة البداية، وماذا يحدث بعد الربط.

في التطبيق: **البريد الوارد** ← **القنوات** (`/channels`).

لفهرس مسؤول الربط: [مسار ربط القنوات](/ar/help-center/guides/channels/path-admin).

## ماذا تغطي هذه الوحدة؟

| هنا (قنوات التواصل) | في خدمة العملاء |
| --- | --- |
| إضافة القناة وربط الحساب | قراءة الرسالة والرد اليومي |
| إعداد القناة وقدراتها | الفلاتر والإسناد والحالات |
| أخطاء الربط الشائعة (خصوصاً واتساب) | تعليقات السوشيال والرد الخاص داخل الوارد |
| خريطة سريعة لما بعد الربط (مثل مدير واتساب) | المكالمات داخل الوارد |

بعبارة أخرى: هذه الصفحات تجيب «كيف أصلّح الاتصال؟»، وصفحات [خدمة العملاء](/ar/help-center/guides/inbox/overview) تجيب «كيف أعمل على الرسالة بعد وصولها؟».

## أنواع القنوات المتاحة اليوم

عند النقر على **إنشاء جديد** تظهر أنواع حقيقية في الواجهة — بلا فايبر أو تيليجرام:

| في نافذة الإضافة | صفحة الدليل |
| --- | --- |
| **الدردشة المباشرة** | [كرزون ماسنجر](/ar/help-center/guides/channels/messenger) |
| **واتساب** | [واتساب](/ar/help-center/guides/channels/whatsapp) |
| **ماسنجر فيسبوك** | [ماسنجر فيسبوك](/ar/help-center/guides/channels/facebook-messenger) |
| **تعليقات فيسبوك** | [تعليقات فيسبوك](/ar/help-center/guides/channels/facebook-comments) |
| **ماسنجر إنستغرام** / في الدليل: رسائل إنستغرام | [رسائل إنستغرام](/ar/help-center/guides/channels/instagram-messenger) |
| **تعليقات إنستغرام** | [تعليقات إنستغرام](/ar/help-center/guides/channels/instagram-comments) |
| **تيك توك** | [تيك توك للأعمال](/ar/help-center/guides/channels/tiktok) |
| **ويب هوك وارد** | [ويب هوك وارد](/ar/help-center/guides/channels/incoming-webhook) |
| **بريد إلكتروني للأعمال** | [بريد الأعمال من كرزون](/ar/help-center/guides/channels/business-email) |
| **ربط صندوق بريد موجود** | [بريد إلكتروني (IMAP/SMTP)](/ar/help-center/guides/channels/imap-email) |

كل قناة في **دليل القنوات** متساوية الأهمية في المرجع: لا توجد «قنوات إضافية» هامشية. البريد فقط له قائمة فرعية لأنه يحتاج مقارنة بين خيارين.

## كيف تختار من أين تبدأ؟

| هدفك | ابدأ من |
| --- | --- |
| لا أعرف أي قناة أربط أولاً | هذه الصفحة ثم [إضافة القنوات وإدارتها](/ar/help-center/guides/channels/add-and-manage) |
| موقع يزوره العملاء | [كرزون ماسنجر](/ar/help-center/guides/channels/messenger) |
| خط واتساب للأعمال | [واتساب](/ar/help-center/guides/channels/whatsapp) |
| صفحة فيسبوك أو حساب إنستغرام | صفحات الدليل الخاصة بكل نوع |
| رسائل تيك توك للأعمال | [تيك توك للأعمال](/ar/help-center/guides/channels/tiktok) |
| نظام داخلي يرسل رسائل إلى كرزون | [ويب هوك وارد](/ar/help-center/guides/channels/incoming-webhook) |
| بريد support@ أو صندوق Gmail موجود | [أي بريد أختار؟](/ar/help-center/guides/channels/email-choose) |

## بعد الربط: ماذا يحدث؟

1. تظهر القناة في قائمة `/channels` بحالة نشطة أو غير نشطة.  
2. تصل الرسائل إلى [البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) بشارة مصدر واضحة.  
3. تستطيع ضبط [الرد الآلي](/ar/help-center/guides/automations/channel-bots) لكل قناة تدعمه.  
4. بعض القنوات تفتح أسطحاً أعمق لاحقاً (مثل مدير واتساب للقوالب والتدفقات) — هنا نضع خريطة وروابط فقط؛ العمق في موجات لاحقة.

<Frame caption="من قائمة القنوات حتى ظهور الرسالة في الوارد">
  <video controls src="/images/help/channels/overview-after-connect-video.mp4" />

<Tip>
سمِّ كل قناة باسم يفهمه الفريق («واتساب المبيعات»، «تعليقات صفحة الرئيسي») واربطها بالقسم المناسب منذ الإنشاء. الاسم والقسم يظهران في الفرز اليومي.
</Tip>

## الخطوة التالية

تعلّمت خريطة القنوات وما يصل بعد الربط. بعد ذلك:

- ابدأ بـ [إضافة القنوات وإدارتها](/ar/help-center/guides/channels/add-and-manage) لأول تكامل.
- أو افتح [مسار ربط القنوات](/ar/help-center/guides/channels/path-admin) إن كنت ترتّب عدة أنواع.
