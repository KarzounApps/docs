عندما يملك نظام داخلي رسائل عملاء لا تمر بقناة جاهزة، تحتاج جسراً واضحاً إلى الوارد دون خلطه بأتمتة عامة.

تنشئ قناة **ويب هوك وارد** عنوان استقبال بمخطط ثابت فتنشأ المحادثة في **البريد الوارد** عند `POST` ناجح.

يشرح هذا الدليل حدود القناة، وكيف تملأ النموذج وترسل حمولة تجريبية، وما الحقول التي تهم التشغيل.

في الإضافة: **ويب هوك وارد** · `/channels?add=webhook`.

## وضّح الحدود أولاً

| هذا | ليس هذا |
| --- | --- |
| قناة وارد لمحادثات العملاء | مشغّل أتمتة «عند وصول ويب هوك» لأي جسم |
| مخطط حقول معروف (محتوى، عميل، شركة…) | استقبال حر بلا شكل |
| بديل لربط نظام داخلي/CRM بسيط | بديل عن [طلب HTTP](/ar/help-center/guides/automations/nodes/actions/http-request) الصادر من الأتمتة |
| تكامل تشغيل للفريق | مرجع مطوّر GraphQL الكامل |

إن احتجت المنصة أن **تستدعي** نظاماً خارجياً: ابنِ ذلك داخل مسار أتمتة بطلب HTTP. إن احتجت تطبيق متجر جاهز: راجع [التطبيقات](/ar/help-center/guides/automations/apps/overview).

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | تكامل `webhook` بعنوان استقبال ورمز/أصل للتحقق |
| **متى تظهر رسالة** | عند `POST` ناجح يتضمن محتوى رسالة وفق المخطط |
| **الاستخدام** | نماذج داخلية، أنظمة تذاكر قديمة، جسور مخصصة |
| **متى لا** | تريد فلو أتمتة يبدأ من حدث عشوائي بلا محادثة — هذا ليس المكان |
| **الأثر** | محادثة في الوارد يمكن للفريق الرد عليها كقناة عادية |

## قبل أن تبدأ

- نظام خارجي يستطيع إرسال `POST` إلى عنوان الاستقبال
- قسم في كرزون
- فهم الحدود أعلاه: مخطط ثابت لمحادثة واردة — ليس مشغّل أتمتة عاماً

## المخطط الثابت (ما يهم المشغّل)

جسم الطلب يدعم حقولاً محددة — أهمها للتشغيل:

| الحقل | الدور |
| --- | --- |
| **content** | نص الرسالة؛ بدونه لا تُنشأ رسالة محادثة بالمسار المعتاد |
| **customerFirstName / LastName / PrimaryEmail / PrimaryPhone / Code / Avatar / State** | إنشاء أو تحديث جهة الاتصال |
| **customFields** أو **data** | حقول مخصصة للعميل |
| **attachments** | مرفقات مرتبطة بالرسالة |
| **formContent** | عندما تكون الرسالة من نوع نموذج |
| **company…** | ربط أو إنشاء شركة اختيارياً |

التحقق: يجب أن يمرّر الطلب قيمة تطابق **الرمز** أو **الأصل** المعرّفين على القناة (حسب ما ضبطت). هناك أيضاً حماية تكرار قصيرة لنفس المحتوى والعميل — لا ترسل نفس التجربة مرات متتالية وتتوقع محادثات جديدة فورية.

<Warning>
الرد الآلي للبوت **غير مدعوم** على قناة ويب هوك وارد في المسار الحالي. صمّم التسليم للفريق البشري أو عالج المنطق في نظامك قبل الإرسال.
</Warning>

## بعد الربط

| إجراء | أين |
| --- | --- |
| تعديل الاسم/القسم | `/channels/:id/edit` |
| جلب البيانات | من قائمة إجراءات القناة عند توفره |
| العمل على الرسائل | [البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) |

للتوثيق البرمجي الأوسع (GraphQL، مفاتيح، ويب هوك مطوّر): تبويب المطوّرين — خارج مركز المساعدة التشغيلي.

## أخطاء شائعة

| العَرَض | التصرف |
| --- | --- |
| لا تُنشأ محادثة | الطلب بلا `content`، أو فشل التحقق من الرمز/الأصل |
| نفس التجربة لا تُنشئ محادثة جديدة | حماية تكرار قصيرة لنفس المحتوى والعميل — غيّر المحتوى أو انتظر |
| البوت لا يرد | الرد الآلي غير مدعوم على هذه القناة — سلّم للفريق أو عالج المنطق قبل الإرسال |
