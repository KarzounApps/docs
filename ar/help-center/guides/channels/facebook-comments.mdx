عندما تتراكم تعليقات المنشورات في فيسبوك فقط، يصعب الرد العام أو الخاص مع بقية عمل الفريق.

تجلب قناة **تعليقات فيسبوك** تعليقات الزوار على منشورات الصفحة إلى الحساب لتعالجها من **البريد الوارد**.

يشرح هذا الدليل كيف تربط الصفحة وتختبر بتعليق حقيقي، وأين يُمارَس الرد اليومي بعد الربط.

في الإضافة: **تعليقات فيسبوك** · المسار: `/channels?add=facebook-comments`.

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | تكامل مرتبط بمنشورات الصفحة (في النظام: نوع منشورات فيسبوك) |
| **متى تظهر** | بعد ربط الصفحة ووصول تعليق جديد على منشور متابع |
| **الاستخدام** | فريق السوشيال يراجع التعليقات ويحوّل الحساس لخاص عند الحاجة |
| **متى لا** | تريد رسائل ماسنجر الخاصة فقط — استخدم [ماسنجر فيسبوك](/ar/help-center/guides/channels/facebook-messenger) |
| **الأثر** | خيوط تعليقات في الوارد منفصلة عن محادثات الماسنجر |

يمكن — ويُفضَّل غالباً — ربط **القناتين** لنفس الصفحة: تعليقات + ماسنجر، كل واحدة بنوعها.

## قبل أن تبدأ

- صلاحية أدمن على صفحة فيسبوك
- حساب ميتا يسمح بتعليقات الصفحة
- قسم في كرزون لاختياره عند الإنشاء

## بعد الربط

الربط هنا. الاستخدام هنا:

- [تعليقات السوشيال](/ar/help-center/guides/inbox/social-comments) — الرد الظاهر، الرد الخاص، الإخفاء.  
- [القنوات في البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) — الشارات والفلاتر.  
- أتمتة Comment-to-DM عند بنائها: [رسالة مباشرة](/ar/help-center/guides/automations/nodes/actions/send-dm).

تعديل القناة بعد الإنشاء يركّز على الاسم والقسم ما لم يوفّر حسابك إعدادات إضافية.

## أخطاء شائعة

| العَرَض | التصرف |
| --- | --- |
| لا تظهر صفحات | أعد التفويض بحساب أدمن الصفحة |
| الصفحة «متصلة بالفعل» | عدّل القناة القديمة أو افصلها ثم أنشئ |
| لا تعليقات بعد الربط | القناة غير نشطة، أو التعليق على منشور لا يتابعه التكامل |

## قبل التصعيد

1. راجع [صحة الخدمة](https://status.karzoun.chat/) — إن كان العطل على مستوى المنصة فلا تفتح بلاغاً مكرراً.
2. أكّد أنك أنهيت خطوات هذه الصفحة (والتحقق إن وُجد).
3. جهّز: لقطة الشاشة أو نص الخطأ، الوقت التقريبي، واسم القناة أو التطبيق، وخطوات إعادة الإظهار.

بعد ذلك: [الحصول على الدعم](/ar/help-center/guides/getting-started/get-support).
