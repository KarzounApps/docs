---

**ربط صندوق بريد موجود** يصل كرزون بخادم بريدك الحالي: IMAP للمزامنة الواردة وSMTP لإرسال الردود عبر مزوّدك. البريد يبقى عند Google أو Microsoft أو غيرهما — كرزون مساحة عمل إضافية للفريق.

إن كنت متردداً بين الخيارين: [أي بريد أختار؟](/ar/help-center/guides/channels/email-choose).

في الإضافة قد يظهر الاسم **ربط صندوق بريد موجود** أو وصفاً يذكر IMAP/SMTP · `/channels?add=email`.

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | تكامل `imap` ببيانات مضيف ومستخدم وكلمة مرور |
| **متى تظهر الرسائل** | بعد نجاح الاتصال ودورة الجلب من الصندوق |
| **الاستخدام** | صناديق موظفين أو بريد دعم موجود لا تريد نقله |
| **متى لا** | تريد نطاقاً مُداراً بالكامل داخل كرزون بلا خادم خارجي — استخدم [بريد الأعمال](/ar/help-center/guides/channels/business-email) |
| **الأثر** | نفس الرسالة قد تُرى في Gmail/Outlook **و** في وارد كرزون |

## قبل الربط

جهّز:

- عنوان البريد الكامل  
- **كلمة مرور تطبيق** إن كانت المصادقة الثنائية مفعّلة عند المزوّد  
- مضيف ومنفذ IMAP (شائع 993 مع TLS)  
- مضيف ومنفذ SMTP (شائع 587 مع TLS)  
- قسماً في كرزون

## خطوات الربط

<Steps>
  <Step title="اختر ربط صندوق موجود">
    **القنوات** ← **إنشاء جديد** ← الخيار الخاص بصندوق البريد الموجود / IMAP.
  </Step>
  <Step title="عبّئ بيانات الخادم">
    اسم القناة، مضيف ومنفذ IMAP مع TLS، مضيف ومنفذ SMTP مع TLS، المستخدم، كلمة المرور، والمستخدم الرئيسي أو الأسماء المستعارة إن لزم، ثم القسم.
  </Step>
  <Step title="احفظ واختبر">
    أرسل رسالة إلى الصندوق من عنوان خارجي، وتأكد أنها ظهرت في البريد الوارد، ثم رد من كرزون وتأكد من وصول الرد عبر SMTP.
  </Step>
</Steps>

## بعد الربط

تعديل القناة يركّز على الإعدادات العامة (الاسم والقسم) ما لم يوفّر حسابك شاشة أوسع لبيانات الخادم. راقب حالة القناة **نشط/غير نشط** إن توقفت المزامنة.

| مهمة | مكان |
| --- | --- |
| قراءة والرد | [البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) |
| حملات من كرزون بنطاقك | غالباً أنسب عبر [بريد الأعمال](/ar/help-center/guides/channels/business-email) |
| بريد من مسار أتمتة | [عقدة إرسال بريد](/ar/help-center/guides/automations/nodes/email) |

## أخطاء شائعة

| العَرَض | التصرف |
| --- | --- |
| فشل المصادقة | استخدم كلمة مرور تطبيق؛ راجع أن IMAP مسموح عند المزوّد |
| لا رسائل جديدة | القناة غير نشطة، أو مجلد/فلتر عند المزوّد يحجب الجلب |
| الرد لا يصل | بيانات SMTP أو المنفذ/TLS خاطئة |
| قفل الحساب | كثرة محاولات فاشلة — أصلح البيانات من لوحة المزوّد أولاً |
