عندما يريد الفريق رؤية صندوق Gmail أو Microsoft في كرزون دون نقل الاستضافة، تحتاج بيانات IMAP وSMTP الصحيحة.

يربط **بريد إلكتروني (IMAP/SMTP)** كرزون بخادمك الحالي: جلب وارد عبر IMAP وإرسال الردود عبر SMTP.

يشرح هذا الدليل كيف تملأ النموذج وتختبر الاستقبال والرد، وما تفعله عند فشل المصادقة.

إن كنت متردداً بين الخيارين: [أي بريد أختار؟](/ar/help-center/guides/channels/email-choose).

في نافذة الإضافة قد يظهر النص **ربط صندوق بريد موجود** — المقصود في هذا المرجع هو **بريد إلكتروني (IMAP/SMTP)** · `/channels?add=email`.

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | تكامل `imap` ببيانات مضيف ومستخدم وكلمة مرور |
| **متى تظهر الرسائل** | بعد نجاح الاتصال ودورة الجلب من الصندوق |
| **الاستخدام** | صناديق موظفين أو بريد دعم موجود لا تريد نقله |
| **متى لا** | تريد نطاقاً مُداراً بالكامل داخل كرزون بلا خادم خارجي — استخدم [بريد الأعمال من كرزون](/ar/help-center/guides/channels/business-email) |
| **الأثر** | نفس الرسالة قد تُرى في Gmail/Outlook **و** في وارد كرزون |

## قبل أن تبدأ

جهّز:

- عنوان البريد الكامل  
- **كلمة مرور تطبيق** إن كانت المصادقة الثنائية مفعّلة عند المزوّد  
- مضيف ومنفذ IMAP (شائع 993 مع TLS)  
- مضيف ومنفذ SMTP (شائع 587 مع TLS)  
- قسماً في كرزون

## بعد الربط

تعديل القناة يركّز على الإعدادات العامة (الاسم والقسم) ما لم يوفّر حسابك شاشة أوسع لبيانات الخادم. راقب حالة القناة **نشط/غير نشط** إن توقفت المزامنة.

| مهمة | مكان |
| --- | --- |
| قراءة والرد | [البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) |
| حملات من كرزون بنطاقك | غالباً أنسب عبر [بريد الأعمال من كرزون](/ar/help-center/guides/channels/business-email) |
| بريد من مسار أتمتة | [عقدة إرسال بريد](/ar/help-center/guides/automations/nodes/email) |

## أخطاء شائعة

| العَرَض | التصرف |
| --- | --- |
| فشل المصادقة | استخدم كلمة مرور تطبيق؛ راجع أن IMAP مسموح عند المزوّد |
| لا رسائل جديدة | القناة غير نشطة، أو مجلد/فلتر عند المزوّد يحجب الجلب |
| الرد لا يصل | بيانات SMTP أو المنفذ/TLS خاطئة |
| قفل الحساب | كثرة محاولات فاشلة — أصلح البيانات من لوحة المزوّد أولاً |

## قبل التصعيد

1. راجع [صحة الخدمة](https://status.karzoun.chat/) — إن كان العطل على مستوى المنصة فلا تفتح بلاغاً مكرراً.
2. أكّد أنك أنهيت خطوات هذه الصفحة (والتحقق إن وُجد).
3. جهّز: لقطة الشاشة أو نص الخطأ، الوقت التقريبي، واسم القناة أو التطبيق، وخطوات إعادة الإظهار.

بعد ذلك: [الحصول على الدعم](/ar/help-center/guides/getting-started/get-support).
