تضبط اللون والشعار من الإعدادات، ثم تريد خطاً مختلفاً أو زوايا أنعم أو إخفاء عنصر لا يناسب موقعك.

يتيح لك حقل **CSS مخصص** كتابة تنسيقاتك الخاصة، وتُطبَّق داخل نافذة الدردشة على كل صفحات موقعك دون تعديل كود التثبيت.

يشرح هذا الدليل أين تكتب الـ CSS، وما الأصناف التي تستهدفها، ويعطيك أمثلة جاهزة للنسخ.

## أين تكتبه

<Steps>
  <Step title="افتح إعدادات الماسنجر">
    من **القنوات** افتح قناة **كرزون ماسنجر** واختر **تعديل**.
  </Step>
  <Step title="انتقل إلى خطوة المظهر">
    في أسفل الخطوة افتح **CSS مخصص (متقدم)**.
  </Step>
  <Step title="اكتب الـ CSS واحفظ">
    الصق تنسيقاتك ثم اضغط **حفظ**. تظهر على موقعك خلال دقيقة تقريباً (مدة الكاش).
  </Step>
</Steps>

<Note>
لا تضع الـ CSS في كود التثبيت ولا في ملفات موقعك. نافذة الدردشة تعمل داخل `iframe` مستقل، فلا تصل إليها تنسيقات صفحتك. الحقل في الإعدادات هو المكان الوحيد الذي يصل إلى داخلها.
</Note>

## كيف يعمل

| السؤال | الجواب |
| --- | --- |
| **أين يُطبَّق؟** | داخل نافذة الدردشة فقط، على كل موقع يعرض هذه القناة |
| **متى يُطبَّق؟** | بعد تنسيقات النافذة نفسها، فيتغلّب عليها في الغالب |
| **ماذا لا يغيّر؟** | زر فتح الدردشة (المشغّل)، وموضع النافذة وحجمها على الصفحة. راجع «ما خارج النافذة» أدناه |
| **هل يتأثر بالتحديثات؟** | قد يتأثر. الأصناف أدناه داخلية، وقد يتغيّر بعضها مع تحديث تصميم النافذة |

<Warning>
**لون العلامة التجارية** يُطبَّق مباشرة على الترويسة وفقاعات الزائر وزر الإرسال. لتغيير ألوان هذه العناصر أضف `!important`، وإلا يبقى لون الإعدادات.
</Warning>

## الأصناف الأساسية

| المحدِّد | العنصر |
| --- | --- |
| `--primary` | متغيّر لون العلامة (يُضبط من الإعدادات) |
| `.header` | الترويسة أعلى النافذة |
| `.header-title` · `.header-status` | اسم النافذة وحالة الاتصال |
| `.header-logo-wrap` | إطار الشعار في الترويسة |
| `#homeScreen` | الشاشة الرئيسية |
| `.greetings h2` · `.greetings p` | عنوان التحية ونصها |
| `.action-card` | بطاقات الشاشة الرئيسية (ابدأ محادثة، تواصل معنا…) |
| `#chatScreen` | شاشة المحادثة |
| `#messages` | منطقة الرسائل |
| `.msg` | أي فقاعة رسالة |
| `.msg.customer` | رسائل الزائر |
| `.msg.agent` · `.msg.bot` | رسائل الفريق والبوت |
| `.msg-time` | وقت الرسالة |
| `.composer` | شريط الكتابة أسفل المحادثة |
| `.composer-input` | حقل الكتابة |
| `.composer-send` | زر الإرسال |
| `.composer-attach` · `.composer-mic` | زر المرفقات وزر التسجيل الصوتي |
| `.ix-btn` | أزرار الرسائل التفاعلية |
| `.bottom-nav` · `.bottom-nav-item` | شريط التنقل السفلي |
| `.powered-by` | سطر «بواسطة كرزون» |
| `html[dir="rtl"]` | النافذة حين تكون بالعربية |

## أمثلة

### خط مختلف

```css
@import url('https://fonts.googleapis.com/css2?family=Tajawal:wght@400;500;700&display=swap');

html, body {
  font-family: 'Tajawal', system-ui, sans-serif;
}
```

<Tip>
اجعل `@import` في أول سطر من الحقل، وإلا يتجاهله المتصفح.
</Tip>

### ترويسة بلون ثابت بدل التدرّج

```css
.header {
  background: #0f172a !important;
}
```

### فقاعات الرسائل

```css
/* رسائل الزائر */
.msg.customer {
  background: #111827 !important;
  border-radius: 12px;
}

/* رسائل الفريق والبوت */
.msg.agent,
.msg.bot {
  background: #eef2ff;
  color: #1e1b4b;
  border-radius: 12px;
}
```

### زوايا حادّة لكل العناصر

```css
.action-card,
.msg,
.composer-input,
.ix-btn {
  border-radius: 4px;
}

.composer-send {
  border-radius: 8px;
}
```

### حجم خط أكبر في المحادثة

```css
.msg {
  font-size: 15px;
  line-height: 1.6;
}

.composer-input {
  font-size: 15px;
}
```

### بطاقات الشاشة الرئيسية

```css
.action-card {
  background: #fff;
  border-color: var(--primary);
}

.action-card:hover {
  transform: none;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
}
```

### إخفاء عناصر

```css
/* حالة الاتصال تحت اسم النافذة */
.header-status {
  display: none;
}

/* أوقات الرسائل */
.msg-time {
  display: none;
}
```

<Note>
لإخفاء زر المرفقات أو التسجيل الصوتي أو الإيموجي، أو سطر «بواسطة كرزون»، استخدم المفاتيح الموجودة في الإعدادات بدل CSS.
</Note>

### تنسيق خاص بالعربية

```css
html[dir="rtl"] .greetings h2 {
  font-size: 22px;
  letter-spacing: 0;
}
```

### وضع داكن

```css
body,
.composer,
#homeScreen {
  background: #0b1120;
  color: #e2e8f0;
}

.msg.agent,
.msg.bot,
.action-card {
  background: #1e293b;
  border-color: #334155;
  color: #e2e8f0;
}

.composer-input {
  background: #1e293b;
  border-color: #334155;
  color: #e2e8f0;
}
```

## ما خارج النافذة

زر فتح الدردشة وإطار النافذة يعيشان في صفحة موقعك، لا داخل النافذة، فلا يصل إليهما حقل **CSS مخصص**.

| تريد | الطريقة |
| --- | --- |
| تغيير شكل زر الفتح أو نصه أو جهته | من خطوة **المظهر** في إعدادات الماسنجر |
| زرّك الخاص بدل زر كرزون | في خطوة **التثبيت والأمان** اجعل **إظهار زر المحادثة** على **أبداً**، ثم افتح الدردشة من زرّك بـ `Karzoun.messenger.open()` |
| تحريك النافذة أو الزر قليلاً | CSS في موقعك على `#kz-messenger-container` و`#kz-messenger-launcher` مع `!important` |

مثال على زرّك الخاص:

```html
<button onclick="Karzoun.messenger.open()">تحدّث معنا</button>
```

مثال على رفع الزر والنافذة فوق شريط ثابت أسفل موقعك (يُكتب في CSS موقعك، لا في الإعدادات):

```css
#kz-messenger-launcher {
  bottom: 90px !important;
}

#kz-messenger-container {
  bottom: 160px !important;
}
```

## أخطاء شائعة

| ما يحدث | السبب والحل |
| --- | --- |
| لم يتغيّر لون الترويسة أو الفقاعات | هذه العناصر تأخذ لون الإعدادات مباشرة. أضف `!important` |
| لم يظهر التغيير على الموقع | انتظر دقيقة بعد الحفظ، ثم حدّث الصفحة في نافذة خاصة |
| الخط المستورد لا يعمل | `@import` ليس في أول سطر من الحقل |
| كتبت CSS في موقعك ولم يتغيّر شيء | الصفحة لا تصل إلى داخل النافذة. انقله إلى حقل **CSS مخصص** |
| تغيّر شكل عنصر بعد تحديث | تغيّر صنفه الداخلي. راجع الجدول أعلاه وحدّث المحدِّد |

## الخطوة التالية

صار بإمكانك تخصيص نافذة الدردشة بما يتجاوز الإعدادات. بعد ذلك:

- راجع بقية خطوات الإعداد في [كرزون ماسنجر](/ar/help-center/guides/channels/messenger).
- تحقّق من الشكل على الجوال، فالنافذة تملأ الشاشة هناك.
