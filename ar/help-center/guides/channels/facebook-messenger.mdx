عندما تبقى رسائل صفحة فيسبوك في صندوق ميتا، يعمل فريق الدعم بمعزل عن واتساب والبريد.

تجلب قناة **ماسنجر فيسبوك** الرسائل الخاصة للصفحة إلى **البريد الوارد** — وليست قناة التعليقات على المنشورات.

يشرح هذا الدليل كيف تربط حساب ميتا وتختار الصفحة حتى تصل محادثة اختبار.

في الإضافة: **ماسنجر فيسبوك** · المسار: `/channels?add=facebook-messenger`.

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | تكامل `facebook-messenger` مربوط بصفحة فيسبوك عبر حساب ميتا |
| **متى تظهر الرسائل** | بعد اختيار الصفحة وإنشاء القناة وتفعيلها |
| **الاستخدام** | فريق الدعم يقرأ ويرد على رسائل الصفحة من كرزون |
| **متى لا** | تريد فقط تعليقات المنشورات العامة — استخدم [تعليقات فيسبوك](/ar/help-center/guides/channels/facebook-comments) |
| **الأثر** | محادثات خاصة بشارة فيسبوك؛ يمكن ضبط رد آلي عند الإنشاء |

## قبل أن تبدأ

- صلاحية أدمن على صفحة فيسبوك
- حساب ميتا يسمح بربط الصفحات والرسائل
- قسم في كرزون لاختياره عند الإنشاء

## بعد الربط

| ماذا | أين |
| --- | --- |
| تعديل الاسم والقسم | `/channels/:id/edit` |
| الرد اليومي | [البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) |
| رد آلي وكلمات مفتاحية | [الرد الآلي](/ar/help-center/guides/automations/channel-bots) |
| رسالة مباشرة من مسار أتمتة | [إرسال رسالة مباشرة](/ar/help-center/guides/automations/nodes/actions/send-dm) |

<Warning>
صلاحيات الصفحة يجب أن تبقى سارية. إن توقفت الرسائل، راجع صلاحية الحساب في ميتا وحالة القناة في كرزون قبل إعادة البناء من الصفر.
</Warning>

## أخطاء شائعة

| العَرَض | السبب المحتمل | التصرف |
| --- | --- | --- |
| لا تظهر صفحات | الحساب بلا صفحات أو بلا صلاحية | أعد التفويض بحساب أدمن الصفحة |
| الصفحة «متصلة بالفعل» | مستخدمة بقناة أخرى | عدّل القناة القديمة أو افصلها |
| فشل جلب الصفحات | جلسة منتهية | أغلق النافذة وأعد الربط |
