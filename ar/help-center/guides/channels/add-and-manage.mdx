عندما تضيف قناة من شاشة مختلفة في كل مرة، يصعب معرفة أين تُفعَّل أو تُؤرشف أو تُسمَّى.

توفّر قائمة **القنوات** في كرزون (`/channels`) مكاناً واحداً لإضافة التكامل ومراجعة الحالة وفتح التعديل حسب النوع.

يشرح هذا الدليل كيف تنشئ قناة من **إنشاء جديد** حتى رسالة الاختبار، وكيف تدير التفعيل والأرشفة.

في التطبيق: **البريد الوارد** ← **القنوات** (`/channels`).

## التعريف والأثر

| | |
| --- | --- |
| **المعنى** | قائمة القنوات حيث تضيف تكاملاً وتفعّله أو تؤرشفه |
| **متى تستخدمه** | أول ربط، أو عند توقف الرسائل، أو لإعادة تسمية قناة وربطها بقسم |
| **متى لا** | الرد اليومي على الرسائل — ذلك في [البريد الوارد](/ar/help-center/guides/inbox/channels-in-inbox) |
| **الأثر** | كل قناة **نشطة** تصل محادثاتها للوارد مع القسم والإسناد |

## قبل أن تبدأ

- صلاحية إدارة القنوات في الحساب
- قسم واحد على الأقل في كرزون
- حساب المزود جاهز (ميتا، تيك توك للأعمال، أو بيانات البريد)

## ماذا تعني الحقول المشتركة؟

| الحقل | معناه | متى يهم |
| --- | --- | --- |
| **اسم القناة** | الاسم الذي يراه فريقك في القائمة والفلاتر | سمِّ حسب الدور لا حسب المزود فقط |
| **القسم** | يربط المحادثات الواردة بتنظيم الفريق والإسناد | ضروري قبل الحفظ في معظم المعالجات |
| **النوع** | يحدد المعالج والإعدادات اللاحقة | لا يُغيَّر بعد الإنشاء — احذف وأنشئ من جديد إن اخترت خطأ |

للدردشة المباشرة تُنشأ القناة بالاسم (والقسم يُختار تلقائياً إن وُجد قسم واحد)، ثم تضبط المظهر والتثبيت من شاشة الماسنجر. التفاصيل في [كرزون ماسنجر](/ar/help-center/guides/channels/messenger).

## إدارة القائمة

أعلى الصفحة:

| أداة | ماذا تفعل |
| --- | --- |
| **بحث** | تصفية بالاسم |
| **نوع القناة** | واتساب، ماسنجر، فيسبوك، إنستغرام، بريد، ويب هوك، تيك توك… |
| **الحالة** | نشط / غير نشط |
| **عرض بطاقات أو قائمة** | نفس البيانات بتخطيطين |

### إجراءات القناة

من قائمة الإجراءات على البطاقة أو الصف:

| الإجراء | الأثر |
| --- | --- |
| **تعديل** / **تعديل القناة** | يفتح إعدادات النوع (انظر الجدول أدناه) |
| **تفعيل** / **إلغاء التفعيل** | يشغّل أو يوقف استقبال القناة دون حذفها |
| **أرشفة** | تخرج القناة من الاستخدام اليومي |
| **حذف** | إزالة نهائية بعد التأكيد — استخدمها بحذر |
| **إصلاح** | لبعض أنواع ميتا/التكاملات عند اضطراب الربط (لا يظهر لكل الأنواع) |
| **تثبيت الكود** | لماسنجر كرزون فقط — يفتح مقتطف التثبيت |
| **جلب البيانات** | لقناة ويب هوك وارد عند الحاجة |

## أين يُفتح تعديل كل نوع؟

| النوع | مسار التعديل بعد الإنشاء |
| --- | --- |
| كرزون ماسنجر (الدردشة المباشرة) | **تعديل القناة** → `/messenger/:id/edit` للمظهر والسلوك؛ وهناك أيضاً إعدادات عامة للاسم والقسم |
| واتساب | `/channels/:id/edit` مع تبويب **مدير واتساب** |
| فيسبوك / إنستغرام / تيك توك / ويب هوك | `/channels/:id/edit` — غالباً الإعدادات العامة (الاسم والقسم) |
| بريد الأعمال من كرزون | `/channels/:id/edit` مع تبويبات البريد وDNS والأمان |
| بريد إلكتروني (IMAP/SMTP) | `/channels/:id/edit` (إعدادات عامة؛ بيانات الخادم حسب الحساب) |

إعداد **الرد الآلي** والكلمات المفتاحية ليس من قائمة القنوات مباشرة، بل من **الأتمتة** ← **الرد الآلي**. راجع [إعداد الرد الآلي للقناة](/ar/help-center/guides/automations/channel-bots).

## بعد الربط

1. اختبر رسالة حقيقية من المصدر.  
2. راجع ظهور الشارة في البريد الوارد.  
3. اضبط الرد الآلي إن احتجت مساراً افتراضياً.  
4. إن فشل ربط واتساب أو ميتا، ابدأ من صفحة [واتساب](/ar/help-center/guides/channels/whatsapp) (أخطاء شائعة مدمجة هناك).

## أخطاء شائعة

| العَرَض | التصرف |
| --- | --- |
| لا تصل رسائل جديدة | القناة **غير نشطة** أو مؤرشفة — راجع قائمة الإجراءات قبل افتراض عطل المزود |
| «متصلة بالفعل» / تكرار | الحساب أو الصفحة مستخدمة بقناة من نفس النوع — عدّل القديمة |
| فشل التفويض | اسمح بالنوافذ المنبثقة وأعد المحاولة بحساب الأدمن الصحيح |
