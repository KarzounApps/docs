عندما تريد الفريق أن يرد على واتساب من نفس مكان بقية القنوات، يبقى الرقم عند ميتا ويحتاج مساراً صحيحاً قبل أول رسالة.

تربط قناة **واتساب** في كرزون الرقم بحساب واتساب للأعمال ليصل إلى [البريد الوارد](/ar/help-center/guides/inbox/overview)، ضمن سياسات ميتا.

يشرح هذا الدليل كيف تختار أحد مسارات الربط الأربعة، تكمل الخطوات حتى رسالة اختبار، ومتى تنتقل إلى مدير واتساب.

للعمق بعد الربط ابدأ من [نظرة عامة على مدير واتساب](/ar/help-center/guides/whatsapp/overview).

  <img src="/images/brands/meta-business-partner.png" alt="Meta Business Partners" width="220" height="38" />
  <p>كرزون **شريك أعمال معتمد من ميتا** (Meta Business Partner) و**شريك حلول واتساب** — الربط عبر المسار الرسمي لـ Cloud API.</p>
</div>

في التطبيق: **البريد الوارد** ← **القنوات** ← **إنشاء جديد** ← **واتساب**، أو `/channels?add=whatsapp`.

## ماذا تعني هذه القناة؟

| | |
| --- | --- |
| **المعنى** | تكامل واتساب Cloud API (أو مسار تعايش/نقل) مربوط بحسابك في كرزون |
| **متى تظهر الرسائل** | بعد إكمال الخطوات وتفعيل القناة ونجاح الرقم |
| **الاستخدام** | دعم ومبيعات على واتساب من البريد الوارد |
| **متى لا تبدأ هنا** | إن لم تملك صلاحية Business Manager أو رقماً جاهزاً للربط |
| **الأثر** | شارة واتساب في الوارد + أسطح مدير واتساب بعد الربط |

## قبل أن تبدأ

- حساب فيسبوك حقيقي بصلاحية مناسبة على حساب الأعمال.
- السماح بالنوافذ المنبثقة أثناء الربط.
- قسم في كرزون جاهز لاختياره في خطوة المراجعة.
- إن كان الرقم على تطبيق واتساب للجوال (وليس مسار تعايش): خطط لنقل الرقم وفق تعليمات ميتا — لا يعمل نفس الرقم على التطبيق وعلى الـ API العادي معاً دون المسار الصحيح.

راجع أيضاً [متطلبات الحساب](/ar/help-center/guides/whatsapp/concepts/account-requirements) و[طرق الربط](/ar/help-center/guides/whatsapp/concepts/connection-methods).

## اختر مسار الربط

في خطوة **ربط الحساب** تظهر حسابات متصلة سابقاً، أو تربط حساباً جديداً عبر أحد المسارات:

| البطاقة في الواجهة | متى تستخدمها |
| --- | --- |
| **رقم واتساب جديد عبر كرزون** | تبدأ من الصفر؛ كرزون يتولى إعداد ميتا وفوترة الرسائل |
| **الاستمرار مع تطبيق واتساب بيزنس** | الرقم على تطبيق واتساب بيزنس وتريد الإبقاء عليه مع كرزون (تعايش) |
| **استخدام Cloud API الخاص بك من Meta** | تدير الحساب في Meta Business Manager وتدفع لميتا مباشرة |
| **نقل رقم من مزود آخر** | الرقم أصلاً على Cloud API عند مزود آخر — يفتح خطوات النقل |

## نقل رقم من مزود آخر

استخدم **بدء نقل الرقم** فقط إذا كان الرقم أصلاً على Cloud API عند مزود آخر. الخطوات المنفصلة تطلب غالباً:

1. تعطيل التحقق بخطوتين على الرقم المصدر — [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa).
2. توفر الهاتف لاستقبال رمز التحقق.
3. توثيق حساب ميتا للأعمال واسم عرض معتمد.
4. ربط حساب WABA الوجهة، إدخال الرقم، ثم التحقق والمراجعة.

## تعايش مع تطبيق واتساب بيزنس

مسار **الاستمرار مع تطبيق واتساب بيزنس** يبقي الفريق على التطبيق مع وصول كرزون لنفس الرقم. بعد إنشاء القناة تظهر شاشة النجاح مع بطاقة **تقدم المزامنة** إن بدأت المزامنة.

### قراءة حالات المزامنة

| السطر في الواجهة | الحالات الشائعة على الشارة | ماذا تعني؟ |
| --- | --- | --- |
| **مزامنة جهات الاتصال** | `pending` · `in_progress` · `completed` · `failed` | استيراد جهات التطبيق إلى كرزون. عند اكتمال جزئي/كامل يظهر عدد المستورد |
| **مزامنة سجل الرسائل** | `pending` · `in_progress` · `completed` · `declined` · `failed` | استيراد سجل المحادثات. أثناء `in_progress` يظهر شريط تقدّم؛ `declined` = المستخدم رفض مشاركة السجل من التطبيق |

اترك الشاشة مفتوحة حتى تكتمل المزامنة أو انتقل للقناة وانتظر ظهور المحادثات/الجهات. رسالة خطأ حمراء تحت البطاقة تعني فشلاً — أعد المحاولة أو راجع التطبيق ثم الدعم.

لا تتوقع من مسار التعايش ما يوفره Cloud API الكامل من كرزون: الملف والصورة للقراءة فقط؛ لا مكالمات ولا كتالوج عبر واجهة كرزون؛ غيّر اسم العرض من التطبيق أو مدير ميتا. التفاصيل في [طرق الربط](/ar/help-center/guides/whatsapp/concepts/connection-methods).

## أخطاء شائعة عند الربط (ميتا / واتساب)

معظم فشل الربط يأتي من ميتا أثناء النافذة المنبثقة أو التحقق — ليس من زر كرزون نفسه. تحقق أولاً من [صحة خدمة كرزون](https://status.karzoun.chat/) و[حالة واتساب للأعمال لدى ميتا](https://metastatus.com/whatsapp-business-api).

### حساب الأعمال والمدير

| رسالة / عَرَض | السبب المحتمل | ماذا تفعل |
| --- | --- | --- |
| خطأ عام أثناء المعالجة | حساب فيسبوك جديد أو غير موثوق | استخدم حساباً شخصياً نشطاً وحقيقياً |
| حد أقصى لحسابات Business | تجاوزت الحد | أعد استخدام حساب أعمال موجود |
| لا تملك صلاحية Admin | دور غير كافٍ | اطلب صلاحية مسؤول على حساب الأعمال |
| 2FA غير مفعّل | ميتا تفرض المصادقة الثنائية | فعّل 2FA على فيسبوك ثم أعد المحاولة |
| لا يمكن اختيار Business Manager | حساب مقيد أو غير مؤهل | راجع Business Support Home أو أنشئ حساباً مؤهلاً |

### حساب واتساب للأعمال (WABA)

| رسالة / عَرَض | السبب المحتمل | ماذا تفعل |
| --- | --- | --- |
| الحساب مقيد (Restricted) | سياسة أو اشتباه | اطلب مراجعة من Business Support Home |
| حد إنشاء WABA | تحتاج توثيقاً | أكمل [توثيق الأعمال](/ar/help-center/guides/business-verification/overview) |
| لا يمكن توثيق الحساب | بيانات مرفوضة | صحّح المستندات حسب إيميل ميتا وأعد التقديم |

### الرقم والتحقق

| رسالة / عَرَض | السبب المحتمل | ماذا تفعل |
| --- | --- | --- |
| الرقم مسجّل على واتساب موجود | الرقم على تطبيق الجوال | احذف حساب واتساب من الهاتف قبل ربط API (ما لم تستخدم مسار تعايش صراحةً) |
| الرقم محظور | نشاط أو شكاوى | راجع الدعم وقدّم التماساً |
| الحد الأقصى للأرقام | حصة الحساب | احذف أرقاماً غير مستخدمة أو أكمل التوثيق |
| اسم العرض يخالف السياسات | Display Name مرفوض | عدّل الاسم ليطابق هوية النشاط |
| طلبت/خمّنت الرمز كثيراً | حد OTP | انتظر 12–24 ساعة أو بدّل رسالة نصية ↔ مكالمة صوتية |
| الرقم غير صالح | صيغة أو بدالة | صحّح رمز الدولة؛ عطّل IVR مؤقتاً إن لزم |

### أخطاء تظهر داخل كرزون

| عَرَض | ماذا تفعل |
| --- | --- |
| النافذة المنبثقة محظورة | اسمح بالنوافذ المنبثقة لنطاق كرزون ثم **حاول مرة أخرى** |
| فشل التسجيل المضمّن / انتهاء الرمز | أعد الربط؛ لا تترك الجلسة مفتوحة طويلاً |
| تعذّر تحميل حسابات WABA | حدّث الصفحة وأعد اختيار الحساب |
| الرقم متصل مسبقاً | استخدم القناة الموجودة أو افصل الربط القديم أولاً |

<Tip>
تجنب VPN أثناء الربط، ولا تنشئ حساب فيسبوك وهمياً «للتجربة» — ميتا ترفضه بسرعة. وثّق النشاط التجاري مبكراً لتقليل القيود.
</Tip>

## أسئلة شائعة

**هل أحتاج حذف واتساب من الهاتف؟** في المسار القياسي لـ Cloud API نعم إن كان الرقم ما زال على التطبيق. مسار التعايش هو الاستثناء المعتمد.

**لماذا تُتخطّى خطوة توثيق الرقم؟** مسارا التعايش وCloud API الخاص قد لا يطلبان رمز SMS/مكالمة داخل كرزون.

**فشل الربط لكل الفريق؟** راجع الصفحتين الصحيّتين أعلاه قبل إعادة المحاولة المتكررة، ثم [الحصول على الدعم](/ar/help-center/guides/getting-started/get-support).
