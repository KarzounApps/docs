---

قناة **واتساب** تصل رسائل الرقم المرتبط بحساب واتساب للأعمال إلى البريد الوارد، وتمكن الفريق من الرد ضمن سياسات ميتا. هذه الصفحة للربط والبدء وأخطاء الربط. للعمق (قوالب، تدفقات، مكالمات، تجارة، توثيق) ابدأ من [نظرة عامة على واتساب كرزون](/ar/help-center/guides/whatsapp/overview).

في التطبيق: **البريد الوارد** ← **القنوات** ← **إنشاء جديد** ← **واتساب**.

## ماذا تعني هذه القناة؟

| | |
| --- | --- |
| **المعنى** | تكامل واتساب Cloud API (أو مسار تعايش/نقل) مربوط بمساحة عملك |
| **متى تظهر الرسائل** | بعد إكمال المعالج وتفعيل القناة ونجاح الرقم |
| **الاستخدام** | دعم ومبيعات على واتساب من صندوق الفريق |
| **متى لا تبدأ هنا** | إن لم تملك صلاحية Business Manager أو رقماً جاهزاً للربط |
| **الأثر** | شارة واتساب في الوارد + أسطح مدير واتساب بعد الربط |

## قبل أن تبدأ

- حساب فيسبوك حقيقي بصلاحية مناسبة على حساب الأعمال.  
- السماح بالنوافذ المنبثقة أثناء الربط.  
- قسم في كرزون جاهز لاختياره في خطوة المراجعة.  
- إن كان الرقم على تطبيق واتساب للجوال (وليس مسار تعايش): خطط لنقل الرقم وفق تعليمات ميتا — لا يعمل نفس الرقم على التطبيق وعلى الـ API العادي معاً دون المسار الصحيح.

## خطوات الربط (المعالج)

<Steps>
  <Step title="افتح معالج واتساب">
    من **إنشاء جديد** اختر **واتساب**، أو استخدم `/channels?add=whatsapp`.
  </Step>
  <Step title="اربط الحساب">
    اختر حساباً متصلاً سابقاً، أو اربط جديداً عبر أحد المسارات:
    - رقم واتساب جديد عبر كرزون (Embedded Signup)
    - الاستمرار مع تطبيق واتساب بيزنس (تعايش / Coexistence)
    - استخدام Cloud API الخاص بك من Meta
    - نقل رقم من مزود آخر (يفتح معالج النقل)
  </Step>
  <Step title="اختر حساب واتساب للأعمال والرقم">
    حدّد WABA والرقم. يمكنك إضافة رقماً عند الحاجة ثم متابعة التحقق.
  </Step>
  <Step title="وثّق الرقم إن طُلب">
    في المسار القياسي يصل رمز تحقق (رسالة أو اتصال). مسارات التعايش وCloud API الخاص قد تتخطى هذه الخطوة.
  </Step>
  <Step title="راجع الاسم والقسم وأنشئ">
    اسم القناة يُقترح غالباً من الاسم المعتمد للرقم — عدّله إن لزم، اختر القسم، وأكمل.
  </Step>
  <Step title="اختبر">
    أرسل رسالة من هاتف حقيقي، وتأكد من ظهورها في البريد الوارد، ثم افتح إعداد الملف الشخصي من شاشة النجاح إن ظهرت.
  </Step>
</Steps>

### نقل رقم من مزود آخر

معالج مستقل يطلب غالباً: تعطيل التحقق بخطوتين عند المزود السابق، توفر الهاتف، توثيق الأعمال، واسم عرض معتمد، ثم ربط وجهة WABA وإدخال الرقم والتحقق. استخدمه فقط إذا كان الرقم أصلاً على Cloud API عند مزود آخر.

<Info>
**وسائط مطلوبة:** معالج ربط واتساب في خطوة اختيار الحساب ثم اختيار الرقم.  
المسار المقترح: `/images/help/channels/whatsapp-onboarding-steps.webp`  
**فيديو (مستحسن):** مسار ربط قياسي حتى ظهور القناة في القائمة.
</Info>

## أخطاء شائعة عند الربط (ميتا / واتساب)

معظم فشل الربط يأتي من ميتا أثناء النافذة المنبثقة أو التحقق — ليس من زر كرزون نفسه.

### حساب الأعمال والمدير

| رسالة / عَرَض | السبب المحتمل | ماذا تفعل |
| --- | --- | --- |
| خطأ عام أثناء المعالجة | حساب فيسبوك جديد أو غير موثوق | استخدم حساباً شخصياً نشطاً وحقيقياً |
| حد أقصى لحسابات Business | تجاوزت الحد | أعد استخدام حساب أعمال موجود |
| لا تملك صلاحية Admin | دور غير كافٍ | اطلب صلاحية مسؤول على حساب الأعمال |
| 2FA غير مفعّل | ميتا تفرض المصادقة الثنائية | فعّل 2FA على فيسبوك ثم أعد المحاولة |
| لا يمكن اختيار Business Manager | حساب مقيد أو غير مؤهل | راجع Business Support Home أو أنشئ حساباً مؤهلاً |

### حساب واتساب للأعمال (WABA)

| رسالة / عَرَض | السبب المحتمل | ماذا تفعل |
| --- | --- | --- |
| الحساب مقيد (Restricted) | سياسة أو اشتباه | اطلب مراجعة من Business Support Home |
| حد إنشاء WABA | تحتاج توثيقاً | أكمل Business Verification |
| لا يمكن توثيق الحساب | بيانات مرفوضة | صحّح المستندات حسب إيميل ميتا وأعد التقديم |

### الرقم والتحقق

| رسالة / عَرَض | السبب المحتمل | ماذا تفعل |
| --- | --- | --- |
| الرقم مسجّل على واتساب موجود | الرقم على تطبيق الجوال | احذف حساب واتساب من الهاتف قبل ربط API (ما لم تستخدم مسار تعايش صراحةً) |
| الرقم محظور | نشاط أو شكاوى | راجع الدعم وقدّم التماساً |
| الحد الأقصى للأرقام | حصة الحساب | احذف أرقاماً غير مستخدمة أو أكمل التوثيق |
| اسم العرض يخالف السياسات | Display Name مرفوض | عدّل الاسم ليطابق هوية النشاط |
| طلبت/خمّنت الرمز كثيراً | حد OTP | انتظر 12–24 ساعة أو بدّل SMS ↔ اتصال |
| الرقم غير صالح | صيغة أو بدالة | صحّح رمز الدولة؛ عطّل IVR مؤقتاً إن لزم |

### أخطاء تظهر داخل كرزون

| عَرَض | ماذا تفعل |
| --- | --- |
| النافذة المنبثقة محظورة | اسمح بالنوافذ المنبثقة لنطاق كرزون |
| فشل Embedded Signup / انتهاء الرمز | أعد الربط؛ لا تترك الجلسة مفتوحة طويلاً |
| تعذّر تحميل حسابات WABA | حدّث الصفحة وأعد اختيار الحساب |
| الرقم متصل مسبقاً | استخدم القناة الموجودة أو افصل الربط القديم أولاً |

<Tip>
تجنب VPN أثناء الربط، ولا تنشئ حساب فيسبوك وهمياً «للتجربة» — ميتا ترفضه بسرعة. وثّق النشاط التجاري مبكراً لتقليل القيود.
</Tip>

## بعد الربط: خريطة مدير واتساب

من **تعديل** القناة `/channels/:id/edit` تجد تبويب **مدير واتساب**. هذه خريطة لما داخله — بروابط فقط حيث وُجدت صفحات، بلا عمق تشغيلي هنا:

| داخل المدير | ماذا ستجد لاحقاً / أين |
| --- | --- |
| **الملف الشخصي** | صورة ووصف وبيانات النشاط |
| **رموز QR** | روابط دخول للمحادثة |
| **القوالب** | قوالب ميتا — أدلة واتساب |
| **التدفقات** | WhatsApp Flows — راجع مجموعة **تدفقات واتساب** في مركز المساعدة |
| **مدير الإعلانات / CTWA** | [إعلانات تفتح محادثة](/ar/help-center/guides/whatsapp/ads/overview) |
| **المكالمات** | [مكالمات واتساب](/ar/help-center/guides/whatsapp/calls/overview) · [المكالمات في البريد الوارد](/ar/help-center/guides/inbox/calls-in-inbox) |
| **التجارة الإلكترونية** | [التجارة والكتالوج](/ar/help-center/guides/whatsapp/commerce/overview) |
| **التحليلات** | [رسائل وقوالب](/ar/help-center/guides/whatsapp/analytics/messages) · [تكاليف ومكالمات](/ar/help-center/guides/whatsapp/analytics/costs) |
