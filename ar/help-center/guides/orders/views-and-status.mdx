عندما تحتاج ترتيب الطلبات حسب مرحلة التنفيذ دون فتح لوحة المتجر في كل مرة، تحتاج عروضاً واضحة ومعنى دقيقاً لكل حالة.

في `/orders` تتابع الطلبات المتزامنة بعرضين: **كانبان** (افتراضي) و**قائمة**. الحالات هنا سجل كرزون — تغييرها لا يعني بالضرورة تحديث لوحة سلة أو زد.

يشرح هذا الدليل الفلاتر والعروض، حالات الطلب والدفع، ومتى تغيّر الحالة ومتى تترك المتجر مصدراً للحقيقة.

## العروض والفلاتر

| العنصر | ماذا يفعل |
| --- | --- |
| **كانبان** | أعمدة حسب حالة الطلب؛ اسحب البطاقة لتغيير الحالة |
| **قائمة** | جدول مع أعمدة العميل والمبلغ والدفع والحالة والمنصة؛ غيّر الحالة من القائمة المنسدلة في الصف |
| **فلتر الحالة** | عمود/صفوف لحالة واحدة أو **جميع الحالات** |
| **تاريخ الإنشاء** | نطاق زمني لتضييق القائمة |
| **فتح التفاصيل** | درج يعرض البنود، الشحن، الدفع، وسجل الحالة |

الرابط مع `?orderId=` يفتح نفس الطلب لاحقاً؛ من البطاقة أو القائمة يمكن **نسخ الرابط**. إن وُجد رابط متجر يظهر **عرض في المتجر**.

## حالات الطلب (عشر)

هذه التسميات المعتمدة في الواجهة العربية. قد تظهر أعمدة إضافية برموز منصة إن وصلت حالة غير قياسية من المتجر.

| الحالة في الواجهة | المعنى التشغيلي المعتاد |
| --- | --- |
| **تم الإنشاء** | الطلب ظهر في كرزون بعد المزامنة أو الإنشاء من المصدر |
| **قيد الانتظار** | بانتظار إجراء (دفع، تأكيد، أو معالجة) |
| **قيد المعالجة** | الفريق/المتجر يعمل على التجهيز |
| **تم الشحن** | غادر المستودع أو سُجّل شحنه |
| **تم التسليم** | وصل للعميل |
| **مكتمل** | أُغلق مسار التنفيذ بنجاح |
| **ملغي** | أُلغي الطلب |
| **مسترد** | اكتمل مسار الاسترداد المالي المرتبط بالطلب |
| **مرتجع** | مرتجع بضاعة/طلب |
| **معلق** | أُوقف مؤقتاً (مراجعة، نقص مخزون، …) |

## حالات الدفع (خمس)

تظهر كشارة على البطاقة وفي القائمة والتفاصيل — مستقلة عن عمود حالة الطلب.

| الحالة | المعنى |
| --- | --- |
| **قيد الانتظار** | لم يُؤكد الدفع بعد |
| **مدفوع** | اكتمل الدفع |
| **مسترد** | أُعيد المبلغ |
| **جزئي** | دُفع جزء من المبلغ |
| **فشل** | فشلت محاولة الدفع |

## تغيير الحالة — متى تستخدمه ومتى لا

1. اسحب البطاقة في الكانبان إلى العمود الجديد، أو اختر الحالة من القائمة في عرض القائمة.
2. انتظر حفظ التغيير؛ عند الفشل تظهر رسالة **فشل في تغيير الحالة**.

**استخدمه** عندما يتفق فريقك أن كرزون هو لوحة المتابعة اليومية وتقبل احتمال اختلاف العرض عن لوحة المتجر.

**لا تستخدمه** كبديل وحيد لإلغاء أو شحن في سلة/زد إن كانت سياسة التشغيل تعتمد لوحة المتجر كمصدر حقيقة — غيّر هناك أولاً وانتظر المزامنة إن لزم.

أزرار الأرشفة والحذف في الواجهة **غير مفعّلة** من شاشة الطلبات؛ لا تعتمد عليها لحذف سجل.
