عندما تحتاج إجابة من العميل قبل متابعة المسار — اختيار أو نص أو رقم — الرسالة وحدها لا تنتظر.

عقدة **طرح سؤال** ترسل السؤال، تنتظر، وتحفظ الإجابة إن أردت، مع مخارج للإجابة وبدون إدخال.

يشرح هذا الدليل أنواع السؤال والمخارج، ومتى تسمح بنص حر مع الاختيار.

## بطاقة سريعة

| | |
| --- | --- |
| **الفئة** | التواصل |
| **المدخل** | واحد |
| **المخارج** | **إجابة** (أو مخرج لكل خيار) · **بدون إدخال** · **بدون تطابق** |
| **الحد الأقصى للخيارات** | ١٠ |
| **حد نص السؤال** | ٦٤٠ حرفاً |

هذه العقدة **تُرسل وتنتظر**. المسار يتوقف عندها حتى يجيب العميل أو تنتهي المهلة — هذا يجعلها أقوى عناصر المسار وأخطرها إن أُسيء ضبطها.

## الحقول

| الحقل | ماذا يفعل |
| --- | --- |
| **نص السؤال** | ما يراه العميل — يدعم إدراج المتغيرات، حتى ٦٤٠ حرفاً |
| **نوع الإجابة** | **اختيار (أزرار)** أو أحد أنواع النص الحر (أدناه) |
| **حفظ الإجابة في** | حقل على بطاقة العميل تُخزَّن فيه القيمة |
| **نص زر الإرسال** *(نوع اختيار فقط)* | يظهر فقط عند نوع "اختيار"، حتى ٢٤ حرفاً |
| **السماح بنص حر** *(نوع اختيار فقط)* | يضيف مساراً للعميل الذي لا ينطبق عليه أي خيار |
| **نوع النص الحر** *(إذا فُعّل أعلاه)* | أي نوع من أنواع النص الحر أدناه |
| **مهلة عدم الإدخال** | رقم + وحدة (دقائق/ساعات/أيام) — الافتراضي دقيقة واحدة |

## أنواع الإجابة

### اختيار (أزرار)

العميل يختار من قائمة خيارات جاهزة. كل خيار يحتوي:

| حقل الخيار | ماذا يعني |
| --- | --- |
| **النص** | ما يظهر على الزر |
| **الوصف** *(اختياري)* | سطر توضيحي إضافي |
| **القيمة** | ما يُخزَّن فعلياً — تُملأ تلقائياً من النص إن تركتها فارغة |

حتى **١٠ خيارات**، قابلة لإعادة الترتيب بالسحب. كل خيار يصبح **مخرجاً مستقلاً** على اللوحة — تربط كل خيار بالفرع المناسب له.

### النص الحر (١١ نوعاً)

| النوع | يقبل |
| --- | --- |
| **نص** | أي كتابة حرة |
| **رقم** | قيمة رقمية |
| **بريد إلكتروني** | عنوان بريد صالح |
| **رقم هاتف** | رقم هاتف |
| **تاريخ** | قيمة تاريخ |
| **رابط (URL)** | رابط صالح |
| **صورة / فيديو / صوت / ملف** | مرفق من النوع المحدد |
| **موقع** | مشاركة موقع |

هذه الأنواع **لا خيارات فيها** — العميل يكتب أو يرفق حراً، والنظام يتحقق من صحة الصيغة (بريد صالح، رابط صالح...) قبل قبولها كإجابة.

## السماح بنص حر مع الاختيار

إذا فعّلت **السماح بنص حر** مع نوع "اختيار"، يمكن للعميل أن يكتب بدلاً من الضغط على زر. اختر لهذا النص الحر **نوعاً** من القائمة أعلاه (نص، رقم، بريد...) ليتحقق النظام من صيغته.

هذا يمنحك الأفضل من العالمين: أزرار سريعة لمن يريد الاختصار، وباب مفتوح لمن لا ينطبق عليه أي خيار جاهز.

## المخارج الثلاثة

| المخرج | متى يُسلك |
| --- | --- |
| **إجابة** | العميل أجاب إجابة مقبولة — عند نوع "اختيار" يوجد مخرج مستقل لكل خيار |
| **بدون إدخال** | انقضت مهلة عدم الإدخال ولم يجب العميل |
| **بدون تطابق** | أجاب بشيء غير صالح (بريد خاطئ الصيغة مثلاً) أو لا يطابق أي خيار متاح |

<Warning>
اربط **بدون إدخال** و**بدون تطابق** دائماً بشيء مفيد — تذكير، إعادة صياغة، أو تحويل لموظف بشري. تركهما بلا وجهة يعني أن العميل المتأخر أو من أجاب بطريقته الخاصة يبقى معلّقاً بلا رد ولا تصعيد.
</Warning>

## المهلة الزمنية

رقم + وحدة (دقائق/ساعات/أيام)، الافتراضي **دقيقة واحدة**. عند انقضائها بلا إجابة يُسلك مخرج **بدون إدخال**.

اختر المهلة حسب طبيعة السؤال: أسئلة سريعة (اختيار من ثلاثة خيارات) لا تحتاج أكثر من دقائق قليلة، بينما سؤال يتطلب تفكيراً أو مرفقاً (صورة، ملف) يستحق مهلة أطول — ساعة أو أكثر.

## لماذا يهم «حفظ الإجابة في»؟

عندما تحفظ الإجابة في حقل تصبح:

- ظاهرة في **لوحة العميل** بجانب المحادثة، فلا يعيد الموظف السؤال نفسه.
- قابلة للاستخدام في **عقدة الشرط** لاحقاً داخل المسار نفسه.
- قابلة للاستخدام في **الشرائح** والاستهداف في الحملات.

سؤال بلا حفظ إجابة يفيد لحظته فقط، ثم تضيع المعلومة.

## كم سؤالاً قبل أن تتعب العميل؟

سؤالان أو ثلاثة كحد عملي قبل إعطاء قيمة أو تحويله لموظف. المسار الذي يستجوب العميل خمس مرات قبل أي فائدة يُهجَر.

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| سؤال بلا **حفظ في** | المعلومة تضيع ويكررها الموظف | اربطه بحقل مناسب |
| ترك **بدون إدخال** فارغاً | العميل الصامت يبقى معلّقاً | ذكّره أو حوّله لموظف |
| ترك **بدون تطابق** فارغاً | إجابة غير صالحة توقف المسار صمتاً | أضف إعادة صياغة أو تحويل |
| خيارات بنصوص طويلة | صعبة القراءة على الجوال | كلمتان لكل خيار |
| مهلة قصيرة جداً لسؤال يتطلب مرفقاً | العميل يفوّت المهلة | مهلة أطول لأنواع الصور/الملفات |
| تجاوز ١٠ خيارات | الواجهة تمنع الإضافة | قسّم لسؤالين أو استخدم قائمة واتساب |
