عندما تجمع تقييماً داخل المسار وتريد حفظه على المحادثة فوراً، لا تحتاج أداة استبيان خارجية.

إجراء **تسجيل تقييم** يكتب CSAT في قاعدة البيانات ويظهر في لوحة العميل بالبريد الوارد.

يشرح هذا الدليل متى تضعه بعد سؤال التقييم.

## بطاقة سريعة

| | |
| --- | --- |
| **الاسم البرمجي** | `insertFeedback` |
| **الفئة في المنتقي** | محادثات |
| **أين يعيش** | إجراء واحد داخل [عقدة الإجراء](/ar/help-center/guides/automations/nodes/actions/overview) |
| **يتطلب** | محادثة وعميل في سياق التنفيذ |

هذا الإجراء يكتب تقييماً (CSAT) مباشرة في قاعدة البيانات لنفس المحادثة الجارية — بلا حاجة لإرسال استبيان خارجي أو ربط أداة أخرى. يظهر التقييم فوراً في [لوحة العميل](/ar/help-center/guides/inbox/customer-panel#تقييم-العميل) بجانب باقي بيانات المحادثة.

## أبعاد التقييم الستة

كل بُعد رقم من ١ إلى ٥، وكلها **اختيارية** — تختار أياً منها يناسب مسارك:

| البُعد | يقيس |
| --- | --- |
| **سرعة الاستجابة** | مدى سرعة الرد على العميل |
| **معرفة الموظف** | مدى فهم الموظف (أو البوت) لطلب العميل |
| **رضا العميل** | الرضا العام عن التعامل |
| **الاحترافية** | أسلوب التعامل والتواصل |
| **المتابعة** | مدى المتابعة بعد الرد الأول |
| **جودة المنتج/الخدمة** | تقييم المنتج أو الخدمة نفسها، لا التعامل |

## حساب "التجربة الإجمالية"

إن أدخلت قيمة لواحد أو أكثر من الأبعاد أعلاه، يحسب الإجراء تلقائياً **متوسط الأبعاد المُدخلة** ويحفظه كحقل "التجربة الإجمالية" — لا تحتاج لحسابه بنفسك.

<Tip>
لا تلزم نفسك بتعبئة الأبعاد الستة كلها في كل استخدام. لو كان سؤالك الآلي يجمع تقييماً عاماً واحداً فقط (مثال: "قيّم تجربتك من ١ إلى ٥")، اربطه ببُعد **رضا العميل** فقط، واترك الباقي فارغاً.
</Tip>

## التعليقات النصية

حقلان مستقلان للنص الحر:

| الحقل | يُستخدم لـ |
| --- | --- |
| **تعليقات (Comments)** | نص التعليق الأساسي المرتبط بالتقييم |
| **ملاحظات إضافية (Additional Feedback)** | نص إضافي منفصل، لا يؤثر على الأبعاد الرقمية |

## ماذا لو أُرسل الإجراء بلا أرقام جديدة؟

إن احتوى الإجراء على تعليق نصي فقط بلا أي رقم تقييم جديد، **يحتفظ النظام بآخر أرقام تقييم مسجّلة لهذه المحادثة** ويضيف التعليق الجديد إليها فقط — بحيث لا تُفقد الأرقام السابقة عند إضافة تعليق متابعة لاحق.

<Warning>
الإجراء **يفشل** إن لم يُرفق ولا رقم تقييم واحد صالح (١-٥) ولا أي تعليق نصي. تأكد من وجود قيمة واحدة على الأقل قبل النشر — وصّل مخرج فشل بديل إن كان السؤال الآلي يسمح للعميل بتجاوز التقييم بلا إجابة.
</Warning>

## ماذا يحدث بعد التسجيل؟

- يظهر التقييم فوراً في [لوحة العميل](/ar/help-center/guides/inbox/customer-panel#تقييم-العميل) لأي موظف يفتح المحادثة.
- يُطلَق حدث `conversation.feedbackAdded` — تستطيع بناء مسار أتمتة آخر يستمع لهذا الحدث (مثال: تنبيه المدير عند تقييم منخفض).

## متى تستخدمه؟

| احتياجك | الأنسب |
| --- | --- |
| تسجيل تقييم رضا العميل مباشرة بعد سؤال آلي | تسجيل تقييم العميل |
| إرسال استبيان رضا مفصّل خارجي (نموذج، بريد) | [إرسال بريد إلكتروني](/ar/help-center/guides/automations/nodes/email) أو أداة استبيانات خارجية عبر [طلب HTTP](/ar/help-center/guides/automations/nodes/actions/http-request) |

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| قيمة تقييم خارج المدى ١-٥ | تُتجاهَل القيمة بصمت | تأكد أن السؤال الآلي يقبل فقط قيماً بين ١ و٥ |
| الإجراء بلا رقم ولا تعليق | فشل الإجراء بالكامل | وصّل مخرج فشل، أو اجعل حقلاً واحداً على الأقل إلزامياً في السؤال السابق |
| تنفيذ الإجراء خارج سياق محادثة فعلية | فشل الإجراء (يتطلب محادثة وعميل محدَّدين) | تأكد أن المشغّل والمسار يحملان سياق محادثة قبل هذا الإجراء |
