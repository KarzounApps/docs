## بطاقة سريعة

| | |
| --- | --- |
| **الاسم البرمجي** | `setProperty` |
| **الفئة في المنتقي** | أساسي |
| **أين يعيش** | إجراء واحد داخل [عقدة الإجراء](/ar/help-center/guides/automations/nodes/actions/overview) |
| **عدد العوامل** | ٤٧ عاملاً: ٢٠ للنص، ١٦ للأرقام، ٨ للتاريخ، ٢ للمنطقي، ١ لـ JSON |

هذا هو الإجراء الذي يحوّل الأتمتة من "مرسل رسائل" إلى **نظام يبني معرفة تراكمية حقيقية عن عملائك**. لا يقتصر على "اكتب قيمة في حقل" — بداخله محرك معالجة نصوص وأرقام وتواريخ كامل، بحيث تحسب وتحوّل وتنسّق البيانات في نفس الخطوة التي تحفظها.

<Info>
**وسائط مطلوبة:** محرر تحديث خاصية العميل مفتوحاً، يظهر فيه اختيار الحقل الهدف، ثم قائمة العوامل المتاحة حسب نوع الحقل، ثم الحقول الإضافية لعامل "استخراج نص قبل" كمثال.
المسار المقترح: `/images/help/automations/action-set-property.webp`
</Info>

## كيف يعمل

1. تختار **الحقل الهدف**: أي حقل على بطاقة العميل — افتراضي (المدينة، اللغة المفضلة) أو مخصص أنشأته أنت.
2. نوع الحقل يحدد تلقائياً **مجموعة العوامل المتاحة** (نص، رقم، تاريخ، منطقي، أو JSON) — لا ترى عوامل لا تناسب نوع الحقل.
3. تختار **العامل**، فتظهر فقط الحقول الإضافية التي يحتاجها هذا العامل تحديداً (قيمة، رقم، نقطة بداية، طول، نص للبحث...).

<Tip>
هذا ما يحوّل الأتمتة من مرسل رسائل إلى نظام معرفة متراكمة:

1. السؤال الآلي يجمع معلومة من العميل.
2. هذا الإجراء يعالجها (ينسّقها، يحسبها، يحوّلها) ويحفظها على البطاقة.
3. [الشريحة](/ar/help-center/guides/contacts/segments/overview) تستخدمها للاستهداف.
4. [الحملة](/ar/help-center/guides/broadcasts/audience) القادمة تصل لمن يجب فقط.
</Tip>

## عوامل النص (٢٠ عامل)

| العامل | ماذا يفعل |
| --- | --- |
| **قيمة مباشرة** | يكتب القيمة كما هي (نص ثابت أو متغيّر من المسار) |
| **قيمة متعددة الأسطر** | نفس القيمة المباشرة، لكن بمساحة تحرير تدعم فواصل الأسطر — للنصوص الطويلة |
| **حساب بمعادلة رياضية** | يحسب نتيجة معادلة نصية تكتبها وتحفظ النتيجة كنص |
| **تقليم الفراغات (Trim)** | يحذف الفراغات الزائدة من بداية ونهاية النص |
| **نص جزئي (Substring)** | يستخرج جزءاً من النص بتحديد **نقطة البداية** و**الطول** |
| **استبدال نص** | يبحث عن نص ويستبدله بآخر (غير حسّاس لحالة الأحرف) |
| **استبدال نص (حسّاس لحالة الأحرف)** | نفس الاستبدال لكن بمطابقة دقيقة لحالة الأحرف الكبيرة/الصغيرة |
| **تحويل لحروف صغيرة** | يحوّل كل النص لحروف صغيرة (`lower case`) |
| **تحويل لحروف كبيرة** | يحوّل كل النص لحروف كبيرة (`UPPER CASE`) |
| **توليد نص عشوائي** | يولّد نصاً عشوائياً بصيغة (Formatter) تحددها — مفيد لتوليد رموز أو أكواد فريدة |
| **ترميز URL (Encode)** | يحوّل النص لصيغة صالحة للاستخدام داخل رابط (URL Encoding) |
| **فك ترميز URL (Decode)** | يعكس عملية الترميز أعلاه |
| **ترميز Base64** | يحوّل النص لصيغة Base64 |
| **فك ترميز Base64** | يعكس عملية ترميز Base64 |
| **تحويل لصيغة رابط (Slug)** | يحوّل النص لصيغة صالحة داخل روابط الويب (أحرف صغيرة، شرطات بدل فراغات) |
| **النص قبل أول تطابق** | يستخرج كل ما يسبق أول ظهور لنص تبحث عنه |
| **النص قبل آخر تطابق** | يستخرج كل ما يسبق آخر ظهور لنص تبحث عنه |
| **النص بعد أول تطابق** | يستخرج كل ما يأتي بعد أول ظهور لنص تبحث عنه |
| **النص بعد آخر تطابق** | يستخرج كل ما يأتي بعد آخر ظهور لنص تبحث عنه |
| **طول النص** | يحسب عدد الأحرف في النص ويحفظه كرقم |

<Tip>
مثال عملي لـ«النص بعد آخر تطابق»: لو كان بريد العميل `ahmed@company.com`، استخدمه بالبحث عن `@` لاستخراج `company.com` وحفظه في حقل «نطاق البريد» — مفيد لتصنيف العملاء حسب الشركة تلقائياً.
</Tip>

## عوامل الأرقام (١٦ عامل)

| العامل | ماذا يفعل |
| --- | --- |
| **قيمة مباشرة** | يكتب الرقم كما هو |
| **حساب بمعادلة رياضية** | يحسب نتيجة معادلة رقمية تكتبها |
| **زيادة الرقم بـ...** | يضيف قيمة لرقم الحقل الحالي ويحفظ الناتج في نفس الحقل |
| **تقليل الرقم بـ...** | يطرح قيمة من رقم الحقل الحالي |
| **توليد رقم عشوائي** | يولّد رقماً عشوائياً بين **الحد الأدنى** و**الحد الأعلى** تحددهما |
| **جمع (+)** | يجمع قيمتين رقميتين |
| **طرح (−)** | يطرح رقماً من آخر |
| **ضرب (×)** | يضرب قيمتين رقميتين |
| **قسمة (÷)** | يقسم قيمة على أخرى |
| **باقي القسمة (mod)** | يحسب باقي قسمة رقم على آخر |
| **رفع لأس (^)** | يرفع رقماً لأس معين |
| **اللوغاريتم الطبيعي** | يحسب اللوغاريتم الطبيعي للرقم |
| **الجذر التربيعي** | يحسب الجذر التربيعي للرقم |
| **تقريب (Round)** | يقرّب الرقم لأقرب عدد صحيح |
| **جزء صحيح للأسفل (Floor)** | يقرّب الرقم للأسفل دائماً |
| **جزء صحيح للأعلى (Ceil)** | يقرّب الرقم للأعلى دائماً |

## عوامل التاريخ (٨ عوامل)

| العامل | ماذا يفعل |
| --- | --- |
| **قيمة مباشرة** | يكتب تاريخاً محدداً |
| **تنسيق حقل تاريخ** | يعيد تنسيق تاريخ موجود بصيغة عرض تحددها |
| **اليوم** | يحفظ تاريخ اليوم الحالي — لا يحتاج أي حقل إضافي |
| **غداً** | يحفظ تاريخ الغد |
| **أمس** | يحفظ تاريخ أمس |
| **إضافة أيام** | يضيف عدداً من الأيام لتاريخ موجود |
| **إضافة أسابيع** | يضيف عدداً من الأسابيع لتاريخ موجود |
| **إضافة أشهر** | يضيف عدداً من الأشهر لتاريخ موجود |

<Tip>
مثال عملي: بعد تأكيد طلب، استخدم **إضافة أيام** (٧ أيام مثلاً) على تاريخ اليوم واحفظه في حقل «تاريخ متابعة الرضا» — ثم استخدم [المشغّل الزمني/الشرط](/ar/help-center/guides/automations/nodes/condition) في مسار آخر لإرسال استفسار رضا تلقائي في ذلك التاريخ.
</Tip>

| العامل | ماذا يفعل |
| --- | --- |

| **ضبط خطأ (False)** | يضبط الحقل المنطقي على `false` |

## عامل JSON (عامل واحد)

| العامل | ماذا يفعل |
| --- | --- |
| **قيمة JSON مباشرة** | يكتب بنية JSON كاملة (كائن أو مصفوفة) في الحقل مباشرة |

## متى تستخدمه؟

| احتياجك | الأنسب |
| --- | --- |
| حفظ معلومة جمعتها من سؤال آلي كما هي | **قيمة مباشرة** |
| حساب أو تحويل القيمة قبل حفظها | العامل المناسب من الجداول أعلاه |
| منطق معقد يتجاوز العوامل الجاهزة | [دالة JavaScript](/ar/help-center/guides/automations/nodes/actions/js-function) ثم [تحديث خاصية العميل](#) بالنتيجة |
| إضافة أو إزالة **وسم** بدل حقل خاصية | [إجراءات الوسوم](/ar/help-center/guides/automations/assign-tag-note#إجراءات-الوسوم) |

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| اختيار عامل رقمي على حقل نصي فعلياً | فشل الحفظ أو قيمة غير متوقعة | تأكد من نوع الحقل الهدف قبل اختيار العامل |
| استخدام «زيادة/تقليل الرقم» بلا قيمة ابتدائية موجودة | نتيجة غير متوقعة إن كان الحقل فارغاً | تأكد من وجود قيمة ابتدائية أو استخدم «قيمة مباشرة» أولاً |
| نص بحث («find») غير مطابق فعلياً في عوامل الاستخراج | نتيجة فارغة بصمت | اختبر العامل بقيمة حقيقية قبل النشر |
| استخدام عوامل التاريخ بدون تحديد صيغة تنسيق واضحة | تاريخ يظهر بصيغة غير متوقعة في الرسائل | حدد صيغة العرض بوضوح في «تنسيق حقل تاريخ» |
| الاعتماد على عامل معقد بدل الأبسط الكافي | صعوبة صيانة المسار لاحقاً | اختر أبسط عامل يحقق الهدف |
