## بطاقة سريعة

| | |
| --- | --- |
| **الفئة** | التكاملات |
| **المدخل** | واحد |
| **المخرج** | واحد رئيسي + مخرج فشل مستقل لكل إجراء يدعمه |
| **البنية** | قائمة إجراءات مرتّبة، تُنفَّذ الواحد تلو الآخر من الأعلى للأسفل |

هذه العقدة هي **الأكثر كثافة في كل الأتمتة**. بداخلها أكثر من ٥٠ إجراء جاهزاً يغطي أشهر العمليات التشغيلية بلا أي إعداد تقني، بالإضافة لإجراءات متقدمة تفتح المسار على أي نظام خارجي على الإنترنت — وهنا يتحول مسارك من "رد آلي" إلى **تكامل برمجي حقيقي**.

## الآلية العامة

- تضيف إجراءات للقائمة بالترتيب الذي تريد تنفيذه به.
- كل إجراء له **مفتاح تفعيل** — تستطيع تعطيل إجراء مؤقتاً دون حذفه.
- تسحب الإجراءات لإعادة ترتيبها؛ الترتيب مهم لأن كل إجراء لاحق قد يعتمد على نتيجة سابق (مثال: طلب HTTP يحفظ قيمة، ثم إجراء لاحق يستخدمها في شرط أو رسالة).
- **لا يمكن حذف آخر إجراء متبقٍ** — العقدة تحتاج إجراءً واحداً على الأقل لتكون صالحة.
- الإجراءات مبوَّبة بفئات في منتقي الإضافة، لتسهيل العثور على ما تحتاجه بين العشرات المتاحة.

<Info>
**وسائط مطلوبة:** عقدة إجراء مفتوحة بثلاثة إجراءات مرتّبة (إسناد، ثم طلب HTTP، ثم وسم)، مع أيقونة سحب لإعادة الترتيب ومفتاح تفعيل لكل إجراء.
المسار المقترح: `/images/help/automations/node-actions-list.webp`
</Info>

## المتغيرات الديناميكية

معظم حقول الإجراءات في هذه العقدة تقبل **متغيرات المسار** (`{{...}}`) — قيمة عميل، إجابة سؤال سابق، أو نتيجة إجراء سابق. هذا ما يجعل نفس الإجراء يتصرف بشكل مختلف لكل عميل حسب بياناته الحقيقية، بدل قيمة ثابتة واحدة لكل من يمر بالمسار.

## فئات الإجراءات

المنتقي يعرض الإجراءات مقسّمة حسب فئتها. القائمة الظاهرة عندك تعتمد على القنوات والتطبيقات المرتبطة بمساحة عملك — إن لم تجد إجراء تطبيق معيّن، فالتطبيق غالباً غير مرتبط بعد؛ راجع [تثبيت تطبيق وربطه](/ar/help-center/guides/automations/apps/install-connect).

## الإجراءات المتقدمة: الاتصال بأي شيء

هذه الإجراءات هي الفارق بين "أتمتة داخلية محدودة" و"محرك تكامل كامل" — بها، أي نظام له واجهة برمجية على الإنترنت يصبح جزءاً من مسارك:

| الإجراء | ماذا يفعل باختصار | المرجع الكامل |
| --- | --- | --- |
| **طلب HTTP** | يتصل بأي واجهة برمجية خارجية على الإنترنت، بمحرر Postman كامل | [طلب HTTP](/ar/help-center/guides/automations/nodes/actions/http-request) |
| **GraphQL الداخلي** | يستدعي واجهة كرزون البرمجية نفسها لعمليات دقيقة لا تغطيها إجراءات جاهزة | [GraphQL الداخلي](/ar/help-center/guides/automations/nodes/actions/graphql) |
| **دالة JavaScript** | كود مخصص كامل الصلاحية لمنطق أو حسابات معقدة | [دالة JavaScript](/ar/help-center/guides/automations/nodes/actions/js-function) |
| **عمليات JSON** | ٢٨ عملية جاهزة لتحويل وتلخيص بيانات JSON بلا كتابة كود | [عمليات JSON](/ar/help-center/guides/automations/nodes/actions/json-operations) |

<Tip>
**متى تستخدم أيّاً من الأربعة؟**

| احتياجك | الإجراء الأنسب |
| --- | --- |
| جلب/إرسال بيانات لأي خدمة خارجية على الإنترنت | طلب HTTP |
| قراءة أو تعديل بيانات كرزون الداخلية ببرمجية دقيقة | GraphQL الداخلي |
| منطق حسابي أو تحويل بيانات لا تغطيه العقد الجاهزة | دالة JavaScript |
| تنظيف أو تحويل استجابة JSON معقدة لحقول بسيطة | عمليات JSON |
</Tip>

## الإجراءات الكبيرة والحساسة: مرجع خاص لكل منها

بعض الإجراءات الجاهزة معقدة بما يكفي لتستحق صفحة مستقلة بذاتها — عدد خيارات كبير، أو أثر مباشر على المال أو رضا العميل:

| الإجراء | لماذا يستحق صفحة خاصة | المرجع الكامل |
| --- | --- | --- |
| **تحديث خاصية العميل** | ٤٧ عامل معالجة نص/رقم/تاريخ/منطقي/JSON | [تحديث خاصية العميل](/ar/help-center/guides/automations/nodes/actions/set-property) |
| **قالب واتساب من الأتمتة** | يرسل لأي رقم خارج المحادثة، بتكلفة فعلية وسياسات ميتا | [قالب واتساب من الأتمتة](/ar/help-center/guides/automations/nodes/actions/whatsapp-template) |
| **رسالة مباشرة (فيسبوك/إنستغرام)** | حتى ٥ رسائل، ١٣ رداً سريعاً، ١٠ بطاقات، ودعم مساعد ذكاء اصطناعي | [رسالة مباشرة](/ar/help-center/guides/automations/nodes/actions/send-dm) |
| **تسجيل تقييم العميل** | ستة أبعاد تقييم مستقلة + حساب تلقائي للمعدل العام | [تسجيل تقييم العميل](/ar/help-center/guides/automations/nodes/actions/insert-feedback) |

## فهرس كل الإجراءات الجاهزة حسب الفئة

باقي أكثر من ٤٠ إجراءً جاهزاً — مجمّعة في صفحة واحدة لكل فئة، لتجد كل ما تحتاجه بسرعة دون تكرار:

| الفئة | يغطي | المرجع |
| --- | --- | --- |
| **الإسناد، الوسوم، الملاحظات، الحالة** | إسناد لموظف/قسم، الإسناد الذكي، الوسوم (محادثة وعميل)، الملاحظة الداخلية، الحل والتأجيل | [الإسناد والوسوم والملاحظات](/ar/help-center/guides/automations/assign-tag-note) |
| **الانتظار والمتابعة** | تأخير التنفيذ، متابعة تُلغى تلقائياً عند رد العميل، ساعات العمل | [الانتظار والمتابعة](/ar/help-center/guides/automations/wait-and-follow-up) |
| **التسليم** | تسليم من بوت لموظف بشري والعكس | [التسليم بين البوت والوكيل](/ar/help-center/guides/automations/handoff) |
| **العمليات والتجارة الإلكترونية** | مواعيد، سلة التسوق، طلبات العميل، بدء الدفع عبر واتساب | [العمليات والتجارة الإلكترونية](/ar/help-center/guides/automations/operations-actions) |
| **الإشعارات** | إشعار واتساب مباشر، إشعار تطبيق (Push) | [إجراءات الإشعارات](/ar/help-center/guides/automations/notifications-actions) |
| **التسويق** | الاشتراك وإلغاء الاشتراك من الحملات | [إجراءات التسويق](/ar/help-center/guides/automations/marketing-actions) |
| **أدوات الوكيل الذكي** | بحث الإنترنت، قراءة صفحة، قاعدة المعرفة، البحث في المنتجات | [أدوات الوكيل الذكي](/ar/help-center/guides/automations/ai-tools-actions) |
| **التطبيقات المثبَّتة** | إجراءات خاصة بكل تطبيق (Google Sheets، سلة، زد...) | [استخدام التطبيقات في الأتمتة](/ar/help-center/guides/automations/apps/use-in-automations) |

## متى تستخدم إجراء جاهز، ومتى تبني بنفسك؟

| الحاجة | الحل الأصح |
| --- | --- |
| عملية شائعة (إسناد، وسم، تأخير) | إجراء جاهز — أسرع وأقل عرضة للخطأ |
| ربط تطبيق مثبَّت (سلة، Google Sheets) | إجراء التطبيق الجاهز إن وُجد |
| خدمة خارجية غير مدعومة كتطبيق | طلب HTTP |
| عملية داخلية دقيقة لا يغطيها إجراء جاهز | GraphQL الداخلي |
| منطق حسابي معقد | دالة JavaScript |

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| ترتيب إجراءات خاطئ (استخدام نتيجة قبل حسابها) | قيمة فارغة أو قديمة | رتّب الإجراءات بحيث يسبق كل اعتماد ما يعتمد عليه |
| تعطيل إجراء بدل حذفه ثم نشر المسار وتوقّع تنفيذه | إجراء معطّل بصمت لا ينفَّذ | تأكد من حالة مفتاح التفعيل قبل النشر |
| استخدام إجراء متقدم (HTTP/JS/GraphQL) لعملية بسيطة لها إجراء جاهز | تعقيد بلا فائدة وصعوبة صيانة | استخدم الإجراء الجاهز الأبسط أولاً |
| نشر إجراء حساس (قالب واتساب، رسالة مباشرة) بلا اختباره فعلياً | خطأ يُكتشف من العميل لا من المطوّر | اختبر كل إجراء جديد قبل تفعيل المسار |
