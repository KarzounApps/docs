## بطاقة سريعة

| | |
| --- | --- |
| **الفئة** | التوضيح |
| **المدخل** | لا يوجد |
| **المخرج** | لا يوجد |
| **التنفيذ** | لا تُنفَّذ أبداً — عنصر بصري فقط |

هذه العقدة الوحيدة **بلا أي منفذ اتصال**. لا تدخل ضمن تدفق التنفيذ إطلاقاً؛ وجودها أو حذفها لا يغيّر سلوك المسار بأي شكل.

## الحقول

| الحقل | ماذا يعني |
| --- | --- |
| **النص** | التعليق أو التوضيح الذي تريد كتابته |
| **اللون** | واحد من ستة ألوان: أصفر، أزرق، أخضر، وردي، بنفسجي، برتقالي (الافتراضي: أصفر) |

يمكنك أيضاً **تكبير حجمها** بالسحب من زاويتها على اللوحة — هذا تغيير بصري فقط لتحسين القراءة، ولا يُحفظ كإعداد منفصل في بيانات العقدة.

<Info>
**وسائط مطلوبة:** لوحة مسار تحتوي عقدة أو عقدتين وملاحظة لاصقة بلون مختلف بجانبها تشرح منطق ذلك الجزء من المسار.  
المسار المقترح: `/images/help/automations/node-sticky-note-example.webp`
</Info>

## لماذا تحتاجها؟

مسار بعشرين عقدة بلا أي توضيح يصعب على أي زميل جديد فهمه بسرعة. الملاحظة اللاصقة تحلّ هذا دون التأثير على المنطق الفعلي:

| استخدام | مثال |
| --- | --- |
| **توضيح قسم كامل** | «هذا الجزء يعالج طلبات الاسترجاع فقط» |
| **تحذير لزميل** | «لا تعدّل هذه العقدة بدون التنسيق مع فريق المبيعات» |
| **تسجيل سبب قرار** | «استخدمنا شرط المدينة هنا لأن التسعير يختلف إقليمياً» |
| **علامة عمل غير مكتمل** | «مؤقت — سيُستبدل بتكامل سلة عند توفره» |

## استخدام الألوان بذكاء

<Tip>
اعتمد نظام ألوان ثابتاً في فريقك — مثلاً: أصفر للتوضيح العام، أحمر/برتقالي للتحذيرات، أخضر للأقسام المكتملة والمختبرة. هذا يجعل مسح اللوحة بالعين كافياً لفهم حالة كل قسم دون قراءة كل نص.
</Tip>

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| توقع أن الملاحظة تؤثر على التنفيذ | فهم خاطئ للمسار | تذكّر: بلا منافذ، بلا تنفيذ، عنصر بصري بحت |
| ملاحظات كثيرة متراكمة وقديمة | لوحة مشوَّشة بمعلومات منتهية الصلاحية | راجع الملاحظات دورياً واحذف ما لم يعد صحيحاً |
| نص طويل جداً داخل ملاحظة صغيرة | صعوبة القراءة | كبّر حجمها أو قسّم الملاحظة لعدة ملاحظات مركّزة |
