عندما يرد المسار على العميل، شكل الرسالة وحدود القناة يحددان إن وصلت كما تتوقع.

عقدة **إرسال رسالة** ترسل حتى خمس رسائل بأنواع متعددة (نص، وسائط، تفاعلية، واتساب) ضمن سياق المحادثة الجارية.

يشرح هذا الدليل أنواع الرسائل، الأزرار، وما يجب الانتباه له قبل النشر.

## بطاقة سريعة

| | |
| --- | --- |
| **الفئة** | التواصل |
| **المدخل** | واحد |
| **المخرج الافتراضي** | مخرج رئيسي واحد («الخطوة التالية») |
| **مخارج إضافية** | تظهر حسب نوع الرسالة — انظر أدناه |
| **الحد الأقصى** | ٥ رسائل في العقدة الواحدة |
| **الاستخدام** | إخبار العميل بشيء، أو إرسال تفاعلي بفروع عند الرد/الفشل |

للنص البسيط بلا أزرار رد: العقدة **تُرسل ولا تنتظر**. إن كنت تحتاج انتظار إجابة حرة والتفرّع عليها، استخدم [عقدة طرح سؤال](/ar/help-center/guides/automations/nodes/question). أما أزرار الرد السريع وقائمة واتساب وقالب/تدفق واتساب فلها **منافذ ربط خاصة** على اللوحة.

## منافذ الإخراج (ليست «مخرج واحد بلا فروع»)

| ما في الرسالة | المنافذ الإضافية على العقدة |
| --- | --- |
| **نص** بأزرار **رد سريع** | منفذ لكل زر رد — نقر العميل يوجّه لذلك الفرع |
| **قائمة واتساب** | منفذ لكل صف في الأقسام |
| **قالب واتساب** بأزرار `BUTTON_` | منفذ لكل زر قالب + منفذ أحمر **عند الفشل** (`onFailure`) إن وُجد |
| **تدفق واتساب (Flow)** | منفذ **عند الإرسال/الإكمال** + منفذ أحمر **عند الفشل** |
| أزرار **رابط (URL)** فقط | بلا منفذ مسار — تفتح الرابط خارجياً |

المخرج الرئيسي يبقى لـ«بعد الإرسال» عندما لا ينتظر المسار تفاعلاً، أو كمسار افتراضي بجانب الفروع. **لا تفترض** أن كل عقدة رسالة لها مخرج واحد فقط.

## أنواع الرسائل الخمسة عشر

الأنواع مقسّمة في المحرر إلى ثلاث مجموعات:

### أساسية

| النوع | المحتوى المطلوب |
| --- | --- |
| **نص** | نص الرسالة + أزرار اختيارية (اقرأ أدناه) |
| **صورة** | رابط الصورة |
| **فيديو** | رابط الفيديو |
| **صوت** | رابط الملف الصوتي |
| **ملف** | رابط الملف |
| **موقع** | خط العرض والطول + اسم وعنوان اختياريان |

### تفاعلية

| النوع | المحتوى المطلوب |
| --- | --- |
| **بطاقة** | ترويسة (صورة/نص) + نص أساسي + تذييل اختياري + أزرار |
| **كاروسيل** | عدة بطاقات (تبدأ ببطاقتين) — كل بطاقة: عنوان، عنوان فرعي، صورة، أزرار |

### خاصة بواتساب

| النوع | المحتوى المطلوب |
| --- | --- |
| **قالب واتساب** | قالب معتمد من ميتا — إلزامي خارج نافذة الرد |
| **تدفق واتساب (Flow)** | نص أساسي + تذييل + زر فتح التدفق + اسم + حقل حفظ نتيجة التدفق |
| **قائمة واتساب** | ترويسة + نص أساسي + تذييل + أقسام، كل قسم يحوي صفوفاً (عنوان + وصف) |
| **طلب موقع واتساب** | نص يطلب من العميل مشاركة موقعه عبر زر تفاعلي |
| **منتج واتساب** | منتج واحد من كتالوجك + تذييل اختياري |
| **قائمة منتجات واتساب** | ترويسة + نص + أقسام منتجات |
| **كاروسيل منتجات واتساب** | نص + قائمة معرّفات منتجات ومتغيراتها |
| **كتالوج واتساب** | نص + تذييل + صورة مصغّرة اختيارية لمنتج |

<Warning>
أنواع واتساب الثمانية (قالب، تدفق، قائمة، طلب موقع، منتج، قائمة منتجات، كاروسيل منتجات، كتالوج) تعمل على قناة واتساب فقط، وبعضها يتطلب كتالوج منتجات مربوطاً أو موافقة ميتا المسبقة على القالب. اختبرها على القناة الحقيقية قبل الاعتماد عليها في مسار حي.
</Warning>

## الأزرار (نوع النص فقط)

عندما تكون الرسالة من نوع **نص**، يظهر محرر أزرار يتيح لك إضافة أزرار بنوعين:

| نوع الزر | ماذا يفعل |
| --- | --- |
| **رابط (URL)** | يفتح صفحة خارجية عند النقر |
| **رد سريع (Quick Reply)** | يربط الزر بعقدة موجودة أو جديدة في المسار — نقر العميل يوجّهه لتلك العقدة |

باقي الأنواع التفاعلية (بطاقة، كاروسيل، قائمة) لها أزرارها الخاصة داخل بنيتها، ولا تستخدم محرر الأزرار العام.

## كم رسالة في العقدة الواحدة؟

**٥ كحد أقصى**، مُطبَّق مباشرة في واجهة الإضافة — الزر يُعطَّل تلقائياً عند الوصول للحد. الرسائل تُرسل بالترتيب الذي تراه في العقدة، وتستطيع سحبها لإعادة الترتيب.

<Tip>
هذا الحد مقصود: خمس رسائل متتابعة سلفاً كثيرة على شاشة عميل. إن احتجت أكثر، الأصح غالباً أن تسأل سؤالاً (عقدة طرح سؤال) أو تنتظر تفاعلاً بدل الاستمرار في الإرسال الأحادي الاتجاه.
</Tip>

## متى تستخدم كل نوع؟

| احتياجك | النوع الأنسب |
| --- | --- |
| ترحيب أو تأكيد بسيط | نص |
| عرض منتج واحد بصرياً | بطاقة أو منتج واتساب |
| عرض عدة منتجات للمقارنة | كاروسيل أو كاروسيل منتجات واتساب |
| قائمة خيارات طويلة | قائمة واتساب |
| نموذج تفاعلي متعدد الخطوات | تدفق واتساب |
| موقع فرع أو نقطة استلام | موقع |
| رسالة مبتدئة من طرفك خارج نافذة الرد على واتساب | قالب واتساب (إلزامي) |
| طلب موقع العميل نفسه | طلب موقع واتساب |

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| خمس رسائل متتابعة في بداية المسار | إحساس بالإغراق | رسالة واحدة ثم سؤال |
| نص عادي خارج نافذة الرد على واتساب | لا تصل الرسالة | استخدم قالب واتساب |
| كاروسيل منتجات بدون كتالوج مربوط | فشل الإرسال | اربط كتالوج المنتجات أولاً |
| زر رد سريع غير موصول بعقدة | نقر العميل بلا نتيجة | اربط الزر بعقدة فعلية |
| نص طويل في زر (أكثر من نافذة القناة) | يُقصّ أو يُرفض | التزم بحدود القناة |
