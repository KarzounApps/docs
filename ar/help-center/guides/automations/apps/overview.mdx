عندما يعيش متجرك وجداولك ومدفوعاتك خارج كرزون، المسار يبقى أعمى إن لم يُربط.

**التطبيقات** جسر يجعل سلة وزد وشوبيفاي وSheets وغيرها تتحدث مع الأتمتة — تثبيتاً وربطاً ثم إجراءً أو مشغّلاً.

يشرح هذا الدليل أين تجد التطبيقات، والفرق بين المتجر والإعدادات واستخدامها داخل المسار.

## أين تجدها؟

هذه أول نقطة تربك المستخدمين، لأن التطبيقات موزّعة على ثلاثة أماكن بأدوار مختلفة:

| المكان | المسار | دوره |
| --- | --- | --- |
| **المتجر** | `/marketplace` | تتصفح التطبيقات المتاحة وتثبّت ما تحتاجه |
| **الإعدادات ← التطبيقات** | `/settings/applications` | تربط التطبيق بحسابك وتديره وتراقب حالته |
| **الأتمتة** | داخل عقدة **إجراء** أو كمشغّل | تستخدم التطبيق فعلياً في مساراتك |

الترتيب دائماً: **تثبيت** من المتجر ← **ربط** من الإعدادات ← **استخدام** في الأتمتة. تخطي أي خطوة يجعل التطبيق يظهر لكنه لا يعمل.

## تطبيق أم قناة؟

فرق جوهري يستحق التوضيح:

| | **قناة تواصل** | **تطبيق (تكامل)** |
| --- | --- | --- |
| ما هي | طريق يصلك عبره العميل | نظام خارجي يتبادل معه كرزون البيانات والأوامر |
| أمثلة | واتساب، إنستغرام، البريد، الدردشة | سلة، Google Sheets، Calendly |
| أين تُدار | القنوات / البريد الوارد | المتجر والإعدادات ← التطبيقات |
| النتيجة | محادثات | بيانات وأحداث وإجراءات |

بعض الأسماء تظهر في المكانين (فيسبوك وإنستغرام مثلاً) بأدوار مختلفة: قناة للمحادثات، وتطبيق لعمليات أخرى. انظر إلى **ما تريد فعله** لا إلى الاسم.

## فئات التطبيقات المتاحة

| الفئة | أمثلة | ماذا تتيح |
| --- | --- | --- |
| **المتاجر الإلكترونية** | سلة · زد · شوبيفاي · ووكومرس · متجرة | مزامنة العملاء والمنتجات والطلبات، وأحداث الطلبات كمشغّلات |
| **الإنتاجية** | Google Sheets · Dropbox · Slack · GitHub | تسجيل البيانات، إشعارات الفريق، ملفات |
| **المواعيد** | Calendly | حجز المواعيد وأحداثها داخل المسار |
| **المدفوعات** | تمارا · تابي · مُيسر · هايبرباي | عمليات دفع وتقسيط ضمن مساراتك |
| **التسويق والقياس** | Meta Conversions API · TikTok Events API · Google Analytics 4 · سناب شات | إرسال أحداث التحويل لمنصات الإعلان |
| **السوشيال** | صفحات فيسبوك · إنستغرام للأعمال | عمليات على حساباتك الاجتماعية |

ما يظهر لك في المتجر هو المتاح فعلياً لحسابك، وقد يزيد مع كل تحديث.

## كيف تدخل التطبيقات مساراتك؟

بطريقتين متكاملتين:

### ١. إجراء داخل المسار

داخل عقدة **إجراء** تختار تطبيقاً متصلاً ثم إجراءً من إجراءاته: أضف صفاً في جدول، أنشئ طلباً، حدّث حالة، أرسل إشعاراً. الأتمتة هنا **تأمر** النظام الخارجي.

### ٢. مشغّل من التطبيق

بعض التطبيقات ترسل أحداثها إلى كرزون، فتصبح بداية للمسار: طلب جديد في متجرك، موعد جديد محجوز، حالة طلب تغيّرت. الأتمتة هنا **تستمع** للنظام الخارجي.

التفاصيل في [استخدام التطبيقات في الأتمتات](/ar/help-center/guides/automations/apps/use-in-automations).

<Warning>
إجراءات التطبيق تعمل فقط عندما تكون حالة التطبيق **متصل**. تطبيق مثبّت لكنه غير مربوط سيجعل الخطوة **تفشل** في سجل التنفيذ — والأتمتة تبدو «لا تعمل» بينما المشكلة في الربط.
</Warning>

## ماذا تربح عملياً؟

| بدون تكامل | مع تكامل |
| --- | --- |
| الموظف يفتح لوحة المتجر ليتحقق من الطلب | بيانات الطلب تصل مع المحادثة |
| تسجيل يدوي للطلبات في جدول | صف يُضاف تلقائياً لحظة الحدث |
| نسيان متابعة سلة متروكة | مسار يبدأ فور وقوع الحدث |
| العميل يعيد شرح مشكلته | سياق جاهز في لوحة العميل |
| تقارير من عدة مصادر متفرقة | بيانات موحّدة قابلة للاستهداف |
