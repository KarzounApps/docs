أغلب أعطال التطبيقات لها أسباب قليلة متكررة. هذه الصفحة مرتّبة بحيث تبدأ بالفحص السريع ثم تنزل إلى الحالة التي تواجهها.

## الفحص السريع (دقيقتان)

قبل أي تشخيص عميق، امرر على هذه النقاط:

1. إن تعطّلت المنصة أو الأتمتة لكل الفريق فجأة، راجع [صحة الخدمة](https://status.karzoun.chat/) أولاً.
2. افتح **الإعدادات ← التطبيقات** — ما شارة حالة التطبيق؟
3. إن كانت **غير متصل** أو **به خطأ**، فالمشكلة في الربط لا في المسار.
4. افتح **سجل التنفيذ** في الأتمتة وحدّد **أي خطوة** فشلت.
5. تحقق أن الأتمتة **مفعّلة** وأن مشغّلها **نشط**.
6. تحقق أن الوجهة في النظام الخارجي ما زالت موجودة بنفس الاسم.

هذه الخطوات تحل أغلب البلاغات دون تصعيد.

<Info>
**وسائط مطلوبة:** صفحة التطبيقات وفيها ثلاثة تطبيقات بشارات مختلفة (متصل، غير متصل، به خطأ)، وبجانبها خطوة فاشلة في سجل التنفيذ.  
المسار المقترح: `/images/help/automations/apps-error-states.webp`
</Info>

## الحالة: التطبيق «غير متصل»

| السبب المحتمل | الحل |
| --- | --- |
| ثُبّت ولم يُربط | افتح **إعداد** وأكمل الربط |
| فشل اختبار بيانات الاعتماد فلم تُحفظ | صحّح المفاتيح واحفظ مجدداً |
| انتهت صلاحية رمز OAuth | **تحديث الرمز** أو **إعادة ربط** |
| سُحبت الأذونات من لوحة المزوّد | أعد الربط وامنح الأذونات |
| تغيّرت كلمة مرور الحساب عند المزوّد | أعد الربط |
| حُذف الحساب أو أُوقف | اربط حساباً بديلاً |

## الحالة: «تكامل مكرر»

تعني أن حساب المزوّد نفسه مربوط بمؤسسة أخرى في كرزون. النظام يمنع ربط الحساب مرتين حتى لا تتضارب البيانات والويب هوك بين حسابين.

المعالجة:

1. تأكد من الحساب التي تعمل عليها الآن.
2. إن كان الربط القديم لحساب لم تعد تستخدمه، افصله من هناك أولاً.
3. إن كنت تحتاج ربط الاثنين فعلاً، استخدم حساباً مختلفاً عند المزوّد.

## الحالة: فشل حفظ بيانات الاعتماد

كرزون يختبر المفاتيح قبل الاعتماد، وعند فشل الاختبار لا يحفظها ويبقى التطبيق **غير متصل**. هذا سلوك مقصود.

| السبب | الحل |
| --- | --- |
| مسافة أو حرف زائد عند النسخ | انسخ المفتاح من جديد بدقة |
| مفتاح بيئة اختبار بدل الإنتاج | استخدم مفتاح البيئة الصحيحة |
| صلاحيات المفتاح غير كافية | أعد إنشاءه بالصلاحيات المطلوبة |
| المفتاح مُلغى أو منتهٍ | أنشئ بديلاً |
| حقل مطلوب فارغ | أكمل كل الحقول |

## الحالة: انقطع الاتصال بعد أن كان يعمل

هذا أكثر عطل يربك الفرق لأنه يقع فجأة بلا تغيير من طرفك.

| السبب | كيف تتأكد | الحل |
| --- | --- | --- |
| انتهاء صلاحية الرمز | الشارة تحوّلت إلى **غير متصل** أو **به خطأ** | **تحديث الرمز** أو إعادة الربط |
| الموظف صاحب الحساب غادر | الربط تم بحساب شخصي | أعد الربط بحساب مؤسسي |
| تغيير في إعدادات المزوّد | رسائل خطأ عند المحاولة | راجع لوحة المزوّد ثم أعد الربط |
| تغيّر خطة الاشتراك عند المزوّد | ميزة كانت متاحة لم تعد | راجع خطتك هناك |

<Tip>
اربط التطبيقات بحساب مؤسسي يملكه النشاط التجاري، لا بحساب موظف. هذا يمنع أكثر من نصف حالات الانقطاع المفاجئ.
</Tip>

## الحالة: المزامنة الأولية لا تكتمل

| السبب | الحل |
| --- | --- |
| حجم البيانات كبير | امنحها وقتاً؛ لا تعيد التشغيل مراراً |
| انقطع الاتصال أثناءها | تأكد من شارة **متصل** ثم أعد المحاولة |
| صلاحيات ناقصة على المتجر | أعد الربط بأذونات كاملة للقراءة المطلوبة |
| حساب لا يملك المتجر | اربط بحساب المالك |

بعد اكتمالها، افحص عيّنة من جهات الاتصال والطلبات للتأكد من صحة البيانات قبل بناء مسارات عليها.

<Warning>
إن لاحظت إرسال رسائل غير مقصودة أثناء المزامنة، **عطّل** الأتمتات المبنية على «عميل جديد» فوراً، ثم عالج الأثر. راجع [تطبيقات المتاجر](/ar/help-center/guides/automations/apps/ecommerce).
</Warning>

## الحالة: إجراء التطبيق يفشل داخل المسار

افتح [سجل التنفيذ](/ar/help-center/guides/automations/execution-history) ← التشغيلة الفاشلة ← **الخطوات** ← اقرأ الخطوة الفاشلة.

| السبب | الحل |
| --- | --- |
| التطبيق **غير متصل** | اربطه ثم أعد اختبار الإجراء |
| الوجهة حُذفت أو أُعيدت تسميتها | أعد اختيارها في الإجراء ثم **إعادة النشر** |
| حقل مطلوب فارغ أو بصيغة خاطئة | صحّح المعاملات واختبر |
| صلاحيات غير كافية للعملية | وسّع صلاحيات المفتاح أو أعد الربط |
| قيد على معدل الطلبات عند المزوّد | قلّل تكرار الاستدعاء أو وزّعه بتأخير |
| عطل مؤقت عند المزوّد | أعد المحاولة لاحقاً وتابع حالة خدمته |

## الحالة: المشغّل من التطبيق لا يعمل

| السبب | الحل |
| --- | --- |
| التطبيق **غير متصل** | اربطه أولاً |
| الحدث غير مدعوم لهذا التطبيق | افتح منتقي المشغّل وتحقق من المتاح فعلاً |
| المشغّل **غير نشط** | فعّل مفتاح **نشط** |
| الأتمتة **مسودة** | **تشغيل مباشر** |
| الحدث وقع قبل النشر | اختبر بحدث جديد |
| الويب هوك لم يُسجَّل عند الربط | أعد الربط لإعادة التسجيل |

## الحالة: التطبيق لا يظهر في المتجر أو الإعدادات

| السبب | الحل |
| --- | --- |
| غير متاح لحسابك | تواصل مع الدعم للاستفسار عن توفره |
| صلاحياتك لا تسمح بإدارة التطبيقات | اطلب الصلاحية من مدير الحساب |
| لم يُثبَّت بعد | ثبّته من **المتجر** |

## قبل التصعيد للدعم

اجمع هذه المعلومات لتختصر الوقت إلى النصف:

1. اسم التطبيق وحالته الظاهرة.
2. طريقة الربط: OAuth أم بيانات اعتماد.
3. وقت آخر عمل ناجح ووقت أول فشل.
4. اسم الأتمتة والخطوة الفاشلة.
5. **البيانات الخام** للتشغيلة الفاشلة من تفاصيل التنفيذ.
6. ما جربته من هذه الصفحة.
