عندما تختار حدثاً من المنتقي، الاسم وحده لا يكفي إن لم تعرف متى يُطلق وما الذي لا يغطيه.

تجمع هذه الصفحة **عائلات أحداث المشغّلات** كما تظهر في المنتقي (حسب ما هو مفعّل في حسابك)، مع أمثلة وحدود شائعة — لا كقائمة أسماء بلا سياق.

في هذا الدليل تتعلّم أي عائلة تناسب احتياجك، ثم تفتح الحدث المناسب في حسابك.

للتفاصيل المشتركة (نشط، شروط، تكاملات) راجع [خيارات المشغّل وكيف يعمل](/ar/help-center/guides/automations/triggers/options).

إن لم يظهر نوع معيّن فغالباً الإضافة غير مفعّلة أو غير مربوطة.

## 1) المحادثة (البريد الوارد)

**متى تختارها:** شيء تغيّر في تنظيم أو حالة المحادثة داخل [البريد الوارد](/ar/help-center/guides/inbox/overview) — لا محتوى كل رسالة.

**نوع المشغّل في المنتقي:** **المحادثات** (`inbox:conversation`)

### أحداث المحادثة

| الحدث في الواجهة | متى يُطلق |
| --- | --- |
| **محادثة جديدة** | إنشاء محادثة |
| **إعادة فتح المحادثة** | إعادة فتح محادثة موجودة |
| **إغلاق المحادثة** | إغلاق بواسطة وكيل أو مسار |
| **محادثة معلقة** | الحالة → معلّقة |
| **تأجيل المحادثة** | تأجيل (snooze) |
| **انتهاء تأجيل المحادثة** | انتهاء فترة التأجيل |
| **إسناد المحادثة** | إسناد لموظف |
| **إسناد المحادثة تلقائياً** | إسناد ذكي/تلقائي |
| **إلغاء إسناد المحادثة** | إزالة المسند إليه |
| **إسناد إلى البوت** | تسليم للبوت |
| **تغيير قسم المحادثة** | تغيير القسم |
| **إضافة وسم للمحادثة** | إضافة وسم |
| **إزالة وسم من المحادثة** | إزالة وسم |
| **إضافة تقييم** | تقييم عميل على المحادثة |
| **تحديث حقل مخصص في المحادثة** | تغيّر حقل مخصص |
| **نقل عميل المحادثة** | ربط/نقل عميل المحادثة |
| **إضافة مشارك إلى المحادثة** | إضافة مشارك |
| **إزالة مشارك من المحادثة** | إزالة مشارك |
| **ذكر مستخدم في المحادثة** | منشن لموظف |
| **تصنيف المحادثة كبريد مزعج** | وضع علامة spam |
| **تحويل المحادثة إلى بطاقة** | تحويل لبطاقة مهمة/صفقة |

**أمثلة مسار:**

| الهدف | الحدث | المسار بإيجاز |
| --- | --- | --- |
| ترحيب وفرز أول | محادثة جديدة | رسالة ← سؤال خيارات ← فروع أو تسليم بشري |
| رضا بعد الخدمة | إغلاق المحادثة | تأخير قصير ← طلب تقييم |
| تصعيد غضب | إضافة تقييم + شرط درجة منخفضة | وسم + ملاحظة + إسناد مشرف |

<Warning>
**لا مشغّل «كل رسالة جديدة».** «محادثة جديدة» تعني افتتاح محادثة، لا تكرار المسار مع كل رسالة داخل محادثة قائمة. لمحتوى الرسالة: [كلمات مفتاحية](/ar/help-center/guides/automations/keywords) أو أسئلة داخل المسار.
</Warning>

## 2) الشريحة والعميل

**متى تختارها:** العميل **أصبح** في فئة (دخل شريحة، غادرها، أُنشئ، أو تغيّرت دورة حياته) — لا أنه راسلك الآن.

| نوع المشغّل | أحداث الواجهة |
| --- | --- |
| **الشريحة** (`core:segment`) | **انضمام عميل إلى شريحة** · **مغادرة عميل للشريحة** |
| **العميل** (`core:customer`) | **إنشاء عميل** · **تحديث حالة العميل** |

**حدود مهمة:**

| غير متاح كمشغّل مباشر | البديل |
| --- | --- |
| تحديث حقل/وسم عميل عادي | ابنِ شريحة على الحقل أو الوسم + مشغّل **الانضمام إلى شريحة** |
| «أي شريحة» عامة | الشريحة **حقل إلزامي واحد** لكل مشغّل — كرّر المشغّل لكل شريحة إن لزم |

<Warning>
تقييم الشرائح ليس دائماً فورياً بالثواني. إن احتجت ردّاً لحظياً على رسالة، استخدم عائلة المحادثة أو السلوك — لا تعتمد على الشريحة كمؤقت دقيق.
</Warning>

قبل استيراد آلاف الجهات: عطّل أتمتات «إنشاء عميل» أو قيّدها بشرط، ثم ألحق القدامى بـ[حملة أتمتة](/ar/help-center/guides/automations/with-broadcasts).

## 3) السلوك (كرزون بكسل)

**متى تختارها:** الزائر **فعل شيئاً على الموقع/المتجر** عبر [كرزون بكسل](/ar/help-center/guides/pixel/overview).

**نوع المشغّل في المنتقي:** **الأحداث السلوكية** (`inbox:event`)

| الحدث في الواجهة | متى يُطلق |
| --- | --- |
| **عرض الصفحة** | مشاهدة صفحة |
| **بدء الجلسة** | جلسة زائر جديدة |
| **حدث التجارة الإلكترونية** | إضافة للسلة، شراء، وما شابه مما يبثّه البكسل |
| **حدث مخصص** | حدث تسمّيه أنت (نقر زر، إرسال نموذج…) |

بلا بكسل موثّق لا يعمل هذا المشغّل. راجع [الأتمتة على الأحداث السلوكية](/ar/help-center/guides/pixel/with-automations).

## 4) واتساب (أحداث القناة)

**نوع المشغّل:** **أحداث واتساب** (`whatsapp:events`) — يظهر بعد ربط واتساب.

| الحدث في الواجهة | متى يُطلق |
| --- | --- |
| **إحالة إعلان واتساب** | نقرة إعلان ثم رسالة إحالة |
| **استفسار منتج واتساب** | استفسار من الكتالوج |
| **طلب واتساب مستلم** | طلب عبر واتساب (مع تفاصيل السلة عند الجاهزية) |
| **اكتمال تدفق واتساب** | إكمال Flow (نموذج، دفع…) |
| **رد إذن مكالمة واتساب** | سماح/رفض إذن المكالمة |
| **مكالمة واتساب فائتة** | مكالمة واردة لم يُجب عليها |
| **اكتمال مكالمة واتساب** | انتهاء مكالمة بنجاح |

قنوات أخرى (إنستغرام، تيك توك، بريد…) قد تضيف مشغّلاتها الخاصة بعد الربط — افتح المنتقي بعد تفعيل القناة. لإرسال خاص من تعليق راجع [رسالة مباشرة](/ar/help-center/guides/automations/nodes/actions/send-dm).

## 5) المهام

**نوع المشغّل:** **مهمة** (`tasks:task`) — يظهر مع إضافة المهام.

| الحدث في الواجهة | متى يُطلق |
| --- | --- |
| **تم إنشاء المهمة** | إنشاء مهمة |
| **تم تحديث المهمة** | تحديث حقول المهمة |
| **تم حذف المهمة** | حذف |
| **تم تعيين المهمة** | إسناد |
| **تم إلغاء تعيين المهمة** | إلغاء الإسناد |
| **تحذير تاريخ استحقاق المهمة** | اقتراب/تجاوز الاستحقاق |
| **تم تغيير مرحلة المهمة** | انتقال بين مراحل اللوحة |

إجراءات المهام داخل المسار (إنشاء/تحديث/نقل…) موثّقة في [العمليات والتجارة الإلكترونية](/ar/help-center/guides/automations/operations-actions).

## 6) الاجتماعات

**نوع المشغّل:** **اجتماع** (`meetings:meeting`)

| الحدث في الواجهة | متى يُطلق |
| --- | --- |
| **تم إنشاء اجتماع** | إنشاء اجتماع |
| **تم تحديث الاجتماع** | تحديث عام (بدون تفصيل نوع التغيّر اليوم) |
| **تم إلغاء الاجتماع** | إلغاء |
| **بدأ الاجتماع** | بدء |
| **اكتمل الاجتماع** | اكتمال |

<Note>
مشغّل **تم تحديث الاجتماع** عام اليوم — لا أحداث منفصلة مثل «أُضيف ضيف» أو «تغيّر الوقت» أو «لن يحضر». للإنشاء من المسار استخدم إجراء **إنشاء اجتماع** (`createMeeting`) لا الـ stub القديم `createAppointment` — راجع [العمليات](/ar/help-center/guides/automations/operations-actions).
</Note>

## 7) التطبيقات (miniapps)

**متى تختارها:** النظام الخارجي (متجر، تقويم، جدول…) هو من **أطلق** الحدث بعد أن يكون التطبيق **متصلاً**.

لا نعدّ كل أحداث التطبيقات هنا — تختلف جذرياً بين تطبيق وآخر. المسار في [استخدام التطبيقات في الأتمتات](/ar/help-center/guides/automations/apps/use-in-automations)، والمتاجر في [تطبيقات المتاجر](/ar/help-center/guides/automations/apps/ecommerce).

## كيف تختار العائلة بسرعة؟

| احتياجك | العائلة |
| --- | --- |
| تغيّر في المحادثة أو تنظيمها | المحادثة |
| صفة/سلوك متراكم على العميل | الشريحة والعميل |
| فعل على الموقع الآن | الأحداث السلوكية (بكسل) |
| إحالة إعلان / طلب / Flow واتساب | أحداث واتساب |
| دورة حياة مهمة على اللوحة | المهام |
| دورة حياة اجتماع تقويم | الاجتماعات |
| حدث من نظام خارجي متصل | التطبيقات |
| نص رسالة واردة | كلمة مفتاحية / رد آلي — لا مشغّل «كل رسالة» |
| دفعة لجمهور موجود | حملة بقناة الأتمتة |

## الخطوة التالية

اخترت عائلة الحدث. بعد ذلك:

- ابنِ المسار من [إنشاء أول أتمتة](/ar/help-center/guides/automations/create-first) أو راجع [نظرة عامة على المشغّلات](/ar/help-center/guides/automations/triggers/overview).
