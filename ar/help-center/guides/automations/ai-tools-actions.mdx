## ما الفرق بين هذه الصفحة وباقي الإجراءات؟

كل إجراء في هذه الصفحة له خاصية برمجية اسمها `ai.enabled: true` — يعني أن **[وكيل المساعد الذكي](/ar/help-center/guides/automations/nodes/ai-agent) يستطيع استدعاءه تلقائياً بنفسه** أثناء المحادثة، دون أن تضيفه أنت يدوياً في مسار. الوكيل يقرر بنفسه أي أداة يحتاجها ومتى، بناءً على رسالة العميل.

هذا هو **الفرق الجوهري** الذي أوضحناه في صفحة [عقدة وكيل المساعد](/ar/help-center/guides/automations/nodes/ai-agent#قدرات-الوكيل-الحقيقية-الأدوات): حقل «الأدوات واكتشاف النوايا» داخل عقدة الوكيل هو نوايا مسمّاة تقود لمخرج مسار محدد — بينما **القدرات (Capabilities)** المفعّلة في ملف تعريف الوكيل هي ما يتيح له استخدام الأدوات الحقيقية أدناه بحرية كاملة أثناء الحوار.

كل هذه الإجراءات متاحة أيضاً للاستخدام اليدوي داخل [عقدة الإجراء](/ar/help-center/guides/automations/nodes/actions/overview) إن احتجت التحكم الكامل بمتى تُستدعى.

<Info>
**وسائط مطلوبة:** محادثة واتساب تُظهر عميلاً يسأل سؤالاً عاماً ("ما آخر أخبار سعر الدولار؟")، ثم رد الوكيل الذكي بمعلومة محدثة فعلياً من الإنترنت — مع تمييز بصري (أيقونة بحث) يوضح أن الوكيل استخدم أداة.
المسار المقترح: `/images/help/automations/ai-tools-web-search.webp`
</Info>

## بحث الإنترنت

| | |
| --- | --- |
| **الاسم البرمجي** | `webSearch` |

يبحث في الإنترنت فعلياً (عبر مزودي بحث مثل Tavily، Brave، Serper) ويُرجع نتائج حقيقية ومحدثة — لا معلومة "محفوظة" في نموذج الذكاء الاصطناعي بل بحث لحظي.

| الحقل | ماذا يعني |
| --- | --- |
| **الاستعلام** | نص البحث *(مطلوب)* |
| **عدد النتائج** | من ١ إلى ١٠ (افتراضي ٥) |
| **نوع البحث** | ويب عام أو أخبار |
| **المدى الزمني** | يوم، أسبوع، شهر، سنة، أو الكل |
| **جلب محتوى أعلى النتائج** | يفعّل جلب تفصيلي للنص الكامل من أفضل نتيجتين تلقائياً بدل الاعتماد على المقتطف فقط |
| **تضمين/استثناء مواقع** | تقييد البحث لمواقع محددة أو استثناء مواقع منها |

<Tip>
أفضل استخدام: الوكيل يبحث أولاً بـ**بحث الإنترنت** لإيجاد الروابط المناسبة، ثم يستخدم **قراءة صفحة** أدناه على أفضل نتيجة لقراءة محتواها كاملاً — بالضبط كما يفعل إنسان يبحث عن معلومة.
</Tip>

## قراءة صفحة

| | |
| --- | --- |
| **الاسم البرمجي** | `fetchWebpage` |

يفتح رابطاً محدداً ويستخرج محتواه — مقالة، توثيق تقني، صفحة منتج، أو أي صفحة عامة.

| وضع الاستخراج | الأفضل لـ |
| --- | --- |
| **مقالة (Article)** *(افتراضي)* | مقالات ومنشورات — يستخرج المحتوى الأساسي فقط بصيغة Markdown |
| **نص (Text)** | صفحات بسيطة، استخراج نصي مباشر |
| **Markdown** | تحويل الصفحة كاملة لصيغة Markdown |
| **محددات CSS (Selectors)** | استخراج عناصر محددة بدقة عبر محددات CSS تكتبها |
| **خام (Raw)** | HTML الخام كما هو — نادراً ما تحتاجه |

## أدوات قاعدة المعرفة والبحث الذكي في المنتجات

هذه الأدوات تبحث داخل **بيانات متجرك نفسه** — لا الإنترنت الخارجي — باستخدام بحث دلالي (Semantic Search) يفهم المعنى لا الكلمات الحرفية فقط:

| الأداة | ماذا تفعل | مثال استخدام |
| --- | --- | --- |
| **البحث في قاعدة المعرفة** | يبحث دلالياً في مقالات [قاعدة المعرفة](/ar/help-center/guides/knowledge-base/overview) التي أنشأتها لعملك | عميل يسأل «ما سياسة الاسترجاع؟» |
| **البحث الدلالي في المنتجات** | يبحث بالوصف والمعنى بدل الكلمة الحرفية | «شيء أنيق ومريح للسهرة» بدل اسم منتج محدد |
| **البحث البصري في المنتجات** | يبحث عن منتجات مشابهة بصرياً لصورة أرسلها العميل | عميل يرسل صورة منتج رآه عند منافس ويسأل «عندكم شيء شبيه؟» |

<Tip>
هذه الأدوات مختلفة عن **إجراءات تصفية المنتجات** أدناه: استخدمها للاستفسارات **الغامضة والوصفية**، واستخدم التصفية للمعايير **الدقيقة والمحددة** (سعر، ماركة، فئة).
</Tip>

## أدوات استكشاف وتصفية كتالوج المنتجات

أربعة أدوات تعمل معاً لتغطية أي طريقة يسأل بها عميل عن منتجاتك:

| الأداة | الاسم البرمجي | متى تُستخدم |
| --- | --- | --- |
| **استعراض الكتالوج** | `browseProducts` | «ما الفئات المتوفرة؟» أو «ما الماركات التي تبيعونها؟» — تصفح بنية المتجر (فئات وماركات) فقط، لا قوائم منتجات |
| **تصفية المنتجات** | `filterProducts` | الأداة الأساسية لأي طلب قائمة منتجات بمعايير محددة: «هواتف سامسونج تحت ١٥٠٠ ريال»، «كل ما هو بخصم»، «الأحدث وصولاً» |
| **تفاصيل منتج** | `getProductDetail` | بعد أن يختار العميل منتجاً من نتائج بحث سابقة — يُرجع الوصف الكامل، الصور، السعر، والمتغيّرات المتاحة |
| **مقارنة منتجات** | `compareProducts` | عندما يطلب العميل تحديداً مقارنة ٢ إلى ٥ منتجات — يُرجع جدول مقارنة مع تحديد الأفضل قيمةً والأرخص |

<Warning>
كل هذه الأدوات تعتمد على **مرجع المنتج (productRef)** المُستخرَج من نتيجة أداة سابقة — الوكيل الذكي مُوجَّه صريحاً بألا "يختلق" مرجعاً غير موجود في نتيجة حقيقية سابقة. هذا يمنع إحالة العميل لمنتج غير موجود فعلاً.
</Warning>

## أداة التوصيات الذكية

| | |
| --- | --- |
| **الاسم البرمجي** | `getRecommendations` |

محرك توصيات بخمس استراتيجيات مختلفة، تُختار واحدة حسب نية العميل:

| الاستراتيجية | تُستخدم عندما يقول العميل |
| --- | --- |
| **منتجات مشابهة** | «شيء يشبه هذا» |
| **منتجات مكمّلة** | «ما الذي يتماشى مع هذا؟» |
| **بدائل أوفر** | «هل يوجد خيار أرخص؟» |
| **ترقية أفضل** | «هل يوجد إصدار أفضل؟» |
| **بناءً على تاريخ الشراء** | «رشّح لي شيئاً» (بلا منتج مرجعي محدد) |

## متى تفعّل كل أداة؟

لا تُفعَّل هذه الأدوات تلقائياً — تختارها بنفسك من **قدرات (Capabilities)** ملف تعريف الوكيل في استوديو الوكلاء:

| احتياج متجرك | فعّل هذه القدرة |
| --- | --- |
| الرد على أسئلة عامة تحتاج معلومة محدثة من الإنترنت | بحث الإنترنت + قراءة صفحة |
| الرد من محتوى الأسئلة الشائعة الخاص بك | قاعدة المعرفة |
| مساعدة تسوق كاملة داخل واتساب | كتالوج المنتجات + السلة + الطلبات (راجع [العمليات والتجارة الإلكترونية](/ar/help-center/guides/automations/operations-actions)) |
| عروض مخصصة تزيد فرص الإتمام | التوصيات الذكية |

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| تفعيل بحث الإنترنت لمتجر لا يحتاجه | الوكيل يبحث خارجياً بدل الرد من معرفتك الخاصة | فعّل فقط القدرات التي تخدم حالة استخدامك |
| توقّع أن قاعدة المعرفة "تعرف" محتوى لم تُضِفه أصلاً | إجابات عامة أو رفض الإجابة | أضف مقالات [قاعدة المعرفة](/ar/help-center/guides/knowledge-base/overview) الفعلية أولاً |
| طلب مقارنة منتج واحد فقط أو أكثر من ٥ | فشل الأداة برسالة واضحة | التزم بحد ٢-٥ منتجات للمقارنة |
| الاعتماد على البحث الدلالي لمعايير دقيقة (سعر، فئة) | نتائج غير دقيقة | استخدم تصفية المنتجات للمعايير المحددة |
