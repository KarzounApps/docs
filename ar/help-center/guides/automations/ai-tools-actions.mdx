## ثلاثة أسطح لا تخلط بينها

| السطح | أين | متى |
| --- | --- | --- |
| **قدرات الوكيل** (Capabilities) | ملف التعريف في استوديو الوكلاء | الوكيل يستدعي الأداة **بنفسه** أثناء الجلسة دون مخرج مسار |
| **نوايا العقدة** + اختياري **انتظار العودة** | [عقدة وكيل المساعد](/ar/help-center/guides/automations/nodes/ai-agent) | توجيه المسار؛ مع انتظار العودة تصبح **أداة مخصصة** تنتهي بـ [العودة إلى الوكيل](#العودة-إلى-الوكيل) |
| **عقدة إجراءات الذكاء الاصطناعي** | لوحة الأتمتة | خطوات ثابتة في المسار: توليد، تصنيف، بحث… **بلا** جلسة وكيل |

الفرق بين النوايا والقدرات مفصّل في [عقدة وكيل المساعد](/ar/help-center/guides/automations/nodes/ai-agent#قدرات-الوكيل-الحقيقية-الأدوات). نمط انتظار العودة كاملاً في [أدوات مخصصة](/ar/help-center/guides/ai/agent-custom-tools).

كثير من أدوات البحث/الكتالوج أدناه كانت تُستدعى ذاتياً عبر القدرات؛ وهي أيضاً متاحة يدوياً داخل **عقدة إجراءات الذكاء الاصطناعي** (وليست داخل عقدة الإجراء العامة بعد نقل فئة الذكاء الاصطناعي).

<Info>
**وسائط مطلوبة:** محادثة واتساب تُظهر عميلاً يسأل سؤالاً عاماً، ثم رد الوكيل بمعلومة من أداة بحث — مع تمييز أن الوكيل استخدم أداة.  
المسار المقترح: `/images/help/automations/ai-tools-web-search.webp`
</Info>

## عقدة إجراءات الذكاء الاصطناعي

عقدة مستقلة في فئة الذكاء الاصطناعي على اللوحة — تشبه عقدة الإجراء لكن قائمتها تقتصر على فئة **ذكاء اصطناعي**:

| مجموعة | أمثلة |
| --- | --- |
| **عمليات نصية وصوت** | توليد نص، إعادة صياغة، تلخيص، تصنيف، استخراج حقول، توليد صوت |
| **بحث واسترجاع** | بحث الإنترنت، قراءة صفحة، بحث معرفة، بحث/تصفية/مقارنة منتجات، توصيات |
| **دورة الوكيل** | **العودة إلى الوكيل** (بعد أداة مخصصة بانتظار العودة) |

استخدم هذه العقدة عندما تريد خطوة ذكاء اصطناعي **محددة في المسار** (بعد شرط أو HTTP)، لا حواراً حراً. لجلسة محادثة كاملة استخدم [وكيل المساعد](/ar/help-center/guides/automations/nodes/ai-agent).

معظم عمليات التوليد/التصنيف تدعم نمط **اختبار ثم ربط الحقول** (Test → map) لمعاينة المخرج قبل الحفظ في متغيرات المسار.

## العودة إلى الوكيل

| | |
| --- | --- |
| **الاسم في الواجهة** | العودة إلى الوكيل / Return to agent |
| **الاسم البرمجي** | `copilotAgentReturn` |

يُستأنف [وكيل المساعد](/ar/help-center/guides/automations/nodes/ai-agent) بعد نية مفعّل عليها **انتظار العودة (أداة مخصصة)**. يقرأ حقل **النتيجة** (مسار متغير/حقل) ويحقنه للوكيل كنتيجة الأداة ليكمل الرد للعميل.

| الحقل | ماذا يعني |
| --- | --- |
| **النتيجة (Result payload)** | مسار القيمة المعادة (مثل جسم HTTP المحفوظ). إن تُرك فارغاً قد تُستخدم معاملات النية كاحتياط — الأفضل نتيجة صريحة |

<Warning>
بدون هذا الإجراء في نهاية فرع الأداة المخصصة، **لن يكتمل** استدعاء الأداة من منظور العميل (صمت — بلا اعتذار تلقائي). لا تعتمد على مهلة خمول الجلسة كبديل للعودة.
</Warning>

سيناريوهات (تتبع شحنة، أهلية عرض، تسعير…): [أدوات مخصصة: انتظار العودة والعودة إلى الوكيل](/ar/help-center/guides/ai/agent-custom-tools).

## بحث الإنترنت

| | |
| --- | --- |
| **الاسم البرمجي** | `webSearch` |

يبحث في الإنترنت فعلياً (عبر مزودي بحث مثل Tavily، Brave، Serper) ويُرجع نتائج حقيقية ومحدثة — لا معلومة "محفوظة" في نموذج الذكاء الاصطناعي بل بحث لحظي.

| الحقل | ماذا يعني |
| --- | --- |
| **الاستعلام** | نص البحث *(مطلوب)* |
| **عدد النتائج** | من ١ إلى ١٠ (افتراضي ٥) |
| **نوع البحث** | ويب عام أو أخبار |
| **المدى الزمني** | يوم، أسبوع، شهر، سنة، أو الكل |
| **جلب محتوى أعلى النتائج** | يفعّل جلب تفصيلي للنص الكامل من أفضل نتيجتين تلقائياً بدل الاعتماد على المقتطف فقط |
| **تضمين/استثناء مواقع** | تقييد البحث لمواقع محددة أو استثناء مواقع منها |

<Tip>
أفضل استخدام: الوكيل يبحث أولاً بـ**بحث الإنترنت** لإيجاد الروابط المناسبة، ثم يستخدم **قراءة صفحة** أدناه على أفضل نتيجة لقراءة محتواها كاملاً — بالضبط كما يفعل إنسان يبحث عن معلومة.
</Tip>

## قراءة صفحة

| | |
| --- | --- |
| **الاسم البرمجي** | `fetchWebpage` |

يفتح رابطاً محدداً ويستخرج محتواه — مقالة، توثيق تقني، صفحة منتج، أو أي صفحة عامة.

| وضع الاستخراج | الأفضل لـ |
| --- | --- |
| **مقالة (Article)** *(افتراضي)* | مقالات ومنشورات — يستخرج المحتوى الأساسي فقط بصيغة Markdown |
| **نص (Text)** | صفحات بسيطة، استخراج نصي مباشر |
| **Markdown** | تحويل الصفحة كاملة لصيغة Markdown |
| **محددات CSS (Selectors)** | استخراج عناصر محددة بدقة عبر محددات CSS تكتبها |
| **خام (Raw)** | HTML الخام كما هو — نادراً ما تحتاجه |

## أدوات قاعدة المعرفة والبحث الذكي في المنتجات

هذه الأدوات تبحث داخل **بيانات متجرك نفسه** — لا الإنترنت الخارجي — باستخدام بحث دلالي (Semantic Search) يفهم المعنى لا الكلمات الحرفية فقط:

| الأداة | ماذا تفعل | مثال استخدام |
| --- | --- |
| **البحث في قاعدة المعرفة** | يبحث دلالياً في مقالات [قاعدة المعرفة](/ar/help-center/guides/knowledge-base/overview) التي أنشأتها لعملك | عميل يسأل «ما سياسة الاسترجاع؟» |
| **البحث الدلالي في المنتجات** | يبحث بالوصف والمعنى بدل الكلمة الحرفية | «شيء أنيق ومريح للسهرة» بدل اسم منتج محدد |
| **البحث البصري في المنتجات** | يبحث عن منتجات مشابهة بصرياً لصورة أرسلها العميل | عميل يرسل صورة منتج رآه عند منافس ويسأل «عندكم شيء شبيه؟» |

<Tip>
هذه الأدوات مختلفة عن **إجراءات تصفية المنتجات** أدناه: استخدمها للاستفسارات **الغامضة والوصفية**، واستخدم التصفية للمعايير **الدقيقة والمحددة** (سعر، ماركة، فئة).
</Tip>

## أدوات استكشاف وتصفية كتالوج المنتجات

أدوات تعمل معاً لتغطية طرق سؤال العميل عن منتجاتك (في المسار عبر إجراءات الذكاء الاصطناعي، و/أو كقدرات للوكيل):

| الأداة | الاسم البرمجي | متى تُستخدم |
| --- | --- | --- |
| **استعراض الكتالوج** | `browseProducts` | «ما الفئات المتوفرة؟» أو «ما الماركات التي تبيعونها؟» — تصفح بنية المتجر (فئات وماركات) فقط، لا قوائم منتجات |
| **تصفية المنتجات** | `filterProducts` | الأداة الأساسية لأي طلب قائمة منتجات بمعايير محددة: «هواتف سامسونج تحت ١٥٠٠ ريال»، «كل ما هو بخصم»، «الأحدث وصولاً» |
| **مقارنة منتجات** | `compareProducts` | عندما يطلب العميل تحديداً مقارنة ٢ إلى ٥ منتجات — يُرجع جدول مقارنة مع تحديد الأفضل قيمةً والأرخص |

<Note>
**تفاصيل منتج** (`getProductDetail`) مخصّصة لاستدعاء الوكيل أثناء الحوار بعد اختيار منتج من نتيجة سابقة — **لا تظهر** في منتقي إجراءات منشئ المسار. الوكيل موجَّه ألا يخترع مرجع منتج غير موجود في نتيجة حقيقية سابقة.
</Note>

<Warning>
أدوات الكتالوج تعتمد على **مرجع المنتج (productRef)** المستخرج من نتيجة سابقة عندما يلزم — لا تختلق مراجعاً يدوياً في المسار إلا إن كنت تملك المرجع من خطوة سابقة موثوقة.
</Warning>

## أداة التوصيات الذكية

| | |
| --- | --- |
| **الاسم البرمجي** | `getRecommendations` |

محرك توصيات بخمس استراتيجيات مختلفة، تُختار واحدة حسب نية العميل:

| الاستراتيجية | تُستخدم عندما يقول العميل |
| --- | --- |
| **منتجات مشابهة** | «شيء يشبه هذا» |
| **منتجات مكمّلة** | «ما الذي يتماشى مع هذا؟» |
| **بدائل أوفر** | «هل يوجد خيار أرخص؟» |
| **ترقية أفضل** | «هل يوجد إصدار أفضل؟» |
| **بناءً على تاريخ الشراء** | «رشّح لي شيئاً» (بلا منتج مرجعي محدد) |

## عمليات التوليد والتحليل (في المسار)

متاحة من **عقدة إجراءات الذكاء الاصطناعي** لمعالجة نص ثابت أو متغير ثم حفظ المخرج:

| الإجراء | الاستخدام النموذجي |
| --- | --- |
| **توليد نص** | صياغة من موجّه (Prompt) + تعليمات نظام اختيارية |
| **إعادة صياغة** | تغيير نبرة/طول نص موجود |
| **تلخيص** | اختصار محادثة أو حمولة طويلة |
| **تصنيف** | اختيار تسمية من قائمة تسميات |
| **استخراج حقول** | نص غير منظم → كائن حسب مخطط |
| **توليد صوت** | نص → ملف صوتي (TTS) |

## متى تفعّل كل أداة كقدرة للوكيل؟

لا تُفعَّل قدرات الوكيل تلقائياً — تختارها من **Tools / الأدوات** في استوديو الوكلاء:

| احتياج متجرك | فعّل هذه القدرة |
| --- | --- |
| الرد على أسئلة عامة تحتاج معلومة محدثة من الإنترنت | بحث الإنترنت + قراءة صفحة |
| الرد من محتوى الأسئلة الشائعة الخاص بك | قاعدة المعرفة |
| مساعدة تسوق كاملة داخل واتساب | كتالوج المنتجات + السلة + الطلبات (راجع [العمليات والتجارة الإلكترونية](/ar/help-center/guides/automations/operations-actions)) |
| عروض مخصصة تزيد فرص الإتمام | التوصيات الذكية |
| استعلام نظام خارجي ثم متابعة الحوار | نية بـ **انتظار العودة** + [العودة إلى الوكيل](/ar/help-center/guides/ai/agent-custom-tools) — ليست قدرة كتالوج وحدها |

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| تفعيل بحث الإنترنت لمتجر لا يحتاجه | الوكيل يبحث خارجياً بدل الرد من معرفتك الخاصة | فعّل فقط القدرات التي تخدم حالة استخدامك |
| توقّع أن قاعدة المعرفة "تعرف" محتوى لم تُضِفه أصلاً | إجابات عامة أو رفض الإجابة | أضف مقالات [قاعدة المعرفة](/ar/help-center/guides/knowledge-base/overview) الفعلية أولاً |
| طلب مقارنة منتج واحد فقط أو أكثر من ٥ | فشل الأداة برسالة واضحة | التزم بحد ٢-٥ منتجات للمقارنة |
| الاعتماد على البحث الدلالي لمعايير دقيقة (سعر، فئة) | نتائج غير دقيقة | استخدم تصفية المنتجات للمعايير المحددة |
| نية بانتظار عودة بلا إجراء العودة | صمت الأداة | أنهِ الفرع بـ العودة إلى الوكيل + نتيجة |
| وضع أدوات الذكاء الاصطناعي داخل عقدة الإجراء العامة | لا تظهر في القائمة | استخدم **عقدة إجراءات الذكاء الاصطناعي** |
