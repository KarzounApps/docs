عندما تحتاج رسالة ترحيب بسيطة أحياناً، ومسار يحدّث عميلاً ويستدعي نظاماً خارجياً ثم يسلّم المحادثة لموظف أحياناً أخرى، تتشتت الأدوات.

توفّر **الأتمتة** في كرزون محرك مسارات: مشغّل يبدأ التشغيلة، وعُقد تقرّر وترسل وتتصل بالمنصة أو بالخارج عبر HTTP وGraphQL والتطبيقات.

يشرح هذا الدليل ماذا تغطي الأتمتة، ومتى تستخدمها بدل الحملة أو الماكرو، ومن أين تبدأ البناء.

في التطبيق: **الأتمتة** ← **الأتمتات** (`/automations`).

لفهرس بناء المسارات: [مسار بناء الأتمتة](/ar/help-center/guides/automations/path-builder).

## الاتصال بالأنظمة الخارجية

الأتمتة لا تقتصر على إجراءات كرزون الجاهزة. من داخل عقدة **إجراء** تستطيع:

| القدرة | الاستخدام |
| --- | --- |
| **طلب HTTP** | استدعاء أي واجهة برمجية خارجية (طريقة، مصادقة، JSON/نص/نماذج) |
| **GraphQL الداخلي** | استدعاء واجهة كرزون البرمجية لعمليات لا تغطيها الإجراءات الجاهزة |
| **دالة JavaScript** | منطق مخصص داخل المسار |
| **عمليات JSON** | استخراج وتحويل بيانات الاستجابة |
| **التطبيقات المثبَّتة** | اختصار جاهز (سلة، زد، Google Sheets…) بدل بناء الاتصال يدوياً |

التطبيقات طريق مختصر؛ **طلب HTTP** هو الطريق العام عندما لا يوجد تطبيق جاهز أو تحتاج طلباً مخصصاً.

<Info>
القدرة أعلاه **صادرة** (المسار يستدعي الخارج). لاستقبال أحداث من مصدر خارجي استخدم تطبيقاً مثبَّتاً أو قناة **ويب هوك وارد** بمخطط ثابت — وليس استقبالاً حراً لأي JSON يبدأ أتمتة مباشرة. راجع [التطبيقات](/ar/help-center/guides/automations/apps/overview).
</Info>

## المكوّنان الأساسيان

| المكوّن | ما هو |
| --- | --- |
| **المشغّل** | الحدث الذي يبدأ المسار: محادثة جديدة، انضمام لشريحة، زيارة صفحة، طلب من متجرك… |
| **العُقدة** | خطوة داخل المسار — ٩ أنواع، كل واحدة بصفحتها المستقلة |

## من أين تأتي الأحداث؟

المشغّل يلتقط **حدثاً محدداً** من مصدر مفعّل لديك — لا يوجد مشغّل «كل رسالة جديدة». المصادر الشائعة عائلات:

| العائلة | متى تفكّر بها |
| --- | --- |
| **البريد الوارد** | تغيّر حالة أو تنظيم محادثة |
| **الشرائح والعملاء** | دخول/خروج شريحة، عميل جديد، دورة حياة |
| **كرزون بكسل** | سلوك على الموقع أو المتجر |
| **القنوات المتخصصة والتطبيقات** | أحداث تظهر بعد ربط القناة أو التطبيق |

الشرح في [نظرة عامة على المشغّلات](/ar/help-center/guides/automations/triggers/overview) و[أنواع المشغّلات بالأمثلة](/ar/help-center/guides/automations/triggers/types).

## متى أتمتة، ومتى شيء آخر؟

| احتياجك | الأداة الصحيحة |
| --- | --- |
| رد فوري لكل من يراسلك | **أتمتة** بمشغّل «محادثة جديدة» |
| رسالة واحدة لجمهور محدد | [حملة تسويقية](/ar/help-center/guides/broadcasts/overview) |
| تسلسل مخصص لكل عميل ينضم لشريحة | **أتمتة** بمشغّل الشريحة |
| خطوات يقررها الموظف يدوياً | [الماكرو](/ar/help-center/guides/automations/macros) |
| توزيع المحادثات على الموظفين | [الإسناد الذكي](/ar/help-center/guides/inbox/smart-assignment) |
| ربط نظام خارجي بمنطقك التشغيلي | **عقدة إجراء** بطلب HTTP أو تطبيق مثبَّت |

## دورة الحياة والتشغيل

كل أتمتة تمر بحالات (مسودة، مفعّلة، غير متصلة، مؤرشفة) ولها سجل تنفيذ لكل تشغيلة. راجع [النشر والمسودة والحالات](/ar/help-center/guides/automations/publish-and-status) و[سجل التنفيذ](/ar/help-center/guides/automations/execution-history).
