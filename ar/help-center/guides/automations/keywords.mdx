الكلمات المفتاحية تجعل رسالة العميل تذهب مباشرة إلى المسار الصحيح بدل المرور بالفرز العام. من يكتب «تتبع طلبي» لا يحتاج قائمة خيارات — يحتاج تتبعاً فورياً.

تجدها في: **الأتمتة** ← **الرد الآلي** (`/automations/channel-bots`) ← قسم **إعدادات الكلمات المفتاحية**، لكل قناة على حدة.

## أعمدة الجدول

| العمود | ماذا يعني |
| --- | --- |
| **الحالة** | مفتاح تشغيل/إيقاف للقاعدة دون حذفها — مفيد للتجريب والمواسم |
| **العامل** | طريقة المطابقة (الجدول أدناه) |
| **القيمة** | النص المطلوب مطابقته — يُترك فارغاً في عوامل الوسائط |
| **الأولوية** | **ساخن** أو **عادي** — تحدد أيّها يُفحص أولاً عند التعارض |
| **الأتمتة** | المسار أو العقدة التي تعمل عند المطابقة |
| **الإجراءات** | تعديل القاعدة أو حذفها |

<Info>
**وسائط مطلوبة:** جدول الكلمات المفتاحية وفيه أربع قواعد بعوامل مختلفة وأولويات مختلفة.  
المسار المقترح: `/images/help/automations/keywords-table.webp`  
**فيديو (مستحسن):** 25 ثانية: إضافة كلمة مفتاحية بعامل «يحتوي» وربطها بمسار.
</Info>

## عوامل المطابقة

### عوامل نصية

| العامل | يطابق عندما | مثال |
| --- | --- | --- |
| **يساوي** | الرسالة كاملة مطابقة تماماً | «١» أو «نعم» |
| **يحتوي** | النص موجود في أي موضع من الرسالة | «شكوى» تطابق «عندي شكوى على الطلب» |
| **يحتوي كلمة** | الكلمة موجودة ككلمة مستقلة | «سعر» لا تطابق «الأسعار» |
| **يبدأ بـ** | الرسالة تبدأ بهذا النص | «طلب» يطابق «طلب رقم ٤٤٢» |

### عوامل نوع الرسالة

| العامل | يطابق عندما |
| --- | --- |
| **صورة** | العميل أرسل صورة |
| **فيديو** | أرسل فيديو |
| **صوت** | أرسل رسالة صوتية |
| **مستند** | أرسل ملفاً |
| **موقع** | أرسل موقعاً |

هذه العوامل **لا تحتاج قيمة** — تُطابق النوع نفسه. وهي مفيدة جداً عملياً:

- **صورة** ← «شكراً على الصورة، يراجعها فريقنا الآن» + إسناد لقسم الدعم الفني
- **موقع** ← ربطه بأقرب فرع أو تأكيد عنوان التوصيل
- **صوت** ← تنبيه أن الرد قد يتأخر قليلاً + تسليم بشري (البوت لا يفهم الصوت)

### أي عامل تختار؟

| احتياجك | العامل |
| --- | --- |
| رد على قائمة أرقام | **يساوي** |
| التقاط نية بأي صياغة | **يحتوي** |
| دقة أعلى بلا مطابقات عرضية | **يحتوي كلمة** |
| رموز طلبات أو صيغ ثابتة | **يبدأ بـ** |
| التعامل مع مرفق | عوامل الوسائط |

<Warning>
**يحتوي** هو الأكثر فائدة والأكثر خطراً. كلمة «لا» بعامل «يحتوي» تطابق «بلاغ» و«مشكلة» وعشرات الكلمات. استخدم **يحتوي كلمة** عندما تكون الكلمة قصيرة أو شائعة الحروف.
</Warning>

## الأولوية: ساخن أم عادي؟

عندما تطابق رسالة أكثر من قاعدة، الأولوية تحسم أيّها يعمل.

اجعل **ساخن** للحالات التي لا تحتمل التأخير أو الخطأ:

- «موظف» · «بشري» · «تحدث مع أحد» ← تسليم بشري فوري
- «إلغاء» · «استرجاع» ← مسار الاسترجاع
- «شكوى» ← مسار الشكاوى مع تصعيد

واترك **عادي** للاستفسارات المعتادة: أسعار، مواعيد، فروع، شحن.

القاعدة: **كل ما يخص الغضب أو المال أو طلب إنسان = ساخن.**

## اختيار الأتمتة أو العقدة

عمود **الأتمتة** يسمح بربط القاعدة بمسار كامل أو بعقدة محددة داخل مسار.

- **مسار كامل**: عندما تكون النية مستقلة بذاتها (تتبع الطلب مثلاً).
- **عقدة محددة**: عندما تريد القفز إلى منتصف مسار قائم بدل تكرار بنائه.

الربط بعقدة يوفّر التكرار، لكنه يجعل تعديل ذلك المسار لاحقاً يؤثر على الكلمة المفتاحية أيضاً. وثّق ذلك بـ**ملاحظة لاصقة** بجانب العقدة المرتبطة.

## بناء قائمة كلمات فعّالة

<Steps>
  <Step title="استخرج الأسئلة الحقيقية">
    افتح البريد الوارد واقرأ خمسين محادثة أخيرة. اكتب الأسئلة الفعلية بكلمات العملاء، لا بكلماتك.
  </Step>
  <Step title="جمّعها في نوايا">
    عشرون سؤالاً غالباً يتجمع في خمس أو ست نوايا: تتبع، سعر، شحن، استرجاع، فرع، موظف.
  </Step>
  <Step title="اختر عامل المطابقة لكل نية">
    الشائع: **يحتوي كلمة** للنوايا العامة، **يساوي** لقوائم الأرقام.
  </Step>
  <Step title="أضف تنويعات العملاء">
    لا تكتفِ بالفصحى: أضف صياغات دارجة، وأخطاء إملائية شائعة، ومرادفات.
  </Step>
  <Step title="اضبط الأولويات">
    الحساس **ساخن**، والباقي **عادي**.
  </Step>
  <Step title="اختبر كل قاعدة بنفسك">
    أرسل الرسالة فعلاً من حساب اختبار وتأكد أنها تذهب للمسار المقصود.
  </Step>
  <Step title="راجع شهرياً">
    القواعد التي لا تُطابق أبداً تُحذف، والأسئلة المتكررة الجديدة تُضاف.
  </Step>
</Steps>

## ماذا لو لم تطابق أي كلمة؟

تتولى الأمر **سير الأتمتة الافتراضي** المضبوط في [إعداد الرد الآلي للقناة](/ar/help-center/guides/automations/channel-bots). الكلمات المفتاحية اختصار للحالات المعروفة، والسير الافتراضي هو شبكة الأمان — لا يجوز أن يكون فارغاً.

## أخطاء شائعة

| الخطأ | النتيجة | الصواب |
| --- | --- | --- |
| كلمة قصيرة بعامل **يحتوي** | مطابقات عشوائية كثيرة | استخدم **يحتوي كلمة** |
| فصحى فقط | لا تطابق كلام العملاء الحقيقي | أضف الدارجة والأخطاء الشائعة |
| «موظف» بأولوية **عادي** | تأخر التسليم البشري | اجعلها **ساخن** |
| ثلاثون قاعدة متداخلة | سلوك غير متوقع يصعب تشخيصه | ابدأ بخمس واضحة |
| قاعدة مرتبطة بمسار **مسودة** | لا شيء يحدث عند المطابقة | انشر المسار |
| بلا سير افتراضي | غير المطابق يبقى بلا رد | اضبط الافتراضي |
| قواعد قديمة لموسم منتهٍ | ردود غير مناسبة | استخدم عمود **الحالة** لإيقافها |
