عندما تكمل عملاً يومياً أو مهمة تدريب، تريد أن تعرف أين تذهب النقاط وكيف تؤثر على ترتيبك هذا الشهر — لا كيف تُدار داخلياً.

كل نقطة في كرزون تُنسب إلى **فئة** (سرعة، جودة، إنتاجية، تدريب، تفاعل). المجموع الشهري يظهر على الصفحة الرئيسية وفي [ملف الموظف](/ar/help-center/guides/settings/team/member-profile)، ويحدد ترتيبك ضمن الفريق.

يشرح هذا الدليل الشهر التقويمي، الفئات الخمس، وما يكافئه المنتج اليوم — دون وعد بأرقام لا تظهر في واجهتك.

## المنافسة شهرية

الترتيب والنقاط المعروضة هي **لهذا الشهر الميلادي** حسب **توقيت الرياض**. في أول يوم من الشهر التالي تبدأ الجولة من صفر للترتيب؛ شارات عتبات الفئات تبقى مرتبطة بمجموعك في الفئات، وشارات الصدارة تُحفظ للفائزين عند إغلاق الشهر.

على ويدجت المتصدرين يظهر اسم الشهر وعدد الأيام المتبقية. تفاصيل التبويبين في [فريق مقابل عالمي](/ar/help-center/guides/training/team-vs-global).

## الفئات الخمس

| الفئة في الواجهة | ماذا تكافئ تقريباً |
| --- | --- |
| **السرعة** | أول رد سريع ضمن مهلة القسم |
| **الجودة** | تقييم عميل مرتفع (أربع نجوم فأكثر) |
| **الإنتاجية** | إغلاق محادثة، أول رد، تحويل لمتابعة، إكمال مهمة أو اجتماع، الحضور |
| **التدريب** | إكمال مهام وأقسام مركز التدريب |
| **التفاعل** | دخول يومي، دعوة زميل، إكمال الملف، رسائلك لزكي |

الأوصاف في الواجهة: ردود سريعة · رضا العملاء · المهام والمحادثات · تقدّم التعلم · استخدام المنصة ومساهمات الفريق.

## ماذا يكافئ المنتج اليوم؟

المبدأ التشغيلي: **الإنهاء أهم من التكرار**. إغلاق محادثة أو إكمال مهمة يساوي أكثر من نقرة وسيطة. الردود المتكررة في نفس الخيط لا تُكدَّس.

### البريد الوارد

| العمل | النقاط | الفئة | حدّ عادل |
| --- | --- | --- | --- |
| ردّك الأول في المحادثة (يراه العميل) | **+3** | الإنتاجية | مرة لكل محادثة |
| ردّك الأول في المحادثة خلال مهلة القسم (افتراضياً 5 دقائق إن لم تُضبط مهلة) | **+5** إضافية | السرعة | مع أول رد فقط |
| رد لاحق في نفس المحادثة في اليوم نفسه | **+1** | الإنتاجية | مرة لكل محادثة في اليوم — ليست ملاحظة داخلية ولا رد بوت |
| إغلاق المحادثة (أو حل جماعي) | **+2** | الإنتاجية | مرة لكل محادثة في اليوم |
| تحويل المحادثة إلى بطاقة دعم | **+4** | الإنتاجية | |
| تقييم عميل **4** أو **5** | **+15** | الجودة | تذهب للموظف **المسند إليه** المحادثة، لا للعميل |

الملاحظات الداخلية والإسناد والوسوم **لا تضيف نقاطاً**. اكتب الملاحظة لأنها تنسّق الفريق، لا لأنها ترفع الترتيب.

### المهام والاجتماعات والحضور

| العمل | النقاط | الفئة | ملاحظة |
| --- | --- | --- | --- |
| إنشاء مهمة يدوياً | **+2** | الإنتاجية | المهام التي تنشئها الأتمتة لا تُكافأ عند الإنشاء |
| نقل مهمة بين المراحل | **+1** | الإنتاجية | مرة لكل مهمة في اليوم |
| إكمال مهمة | **+6** | الإنتاجية | |
| إكمال مهمة قبل الموعد أو عنده | **+3** إضافية | الإنتاجية | |
| تسجيل دخول للوردية | **+2** | الإنتاجية | مرة في يوم الرياض |
| تسجيل خروج | **+3** | الإنتاجية | لكل وردية |
| دخول أو خروج في الوقت أو قبله | **+3** إضافية | الإنتاجية | |
| إنشاء اجتماع | **+3** | الإنتاجية | |
| إكمال اجتماع | **+6** | الإنتاجية | |
| قبول الدعوة | **+1** | الإنتاجية | لكل اجتماع ولكل مشارك |
| تسجيل الحضور في الاجتماع | **+2** | الإنتاجية | لكل اجتماع ولكل مشارك |

### الحساب والتدريب وزكي

| العمل | النقاط | الفئة | حدّ عادل |
| --- | --- | --- | --- |
| تسجيل الدخول في يوم جديد | **+2** | التفاعل | مرة في يوم الرياض (كلمة مرور أو دخول Google) |
| دعوة زميل ينضم للحساب | **+8** | التفاعل | مرة لكل بريد مدعو |
| إكمال الملف (صورة + اسم + قسم) | **+10** | التفاعل | مرة واحدة |
| رسالة تكتبها أنت لزكي | **+3** | التفاعل | لكل رسالة منك — ليست ردود زكي |
| إكمال مهمة تدريب | **+10** | التدريب | |
| إكمال قسم تدريب | **+25** | التدريب | |
| إكمال كل التدريب | **+100** | التدريب | |

قيم التدريب معتمدة في واجهة المنتج حالياً؛ قد تُضبط لاحقاً من الخادم دون تغيير أسماء الفئات.

## ماذا لا تكافئه النقاط؟

النقاط **تحفيز داخل الفريق**، ليست صلاحية نظام ولا بديلاً عن سياسة الخدمة. لا تُكافأ:

- الملاحظات الداخلية والوسوم والإسناد اليدوي
- ردود البوت أو الأتمتة بدل الموظف
- تكرار نفس الإجراء في نفس المحادثة أو المهمة خلال نفس الحد اليومي

إن بدا الترتيب متأخراً عن عملك للتو، حدّث الصفحة الرئيسية. الترتيب العالمي يتأخر أكثر — راجع [فريق مقابل عالمي](/ar/help-center/guides/training/team-vs-global).

## أين ترى نتيجتك؟

- تقدّم مهام التدريب → `/training`
- النقاط والترتيب والشارات لهذا الشهر → الصفحة الرئيسية `/`
- نفس المجموع والفئات والشارات → الشريط الجانبي في [ملف الموظف](/ar/help-center/guides/settings/team/member-profile)

## الخطوة التالية

تعلّمت الفئات وما يُكافأ هذا الشهر. بعد ذلك:

- افهم الشارات وشارات الصدارة في [الشارات](/ar/help-center/guides/training/badges).
- قارن ترتيب الفريق والعالمي من [فريق مقابل عالمي](/ar/help-center/guides/training/team-vs-global).
