بعد الحفظ، النافذة لا تظهر على موقعك حتى يُحمَّل كودها — والمعاينة داخل كرزون لا تغني عن النشر على الصفحة الحقيقية.

من القائمة افتح **تثبيت الكود** لأي صف — الحوار يعطيك مقاطع جاهزة للنسخ: محمل النموذج، حاوية التضمين، أو مشغّل بالنقر.

يشرح هذا الدليل خطوات التثبيت الموصى بها، ومعنى كل مقطع، وأخطاء الظهور الشائعة.

## قبل أن تبدأ

- نافذة محفوظة وحالتها مناسبة للعرض (**نشط** إن كنت تختبر الإنتاج)  
- صلاحية تعديل قالب الموقع أو أداة العلامات (مثل Google Tag Manager)  
- معرفة إن كنت تريد ظهوراً تلقائياً، مضمّناً داخل صفحة، أو فتحاً بزر

## خطوات التثبيت (محمل النموذج — الموصى به)

<Steps>
  <Step title="افتح كود التثبيت">
    من **النوافذ المنبثقة** → قائمة الصف → **تثبيت الكود**.
  </Step>
  <Step title="انسخ وسم السكربت">
    القسم **1. أضف محمل النموذج**: يلصق قبل `</body>`. يحمّل هذا النموذج فقط دون تفعيل المراسلة أو قاعدة المعرفة أو أحداث البكسل الكاملة.

    {/* MEDIA: /images/help/popups/install-copy-gif.webp | GIF 4ث: نسخ محمل النموذج من الحوار */}
    <Frame caption="نسخ محمل النموذج">
      <img src="/images/help/popups/install-copy-gif.webp" alt="نسخ محمل النموذج من حوار التثبيت" />
    </Frame>
  </Step>
  <Step title="التضمين داخل الصفحة (اختياري)">
    للعرض **المضمّن**: ضع عنصر الحاوية حيث تريد النموذج داخل الصفحة (`data-kzn-form="…"`). بدونه يظهر السلوك كنافذة/عرض حسب إعداد النوع.
  </Step>
  <Step title="مشغّل بالنقر (اختياري)">
    زر أو رابط يستدعي فتح النموذج عبر واجهة JavaScript عند الحاجة (مثل زر «تواصل» في الرأس).
  </Step>
  <Step title="انشر واختبر">
    انشر القالب، ثم استخدم **فتح المعاينة** من الحوار أو زر الموقع الحقيقي.

## ماذا تعني المقاطع؟

| المقطع | دوره |
| --- | --- |
| إعدادات + سكربت المحمل | يربط حسابك ويعرّف معرّف النموذج |
| حاوية التضمين | موضع ثابت داخل الصفحة للنموذج المضمّن |
| زر `Karzoun.forms.show` | فتح يدوي عند النقر |

لا تلصق نسختين متعارضتين من سكربت كرزون على نفس الصفحة دون قصد. إن كنت تستخدم البكسل الكامل أيضاً، راجع [الاستخدام مع كرزون بكسل](/ar/help-center/guides/popups/with-pixel).

## أخطاء شائعة

| العرض | السبب المحتمل |
| --- | --- |
| لا يظهر شيء | السكربت غير منشور، أو النافذة مؤرشفة، أو قواعد استهداف تستثني زيارتك |
| يظهر منبثاً بدل مضمّن | لم تُضف حاوية `data-kzn-form` |
| يعمل في المعاينة فقط | الكود على بيئة staging وليس الإنتاج |
