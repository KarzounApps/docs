صفحة **النوافذ الذكية** (`/popups`) هي لوحة التشغيل اليومية للمسؤول: ترى كل النوافذ، أداءها السريع، وتصل للإدخالات والكود دون فتح الموقع.

## أين تصل؟

الشريط: **النوافذ المنبثقة** → قائمة بكل النماذج/النوافذ.

<Info>
**وسائط مطلوبة:** جدول القائمة مع أعمدة الاسم، الحالة، المشاهدات، التحويل، جهات الاتصال، والقائمة الجانبية للإجراءات.  
`/images/help/popups/list-performance.webp`
</Info>

## أعمدة الأداء

| العمود | معناه |
| --- | --- |
| **الاسم** | اسم النموذج الداخلي |
| **الحالة** | **نشط** أو **مؤرشف** |
| **المشاهدات** | مرات ظهور/عرض النافذة |
| **التحويل** | نسبة من شاهدوا إلى من أرسلوا |
| **جهات الاتصال** | ما ارتبط بالإرسالات عند الجمع |
| **أُنشئ بواسطة / تاريخ الإنشاء** | من أنشأ ومتى |

استخدم البحث بالاسم وفلتر **نشط / مؤرشف** لتقليل الضوضاء.

## إجراءات الصف

من قائمة الإجراءات على الصف:

| الإجراء | الاستخدام |
| --- | --- |
| **تعديل** | العودة لخطوات الإطلاق |
| **عرض الإدخالات** | [صفحة الإدخالات](/ar/help-center/guides/popups/submissions) |
| **تثبيت الكود** | [نسخ مقاطع التثبيت](/ar/help-center/guides/popups/install-code) |
| **تكرار** | نسخة سريعة لحملة مشابهة |
| **أرشفة / تفعيل** | إيقاف الظهور دون حذف، أو إعادة التشغيل |
| **حذف** | إزالة نهائية مع الإدخالات — يطلب تأكيداً |

## قراءة سريعة للأداء

- مشاهدات عالية وتحويل منخفض → راجع العرض، طول الحقول، أو التوقيت/القواعد  
- مشاهدات منخفضة → تحقق من التثبيت والقواعد والحالة **نشط**  
- جهات اتصال أقل من الإدخالات → قد يكون **الحفظ كعميل** مطفأً أو الإدخال بلا معرف كافٍ
