معظم الفرق تكتفي بلون السمة من خطوة **النمط**. خطوة **التنسيق** للمصمّم أو المطوّر الذي يحتاج تجاوز المظهر الافتراضي بـ CSS.

تتيح النافذة لون سمة سريعاً، ثم مربع CSS مخصصاً بأصناف جاهزة دون كسر التخطيط إن اختبرت المعاينة.

يشرح هذا الدليل متى يكفي لون السمة، وكيف تستخدم الأصناف، ومتى تتجنب CSS الثقيل.

## لون السمة أولاً

في الخطوة الأولى اختر **لون السمة** ليتوافق مع أزرار وعناصر النافذة. جرّب النتيجة من المعاينة قبل كتابة أي CSS.

## مرجع الأصناف

| الصنف | العنصر |
| --- | --- |
| `.form-wrapper` | حاوية النموذج |
| `.form-header h1` | عنوان النموذج |
| `.form-header p` | وصف النموذج |
| `.form-field` | حاوية الحقل |
| `.form-field input` · `.form-field textarea` · `.form-field select` | عناصر الإدخال |
| `.form-btn-primary` | زر الإرسال وزر المقدمة وزر النافذة بزر |
| `.form-callout` | حاوية المقدمة، ومحتوى النافذة بزر |
| `.form-callout h2` | عنوان المقدمة أو النافذة بزر |
| `.form-success` | حاوية صفحة النجاح |

مثال بسيط:

```css
.form-btn-primary {
  border-radius: 8px;
}
```

## متى تتجنب CSS الثقيل؟

- إن كان التغيير لوناً فقط → استخدم لون السمة  
- تجنّب كسراً للتخطيط على الجوال دون اختبار المعاينة على الهاتف  
- لا تعتمد على محددات خارج هذه الأصناف — قد تتغير واجهة العرض
