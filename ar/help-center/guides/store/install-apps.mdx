عندما تثبّت تطبيقاً من المتجر ثم لا ترى طلبات أو أحداثاً، غالباً توقفت عند **مثبّت** دون إكمال الربط.

يوفر كرزون مساراً واضحاً: تثبيت من `/marketplace` ثم إعداد من **الإعدادات ← التطبيقات** حتى شارة **متصل** — والمزامنة الأولية مرة واحدة إن ظهرت.

يشرح هذا الدليل الفرق بين مثبّت ومتصل، وخطوات الربط بـ OAuth أو بيانات اعتماد API، ومتى تشغّل المزامنة الأولية.

## مثبّت ≠ متصل

| الحالة | أين تراها | المعنى |
| --- | --- | --- |
| **مثبّت** | بطاقة التطبيق في المتجر / قائمة التركيبات | التطبيق مضاف للحساب — قد يبقى بلا صلاحيات خارجية |
| **غير متصل** | **الإعدادات ← التطبيقات** | مثبّت وبلا مصادقة ناجحة |
| **متصل** | نفس الصفحة + رأس إعداد التطبيق | OAuth أو بيانات اعتماد ناجحة — جاهز للاستخدام |
| **نشط / قيد الانتظار** | عناصر **قائمة المتجر** (listings) | دورة شراء/تركيب مختلفة عن تطبيقات سلة/زد المعتادة |

فلاتر الإعدادات الشائعة: **الكل** · **متصل** · **غير متصل** · **عناصر المتجر**.

## OAuth مقابل بيانات اعتماد API

| نوع الربط في صفحة الإعداد | ماذا تفعل | إشارة النجاح |
| --- | --- | --- |
| **اتصال OAuth2** | **ربط…** يفتح نافذة المنصة الخارجية → سجّل الدخول وامنح الصلاحيات → تُغلق النافذة ويعود الحساب متصلاً | شارة **متصل**؛ يمكن **إعادة ربط** أو **فصل** لاحقاً |
| **بيانات اعتماد API** | املأ الحقول (مفتاح، سر، معرّف متجر…) → **حفظ بيانات الاعتماد** | إن فشل اختبار الرمز تُمسح البيانات وتبقى **غير متصل** / «بيانات الاعتماد مطلوبة» |

أخطاء OAuth شائعة بالعربية: تكامل مكرر، المتجر متصل بالفعل، فشلت المصادقة. غالباً يُسمح بمتجر واحد لكل تطبيق في الحساب — افصل القديم قبل ربط جديد إن منعك النظام.

## المزامنة الأولية

- تظهر بعد **متصل** فقط، وعندما يدعم التطبيق المزامنة ولم تكتمل من قبل.
- ليست تلقائية عند التثبيت أو أول ربط — راجع التفاصيل ثم اضغط **بدء المزامنة**.
- بعد التشغيل تُعلَّم مكتملة في الواجهة («تمت المزامنة الأولية مسبقاً») ولا تُعاد من نفس الزر؛ العمل الفعلي قد يستمر في الخلفية.
- لوحات البريد الوارد الاختيارية على نفس صفحة الإعداد منفصلة عن المزامنة — ثبّتها يدوياً إن احتجتها.

## تطبيقات المتاجر مقابل قوائم المتجر

| المسار | الاستخدام اليومي |
| --- | --- |
| `/marketplace/:slug` + `/settings/applications/:ns` | سلة، زد، ومعظم تطبيقات التشغيل |
| `/marketplace/listing/:slug` + التركيبات | قوائم SaaS (تطبيق/قالب/خدمة) بحالات نشط/قيد الانتظار |
| `/marketplace/installations` | **تطبيقاتي المثبتة** — إدارة وإلغاء تثبيت |

لتفاصيل سلة/زد بعد الاتصال: [تطبيقات المتاجر](/ar/help-center/guides/store/ecommerce-apps).

## أخطاء شائعة

| العرض | المعنى | ماذا تفعل |
| --- | --- |
| مثبّت وغير متصل | ناقص OAuth أو مفاتيح | أكمل **إعداد** حتى **متصل** |
| تكرار تكامل / المتجر متصل | ربط مسبق لنفس المتجر | افصل القديم ثم أعد الربط |
| فشل حفظ الاعتماد | اختبار الرمز فشل | راجع المفتاح والصلاحيات في المنصة الخارجية |
| لا زر مزامنة أولية | التطبيق بلا sync أو اكتملت سابقاً | متوقع — لا تنتظر زراً عاماً لكل تطبيق |
