فاتورة المحفظة قد لا تطابق رقم ميتا إن كان المسار **Cloud API الخاص**. تحتاج لوحة تفصل تكلفة الرسائل عن تكلفة المكالمات.

من **نوع التحليلات** تختار **تحليلات التسعير** أو **تحليلات المكالمات**. الأرقام مصدرها ميتا؛ قد تختلف فوترة كرزون إن كان المسار يفوتر عبر [المحفظة](/ar/help-center/guides/settings/billing/wallet-and-credits).

يشرح هذا الدليل بطاقات التسعير وفلاترها، ثم مقاييس المكالمات حسب الاتجاه والدولة.

## تحليلات التسعير

اختر **تحليلات التسعير**. المقاييس المعروضة غالباً: **التكلفة** و**حجم الرسائل** (الرسائل القابلة للفوترة لدى ميتا).

| البطاقة | المعنى |
| --- | --- |
| **إجمالي التكلفة** | المبلغ المعروض للفترة |
| **إجمالي حجم الرسائل** | حجم التسعير لدى ميتا |
| **متوسط التكلفة لكل رسالة** | التكلفة ÷ الحجم |

### الفلاتر والتجميع

| الفلتر | أمثلة في الواجهة |
| --- | --- |
| **أنواع التسعير** | مجاني — نافذة خدمة العملاء · مجاني — نقطة الدخول · مدفوع (عادي) |
| **فئات الرسائل** | تسويق · خدمي · مصادقة · مصادقة دولية · وغيرها كما تُرجعها ميتا |
| **الدول** | تقييد النتائج بدولة المستلم |
| **تجميع حسب** | فئة التسعير · نوع التسعير · مستوى التسعير · الدولة |

النطاق الزمني حتى **6 أشهر** أو نطاق مخصص. تجميع الوقت: كل نصف ساعة · يومي · شهري.

تحقق من متطلبات ميتا الحالية لفئات التسعير — القائمة في الواجهة قد تضم فئات إضافية (تسويق خفيف، جماعي…) حسب ما تُرجع ميتا.

## تحليلات المكالمات

اختر **تحليلات المكالمات**.

<Frame caption="عدد المكالمات والتكلفة وفلتر الاتجاه">
  <img src="/images/help/whatsapp/analytics-costs-calls.webp" alt="تحليلات مكالمات واتساب" />

| المقياس | المعنى |
| --- | --- |
| **عدد المكالمات** | إجمالي المكالمات في الفترة |
| **التكلفة** | تكلفة المكالمات كما تعرضها ميتا |
| **متوسط المدة** | متوسط طول المكالمة |

| الفلتر | المعنى |
| --- | --- |
| **الدول** | دولة المتصل المرتبطة بالرقم |
| **اتجاه المكالمة** | بدأها العميل · بدأها النشاط التجاري · جميع الاتجاهات |
| **تجميع حسب** | الدولة أو اتجاه المكالمة |

إعداد المكالمات على الرقم في [مكالمات واتساب](/ar/help-center/guides/whatsapp/calls/overview). أرقام **التعايش** لا تدير المكالمات من كرزون — [طرق الربط](/ar/help-center/guides/whatsapp/concepts/connection-methods).

## أخطاء شائعة

| عَرَض | ماذا تفعل |
| --- | --- |
| التكلفة في التحليلات لا تطابق المحفظة | مسار **Cloud API الخاص** يُفوتر عند ميتا؛ مسار كرزون عبر المحفظة. راجع [التسعير](/ar/help-center/guides/whatsapp/pricing/overview) |
| تفصيل فارغ | غيّر **تجميع حسب** أو وسّع النطاق الزمني |
| لا مكالمات في التحليلات | المكالمات غير مفعّلة أو الرقم تعايش |

## أسئلة شائعة

**هل هذه أسعار نهائية للفاتورة؟** هي أسعار/أحجام ميتا المعروضة. قد تُضاف رسوم معالجة حسب مسار الربط. اعتمد على المحفظة أو فوترة ميتا للفواتير.

**خطأ دفع 131042؟** [أخطاء واتساب](/ar/help-center/guides/whatsapp/errors) ثم المحفظة أو فوترة ميتا.

## الخطوة التالية

تعلّمت فصل تكلفة الرسائل عن المكالمات. بعد ذلك:

- طابق المسار مع [تسعير وحدود واتساب](/ar/help-center/guides/whatsapp/pricing/overview).
- إن كانت المكالمات صفرية: [تفعيل المكالمات](/ar/help-center/guides/whatsapp/calls/enable-calling).
