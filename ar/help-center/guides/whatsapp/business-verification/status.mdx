## أين تتابع؟

**توثيق الأعمال** ← بطاقة النشاط ← **عرض التفاصيل**.

<Info>
**وسائط مطلوبة:** شارات حالات أو خط زمني: إرسال → مراجعة → ميتا → مُوثّق.  
المسار المقترح: `/images/help/whatsapp/business-verification-status.webp`
</Info>

## قاموس الحالات

| الحالة | ماذا تفعل؟ |
| --- | --- |
| **مسودة** | أكمل المعالج وأرسل |
| **قيد المراجعة** | انتظر مراجعة كرزون |
| **مُعاد** | **تعديل وإعادة إرسال** بعد الملاحظات |
| **في ميتا** | انتظر قرار ميتا |
| **مُوثّق** | راجع حدود [واتساب](/ar/help-center/guides/channels/whatsapp) |
| **مرفوض** | اقرأ السبب وصحّح المستندات |

## بعد التوثيق

- حدود المراسلة من إعدادات القناة.  
- العلامة الخضراء (OBA) من **مدير واتساب** عند الأهلية.
