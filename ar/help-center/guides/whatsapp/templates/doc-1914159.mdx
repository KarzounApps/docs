القالب التسويقي هو النوع الأكثر استخداماً في كرزون، ويُستخدم لإرسال العروض والحملات الترويجية والتهاني والمحتوى التسويقي العام للعملاء خارج نافذة الـ24 ساعة.

> **متى تستخدم القالب التسويقي؟**عندما تريد التواصل مع عملائك بشكل استباقي — مثل إطلاق منتج جديد، أو تقديم خصم، أو إرسال تهنئة بمناسبة، أو تذكير بسلة متروكة — دون أن يكون العميل قد بدأ المحادثة أولاً.

---

انتقل إلى: **القنوات ← اختر قناة واتساب ← تعديل ← مدير واتساب ← القوالب ← إنشاء قالب**

## خطوات إنشاء قالب تسويقي

### 1. معلومات القالب الأساسية

![نموذج إنشاء القالب التسويقي](/images/help/doc-1914159/02-663c5de95a7e.webp)

| الحقل          | الوصف                                                      | مثال                         |
| -------------- | ---------------------------------------------------------- | ---------------------------- |
| **اسم القالب** | بالإنجليزية والأرقام والشرطة السفلية فقط، بحد أقصى 512 حرف | `auto_abandoned_cart_coupon` |
| **اللغة**      | اختر لغة الرسالة (عربي أو إنجليزي أو غيرها)                | العربية                      |
| **الفئة**      | اختر **تسويق**                                             | تسويق                        |

> **ملاحظة:** لا يمكن تغيير الفئة بعد اعتماد القالب من Meta.

---

### 2. الرأس (Header) — اختياري

الرأس هو أول ما يراه العميل في الرسالة. يمكن أن يكون:

| نوع الرأس | الوصف                                    | الحد الأقصى  |
| --------- | ---------------------------------------- | ------------ |
| **بدون**  | لا يوجد رأس                              | —            |
| **نص**    | عنوان نصي قصير مع دعم متغير واحد `{{1}}` | 60 حرف       |
| **صورة**  | صورة JPG أو PNG                          | 5 ميجابايت   |
| **فيديو** | فيديو MP4                                | 16 ميجابايت  |
| **مستند** | ملف PDF                                  | 100 ميجابايت |

---

### 3. جسم الرسالة (Body) — إلزامي

جسم الرسالة هو المحتوى الرئيسي. يدعم:

- **المتغيرات الديناميكية:** استخدم `{{1}}` و`{{2}}` وهكذا لإدراج بيانات مخصصة لكل عميل (الاسم، رقم الطلب، المبلغ...)

- **التنسيق:** **عريض** باستخدام `*نص*`، _مائل_ باستخدام `_نص_`، ~~يتوسطه خط~~ باستخدام `~نص~`، `كود` باستخدام `نص`

- **الرموز التعبيرية:** مدعومة بالكامل 🎉

**مثال على جسم رسالة تسويقية (سلة متروكة مع كوبون):**

```
مرحباً سارة 👋
سلتك بقيمة 300 ريال لا تزال في انتظارك!
أتمّم طلبك الآن واستخدم كود الخصم 🎁 {{2}} من بك
```

> **تذكر:** أضف قيمة نموذجية لكل متغير في حقل "قيم نموذجية" أسفل الجسم — هذا يساعد Meta على مراجعة القالب بشكل صحيح.

---

### 4. التذييل (Footer) — اختياري

نص قصير يظهر أسفل الرسالة بخط رمادي خافت. يُستخدم عادةً لعبارات مثل:

- "شكراً لتسوقك معنا!"

- "للإلغاء أرسل STOP"

الحد الأقصى: **60 حرفاً**.

---

### 5. الأزرار (Buttons) — اختياري

![قسم الأزرار في القالب التسويقي](/images/help/doc-1914159/03-69740e45e4c4.webp)

يمكن إضافة حتى **3 أزرار** من الأنواع التالية:

| نوع الزر          | الوصف                                                            | مثال الاستخدام            |
| ----------------- | ---------------------------------------------------------------- | ------------------------- |
| **زيارة موقع**    | يفتح رابطاً في المتصفح. يدعم رابطاً ثابتاً أو ديناميكياً `{{1}}` | "أتمّم طلبك" → رابط السلة |
| **اتصال**         | يطلب مكالمة هاتفية مباشرة                                        | "اتصل بنا" → رقم الهاتف   |
| **رد سريع**       | زر نصي يرسل رداً محدداً مسبقاً                                   | "نعم، أريد العرض"         |
| **نسخ رمز العرض** | يعرض كود خصم ويتيح نسخه بنقرة واحدة                              | "SAVE20"                  |

> **نصيحة:** زر "نسخ رمز العرض" مخصص للقوالب التسويقية فقط، وهو فعّال جداً في حملات الخصومات لأنه يسهّل على العميل نسخ الكود ومشاركته.

**خيار تفعيل تتبع النقرات:** عند تفعيله، يضيف كرزون معاملات تتبع للرابط لقياس عدد النقرات على الزر.

---

## مثال عملي: قالب السلة المتروكة مع كوبون خصم

هذا مثال حقيقي من كرزون لقالب تسويقي يُذكّر العميل بإتمام طلبه مع كود خصم:

![معاينة قالب السلة المتروكة مع الكوبون](/images/help/doc-1914159/04-1a2289ebee09.webp)

| القسم       | المحتوى                                                                                                    |
| ----------- | ---------------------------------------------------------------------------------------------------------- |
| **الاسم**   | `auto_abandoned_cart_coupon`                                                                               |
| **اللغة**   | العربية                                                                                                    |
| **الفئة**   | تسويق                                                                                                      |
| **الرأس**   | بدون                                                                                                       |
| **الجسم**   | مرحباً `{{1}}` 👋 سلتك بقيمة `{{2}}` ريال لا تزال في انتظارك! أتمّم طلبك الآن واستخدم كود الخصم 🎁 `{{3}}` من بك |
| **التذييل** | —                                                                                                          |
| **الأزرار** | "طلب" (زيارة موقع ديناميكي) + "نسخ رمز العرض" (كود الخصم)                                                  |

## أمثلة على القوالب التسويقية الشائعة

| الاستخدام           | نوع الرأس          | الأزرار المقترحة           |
| ------------------- | ------------------ | -------------------------- |
| سلة متروكة مع كوبون | بدون / صورة المنتج | زيارة موقع + نسخ رمز العرض |
| إطلاق منتج جديد     | صورة المنتج        | زيارة موقع                 |
| تهنئة بمناسبة       | صورة               | رد سريع + زيارة موقع       |
| طلب تقييم           | بدون               | رد سريع (⭐⭐⭐⭐⭐)       |
| حملة موسمية         | فيديو / صورة       | زيارة موقع + نسخ رمز العرض |

---

## بعد الإنشاء

بعد النقر على **حفظ القالب**، يُرسَل القالب لمراجعة Meta ويصبح في حالة **"معلق"**. عادةً تستغرق المراجعة من بضع دقائق حتى 24 ساعة. بعد الاعتماد تتغير الحالة إلى **"معتمد"** ويصبح جاهزاً للاستخدام في الحملات والأتمتة.

> للاطلاع على أسباب رفض القوالب وكيفية التعامل معها، راجع مقالة [أفضل الممارسات والأسئلة الشائعة للقوالب].
