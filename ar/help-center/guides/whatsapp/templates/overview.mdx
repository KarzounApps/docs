خارج نافذة الخدمة لا يكفي نص حر: ميتا تطلب رسالة معتمدة مسبقاً. بدون قالب معتمد يتوقف الإشعار والحملة عند الإرسال.

**قوالب الرسائل** في مدير واتساب رسائل يعتمدها ميتا مسبقاً: هي الطريق المعتمد لبدء محادثة أو المراسلة خارج **نافذة الـ24 ساعة**.

يشرح هذا الدليل متى تحتاج قالباً، وما الفئات والمكوّنات والحالات في الواجهة، ومن أين تبدأ الإنشاء.

**المسار:** البريد الوارد ← القنوات ← تعديل واتساب ← **مدير واتساب ← القوالب**.

## متى تحتاج قالباً؟

- تريد بدء محادثة مع عميل لم يكتب لك مؤخراً
- انتهت نافذة الـ24 ساعة وما زال يجب إبلاغه
- ترسل إشعاراً تشغيلياً أو عرضاً أو رمز تحقق بصيغة ثابتة معتمدة

داخل النافذة يمكنك الرد الحر من [البريد الوارد](/ar/help-center/guides/inbox/whatsapp-templates). القالب يُنشأ هنا ثم يُستخدم من الوارد أو [الحملات](/ar/help-center/guides/broadcasts/whatsapp) أو الأتمتة.

## الفئات في الواجهة

عند **إنشاء قالب** تظهر هذه الفئات (التسمية من المنتج):

| الفئة | الاستخدام |
| --- | --- |
| **خدمي** | تأكيد طلب، شحن، موعد، تنبيه حساب |
| **تسويق** | عروض، إطلاق، دعوات |
| **مصادقة** | رموز OTP — بلا رأس ولا أزرار مخصصة |
| **عرض لفترة محدودة** | عرض ينتهي مع نص عرض وزر نسخ رمز |
| **دوّار** | 2–10 بطاقات أفقية بصورة أو فيديو |
| **بطاقات المنتجات** | بطاقات من الكتالوج مع أسعار |
| **كتالوج** | زر عرض الكتالوج |
| **منتج واحد** | منتج من الكتالوج مع زر عرض ثابت |
| **منتجات متعددة** | مجموعة منتجات مع زر عرض العناصر |

لا يمكن تغيير الفئة بعد الإنشاء. عروض التجارة تحتاج غالباً [كتالوجاً مزامناً](/ar/help-center/guides/whatsapp/commerce/sync). تحقق من متطلبات ميتا الحالية للمراجعة والتسعير.

## مكوّنات القالب

| الجزء | إلزامي؟ | حد تقريبي |
| --- | --- | --- |
| **الرأس** | لا (إلزامي في بعض أنواع التجارة) | نص ~60 حرفاً أو صورة/فيديو/مستند |
| **النص** | نعم | حتى ~1024 حرفاً + متغيرات `{{1}}`… |
| **التذييل** | لا | ~60 حرفاً بلا متغيرات |
| **الأزرار** | لا | رد سريع، زيارة موقع، اتصال، نسخ رمز، **بدء تدفق**، **مكالمة صوتية**، **طلب معلومات الاتصال** — حسب الفئة (حد أقصى لكل نوع) |

اسم القالب: أحرف إنجليزية صغيرة وأرقام وشرطة سفلية فقط.

## حالات القالب بعد الحفظ

| الحالة | المعنى |
| --- | --- |
| **قيد الانتظار** | بانتظار مراجعة ميتا |
| **معتمد** | جاهز للإرسال |
| **مرفوض** | راجع السبب وعدّل أو أنشئ من جديد |
| **متوقف / محذوف** | غير متاح للإرسال |

التفاصيل: [إدارة القوالب ومزامنتها](/ar/help-center/guides/whatsapp/templates/manage).
