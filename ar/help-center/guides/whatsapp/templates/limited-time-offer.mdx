---
title: "عرض محدود الوقت"
description: "أنشئ قالب عرض محدود الوقت (LTO) مع عدّاد أو رسالة انتهاء العرض وفق خيارات ميتا."
---

قوالب **العرض محدود الوقت** صيغة تسويقية متخصصة لعروض تنتهي خلال مدة محددة.

**المسار:** البريد الوارد ← القنوات ← تعديل واتساب ← مدير واتساب ← القوالب ← **إنشاء قالب**.

قالب **عرض لفترة محدودة** (Limited-Time Offer — LTO) هو نوع متخصص من القوالب التسويقية يتميز بإضافة **عداد تنازلي** يظهر في أعلى الرسالة، مما يخلق إحساساً بالإلحاح ويحفّز العميل على التصرف سريعاً.

> **متى تستخدم قالب LTO؟**- رسائل العروض المؤقتة (تخفيضات نهاية الموسم، يوم الجمعة السوداء)- السلال المتروكة مع كود خصم ينتهي خلال ساعات- إطلاق منتج بسعر تأسيسي لفترة محدودة- حملات فلاش سيل (Flash Sale)

---

## الفرق بين قالب LTO والقالب التسويقي العادي

| الميزة            | تسويقي عادي | LTO                        |
| ----------------- | ----------- | -------------------------- |
| **عداد تنازلي**   | ❌          | ✅ يظهر في أعلى الرسالة    |
| **نص العرض**      | ❌          | ✅ حقل نصي مخصص للعرض      |
| **زر نسخ الكود**  | ✅          | ✅                         |
| **زر زيارة موقع** | ✅          | ✅                         |
| **التكلفة**       | عادية       | عادية (نفس تسعير التسويقي) |

---

## الوصول إلى صفحة القوالب

انتقل إلى: **البريد الوارد ← القنوات ← اختر قناة واتساب ← تعديل ← مدير واتساب ← القوالب ← إنشاء قالب**

ثم اختر الفئة: **عرض لفترة محدودة**

---

## خطوات إنشاء قالب LTO

### 1. معلومات القالب الأساسية

| الحقل          | الوصف                                    | مثال             |
| -------------- | ---------------------------------------- | ---------------- |
| **اسم القالب** | بالإنجليزية والأرقام والشرطة السفلية فقط | `camp_eid_2026`  |
| **اللغة**      | اختر لغة الرسالة                         | العربية          |
| **الفئة**      | اختر **عرض لفترة محدودة**                | عرض لفترة محدودة |

---

### 2. نص العرض (Offer Text) — مخصص لـ LTO

![نموذج قالب LTO - الجزء العلوي](/images/help/doc-1914161/01-57a4e203cc53.webp)

هذا الحقل يظهر **فوق الرسالة** في شريط العداد التنازلي. اكتب فيه نص العرض بشكل مختصر وجذاب.

**أمثلة:**

- `خصم 40% — ينتهي قريباً!`

- `عرض العيد — آخر فرصة!`

- `سعر خاص لمدة 24 ساعة فقط`

---

### 3. الرأس (Header) — اختياري

| نوع الرأس | الوصف                                               |
| --------- | --------------------------------------------------- |
| **بدون**  | لا يوجد رأس                                         |
| **صورة**  | صورة المنتج أو الحملة (JPG/PNG، حد أقصى 5 ميجابايت) |
| **فيديو** | فيديو ترويجي (MP4، حد أقصى 16 ميجابايت)             |

---

### 4. جسم الرسالة (Body) — إلزامي

اكتب نص الرسالة مع المتغيرات الديناميكية:

**مثال:**

```
🎉 عرض عيد الأضحى المبارك 🎉
{{1}} كل عام وأنتم بخير 🌙

بمناسبة العيد يسعدنا نقدم لكم خصم خاص لفترة محدودة 🔥
🎁 خصم يصل إلى 40% على جميع المنتجات
استخدم الكود: {{2}}
```

---

### 5. التذييل (Footer) — اختياري

نص قصير يظهر أسفل الرسالة. الحد الأقصى: **60 حرفاً**.

---

### 6. الأزرار (Buttons)

![قسم الأزرار في قالب LTO](/images/help/doc-1914161/02-3b1ea07c56a4.webp)

قوالب LTO تدعم نفس أنواع الأزرار، لكن الأكثر استخداماً هما:

| نوع الزر          | الوصف                                                           | مثال         |
| ----------------- | --------------------------------------------------------------- | ------------ |
| **نسخ رمز العرض** | يعرض كود الخصم ويتيح نسخه بنقرة واحدة                           | `DISCOUNT20` |
| **زيارة موقع**    | يفتح رابط المتجر أو صفحة المنتج. يدعم رابطاً ديناميكياً `{{1}}` | "تسوق الآن"  |

**خيار تفعيل تتبع النقرات:** عند تفعيله، يضيف كرزون معاملات تتبع للرابط لقياس عدد النقرات على الزر.

---

## مثال عملي: قالب حملة العيد

هذا مثال حقيقي من كرزون لقالب LTO لحملة عيد الأضحى:

| القسم        | المحتوى                                                                                                                                             |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **الاسم**    | `camp_eid_2026_1`                                                                                                                                   |
| **اللغة**    | العربية                                                                                                                                             |
| **الفئة**    | عرض لفترة محدودة                                                                                                                                    |
| **نص العرض** | خصم 40% — عرض العيد!                                                                                                                                |
| **الرأس**    | صورة (بانر العيد)                                                                                                                                   |
| **الجسم**    | 🎉 عرض عيد الأضحى المبارك 🎉 `{{1}}` كل عام وأنتم بخير 🌙🐑 — بمناسبة العيد يسعدنا نقدم لكم خصم خاص لفترة محدودة 🔥 خصم يصل إلى 40% على جميع المنتجات |
| **التذييل**  | —                                                                                                                                                   |
| **الأزرار**  | "نسخ رمز العرض" (DISCOUNT20) + "تسوق الآن" (زيارة موقع ديناميكي)                                                                                    |

| القسم        | المحتوى                                                                                                               |

| **الرأس**    | بدون                                                                                                                  |
| **الجسم**    | مرحباً `{{1}}`! لاحظنا أنك تركت سلتك بقيمة `{{2}}` ريال! لا تفوّت الفرصة — استخدم كود الخصم واحصل على 15% خصم على طلبك 🎁 |
| **التذييل**  | —                                                                                                                     |
| **الأزرار**  | "نسخ" (DISCOUNT15) + "أتمّم طلبك" (زيارة موقع ديناميكي)                                                               |

## بعد الإنشاء

بعد النقر على **حفظ القالب**، يُرسَل القالب لمراجعة Meta ويصبح في حالة **"معلق"**. عادةً تستغرق المراجعة من بضع دقائق حتى 24 ساعة. بعد الاعتماد تتغير الحالة إلى **"معتمد"** ويصبح جاهزاً للاستخدام في الحملات والأتمتة.

> للاطلاع على أسباب رفض القوالب وكيفية التعامل معها، راجع [أفضل الممارسات](/ar/help-center/guides/whatsapp/templates/best-practices).
