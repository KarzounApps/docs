---

القوالب **الخدمية** لرسائل مرتبطة بمعاملة أو طلب قائم — ليست للعروض الترويجية.

**المسار:** البريد الوارد ← القنوات ← تعديل واتساب ← مدير واتساب ← القوالب ← **إنشاء قالب**.

القالب الخدمي (Utility) مخصص للرسائل المرتبطة بمعاملات العميل وتحديثات الطلبات والتنبيهات التشغيلية. يتميز بتكلفة أقل من التسويقي وبمعدل قبول أعلى من Meta لأنه يخدم احتياجاً حقيقياً للعميل.

> **متى تستخدم القالب الخدمي؟**عندما تريد إرسال معلومات مرتبطة بطلب أو حساب أو خدمة طلبها العميل مسبقاً — مثل تأكيد الطلب، تتبع الشحنة، تذكير الموعد، أو طلب تقييم.

## خطوات إنشاء قالب خدمي

### 1. معلومات القالب الأساسية

![نموذج إنشاء القالب الخدمي](/images/help/doc-1914160/02-c3030f14962a.webp)

| الحقل          | الوصف                                                      | مثال                                                 |
| -------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| **اسم القالب** | بالإنجليزية والأرقام والشرطة السفلية فقط، بحد أقصى 512 حرف | `auto_order_shipped_tracking`                        |
| **اللغة**      | اختر لغة الرسالة                                           | العربية                                              |
| **الفئة**      | اختر **خدمي**                                              | خدمي — تحديثات المعاملات وتأكيدات الطلبات والتنبيهات |

> **ملاحظة:** لا يمكن تغيير الفئة بعد اعتماد القالب من Meta.

---

### 2. الرأس (Header) — اختياري

| نوع الرأس | الوصف                                    | الحد الأقصى  |
| --------- | ---------------------------------------- | ------------ |
| **بدون**  | لا يوجد رأس                              | —            |
| **نص**    | عنوان نصي قصير مع دعم متغير واحد `{{1}}` | 60 حرف       |
| **صورة**  | صورة JPG أو PNG                          | 5 ميجابايت   |
| **فيديو** | فيديو MP4                                | 16 ميجابايت  |
| **مستند** | ملف PDF                                  | 100 ميجابايت |

في القوالب الخدمية يُفضَّل استخدام رأس **نصي** يلخص موضوع الرسالة مثل "تم شحن طلبك" أو "تأكيد حجزك".

---

### 3. جسم الرسالة (Body) — إلزامي

جسم الرسالة هو المحتوى الرئيسي. يدعم المتغيرات الديناميكية والتنسيق والرموز التعبيرية.

**مثال على جسم رسالة خدمية — تتبع الشحنة:**

```
مرحباً {{1}} 👋
يسعدنا إخبارك بأنه تم شحن طلبك رقم {{2}} بنجاح! 🎉

شركة الشحن: {{3}}
رقم التتبع: {{4}}

يمكنك تتبع حالة شحنتك من خلال الزر أدناه.
```

| المتغير | القيمة النموذجية | الوصف      |
| ------- | ---------------- | ---------- |
| `{{1}}` | أحمد             | اسم العميل |
| `{{2}}` | ORD-12345        | رقم الطلب  |
| `{{3}}` | أرامكس           | شركة الشحن |
| `{{4}}` | ARX987654321     | رقم التتبع |

---

### 4. التذييل (Footer) — اختياري

نص قصير يظهر أسفل الرسالة. في القوالب الخدمية يُستخدم عادةً لعبارات مثل:

- "شكراً لتسوقك معنا!"

- "للاستفسار تواصل معنا"

الحد الأقصى: **60 حرفاً**.

---

### 5. الأزرار (Buttons) — اختياري

![قسم الأزرار والتذييل في القالب الخدمي](/images/help/doc-1914160/03-0835ddf49131.webp)

| نوع الزر       | الوصف                                                  | مثال الاستخدام في القوالب الخدمية            |
| -------------- | ------------------------------------------------------ | -------------------------------------------- |
| **زيارة موقع** | يفتح رابطاً في المتصفح. يدعم رابطاً ديناميكياً `{{1}}` | "تتبع الشحنة" → `karzoun.com/tracking/{{1}}` |
| **اتصال**      | يطلب مكالمة هاتفية مباشرة                              | "اتصل بالدعم"                                |
| **رد سريع**    | زر نصي يرسل رداً محدداً مسبقاً                         | "تم الاستلام ✅"                             |

> **ميزة الرابط الديناميكي:** في زر "زيارة موقع"، يمكنك استخدام `{{1}}` في نهاية الرابط لإدراج قيمة متغيرة (مثل رقم التتبع أو رقم الطلب) تلقائياً لكل عميل. مثال: `https://karzoun.com/tracking/{{1}}`

**خيار "Include call permission request":** عند تفعيله، يضيف مكوناً يطلب من العميل إذن إجراء مكالمة معه خارج نافذة الـ24 ساعة — مفيد لفرق خدمة العملاء.

## أمثلة عملية على القوالب الخدمية

| اسم القالب                    | الاستخدام                    | الأزرار المقترحة                                 |
| ----------------------------- | ---------------------------- | ------------------------------------------------ |
| `auto_order_confirmation`     | تأكيد استلام الطلب مع ملخصه  | "عرض الطلب" (رابط )                              |
| `auto_order_shipped_tracking` | إشعار الشحن مع رقم التتبع    | "تتبع الشحنة" (رابط ديناميكي)                    |
| `auto_cod_confirmation`       | تأكيد طلب الدفع عند الاستلام | "تأكيد الطلب ✅" + "إلغاء الطلب ❌" (ردود سريعة) |
| `auto_appointment_reminder`   | تذكير بموعد قادم             | "تأكيد الحضور" + "إعادة الجدولة"                 |
| `customer_feedback_flow`      | طلب تقييم بعد الاستلام       | "تقييم التجربة" (رابط أو تدفق)                   |

## بعد الإنشاء

بعد النقر على **حفظ القالب**، يُرسَل القالب لمراجعة Meta ويصبح في حالة **"معلق"**. القوالب الخدمية عادةً تُعتمد بشكل أسرع من التسويقية لأنها تخدم احتياجاً مباشراً للعميل.

> للاطلاع على أسباب رفض القوالب وكيفية التعامل معها، راجع [أفضل الممارسات](/ar/help-center/guides/whatsapp/templates/best-practices).
