اسم النشاط والصورة والوصف هي أول ما يراه العميل قبل أن يكتب. إن اختلطت حالة الرقم بتقييم الجودة أو تعذّر حفظ الملف، يبدو الحساب غير جاهز حتى لو كانت الرسائل تصل.

يبين تبويب **الملف الشخصي** في مدير واتساب بطاقتين: **رقم هاتف العمل** (حالة وحساب لدى ميتا) و**الملف التجاري** (صورة ووصف وفئة…).

يشرح هذا الدليل خريطة الشاشة، معنى كل حقل، وكيف تطلب اسم عرض أو تحفظ الملف حسب نوع الربط.

**المسار:** البريد الوارد ← القنوات ← تعديل واتساب ← **مدير واتساب ← الملف الشخصي**.

## خريطة الشاشة

الأرقام أدناه تطابق مناطق التبويب كما تظهر في اللقطة.

| # | ما تراه | ماذا يفعل |
| --- | --- | --- |
| **1** | شارة حالة الرقم (مثل `CONNECTED`) | اتصال الرقم بواجهة ميتا — ليست جودة المراسلة |
| **2** | عنوان البطاقة **رقم هاتف العمل** | بطاقة الحالة والهوية أمام العملاء |
| **3** | **رقم العرض** | الرقم الذي يراه العميل عند البحث/المكالمة |
| **4** | **الاسم الموثق** + شارة حالة الاسم | اسم العرض الحالي وحالة مراجعته لدى ميتا |
| **5** | **تقييم الجودة** / **حد المراسلة** / **وضع الحساب** / **مستوى الإنتاجية** | مؤشرات ميتا للرقم (انظر الجدول التالي) |
| **6** | بطاقة **الملف التجاري** | الصورة وحول والوصف والفئة والعنوان والمواقع و**حفظ الملف الشخصي** |

## بطاقة رقم هاتف العمل

أعلى التبويب. إن كان الربط **تعايشاً** أو **Cloud API الخاص بحسابك** قد يظهر تنبيه فوق البطاقتين يوضح حدود التعديل من كرزون.

| التسمية على الشاشة | المعنى |
| --- | --- |
| شارة الحالة (`CONNECTED` وغيرها) | هل الرقم متصل بواجهة ميتا حالياً |
| **رقم العرض** | الرقم المعروض للعملاء |
| **الاسم الموثق** | اسم العرض الحالي أمام العملاء |
| شارة بجانب الاسم (`APPROVED` / `PENDING REVIEW` / `DECLINED`…) | نتيجة مراجعة ميتا لاسم العرض — ليست تقييم الجودة |
| رابط **إرشادات التسمية** | يفتح قواعد ميتا لأسماء العرض |
| زر **تعديل اسم العرض** | يفتح حوار طلب اسم جديد (إن سمح نوع الربط) |
| **تقييم الجودة** | `GREEN` / `YELLOW` / `RED` / `UNKNOWN` حسب تفاعل العملاء |
| **حد المراسلة** | سقف المحادثات اليومية تقريباً (مثل `1K` / `10K`) — إن ظهر «غير متاح» فالبيانات لم تُجلب |
| **وضع الحساب** | حالة ميتا للرقم (مثل `LIVE`) — **ليست** وضع «تعايش» في كرزون |
| **مستوى الإنتاجية** | مستوى إرسال ميتا (مثل `STANDARD`) |

## تغيير اسم العرض

يظهر تحت **الاسم الموثق**. الأزرار والتنبيهات تتغيّر حسب حالة المراجعة ونوع الربط.

### ما تراه حسب الحالة

| ما يظهر | المعنى والإجراء |
| --- | --- |
| زر **تعديل اسم العرض** | افتح الحوار، أدخل **اسم العرض الجديد**، ثم **إرسال للمراجعة** (حد 200 حرف؛ حتى 10 تغييرات / 30 يوماً) |
| تنبيه أصفر + **تحديث الحالة** | الاسم قيد مراجعة ميتا — لا ترسل طلباً جديداً؛ حدّث لمعرفة النتيجة |
| تنبيه أخضر + **تطبيق الاسم** | ميتا وافقت — طبّق خلال 14 يوماً (أرقام كرزون المدارة فقط؛ يعيد تسجيل الرقم) |
| تنبيه أحمر برفض الاسم | عدّل وفق [إرشادات ميتا](https://www.facebook.com/business/help/757569725593362) وأعد الإرسال |
| تنبيه OBA | حساب أعمال رسمي — غيّر الاسم عبر دعم ميتا، ليس من كرزون |
| تنبيه تعايش | غيّر الاسم من تطبيق واتساب للأعمال أو مدير ميتا |
| تنبيه بعد موافقة على Cloud API الخاص | أكمل إعادة التسجيل من **مدير واتساب في ميتا** — زر **تطبيق الاسم** لا يظهر في كرزون |

## بطاقة الملف التجاري

أسفل الصفحة — «إدارة معلومات ملف واتساب التجاري». ما يراه العميل في ملف نشاطك على واتساب.

| التسمية على الشاشة | ماذا يفعل | حدود مفيدة |
| --- | --- | --- |
| صورة + **تغيير الصورة** | رفع صورة الملف | مربع مفضّل ≥ 640×640؛ حتى 5 ميجابايت؛ JPG أو PNG |
| **حول** | سطر قصير تحت الاسم تقريباً | حتى 139 حرفاً |
| **البريد الإلكتروني** | بريد يظهر في الملف | — |
| **الوصف** | وصف أطول للنشاط | حتى 512 حرفاً |
| **الفئة** | تصنيف النشاط (مثل تسوق وتجزئة، مطعم…) | قائمة ميتا داخل القائمة المنسدلة |
| **العنوان** | عنوان العمل | — |
| **المواقع الإلكترونية** | حتى موقعين | **+ إضافة موقع** يظهر إن بقي مكان |
| شارة **تغييرات غير محفوظة** | ظهرت تعديلات لم تُحفظ بعد | — |
| **حفظ الملف الشخصي** | يدفع التعديلات إلى ميتا | يظهر فقط عندما يكون التعديل متاحاً |

### تعايش (WhatsApp Business App)

- تنبيه: الملف والصورة **للقراءة فقط** في كرزون — عدّلهما من تطبيق واتساب للأعمال.
- لا يظهر زر **حفظ الملف الشخصي**؛ حقول النموذج معطّلة.
- تبويبا **المكالمات** و**التجارة** لا يظهران في المدير لهذا الربط.

## أسئلة شائعة

**هل الشارة الخضراء للتقييم هي العلامة الرسمية؟** لا. `GREEN` تقييم جودة المراسلة. حساب الأعمال الرسمي (OBA) منفصل — [متطلبات الحساب](/ar/help-center/guides/whatsapp/concepts/account-requirements).

- أنشئ رمزاً للمواد المطبوعة من [رموز QR](/ar/help-center/guides/whatsapp/qr-codes).
