ربط الرقم لقطة بلقطة يعيش في دليل القنوات؛ بعد النجاح تحتاج خريطة لما يُدار يومياً، ومسار النقل إن كان الرقم عند مزود آخر.

بعد نجاح الربط يفتح **مدير واتساب** من الحساب نفسه: ملف، رموز QR، قوالب، تدفقات، إعلانات، ومكالمات أو تجارة حسب نوع الربط.

يشرح هذا الدليل ماذا تدير بعد الربط، وكيف يختلف مسار النقل، وأين تبقى إعدادات كرزون مقابل ميتا.

خطوات الربط التفصيلية لرقم جديد أو نقله من مزود آخر في [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp).

## قبل أن تبدأ

- صلاحية تعديل القنوات في الحساب.
- إن كنت تنقل رقماً: الرقم أصلاً على Cloud API عند المزود السابق، والتحقق بخطوتين معطّل عند الحاجة — [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa).

## نقل رقم من مزود آخر

قبل النقل غالباً تحتاج تعطيل المصادقة الثنائية على الرقم في ميتا.

{/* MEDIA: /images/help/whatsapp/connect-migrate-1.webp | قائمة المتطلبات المسبقة للنقل مع خانات التحقق بخطوتين والهاتف والتوثيق واسم العرض */}
<Frame caption="متطلبات النقل قبل بدء الخطوات">
  <img src="/images/help/whatsapp/connect-migrate-1.webp" alt="قائمة المتطلبات المسبقة لنقل رقم واتساب" />
</Frame>

1. عطّل التحقق بخطوتين — [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa).
2. تأكد أن الهاتف يستقبل رمز التحقق، وأن الأعمال موثّقة واسم العرض معتمد.
3. من خطوات الربط اختر **بدء نقل الرقم** وأكمل الوجهة والتحقق.

{/* MEDIA: /images/help/whatsapp/connect-migrate-start-gif.webp | GIF 6ث: اختيار بدء نقل الرقم → ظهور قائمة المتطلبات ثم المتابعة بعد التحقق */}
<Frame caption="بدء نقل الرقم بعد استيفاء المتطلبات">
  <img src="/images/help/whatsapp/connect-migrate-start-gif.webp" alt="اختيار بدء نقل الرقم وظهور متطلبات النقل" />
</Frame>

استخدم النقل فقط إذا كان الرقم أصلاً على Cloud API عند مزود آخر. إن كان الرقم على تطبيق الجوال فقط، اختر المسار القياسي أو [التعايش](/ar/help-center/guides/whatsapp/concepts/connection-methods) حسب حالة الرقم.

## إعدادات كرزون مقابل مدير واتساب

| السطح | يتحكم في |
| --- | --- |
| **الإعدادات العامة** للقناة | **اسم القناة** و**القسم** فقط |
| **مدير واتساب** | إعدادات الحساب لدى ميتا: ملف، قوالب، كتالوج، مكالمات… |

لا تبحث عن رد آلي أو إسناد داخل **الإعدادات العامة**. الرد الآلي: [إعداد الرد الآلي للقناة](/ar/help-center/guides/automations/channel-bots). الإسناد: قواعد البريد الوارد / [الإسناد الذكي](/ar/help-center/guides/inbox/smart-assignment).

## أخطاء شائعة

| عَرَض | ماذا تفعل |
| --- | --- |
| لا يظهر تبويب المكالمات أو التجارة | غالباً رقم **تعايش** — هذه التبويبات لأرقام Cloud API فقط |
| الملف للقراءة فقط | غيّر الصورة والوصف من تطبيق واتساب للأعمال |
| فشل النقل عند التحقق بخطوتين | أكمل [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa) ثم أعد المحاولة |

## أسئلة شائعة

**أين خطوات الربط لقطة بلقطة؟** [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp) — هذه الصفحة ما بعد النجاح.

**الرقم على تطبيق الجوال فقط؟** لا تستخدم النقل من مزود. اختر المسار القياسي أو [التعايش](/ar/help-center/guides/whatsapp/concepts/connection-methods).

## الخطوة التالية

تعلّمت خريطة ما بعد الربط ومتى يُستخدم النقل. بعد ذلك:

- أكمل الهوية من [الملف الشخصي](/ar/help-center/guides/whatsapp/profile).
- إن كان الربط لم يبدأ: [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp).
