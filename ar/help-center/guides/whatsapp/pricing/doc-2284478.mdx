---
يوفر مدير واتساب تحليلات مخصصة لمتابعة **تكاليف الرسائل** و**إحصائيات المكالمات**، مما يساعدك على ضبط ميزانيتك وتحسين أداء فريقك.

---

## الوصول إلى التحليلات

انتقل إلى: **القنوات** ← اختر قناة واتساب ← **مدير واتساب** ← تبويب **التحليلات**

ثم اختر نوع التحليلات من القائمة المنسدلة.

---

## تحليلات التسعير

### الوصول

من قائمة **نوع التحليلات**، اختر **تحليلات التسعير**.

![تحليلات التسعير](/images/help/doc-2284478/01-dd5266eb8008.png)

### المقاييس المتاحة

| المقياس               | الوصف                                       |
| --------------------- | ------------------------------------------- |
| **إجمالي التكلفة**    | مجموع تكلفة الرسائل في النطاق الزمني المحدد |
| **التكلفة لكل تسليم** | متوسط تكلفة الرسالة الواحدة المسلّمة        |
| **التكلفة لكل نقرة**  | متوسط تكلفة الحصول على نقرة واحدة           |

### خيارات الفلترة

يمكن تصفية بيانات التسعير حسب:

- **نوع المحادثة** (تسويقية، خدمة عملاء، مصادقة، مساعدة)

- **النطاق الزمني** (يومي أو أسبوعي)

> **ملاحظة مهمة:** الأسعار المعروضة هي الأسعار المباشرة من ميتا. قد يُضيف مزود الخدمة رسوم معالجة وفوترة إضافية. كما أن هذه الأسعار قابلة للتغيير وفق سياسات ميتا.

## تحليلات المكالمات

### الوصول

من قائمة **نوع التحليلات**، اختر **تحليلات المكالمات**.

![تحليلات المكالمات](/images/help/doc-2284478/06-b3ebbb89f25d.webp)

![شريط تحكم تحليلات المكالمات](/images/help/doc-2284478/07-7ba393f3a2a9.webp)

### المقاييس المتاحة

| المقياس           | الوصف                             |
| ----------------- | --------------------------------- |
| **عدد المكالمات** | إجمالي المكالمات الواردة والصادرة |
| **التكلفة**       | تكلفة المكالمات حسب الدولة        |

### خيارات الفلترة

![لوحة فلاتر المكالمات](/images/help/doc-2284478/08-64a3b9b1e427.webp)

تتوفر خيارات فلترة متقدمة لتحليلات المكالمات:

| الفلتر                | الخيارات                          |
| --------------------- | --------------------------------- |
| **الدول**             | تصفية حسب دولة المتصل             |
| **المقاييس المعروضة** | التكلفة، عدد المكالمات، أو كليهما |
| **اتجاه المكالمة**    | جميع الاتجاهات، واردة، صادرة      |

> **ملاحظة:** الأرقام التي ترجعها ميتا للمكالمات المرتبطة بهذه الدول تشمل الرسائل والمكالمات المرتبطة بالتسليم والمعالجة.

## مقارنة سريعة بين أنواع التحليلات

| النوع                 | الاستخدام الأمثل             |
| --------------------- | ---------------------------- |
| **تحليلات الرسائل**   | متابعة أداء الحملات اليومية  |
| **تحليلات القوالب**   | تقييم فعالية قوالب بعينها    |
| **تحليلات التسعير**   | مراقبة الميزانية والتكاليف   |
| **تحليلات المكالمات** | تقييم حجم المكالمات وتكلفتها |
