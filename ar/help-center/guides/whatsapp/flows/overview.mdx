**تدفقات واتساب (WhatsApp Flows)** نماذج وشاشات تفاعلية داخل المحادثة — قوائم، حقول، تقويم — دون إرسال العميل لرابط خارجي.

**المسار:** البريد الوارد ← القنوات ← تعديل واتساب ← **مدير واتساب ← التدفقات**.

![أمثلة لواجهات واتساب فلو](/images/help/doc-1890480/01-30bcf1abb507.jpg)

## متى تستخدم التدفق؟

| حالة الاستخدام | مثال |
| --- | --- |
| **إتمام طلب** | مقاس، عنوان، طريقة دفع في شاشات متصلة |
| **حجز موعد** | خدمة + تاريخ ووقت |
| **استطلاع / تقييم** | نجوم وملاحظات بعد الخدمة |
| **تسجيل أو تأهيل** | اسم، اهتمامات، ميزانية في نموذج واحد |

إذا يكفي زر أو رابط قصير — استخدم [قالباً](/ar/help-center/guides/whatsapp/templates/overview). إذا تحتاج جمع بيانات متعددة الخطوات — استخدم تدفقاً.

## التدفقات مقابل القوالب

| | القالب | التدفق |
| --- | --- | --- |
| **التفاعل** | أزرار / رابط محدود | شاشات وحقول وقوائم |
| **جمع البيانات** | غالباً عبر رسائل متتالية | داخل النموذج |
| **الإعداد** | أسرع | يحتاج تصميم شاشات ونشراً |

## كيف تعمل في كرزون؟

1. أنشئ أو زامن التدفق من تبويب **التدفقات**.
2. صمّم الشاشات في المحرر المرئي ثم **احفظ** و**انشر** (الحالة يجب أن تكون **منشور** قبل الإرسال).
3. أرسله من [الأتمتة](/ar/help-center/guides/whatsapp/flows/in-automations) (نوع رسالة: تدفق واتساب) أو اربطه بسيناريو تشغيلي.
