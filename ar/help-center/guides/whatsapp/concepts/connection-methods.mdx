---

معالج واتساب في كرزون يعرض مسارات مختلفة حسب حالة رقمك وحساب ميتا. الخطوات التفصيلية والأخطاء في [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp).

**المسار في التطبيق:** البريد الوارد ← القنوات ← إنشاء جديد ← واتساب.

## اختر المسار

| الطريقة | متى تستخدمها |
| --- | --- |
| **حساب جديد (Embedded Signup)** | تبدأ من الصفر برقم جديد عبر نافذة ميتا داخل كرزون |
| **تعايش مع تطبيق بيزنس** | الرقم على تطبيق واتساب بيزنس وتريد الإبقاء على مسار التعايش المدعوم |
| **Cloud API الخاص بك** | لديك إعداد Cloud API من ميتا وتريد ربطه بكرزون |
| **نقل من مزود آخر** | الرقم أصلاً على API عند مزود آخر وتنقله إلى كرزون |

## ملاحظات تشغيلية

- بعد النجاح افتح [مدير واتساب](/ar/help-center/guides/whatsapp/overview). قدرات التبويبات تختلف حسب نوع الربط:
  - **تعايش:** الملف والصورة للقراءة فقط؛ لا مكالمات/كتالوج عبر Cloud API من كرزون؛ اسم العرض من التطبيق أو ميتا.
  - **Cloud API الخاص بك:** معظم المدير يعمل؛ تطبيق اسم العرض بعد الموافقة غالباً من مدير ميتا (إعادة التسجيل).
  - **كرزون Embedded Signup:** الملف واسم العرض (طلب + تطبيق) متاحان من كرزون عند توفرها.
- النقل غالباً يتطلب [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa) عند المزود السابق.
- اختبر برسالة حقيقية في **البريد الوارد** قبل إطلاق حملات أو أتمتة.
