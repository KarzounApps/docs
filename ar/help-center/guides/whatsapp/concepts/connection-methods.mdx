الرقم على الجوال ليس كالرقم على Cloud API عند مزود آخر. اختيار البطاقة الخاطئة يوقف المكالمات أو الكتالوج أو يفشل النقل عند التحقق بخطوتين.

خطوات الربط في كرزون تعرض أربعة مسارات حسب حالة رقمك وحساب ميتا. التفاصيل لقطة بلقطة في [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp).

يشرح هذا الدليل متى تستخدم كل بطاقة، وحدود التعايش، ومتطلبات النقل.

**المسار في التطبيق:** البريد الوارد ← القنوات ← إنشاء جديد ← واتساب.

## اختر المسار

| البطاقة في الواجهة | متى تستخدمها | الفوترة تقريباً |
| --- | --- | --- |
| **رقم واتساب جديد عبر كرزون** | تبدأ من الصفر برقم جديد عبر نافذة ميتا داخل كرزون | كرزون يتولى فوترة الرسائل مع ميتا |
| **الاستمرار مع تطبيق واتساب بيزنس** | الرقم على تطبيق واتساب بيزنس وتريد الإبقاء عليه | حسب حساب ميتا/كرزون المرتبط بالمسار |
| **استخدام Cloud API الخاص بك من Meta** | تدير الحساب في Meta Business Manager | تدفع لميتا مباشرة — كرزون لا يفوتر استخدام واتساب |
| **نقل رقم من مزود آخر** | الرقم أصلاً على API عند مزود آخر | بعد النقل يتبع فوترة الوجهة في كرزون |

## تعايش مع تطبيق واتساب بيزنس

التعايش يبقي الفريق على **تطبيق واتساب بيزنس** (جوال أو سطح مكتب) مع وصول كرزون لنفس الرقم. بعد الإنشاء تظهر بطاقة **تقدم المزامنة**: **مزامنة جهات الاتصال** و**مزامنة سجل الرسائل** مع شارات حالة (`pending` / `in_progress` / `completed` / `failed`؛ وللسجل أيضاً `declined` إن رُفضت المشاركة). قراءة الحالات في [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp) — قسم التعايش.

ما لا يوفّره التعايش من داخل كرزون:

- الملف التجاري والصورة **للقراءة فقط** — عدّلهما من التطبيق.
- لا تبويب **مكالمات** ولا **تجارة/كتالوج** عبر واجهة كرزون.
- لا طلب/تطبيق **اسم العرض** من كرزون — غيّره من التطبيق أو مدير ميتا.

تحقق من متطلبات ميتا الحالية للتعايش قبل الالتزام: الأهلية والشروط تتغيّر.

## نقل من مزود آخر

النقل مسار مستقل، ليس اختيار رقم داخل الربط العادي. المتطلبات في الواجهة:

- تعطيل التحقق بخطوتين على الرقم المصدر — [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa)
- إمكانية الوصول للهاتف للتحقق
- حساب ميتا للأعمال موثّق
- اسم العرض معتمد من ميتا

ثم تربط **حساب WABA الوجهة**، تدخل الرقم المسجّل عند المزود السابق، وتتحقق.

## Cloud API الخاص (حساب ميتا)

معظم مدير واتساب يعمل. بعد موافقة ميتا على اسم عرض جديد أكمل إعادة التسجيل من **مدير واتساب في ميتا** — زر **تطبيق الاسم** في كرزون لا يظهر لهذا المسار.

## رقم جديد عبر كرزون

الملف واسم العرض (طلب + تطبيق بعد الموافقة) متاحان من كرزون عند توفرهما. اختبر برسالة حقيقية في **البريد الوارد** قبل إطلاق حملات أو أتمتة.

## أخطاء شائعة

| عَرَض | ماذا تفعل |
| --- | --- |
| اخترت تعايشاً ثم اختفت المكالمات | متوقع — انتقل لمسار Cloud API إن كنت تحتاج المكالمات/الكتالوج من كرزون |
| النقل يتوقف عند 2FA | أكمل التعطيل من ميتا ثم أعد خطوات النقل |
| النافذة المنبثقة محظورة | اسمح بالنوافذ المنبثقة لنطاق كرزون |

## الخطوة التالية

تعلّمت أي بطاقة تناسب حالة الرقم. بعد ذلك:

- نفّذ الربط من [ربط قناة واتساب](/ar/help-center/guides/channels/whatsapp).
- إن كان نقلاً: [تعطيل المصادقة الثنائية](/ar/help-center/guides/whatsapp/disable-2fa) أولاً.
