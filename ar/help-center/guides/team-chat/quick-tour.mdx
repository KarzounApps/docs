هذه الجولة **للموظف** والمشرف: تسمّي مناطق الشاشة كما تظهر في `/team-chat` حتى تجد الزر بسرعة.

## المناطق الأربع

| المنطقة | ماذا ترى |
| --- | --- |
| **قائمة المحادثات** | عنوان **دردشة الفريق**، بحث، أقسام القنوات / المجموعات / المحادثات المباشرة |
| **رأس المحادثة** | الاسم، عدد الأعضاء، الرسائل المثبتة، إعدادات القناة/المجموعة، قائمة ⋯ |
| **منطقة الرسائل** | الخط الزمني، التفاعلات، فتح سلسلة ردود |
| **المحرّر** | نص، مرفقات، إيموجي، صوت، تلميح Enter / Shift+Enter |

<Info>
**وسائط مطلوبة:** لقطة بعناوين مرقّمة على المناطق الأربع أعلاه.  
المسار المقترح: `/images/help/team-chat/quick-tour-regions.webp`  
**فيديو (مستحسن):** 25 ثانية تمرير من القائمة إلى المحرّر ثم فتح النشاطات.
</Info>

## أزرار رأس القائمة

| الزر | الوظيفة |
| --- | --- |
| **النشاطات** (جرس) | إشارات، تفاعلات، ردود سلاسل، رسائل مباشرة |
| **تصفح القنوات** | انضمام لقنوات عامة |
| **+** | **دردشة جديدة**: رسالة مباشرة / مجموعة / قناة |

## قائمة ⋯ على المحادثة

- **كتم** / **إلغاء الكتم**
- **تثبيت في الأعلى** / **إلغاء التثبيت**
- **مغادرة المحادثة** (للقنوات والمجموعات، لا للرسالة المباشرة)

الإعدادات (أيقونة الترس) تظهر للقناة والمجموعة فقط — ليس للرسالة المباشرة.

## لوحة جانبية عند الحاجة

| اللوحة | متى تفتح |
| --- | --- |
| **سلسلة الرسائل** | عند الرد على رسالة في خيط |
| **الرسائل المثبتة** | من رأس المحادثة |
| **إعدادات القناة** أو **إعدادات المجموعة** | من أيقونة الترس |
| **الأعضاء** | من الإعدادات ← **إدارة** |
