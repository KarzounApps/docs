---

عندما تصل دفعة محادثات متشابهة، لا تكرر الإجراء صفاً صفاً. حدّدها من القائمة ثم استخدم شريط الإجراءات الجماعية — مع حذر لأن التغيير يطبّق على كل المحدد.

## ما الذي تستطيع تغييره؟

- **الحالة**: مثل الحل أو الانتظار أو التأجيل بحسب الخيارات الظاهرة
- **التعيين** أو **إلغاء التعيين**
- **القسم**
- **إضافة الوسوم**

## خطوات آمنة

<Steps>
  <Step title="ضيّق القائمة أولاً">
    استخدم [الفلاتر](/ar/help-center/guides/inbox/list-and-filters) لتصل لمجموعة واضحة: مثال «غير مسندة + قسم المبيعات + وسم طلب جديد».
  </Step>
  <Step title="راجع عيّنة">
    افتح محادثتين أو ثلاثاً. تأكد أنها متشابهة فعلاً وأنه لا توجد محادثة حساسة ضمن المجموعة.
  </Step>
  <Step title="حدد المحادثات">
    استخدم مربعات التحديد بجانب الصفوف. سيظهر شريط الإجراءات الجماعية عند تحديد محادثة واحدة أو أكثر.
  </Step>
  <Step title="نفّذ إجراءً واحداً واضحاً">
    اختر الحالة أو المسؤول أو القسم أو الوسم. إن احتجت عدة تغييرات، افصلها إلى عمليات متتابعة مع مراجعة العدد في كل مرة.
  </Step>
  <Step title="تحقق من النتيجة">
    راجع الفلتر أو افتح عيّنة بعد التطبيق، خاصة عند تغيير الحالة أو القسم.
  </Step>
</Steps>

<Info>
**وسائط مطلوبة:** قائمة مفلترة مع تحديد عدة محادثات وشريط الإجراءات الجماعية (حالة، تعيين، قسم، وسم).  
المسار المقترح: `/images/help/inbox/bulk-actions-toolbar.webp`  
**فيديو (مستحسن):** فلترة محادثات غير مسندة → تحديدها → نقلها لقسم وتطبيق وسم.  
**عرض تفاعلي (مستحسن):** تجربة تحديد/إلغاء تحديد ومراجعة عدد المحادثات قبل الإجراء.
</Info>

## أمثلة جيدة

| الهدف | العملية |
| --- | --- |
| توجيه دفعة طلبات متشابهة | فلتر الوسم أو القناة → تغيير القسم |
| وضع علامة متابعة على محادثات حملة | فلتر القناة/التاريخ → إضافة وسم |
| تنظيف دفعة انتهت فعلاً | راجع عينة → تغيير الحالة إلى تم الحل |

<Warning>
لا تغلق محادثات كثيرة فقط لتصفية القائمة. إن كان العميل ينتظر معلومة أو موعد متابعة، استخدم «بانتظار العميل» أو «تأجيل» أو اتركها للمسؤول المناسب.
</Warning>
