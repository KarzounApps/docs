لوحة الجرس تعرض **كل** ما يسمح به النظام؛ **التفضيلات** تحدد **ما يصل** و**كيف** — ويب داخل التطبيق، بريد، أو Push.

> **الجمهور:** كل موظف.  
> المسار: `/settings/notifications` أو من رابط في لوحة الجرس.

<Info>
**وسائط مطلوبة:** جدول تفضيلات — فئة «صندوق الوارد» م expanded مع صف «تم تعيينك» وأعمدة ✓ الويب / البريد / الفوري.  
المسار المقترح: `/images/help/notifications/preferences-grid.webp`
</Info>

## القنوات الثلاث

| القناة | متى تفيد |
| --- | --- |
| **الويب** | أنت داخل كرزون — الجرس |
| **البريد الإلكتروني** | خارج المنصة، ملخص |
| **الإشعارات الفورية** | متصفح/جهاز — [desktop-push](/ar/help-center/guides/notifications/desktop-push) |

كل **نوع** (صف) له مفاتيح مستقلة — يمكن ويب بدون بريد.

## الفئات

| الفئة | ركّز على |
| --- | --- |
| **صندوق الوارد والمحادثات** | تعيين، منشن، قسم |
| **المهام** | تعيين مهمة |
| **محادثة الفريق** | DM وقنوات |
| **الاجتماعات** | دعوات |
| **قاعدة المعرفة** | مراجعات مقالات |
| **سجل الدوام** | حضور وطلبات |
| **النظام** | استيراد، تنبيهات إدارية |

## حفظ

التغيير **فوري** — لا زر حفظ منفصل في معظم النسخ. اختبر بمحادثة تجريبية.
