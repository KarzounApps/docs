عندما تحتاج الوكيل لأدوات خارج كرزون (مستودع كود، تقويم، نظام طرف ثالث يعرض MCP)، لا تكفي قدرات المنصة — تربط **خادم MCP خارجي** ثم تلصقه بالوكيل.

يشرح هذا الدليل: صفحة **خوادم MCP**، اختبار الاتصال، تفعيل الأدوات، وتبويب **MCP** في محرّر الوكيل — مع تمييز واضح عن MCP المطوّرين (الاتصال *إلى* كرزون).

<Info>
هذا المسار لـ**وكلاء كرزون يستدعون أدوات خارجية**. إن أردت أن يتصل Claude أو Cursor أو ChatGPT ببيانات مساحة عملك عبر API، راجع توثيق المطوّرين: [خادم Karzoun MCP](/ar/mcp-server).
</Info>

## أين؟

في التطبيق:

1. **الذكاء الاصطناعي** ← **خوادم MCP** (`/ai/mcp`) — إضافة الخوادم واختبارها وتفعيل الأدوات  
2. **استوديو الوكلاء** ← وكيل ← تبويب **MCP** — إرفاق الخوادم المتصلة بهذا الوكيل  

نفس بوابة الوصول تقريباً لـ[استوديو الوكلاء](/ar/help-center/guides/ai/agent-studio) (خطة المساعد + صلاحية العرض).

## الترتيب الصحيح

<Steps>
  <Step title="أضف خادماً في خوادم MCP">
    افتح **خوادم MCP** وأدخل:

    | الحقل | المعنى |
    | --- | --- |
    | **الاسم** | اسم واضح للفريق (فريد؛ غير حساس لحالة الأحرف) |
    | **الرابط (URL)** | عنوان Streamable HTTP لخادم MCP البعيد |
    | **Bearer token** | اختياري إن طلب الخادم توكن في الترويسة |
    | **ترويسات مخصصة** | اختياري — مفاتيح/قيم إضافية للمصادقة |

    لا تكرر نفس الاسم أو نفس الرابط لخادمَين.
  </Step>

  <Step title="اختبر الاتصال">
    من بطاقة الخادم شغّل **اختبار / Test**. يجب أن تصبح الحالة **متصل (connected)** وتظهر قائمة الأدوات المكتشفة.

    إن فشل الاختبار: راجع الرابط، التوكن، الترويسات، وأن الخادم يقبل طلبات من شبكتك.
  </Step>

  <Step title="فعّل الأدوات التي تحتاجها فقط">
    على الخادم المتصل: عطّل الأدوات غير الضرورية. كل أداة مفعّلة تزيد ضوضاء السياق والتكلفة وخطر الاستدعاء الخطأ.
  </Step>

  <Step title="أرفق الخادم بالوكيل">
    افتح الوكيل في الاستوديو ← تبويب **MCP** ← فعّل المفتاح بجانب الخوادم ذات الحالة **متصل**.

    الخوادم غير المختبَرة تظهر باهتة ولا تُرفق حتى تنجح.
  </Step>

  <Step title="احفظ واختبر">
    احفظ الوكيل. جرّبه في [المساعد](/ar/help-center/guides/ai/copilot-getting-started) إن كان للفريق، أو عبر [النشر مع الأتمتة](/ar/help-center/guides/ai/deploy-with-automations) أمام العملاء.
  </Step>
</Steps>

## MCP مقابل قدرات المنصة

| | **قدرات Tools** | **MCP** |
| --- | --- | --- |
| المصدر | أدوات كرزون (معرفة، كتالوج، تصعيد…) | خادم خارجي تعرضه أنت |
| أين؟ | تبويب **Tools / الأدوات** | صفحة **خوادم MCP** + تبويب **MCP** |
| متى؟ | أغلب بوتات واتساب والدعم | تكامل مع أنظمة طرف ثالث عبر بروتوكول MCP |

راجع أيضاً: [الأدوات والوصول](/ar/help-center/guides/ai/agent-tools-access) · [أدوات مخصصة (انتظار العودة)](/ar/help-center/guides/ai/agent-custom-tools) لمسارات HTTP داخل الأتمتة دون MCP.

## أمان سريع

- خزّن التوكنات والترويسات كأسرار حساب — لا تلصقها في تعليمات الوكيل العامة.  
- ابدأ بأقل أدوات ممكنة (قراءة إن وُجدت).  
- راقب سلوك الوكيل بعد الإرفاق قبل توسيع الصلاحيات.  
- وكيل أمام العملاء + أدوات كتابة خارجية = راجع المخاطر مثل قدرات **الفريق والإدارة**.
