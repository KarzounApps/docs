بدون قدرة مفعّلة، لا يستطيع الوكيل لمس بيانات المنصة حتى لو ذكرتها في التعليمات — فيظهر وكأنه «لا يفهم» الطلب.

**القدرات** هي أدراج أدوات المنصة التي يُسمح للوكيل باستدعائها من تبويب **Tools / الأدوات** في الاستوديو.

يشرح هذا الدليل مستويات الصلاحية، جمهور العملاء مقابل الفريق، والفرق بين القدرة والمهارة مع مسار ضبط آمن لواتساب.

## أين تضبط؟

في التطبيق: **استوديو الوكلاء** ← وكيل ← تبويب **Tools / الأدوات** (قائمة القدرات والصلاحيات).

## مستويات الصلاحية

| المستوى | المعنى |
| --- | --- |
| **قراءة** | عرض وبحث دون تغيير |
| **قراءة + كتابة** | إنشاء وتحديث |
| **وصول كامل** | بما في ذلك الحذف حيث تدعمه الوحدة |

فعّل **أقل** مجموعة ممكنة. «تفعيل الكل» يزيد الضوضاء، التكلفة، وخطر أخطاء على بيانات حساسة.

## جمهور القدرة

| المجموعة | الاستخدام الآمن |
| --- | --- |
| **عامة / للعملاء** | غالباً آمنة على واتساب والدردشة: معرفة، كتالوج، سلة، طلبات، تصعيد… |
| **فريق وإدارة** | لزكي ووكلاء داخليين فقط: أتمتة، إدارة منتجات، فريق، إعدادات وارد، مهام إدارية… |

<Warning>
لا تفعّل قدرات **الفريق والإدارة** على وكيل يرد على عملاء القنوات العامة إلا بقرار واعٍ. الواجهة تعلّم هذه المنطقة كمنطقة خطر — خطأ واحد قد يعدّل كتالوجاً أو أتمتة أو سجلات عملاء.
</Warning>

## أمثلة شائعة

| القدرة (مفهوم) | لوكيل عملاء؟ | ملاحظة |
| --- | --- | --- |
| قاعدة المعرفة | نعم | قراءة للإجابة؛ كتابة لإنشاء مقالات للفريق |
| تصفح كتالوج المنتجات | نعم | استكشاف وبحث |
| سلة التسوق / الدفع | نعم بحذر | يغيّر سلة العميل |
| الاستعلام عن الطلبات | نعم | لا ينشئ ولا يلغي طلبات |
| التصعيد | نعم | يفتح المحادثة لموظف بشري |
| المحادثات | بحذر | إدارة خيوط؛ ليس بديلاً عن التصعيد البسيط |
| الأتمتة | لا — فريق | بناء المسارات |
| إدارة كتالوج المنتجات | لا — فريق | إنشاء/حذف منتجات |
| إدارة واتساب للأعمال | لا — فريق | قوالب، ملف تجاري، تدفقات — ليس رد المحادثة اليومي |
| مهام / مهام إدارية | فريق أو داخلي | بناء اللوحات غير مناسب لبوت المتجر |

أسماء البطاقات في الواجهة تتحدث مع الوقت؛ اختر بالوصف والجمهور لا بالتخمين.

## القدرات لا تساوي المهارات

| | **قدرة** | **مهارة** |
| --- | --- | --- |
| ماذا تفعل؟ | تفتح أدوات | تعلّم *متى وكيف* |
| أين؟ | تبويب الأدوات | تبويب المهارات |
| هل تمنح وصولاً؟ | نعم | **لا** — تعلن متطلباتها فقط |

إن عيّنت مهارة «تصميم الأتمتة» دون تفعيل قدرة الأتمتة، يظهر تحذير — فعّل القدرة أو أزل المهارة. التفاصيل: [المهارات](/ar/help-center/guides/ai/agent-skills).

## مسار ضبط مقترح

1. دعم واتساب بسيط: معرفة (قراءة) + تصعيد.  
2. تجارة: أضف كتالوجاً؛ ثم سلة/طلبات فقط إن كانت القناة متصلة حقاً.  
3. وكيل داخلي لزكي/الفريق: قدرات الإدارة على ملف **منفصل** عن بوت العملاء.  
4. اختبر قبل [النشر عبر الأتمتة](/ar/help-center/guides/ai/deploy-with-automations).
