قبل فتح الاستوديو، اختيار **النمط** الخاطئ يكلّف أسابيع من تعديل تعليمات وقدرات لا تناسب القناة.

تجمع هذه الصفحة أنماطاً مجرّبة وورقة عمل وأخطاء شائعة — مرجعاً لزكي ولفريقك.

يشرح هذا الدليل كيف تختار نمطاً واحداً أولاً، تملأ ورقة العمل، ثم تنسخ وصفة جاهزة دون خلط الطبقات.

## أنماط الوكلاء (اختر واحداً أولاً)

| النمط | الوظيفة | قدرات نموذجية | معرفة | أتمتة متقدمة |
| --- | --- | --- | --- | --- |
| **دعم واجهة متجر** | سياسات + توصية خفيفة + توجيه للمتجر | معرفة + تصعيد | أسعار/شحن/حدود ادعاءات في RAG | تصعيد فوري لتتبع/إلغاء |
| **مبيعات استشارية** | اكتشف الحاجة ثم طابق من الكتالوج | معرفة + كتالوج (+ سلة بحذر) | **أدلة بيع واعتراضات** في RAG؛ الأسعار من الكتالوج | إغلاق برابط أو جمع طلب؛ Flow طلب لاحقاً |
| **كتالوج سريع** | إجابة عن المنتجات | كتالوج + معرفة سياسات | سياسات في RAG لا في التعليمات | تصعيد للعروض المخصصة |
| **دعم ما بعد البيع فقط** | شكاوى وتتبع بلا بيع أثناء الشكوى | معرفة + تصعيد (+ طلبات إن وُجدت) | سياسات وإرجاع | لا Upsell على شكوى نشطة |
| **استقبال / مواعيد** | معلومات + حجز منظم | معرفة + تصعيد | دوام وأسعار خدمات | [حجز Flow](/ar/help-center/guides/ai/agent-booking-flows) + [تصعيد منظّم](/ar/help-center/guides/ai/agent-handover) |

### أ. عن نشاطك

| السؤال | إجابتك |
| --- | --- |
| النمط من الجدول أعلاه | |
| اسم النشاط والقناة الرئيسية | |
| لغة المحادثة | |
| أعلى ٥–١٠ طلبات من العملاء | |
| ماذا **يُمنع** على الوكيل؟ | |

### ب. صنّف كل طلب

| النوع | مثال | ماذا يفعّل عادةً |
| --- | --- | --- |
| معلومة | سعر، دوام، عنوان | معرفة منشورة |
| إجراء تجارة | إضافة للسلة، حالة طلب | قدرات كتالوج/سلة/طلبات + تعليمات |
| مبيعات استشارية | «أبي سجادة لغرفة الضيوف» | اكتشاف في التعليمات → ثم كتالوج؛ دليل بيع في RAG |
| تصعيد | شكوى، طلب موظف | [تصعيد](/ar/help-center/guides/ai/agent-handover) — بسيط أو منظّم |
| حجز / نموذج | موعد، تسجيل خدمة | [نية → واتساب Flow](/ar/help-center/guides/ai/agent-booking-flows) |

### ج. سلم أولويات (رسالة فيها أكثر من طلب)

مثال تجارة: إساءة/شكوى → تتبع/إلغاء → شراء → عام.  
مثال عيادة: طارئ → طبي/وسائط → شكوى → موظف → ملف → حجز → أسعار.  
**لا تَبِع أثناء شكوى نشطة.**

### د. شخصية بجملة

نبرة + أسلوب رد + «لا تفعل» واحدة على الأقل.

ثم: [استوديو الوكلاء](/ar/help-center/guides/ai/agent-studio).

## وصفات جاهزة

### 1) دعم واجهة متجر (واتساب)

| الطبقة | الضبط |
| --- | --- |
| معرفة | سياسات، أسعار إن كانت ثابتة، حدود صحية/قانونية بلا وعود مطلقة |
| تعليمات | لهجة؛ أولويات؛ صيغة تتبع ثابتة؛ استدعِ التصعيد **قبل** «بحوّلك»؛ لا تنكر وجود طلب |
| قدرات | معرفة (قراءة) + تصعيد |
| مهارات | لا شيء |
| أتمتة | عقدة وكيل + نية تحويل؛ اختبر مصفوفة أسعار/دفع/تتبع |

**تعليمات للصق:**

```text
تحدث بلهجة واضحة ومختصرة مناسبة لواتساب.
أجب عن السياسات والأسعار من المعرفة فقط — لا تخمّن خصماً أو موعد تسليم غير موجود في المعرفة.
إن طلب العميل موظفاً أو ظهرت شكوى/إساءة: صعّد فوراً دون جدال.
لصيغة تتبع الطلب استخدم حقلاً واحداً واضحاً؛ إن نقص الرقم اطلبه مرة واحدة ثم صعّد إن لزم.
بعد التصعيد: لا ترسل رسالة إضافية.
```

### 2) مبيعات استشارية + كتالوج

| الطبقة | الضبط |
| --- | --- |
| معرفة | أدلة اختيار، اعتراضات، بكجات، مقارنة أبعاد؛ **ليس** سعر SKU الحي |
| تعليمات | `اكتشف → طابق → أثْرِ → أغلق`؛ سؤال واحد؛ **ممنوع** بحث منتج قبل فهم الاستخدام |
| قدرات | معرفة + كتالوج (+ بحث بصري إن لزم) ثم سلة/طلبات بحذر |
| مهارات | لا شيء إلا كتيب بيع داخلي معقّد |
| ردود | أنواع رسائل المنتجات التي يدعمها رقمك |

**تعليمات للصق:**

```text
الترتيب: اكتشف الحاجة (سؤال واحد) → ابحث في الكتالوج → قدّم خياراً أو اثنين كحد أقصى → أغلق برابط أو خطوة شراء واضحة.
ممنوع اختلاق منتجات أو أسعار — الاعتماد على نتائج الأدوات فقط.
لا تَبِع أثناء شكوى نشطة؛ صعّد أولاً.
إن لم يوجد تطابق جيد: قل ذلك بوضوح واعرض تصعيداً لموظف المبيعات.
```

### 3) استقبال عيادة / مواعيد (المستوى المتقدم)

| الطبقة | الضبط |
| --- | --- |
| معرفة | خدمات، دوام، أسعار — **بلا تشخيص**؛ فجوات السعر → صعّد |
| تعليمات | سلم أولويات؛ ممنوعات طبية؛ صمت أثناء Flow؛ غادر بعد تصعيد منظّم |
| قدرات | معرفة + تصعيد (أو أدوات نية مخصّصة عبر العقدة) |
| أتمتة | [نية حجز → Flow لكل مسار](/ar/help-center/guides/ai/agent-booking-flows)؛ [handover بحقول](/ar/help-center/guides/ai/agent-handover)؛ الطلب ≠ تأكيد موعد |

**تعليمات للصق:**

```text
لا تشخّص ولا تصف علاجاً. المعلومات الطبية العامة من المعرفة فقط.
للحجز: اطلب إكمال واتساب Flow المناسب؛ لا تجمع كل الحقول في الدردشة.
قل صراحة أن إرسال النموذج طلب قيد المراجعة وليس تأكيد موعد.
طوارئ أو شكوى أو طلب موظف: صعّد فوراً ثم توقف عن الرد.
أثناء انتظار الـ Flow: لا تكرر الأسئلة.
```

### 4) مساعد فريق داخلي (ليس بوت عملاء)

| الطبقة | الضبط |
| --- | --- |
| ملف | وكيل مخصص منفصل أو **زكي** |
| قدرات | أتمتة، معرفة كتابة، واتساب للأعمال… حسب الدور |
| مهارات | تصميم الأتمتة / مدير واتساب / تأليف معرفة |
| تحذير | لا تربط هذا الملف بعقدة أمام عملاء القناة |

## معرفة المبيعات مقابل معرفة السياسات

| | أدلة المبيعات في RAG | السياسات / ما بعد البيع |
| --- | --- | --- |
| المحتوى | أسئلة اكتشاف، جداول ملاءمة، ردود اعتراض، قائمة حقول طلب واتساب | شحن، إرجاع، تالف، تأخير |
| مع كتالوج | الأسعار والمخزون من الأدوات | الحقائق التشغيلية من المقالات |
| بلا كتالوج (SKU محدود) | توصية خفيفة + رابط متجر | الأسعار قد تكون في RAG مع مقال مرجعي سريع |

## أخطاء تجعل الوكيل «سيئاً»

| الخطأ | ماذا يحدث | الإصلاح |
| --- | --- | --- |
| سلوك داخل مقالات RAG | قواعد قديمة عشوائية | [المعرفة والتعليمات](/ar/help-center/guides/ai/agent-knowledge) |
| سياسات طويلة داخل التعليمات فقط | تضخم وصعوبة تحديث | انقل للمعرفة (درس متاجر قديمة) |
| تفعيل كل القدرات | بطء وخطر بيانات | [الأدوات](/ar/help-center/guides/ai/agent-tools-access) |
| قدرات إدارة على بوت واتساب | تعديل كتالوج/CRM | وكيل داخلي منفصل |
| كتالوج بلا عملية بيع | ردود عامة | وصفة المبيعات الاستشارية |
| جمع حجز طويل في الدردشة | حقول ناقصة | [واتساب Flow](/ar/help-center/guides/ai/agent-booking-flows) |
| «بحوّلك» بلا أداة | عميل معلّق | [تصعيد](/ar/help-center/guides/ai/agent-handover) |
| تأكيد موعد من الوكيل | توقعات خاطئة | طلب عبر Flow + تأكيد بشري |
| بلا اختبار أسعار/ادعاءات | هلوسة مكلفة | مصفوفة اختبار قبل الإطلاق |
| أتمتة مسودة | لا يرد على القناة | انشر المسار |

## اسأل زكي

«ابنِ لي وصفة وكيل [النمط] لـ…» أو «راجع تعليمات حجز Flow» أو «حوّل تصعيدي إلى حقول منظمة». زكي يشغّل مهارة نظام **Agent Builder** لتصميم ومراجعة الوكلاء المخصصين (إنشاء/تعديل ملفات الاستوديو ضمن صلاحياتك). بعد الاقتراح راجع الحفظ في [استوديو الوكلاء](/ar/help-center/guides/ai/agent-studio) والنشر عبر [الأتمتة](/ar/help-center/guides/ai/deploy-with-automations).
