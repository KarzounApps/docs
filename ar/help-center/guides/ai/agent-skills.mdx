عندما يتكرر إجراء معقّد (تصميم أتمتة، إدارة واتساب للأعمال، تأليف معرفة)، التعليمات القصيرة وحدها لا تكفي — تحتاج كتيب تشغيل يُحمَّل عند الحاجة.

**المهارة** حزمة خبرة: متى تُفعَّل، وكيف يعمل الوكيل خطوة بخطوة، وأحياناً مراجع معرفة. **ليست** مفتاح تشغيل لكل أدوات المنصة.

يشرح هذا الدليل المكتبة، معالج الإنشاء، ومتى تكتفي بالتعليمات دون مهارة.

## أين تضبط؟

في التطبيق: **استوديو الوكلاء** ← وكيل ← تبويب **المهارات**، أو **مكتبة المهارات** (`/agents/skills`) من قائمة الوكلاء.

## ماذا تفعل المهارة؟ وماذا لا تفعل؟

| تفعل | لا تفعل |
| --- | --- |
| تضيف إجراءات عمل ودقة عند المهمة المناسبة | لا تفتح أدوات وحدها |
| تعلن **قدرات مطلوبة** (للتحذير في الواجهة) | لا تستبدل تبويب الأدوات |
| تُحمَّل عند الحاجة أثناء الحوار | لا تغني عن التعليمات الأساسية للوكيل |

بدون القدرة المطلوبة: المهارة قد تُذكر، لكن الأدوات لن تُربط — أصلح من [الأدوات والوصول](/ar/help-center/guides/ai/agent-tools-access).

## مكتبة المهارات

المسار: `/agents/skills`. هنا تظهر تبويبات المصدر:

| التبويب | المحتوى |
| --- | --- |
| **الكل** | مهارات النظام + مهارات حسابك |
| **مخصص** (حسابك / tenant) | كتيبات أنشأها فريقك — قابلة للتعديل |
| **نظام** | كتيبات كرزون الجاهزة — للاستخدام لا للتعديل الكامل |

من المكتبة: بحث، بطاقة مهارة، و**إنشاء مهارة** يفتح خطوات الإنشاء. استيراد المهارات من ملف قد يظهر معطّلاً («قريباً») — لا تعتمد عليه بعد.

هذه التبويبات خاصة بالمهارات — **ليست** تبويبات معرض [استوديو الوكلاء](/ar/help-center/guides/ai/agent-studio) (المعرض مخصص فقط).

## خطوات إنشاء مهارة

عند **إنشاء** أو **تعديل** مهارة حساب، تمر الخطوات الخمس بالترتيب:

| الخطوة (واجهة EN) | ماذا تضبط |
| --- | --- |
| **Identity** | المعرّف، الاسم، الأيقونة، الفئة، الجمهور (عملاء / فريق / كلاهما)، الوصف القصير |
| **Trigger** | متى تُحمَّل المهارة («استخدم عندما…») |
| **Playbook** | تعليمات التشغيل خطوة بخطوة |
| **Required tools** | القدرات المطلوبة والحد الأدنى من الصلاحية — للتحذير إن نقصت على الوكيل |
| **Knowledge** | مراجع معرفة اختيارية مرتبطة بالمهارة |

احفظ بعد اكتمال الخطوات الإلزامية. تعيين المهارة على وكيل **لا يمنح** الوصول للأدوات؛ فعّل القدرات من تبويب أدوات الوكيل.

## متى تضيف مهارة؟ ومتى تكتفي بالتعليمات؟

| الموقف | القرار |
| --- | --- |
| تصعيد بسيط + فقرة في التعليمات | **قدرة تصعيد** فقط — بلا مهارة |
| بناء وتصحيح أتمتة باحتراف | مهارة **تصميم الأتمتة** + قدرة الأتمتة |
| إدارة قوالب واتساب للأعمال وملف الرقم | مهارة **مدير واتساب** + قدراتها |
| كتابة/مراجعة مقالات معرفة بمنهجية | مهارة تأليف/مراجعة المعرفة + قدرة المعرفة |
| تصميم وكلاء مخصصين مع زكي | مهارة نظام **Agent Builder** (حيّة) — راجع [الوصفات](/ar/help-center/guides/ai/agent-recipes) |
| بيع استشاري بنص قصير | تعليمات أو وصفة — ليس شرطاً مهارة نظام |

لا تنشئ مهارة لكل زر. المهارة للإجراء المتكرر والمعقد.

## مهارات النظام (أمثلة)

الأسماء المعروضة قد تختلف قليلاً حسب اللغة؛ المعنى:

| المهارة | متى تستخدمها | قدرات نموذجية مطلوبة |
| --- | --- | --- |
| تصميم الأتمتة | إنشاء/تعديل/اختبار مسارات | أتمتة (كتابة) + قراءات داعمة |
| **Agent Builder** | تصميم/مراجعة وكيل مخصص عبر زكي | استوديو الوكلاء (كتابة) + قراءات معرفة/أتمتة |
| مدير واتساب | قوالب، ملف أعمال، QR، تدفقات، كتالوج ميتا | إدارة واتساب + قراءة إعدادات وارد |
| التسويق بالبريد | قناة بريد، شرائح، قوالب، حملات | قوالب بريد / شرائح / حملات حسب التفعيل |
| تأليف قاعدة المعرفة | هيكل مقالات، فصل الحقائق عن السلوك | معرفة (كتابة) |

زكي يأتي بمهارات نظام مناسبة لدوره كمساعد فريق (ومنها Agent Builder). الوكيل المخصص أمام العملاء غالباً **بدون** مهارات نظام إدارية.

## أخطاء شائعة

| الخطأ | الصواب |
| --- | --- |
| تعيين مهارة أتمتة على بوت واتساب للعملاء | ابْنِ وكيلاً داخلياً منفصلاً |
| الاعتماد على المهارة بدل تفعيل القدرة | فعّل القدرة أولاً |
| مهارة بلا وصف «استخدم عندما…» | اكتب محفّزاً واضحاً في خطوة Trigger |
| خلط المهارة مع **نوايا** عقدة الأتمتة | النوايا لتوجيه المسار بعد الجلسة — راجع [النشر عبر الأتمتة](/ar/help-center/guides/ai/deploy-with-automations) |
| توقع تبويبات الكل/نظام داخل `/agents` | المعرض مخصص فقط؛ التبويبات في `/agents/skills` |
