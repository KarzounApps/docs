الوكيل بلا معرفة يرد من تدريبه العام فقط. بلا مهارات لا يستطيع لمس بيانات مساحة عملك. تبويبا **المعرفة** و**المهارات** في استوديو الوكلاء يحددان ماذا يعرف الوكيل وماذا يُسمح له أن يفعل.

> **الجمهور:** مشرف يضبط وكلاء العملاء أو المساعدين الداخليين.

في التطبيق: **استوديو الوكلاء** ← افتح وكيلاً ← تبويب **المعرفة** أو **المهارات**.

## المعرفة

| الحقل | ماذا يعني | متى تستخدمه |
| --- | --- | --- |
| **مواضيع قاعدة المعرفة** | مواضيع يبحث فيها الوكيل وقت الإجابة ويستشهد بعناوين المقالات | سياسات الشحن، الأسئلة الشائعة، كتالوج نصي |
| **تعليمات مخصصة** | قواعد ثابتة تُحقن في موجّه النظام (افعل / لا تفعل، تصعيد) | حواجز أسعار، لهجة العلامة، متى يسلّم لموظف |

اترك المواضيع فارغة إن أردت إجابات عامة فقط. أنشئ المقالات أولاً من **قاعدة المعرفة** (`/knowledge-base`) ثم اربط المواضيع هنا.

<Info>
**وسائط مطلوبة:** تبويب المعرفة مع موضوعين مختارين وصندوق تعليمات فيه قاعدة «لا تعد بأسعار».  
المسار المقترح: `/images/help/ai/agent-knowledge-tab.webp`
</Info>

## المهارات: ماذا يستطيع أن يفعل؟

المهارات وحدات على بيانات المنصة. لكل مهارة مستوى:

| المستوى | المعنى |
| --- | --- |
| **قراءة** | عرض وبحث دون تغيير |
| **قراءة + كتابة** | إنشاء وتحديث |
| **وصول كامل** | بما في ذلك الحذف حيث تدعمه الوحدة |

### جمهور المهارة

| المجموعة | الاستخدام الآمن |
| --- | --- |
| **المهارات العامة** | غالباً آمنة لوكلاء خدمة العملاء (كتالوج، سلة، معرفة، تصعيد…) |
| **مهارات الفريق والإدارة** | للمشغّلين الداخليين فقط — أتمتة، إدارة منتجات، فريق، إعدادات… |

<Warning>
لا تفعّل مهارات **الفريق والإدارة** على وكيل يرد على عملاء واتساب أو الدردشة العامة. خطأ واحد قد يغيّر كتالوجاً أو أتمتة أو سجلات CRM. الواجهة تعلّم هذه المنطقة كـ **منطقة خطر**.
</Warning>

### أمثلة شائعة

| مهارة | مناسبة لوكيل عملاء؟ | ملاحظة |
| --- | --- | --- |
| قاعدة المعرفة | نعم | قراءة للإجابة؛ كتابة لإنشاء مقالات للفريق |
| تصفح كتالوج المنتجات | نعم | استكشاف وبحث |
| سلة التسوق والدفع | نعم بحذر | يغيّر سلة العميل |
| الاستعلام عن الطلبات | نعم | لا ينشئ/يلغي طلبات |
| التصعيد | نعم | يفتح المحادثة لموظف |
| الأتمتة | لا — فريق فقط | بناء وتعديل المسارات |
| إدارة كتالوج المنتجات | لا — فريق فقط | إنشاء/حذف منتجات |
| الفريق والهيكل | لا — فريق فقط | دعوات وصلاحيات |

**تفعيل الكل** يمنح خيارات أكثر وقد يبطئ الرد ويقلل الدقة — فعّل ما يحتاجه الدور فقط.

## مبدأ الضبط

1. ابدأ بمعرفة + تصعيد + قراءة كتالوج لوكيل الدعم.  
2. أضف السلة/الطلبات فقط إن كانت القناة متصلة بتجارة حقيقية.  
3. أنشئ وكيلاً **منفصلاً** للفريق الداخلي بمهارات الإدارة.  
4. اختبر في المساعد قبل ربط الأتمتة.
