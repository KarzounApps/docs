description: "تبويبات ملف العضو: نظرة، حضور، محادثات، نشاط — مراجعة أداء وتنظيم من /settings/team-members/:id."
---

**ملف الموظف** يركّز على **عضو الفريق** — ليس [ملف عميل](/ar/help-center/guides/contacts/profile). المشرف يفتحه لمتابعة الحضور، المحادثات المسندة، والسجل التنظيمي.

> المسار: `/settings/team-members/:id` (من قائمة الفريق أو من اسم الموظف في الواجهة).

<Info>
**وسائط مطلوبة:** ملف عضو — الشريط الجانبي (صورة، قسم، توفر) + تبويب «نظرة عامة» مع الإسنادات التنظيمية.  
المسار المقترح: `/images/help/settings/team/member-profile-overview.webp`
</Info>

## الشريط الجانبي

| عنصر | ماذا يعرض |
| --- | --- |
| **الصورة والاسم** | هوية العضو |
| **المنصب** | من [الهيكل](/ar/help-center/guides/settings/team/positions) |
| **التوفر الحالي** | Online / مشغول / … |
| **ودجت الساعة** | حضور اليوم — رابط [الحضور](/ar/help-center/guides/attendance/overview) |

## التبويبات

| التبويب | المحتوى |
| --- | --- |
| **نظرة عامة** | أقسام، فروع، مناصب، مجموعات صلاحيات |
| **الحضور** | سجلات الحضور والغياب |
| **الجدول** | نوبات/جدول — طلبات من هنا |
| **المحادثات** | محادثات مرتبطة بالعضو (مسندة أو شارك فيها) |
| **النشاط** | سجل إسناد تنظيمي + سجل نشاط |
| **الملفات** | مستندات م linked بالعضو |

## شريط الإجراءات

أعلى الصفحة: **تعديل**، **توفر**، **طلب غياب**، **إعادة تعيين كلمة المرور** — حسب صلاحياتك. نفس الإجراءات متاحة من [قائمة الفريق](/ar/help-center/guides/settings/team/invite-and-manage).

## متى تفتح الملف؟

| الموقف | التبويب |
| --- | --- |
| مراجعة أسبوعية | **المحادثات** + **الحضور** |
| تحقيق CSAT منخفض | **المحادثات** ثم [الرؤى](/ar/help-center/guides/insights/csat) |
| تغيير قسم | **نظرة عامة** أو **تعديل** |
| onboarding | **نظرة عامة** — تأكد قسم ومجموعة |

## الفرق عن «يوم الموظف»

| ملف الموظف | [يومك في البريد الوارد](/ar/help-center/guides/inbox/agent-day) |
| --- | --- |
| يراه المشرف | يراه الموظف لنفسه |
| حضور + سجل | تشغيل يومي في الوارد |
