عندما يحتاج المشرف مراجعة حضور أو محادثات مسندة، ملف العميل في جهات الاتصال ليس المكان الصحيح.

**ملف الموظف** يركّز على **عضو الفريق** — ليس [ملف عميل](/ar/help-center/guides/contacts/profile). المشرف يفتحه لمتابعة الحضور، المحادثات المسندة، والسجل التنظيمي، ونقاط الشهر والشارات.

يشرح هذا الدليل الشريط الجانبي والتبويبات ومتى تفتح كل تبويب.

> المسار: `/settings/team-members/:id` (من قائمة الفريق أو من اسم الموظف في الواجهة).

## قبل أن تبدأ

- افتح من [قائمة الفريق](/ar/help-center/guides/settings/team/invite-and-manage) بالنقر على الصف.
- بعض أزرار الشريط العلوي تظهر فقط حسب صلاحياتك.

## الشريط الجانبي

| عنصر | ماذا يعرض |
| --- | --- |
| **الصورة والاسم** | هوية العضو |
| **المنصب** | من [الهيكل](/ar/help-center/guides/settings/team/positions) |
| **التوفر الحالي** | Online / مشغول / … |
| **ودجت الساعة** | حضور اليوم — رابط [الحضور](/ar/help-center/guides/attendance/overview) |
| **النقاط والترتيب** | مجموع **هذا الشهر** وترتيب العضو ضمن الفريق |
| **أشرطة الفئات** | سرعة، جودة، إنتاجية، تدريب، تفاعل — نفس [النقاط والفئات](/ar/help-center/guides/training/points-and-categories) |
| **الشارات** | عتبات الفئات وشارات صدارة الشهر — [الشارات](/ar/help-center/guides/training/badges) |

## التبويبات

| التبويب | المحتوى |
| --- | --- |
| **نظرة عامة** | أقسام، فروع، مناصب، مجموعات صلاحيات |
| **الحضور** | سجلات الحضور والغياب |
| **الجدول** | نوبات/جدول — طلبات من هنا |
| **المحادثات** | محادثات مرتبطة بالعضو (مسندة أو شارك فيها) |
| **النشاط** | سجل إسناد تنظيمي + سجل نشاط |
| **الملفات** | مستندات مرتبطة بالعضو |

## شريط الإجراءات

أعلى الصفحة: **تعديل**، **توفر**، **طلب غياب**، **إعادة تعيين كلمة المرور** — حسب صلاحياتك. نفس الإجراءات متاحة من [قائمة الفريق](/ar/help-center/guides/settings/team/invite-and-manage).

## متى تفتح الملف؟

| الموقف | التبويب |
| --- | --- |
| مراجعة أسبوعية | **المحادثات** + **الحضور** + الشريط الجانبي للنقاط |
| تحقيق CSAT منخفض | **المحادثات** ثم [الرؤى](/ar/help-center/guides/insights/csat) |
| تغيير قسم | **نظرة عامة** أو **تعديل** |
| انضمام جديد | **نظرة عامة** — تأكد قسم ومجموعة |

## الفرق عن «يوم الموظف»

| ملف الموظف | [يومك في البريد الوارد](/ar/help-center/guides/inbox/agent-day) |
| --- | --- |
| يراه المشرف | يراه الموظف لنفسه |
| حضور + سجل | تشغيل يومي في الوارد |

## أخطاء شائعة

| الخطأ | النتيجة |
| --- | --- |
| البحث عن ملف عميل هنا | هذا لعضو الفريق فقط |
| افتراض أن كل الأزرار ظاهرة | الصلاحيات تخفي بعضها |

## أسئلة شائعة

**هل يفتح الموظف ملفه بنفسه؟**  
غالباً يرى ملفه أو إعدادات شخصية محدودة؛ مراجعة الأداء الشاملة للمشرف.

**أين أغيّر القسم؟**  
**تعديل** من الملف أو من قائمة الفريق.

## الخطوة التالية

تعلّمت قراءة ملف العضو تبويباً تبويباً. بعد ذلك:

- لضبط الحالة التشغيلية: [التوفر](/ar/help-center/guides/settings/team/availability).
- لمراقبة المحادثات: [مراقبة المحادثات](/ar/help-center/guides/inbox/supervise-queue).
