**الفرع** = موقع físico أو كيان legal (الرياض، جدة، فرع B2B…) — يكمّل **القسم** ولا يستبدله. مفيد للفلاتر في [قائمة الفريق](/ar/help-center/guides/settings/team/invite-and-manage) والتقارير التنظيمية.

> المسار: `/settings/structure` ← تبويب **الفروع**.

<Info>
**وسائط مطلوبة:** تبويب الفروع — نموذج «إنشاء فرع» مع عنوان ومشرف.  
المسار المقترح: `/images/help/settings/team/branches-form.webp`
</Info>

## الفرع مقابل القسم

| | **فرع** | **قسم** |
| --- | --- | --- |
| **يسأل** | أين؟ | ماذا يعمل الفريق؟ |
| **مثال** | «فرع الدمام» | «دعم العملاء» |
| **في الوارد** | فلترة إدارية | طابور وإسناد |
| **إلزامي للدعوة** | اختياري | **إلزامي** |

## إنشاء فرع

| الحقل | ملاحظة |
| --- | --- |
| **الرمز / العنوان** | للتعرف في القوائم |
| **الأصل** | فرع تحت مجموعة |
| **المشرف** | بريد مسؤول الموقع |
| **العنوان** | للمرجعية التشغيلية |

## ربط الأعضاء

عند دعوة أو **تعديل** عضو: **اختر الفرع** — يسهّل على المشرف «كل الفروع» vs فرع واحد في قائمة `/settings/team-members`.

## متى تحتاج فروعاً؟

| نعم | لا |
| --- | --- |
| 3+ مواقع بمديرين | شركة صغيرة remote |
| تقارير HR حسب الموقع | قسم واحد فقط |
| SLA مختلف per city | لا فلترة جغرافية |
