كل مقعد جديد = **دعوة** + **قسم** + **مجموعة صلاحيات**. بدون الثلاثة يتعثر التعيين في [البريد الوارد](/ar/help-center/guides/inbox/assign) أو يفتح الموظف صلاحيات زائدة.

> المسار: `/settings/team-members`.

## دعوة عضو جديد

<Steps>
  <Step title="دعوة أعضاء جدد">
    من `/settings/team-members` — **دعوة أعضاء جدد** أو **إضافة موظفين**.
  </Step>
  <Step title="املأ الصف">
    **الاسم**، **البريد** (إلزامي)، **مجموعة الصلاحيات** (إلزامي)، **القسم** (إلزامي)، **الفرع** (اختياري)، **كلمة مرور مؤقتة** (حسب النموذج).
  </Step>
  <Step title="أرسل">
    يصل للمدعو **رابط إعداد الحساب** على بريده.
  </Step>
  <Step title="أضف صفوفاً">
    **إضافة عضو آخر** لدفعة واحدة.
  </Step>
</Steps>

<Info>
**وسائط مطلوبة:** نافذة «دعوة أعضاء الفريق» بصفين: بريد + مجموعة + قسم.  
المسار المقترح: `/images/help/settings/team/invite-and-manage-dialog.webp`  
**فيديو (مستحسن):** 40 ثانية من فتح الدعوة حتى «تم إرسال الدعوات».
</Info>

## قائمة الأعضاء

| فلتر | فائدة |
| --- | --- |
| **بحث** | اسم أو بريد |
| **الفرع / القسم** | فرق موزّعة |
| **حالة الدعوة** | معلّق / محقق |
| **نشط / غير نشط** | من عُطّل |

النقر على صف يفتح [ملف الموظف](/ar/help-center/guides/settings/team/member-profile) (`/settings/team-members/:id`).

## إجراءات على عضو

| الإجراء | متى |
| --- | --- |
| **تعديل العضو** | تغيير قسم، مجموعة، فرع |
| **إعادة إرسال الدعوة** | لم يسجّل بعد |
| **تعطيل / تفعيل** | مغادرة أو إجازة طويلة — لا حذف فوري |
| **تعيين التوفر** | Online، مشغول، استراحة، غير متصل |
| **إعادة تعيين كلمة المرور** | من قائمة ⋮ |

<Warning>
**تعطيل** يمنع الدخول — المحادثات المسندة قد تحتاج [إعادة تعيين](/ar/help-center/guides/inbox/assign) قبل التعطيل.
</Warning>

## المقاعد والفوترة

كل مستخدم **نشط** يحسب في [المقاعد](/ar/help-center/guides/settings/billing/plan-and-payment). قبل دعوة ٢٠ شخصاً: راجع حد الخطة و**مزامنة المقاعد**.

## أخطاء شائعة

| الخطأ | النتيجة |
| --- | --- |
| مجموعة «مدير» لكل الوافدين | وصول لإعدادات/Fوترة |
| قسم فارغ | فشل الدعوة أو تعيين معطّل |
| نسيان إعادة الدعوة | موظف «عالق» أسبوعاً |
