**المنتجات والخدمات** في الإعدادات (`/settings/products-services`) كتalog **داخل كرزون** — للإدراج في رسائل، [أتمتة](/ar/help-center/guides/automations/overview)، و[طلبات](/ar/help-center/guides/orders/overview). ليس بالضرورة نفس كتalog **سلة** أو **زد** إن كان متجرك منفصلاً.

> **صلاحية:** `manageProducts`.

<Info>
**وسائط مطلوبة:** صفحة المنتجات — عرض جدول مع فلاتر الحالة والنوع وأزرار «إضافة منتج» و«استيراد».  
المسار المقترح: `/images/help/settings/products/overview-catalog.webp`
</Info>

## كتalog كرزون vs متجر متصل

| المصدر | متى |
| --- | --- |
| **يدوي / استيراد CSV** | `/settings/products-services` |
| **تطبيق سلة/زد/شوبيفاي** | [المتجر](/ar/help-center/guides/store/overview) — مزامنة منتجات |
| **واتسApp Commerce** | [تجارة واتسApp](/ar/help-center/guides/whatsapp/commerce/overview) |

قد ترى **نفس SKU** من مصدرين — حدّد «مصدر الحقيقة» لفريقك لتجنّب أسعار متعارضة.

## أنواع المنتجات

| النوع | مثال |
| --- | --- |
| **منتج** | SKU مادي |
| **خدمة** | تركيب، استشارة |
| **رقمي** | ملف، اشتراك محتوى |
| **اشتراك** | باقة متكررة |

## حالات العرض

| الحالة | المعنى |
| --- | --- |
| **مسودة** | غير جاهز |
| **نشط** | يظهر في الاستخدام |
| **معطل / مخفي / مؤرشف** | لا يُعرض للعملاء أو للاختيار |

<Warning>
إذا **كل المتغيرات** غير نشطة، تحذير الكتalog: المنتج «غير متوفر» — راجع [الفئات والمتغيرات](/ar/help-center/guides/settings/products/categories-variants).
</Warning>

## العرض: شبكة أو جدول

**عرض شبكي** للمعاينة السريعة · **عرض جدول** للفرز والإجراءات الجماعية. فلاتر: **بحث**، **حالة**، **نوع**، **علامة تجارية**.

## أين يُستخدم الكتalog؟

- رسائل [واتسApp Commerce](/ar/help-center/guides/whatsapp/commerce/messages)  
- إجراءات أتمتة على الطلبات  
- [الطلبات](/ar/help-center/guides/orders/overview) في المنصة
