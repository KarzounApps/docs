عشرات أو مئات الـ SKU تستحق **استيراد CSV** بدل [إضافة منتج](/ar/help-center/guides/settings/products/add-product) واحداً تلو الآخر.

> المسار: `/settings/products-services` ← **استيراد**.

<Steps>
  <Step title="1 — الرفع">
    **اسحب CSV** أو تصفّح. **حمّل قالب استيراد المنتجات** إن بدأت من الصفر. يدعم **.csv** فقط.
  </Step>
  <Step title="2 — ربط الأعمدة">
    كل **عمود CSV** → **حقل منتج** (اسم، رمز، سعر…) أو **تخطي**.
  </Step>
  <Step title="3 — التأكيد">
    راجع عدد الصفوف والأعمدة المربوطة — **اسم الاستيراد** للتتبع — **بدء الاستيراد**.
  </Step>
</Steps>

<Info>
**وسائط مطلوبة:** خطوة «ربط الأعمدة» — عمود «name» مربوط بـ «اسم المنتج» وعداد «X من Y أعمدة تم ربطها».  
المسار المقترح: `/images/help/settings/products/import-mapping.webp`  
**فيديو (مستحسن):** 45 ثانية: قالب → رفع → ربط → بدء.
</Info>

## قبل الرفع

| تحقق | لماذا |
| --- | --- |
| **رمز/اسم** فريدان | تقليل رفض الصفوف |
| **عملة** متوافقة مع [الإعدادات العامة](/ar/help-center/guides/settings/general) | أسعار صحيحة |
| **UTF-8** للعربية | تجنّب رموز مشوّهة |
| نسخة احتياطية | الاستيراد يحدّث أو يُنشئ — راجع سياسة التكرار في الواجهة |

## أخطاء شائعة

| رسالة | الحل |
| --- | --- |
| ملف فارغ | صف بيانات + رأس أعمدة |
| تعذر التحليل | فاصلة/ترميز CSV |
| عمود غير مربوط | «اسم المنتج» إلزامي غالباً |

## بعد الاستيراد

- راجع **الحالة** (مسودة vs نشط) في [الكتalog](/ar/help-center/guides/settings/products/overview)  
- أضف **صوراً** يدوياً — CSV قد لا يتضمن ملفات  
- للمتجر الم live: قارن مع [مزامنة التطبيق](/ar/help-center/guides/store/ecommerce-apps)
