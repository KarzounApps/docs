المحفظة تقول كم بقي؛ **الاستخدام** يقول أين ذهب؛ **الفواتير** وثيقة المحاسبة. الثلاثة تكمل دورة الفوترة.

| الصفحة | المسار |
| --- | --- |
| **الاستخدام** | `/settings/billing/usage` |
| **الفواتير** | `/settings/billing/invoices` |
| نظرة عامة | `/settings/billing` |

## مستكشف الاستخدام

- يعرض استهلاك الفترة الحالية أو نطاقاً تاريخياً عند إنشاء تقرير.  
- بنود شائعة: رموز الذكاء، تشغيل الأتمتة، جهات الاتصال — حسب تسعير حسابك.  
- قد تظهر **تكلفة مقدّرة** بجانب الكمية.

استخدمه أسبوعياً إن كان لديك وكلاء قنوات أو حملات أتمتة كثيفة. لخفض رموز الذكاء راجع [رصيد الرموز](/ar/help-center/guides/ai/credits).

<Info>
**وسائط مطلوبة:** مستكشف الاستخدام مع بند رموز الذكاء، وبجانب تبويب الفواتير بقائمة.  
المسار المقترح: `/images/help/settings/billing-usage-invoices.webp`
</Info>

## الفواتير

| إجراء | المعنى |
| --- | --- |
| **عرض** | فتح تفاصيل الفاتورة |
| **تنزيل** | ملف للمحاسبة |
| حالات الصف | مدفوعة / مستحقة / … حسب ما يعرضه النظام |

الفاتورة تغطي عادة رسوم الاشتراك/المقاعد؛ الاستهلاك المقيّس يظهر في الاستخدام وخصم المحفظة — لا تخلط بينهما عند مطابقة الأرقام.

## صفحات إضافية قد تظهر

`/settings/billing/seats` و`/features` و`/analytics` قد تكون موصولة من الخطة أو موجودة دون تبويب رئيسي — استخدمها إن ظهرت؛ المصدر التشغيلي اليومي يبقى الخطة + الاستخدام + المحفظة + الفواتير.
