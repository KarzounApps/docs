عندما يلتبس اسم الشاشة مع اسم قريب، يتفرّق الفريق بين «صندوق الوارد» و«وكلاء الدعم» و«مساحة العمل» بينما المنتج يستخدم أسماء أخرى.

يثبّت هذا المسرد الأسماء الرسمية لمركز مساعدة كرزون: ما نستخدمه، وما هو محظور، ومتى ننقل تسمية الواجهة كما هي.

تتعرّف في هذا الدليل على المصطلحات المقفلة وتسميات الواجهة التي تُنقل حرفياً.

نبرة مركز المساعدة = **ودّي تشغيلي (Friendly SaaS)** — موقف → وعد → «يشرح هذا الدليل…» — وليس كتيّب أوامر جاف؛ المصطلحات في الجدول أدناه تبقى مقفلة بلا تغيير. إن تعارض نص قديم مع هذا الجدول: صحّح النص أو انقل تسمية الواجهة حرفياً بين علامات مع توضيح.

## المصطلحات المقفلة

| المصطلح الرسمي | المعنى / أين | محظور أو تجنّب | ملاحظات |
| --- | --- | --- | --- |
| **البريد الوارد** | شاشة `/inbox` — عمل خدمة العملاء | مركز المحادثات · صندوق الوارد · البريد الوارد الموحد | مجموعة الأدلة في الشريط: **خدمة العملاء**. استثناء لغوي: «صندوق الوارد» مقبول فقط لوصف صندوق بريد المستلم في حملات الإيميل |
| **موظف / موظفون** | أعضاء الفريق البشري في الدعم والمبيعات | وكيل / وكلاء الدعم (عن البشر) | استثناء: انقل تسمية الواجهة حرفياً إن ظهرت «وكيل بشري» |
| **وكيل / وكلاء** | وكلاء الذكاء الاصطناعي فقط | استخدام «وكيل» عن موظف بشري في السرد | استوديو الوكلاء · عقدة وكيل المساعد · أدوات الوكيل الذكي |
| **حساب / حسابك في كرزون** | بيئة عمل العميل في كرزون | مساحة · مساحة العمل | «مساحة» فقط للحيز الحرفي (تخزين، لوحة، أسماء…) |
| **القناة** | تكامل وصول العملاء من `/channels` | خلط «قناة» مع «حملة» | الربط في **قنوات التواصل**؛ الاستخدام اليومي في البريد الوارد |
| **القسم** | فريق تشغيل تُربَط به القنوات والموظفون | | أساس الإسناد والإسناد الذكي |
| **زكي / المساعد الذكي** | مساعد الموظفين في `/copilot` | خلطه ببوت واتساب للعملاء | للمنصة الداخلية؛ بوت القناة مسار أتمتة منفصل |
| **الرد الآلي** | ترحيب وسلوك القناة من `/automations/channel-bots` | تسمية الوحدة كلها «منشئ الرد الآلي» | سطح داخل **الأتمتة** |
| **الحملات التسويقية** | مجموعة الأدلة؛ المنتج التسويقي | اختزال القنوات لواتساب/بريد فقط | في الواجهة عند النقر: **الرسائل الجماعية** (`/broadcast`) |
| **إسناد / إسناد ذكي** | توزيع المحادثات | تعيين / التعيين الذكي (في السرد) | إن بقيت تسمية قديمة في الواجهة فانقلها كما تظهر |
| **المسؤول المسند إليه** | من يملك المحادثة | «المسؤول» وحده إن لبس المعنى | |
| **محادثة** | خيط تواصل مع عميل | تذكرة · تذاكر (كنظام تذاكر) | تحويل المتابعة الطويلة: **بطاقة دعم** من المهام |
| **بطاقة دعم** | مهمة مرتبطة بعميل/محادثة | تذكرة · «من المحادثة إلى مهمة» | العمل الداخلي بلا عميل = **مهمة** |
| **مراقبة المحادثات** / **قائمة المحادثات** / **غير المسندة** | أسطح المتابعة والتوزيع | طابور · الطابور · طوابير · مراقبة الطابور | لمهلة المكالمات: **مهلة الانتظار** |
| **محادثة الفريق** | `/team-chat` | محادثات الفريق | منتج منفصل عن البريد الوارد |
| **النوافذ والنماذج** | منتج النوافذ المنبثقة والنماذج | صياد الزوار كاسم أساسي | صياد الزوار = مرادف تسويقي قديم فقط |
| **الشرائح** | مجموعات جمهور ديناميكية/ثابتة | | جاهزة قبل الحملات |
| **كرزون بكسل** | تتبع سلوك الموقع/المتجر | | يغذّي الملف والشرائح والأتمتة |
| **الأتمتة** | مسارات `/automations` | منشئ الرد الآلي (كاسم وحدة) | الرد الآلي = سطح داخل الأتمتة |
| **تسليم إلى وكيل بشري** | اسم إجراء في الواجهة | إعادة صياغة الاسم في السرد دون توضيح أنه اسم واجهة | في السرد بعد الإجراء قل **موظف** لا «وكيل» |
| **قوائم التنقّل** | مجموعات الشريط | خلط اسم المجموعة باسم الميزة | خدمة العملاء ≠ البريد الوارد في التسمية |

## تسميات واجهة تُنقل كما هي

| في الواجهة | في المرجع |
| --- | --- |
| البريد الوارد | البريد الوارد |
| الرسائل الجماعية | عند توجيه النقر؛ وفي الشرح: الحملات التسويقية |
| تسليم إلى وكيل بشري | انقل الاسم؛ ثم اشرح أنه لموظف بشري |
| وكيل المساعد | وكيل (ذكاء اصطناعي) |
| العودة إلى الوكيل | إجراء AI — لا تُستبدل بـ«موظف» |
| خاصتي · غير مسندة · شاركت فيها | كما في تبويبات القائمة |
