بمجرد تسجيل الدخول تجد نفسك في لوحة التحكم — مركز عملياتك اليومية في كرزون. تتكون الواجهة من ثلاثة أقسام رئيسية.

![لوحة التحكم](/images/help/doc-2163846/01-392549f16d68.webp)

---

## 1. شريط الهيدر (العلوي)

يوجد في أعلى الشاشة ويحتوي على:

| العنصر                | الوظيفة                                 |
| --------------------- | --------------------------------------- |
| **شريط البحث**        | ابحث عن جهة اتصال، محادثة، أو طلب بسرعة |
| **أيقونة الجرس 🔔**   | إشعارات النظام والتنبيهات               |
| **أيقونة الإيميل ✉️** | إرسال بريد إلكتروني بشكل سريع           |
| **أيقونة واتساب 💬**  | إرسال قالب واتساب بشكل سريع             |
| **الملف الشخصي**      | إدارة حسابك وإعداداتك الشخصية           |

### قائمة الملف الشخصي

بالنقر على صورتك في أعلى اليسار تظهر قائمة تحتوي على:

- **الحالة:** تغيير حالتك (متاح / مشغول / غير متاح)
- **المظهر:** تبديل بين الوضع الفاتح والداكن
- **اللغة:** تغيير لغة الواجهة
- **ملفي الشخصي:** تعديل بياناتك الشخصية
- **تغيير كلمة المرور**
- **توقيعات البريد:** إدارة توقيعاتك في البريد الإلكتروني
- **المساعدة والموارد**
- **إبلاغ عن خطأ / اقتراح**
- **تسجيل الخروج**

## 2. القائمة الجانبية

تنقلك بين جميع أقسام كرزون. إليك ما يحتويه كل قسم:

| القسم                | ما بداخله                                                        |
| -------------------- | ---------------------------------------------------------------- |
| **البريد الوارد**    | المحادثات، القنوات، الردود السريعة، الإسناد الذكي، محادثة الفريق |
| **جهات الاتصال**     | العملاء، الشرائح، النوافذ المنبثقة                               |
| **الرسائل الجماعية** | قائمة الرسائل، قوالب البريد، التحليلات، التقويم                  |
| **الأتمتة**          | الأتمتات، المشغّلات، الماكرو، الرد الآلي                         |
| **الذكاء الاصطناعي** | المساعد، استوديو الوكلاء                                         |
| **الرؤى**            | لوحة التحكم التحليلية، الإنشاء السريع                            |
| **مدير الملفات**     | جميع الملفات، الملفات المرفوعة                                   |
| **المهام**           | إدارة مهام الفريق                                                |
| **الطلبات**          | طلبات العملاء                                                    |
| **الاجتماعات**       | الاجتماعات، الغرف                                                |
| **الحضور والانصراف** | السجلات، الوقت، الطلبات، الجدول، التقرير                         |
| **قاعدة المعرفة**    | المواضيع، المقالات                                               |
| **المتجر**           | ربط المتجر الإلكتروني                                            |
| **الإعدادات**        | إعدادات الحساب والفريق                                      |

## 3. محتوى لوحة التحكم

### بطاقات الإحصائيات

أربع بطاقات تعطيك ملخصاً فورياً ليومك:

- **المحادثات المفتوحة:** عدد المحادثات التي تنتظر ردك.
- **مهامي:** المهام المسندة إليك.
- **اجتماعات اليوم:** جدول اجتماعاتك القادمة.
- **الوردية النشطة:** مدة حضورك المسجّل.

### الإجراءات السريعة

اختصارات لأكثر الإجراءات تكراراً:

- **محادثة جديدة:** لبدء شات مع عميل.
- **إنشاء مهمة:** لإضافة مهمة لك أو لفريقك.
- **جدولة اجتماع:** لحجز موعد جديد.

### يحتاج إلى انتباه

قسم يجمع المحادثات التي تحتاج متابعة فورية.

### محادثاتي

آخر المحادثات التي شاركت فيها للوصول السريع إليها.

### التقدم في التدريب

يعرض نسبة إتمامك لمحتوى التدريب المتاح في كرزون.
