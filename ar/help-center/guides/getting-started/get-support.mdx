عندما يتعطل شيء في الحساب، يطول البلاغ إن نُسخ من دون وقت أو مسار أو لقطة — أو إن كان العطل عاماً ظاهراً على بوابة الحالة.

قبل التصعيد، راجع [صحة الخدمة](https://status.karzoun.chat/) وجهّز ما يحتاجه الدعم في أول رسالة.

يشرح هذا الدليل الترتيب: صحة الخدمة، ثم ما ترفق، ثم أين تتواصل — دون إرسال كلمات مرور أو مفاتيح API.

## الخطوات

<Steps>
  <Step title="راجع صحة الخدمة أولاً">
    افتح [صحة الخدمة](https://status.karzoun.chat/) قبل فتح بلاغ.

    - إن ظهر عطل عام على البوابة أو واتساب أو الأتمتة أو الحملات أو التكاملات، انتظر التحديث هناك — غالباً لا حاجة لبلاغ مكرر.
    - عطل واتساب لدى ميتا ليس دائماً عطلاً في كرزون؛ راجع أيضاً [حالة واتساب للأعمال لدى ميتا](https://metastatus.com/whatsapp-business-api) عند مشاكل القناة فقط.

    {/* MEDIA: /images/help/getting-started/get-support-status.webp | بوابة status.karzoun.chat تعرض حالة المكوّنات (وارد، واتساب، أتمتة، حملات) */}
    <Frame caption="صحة الخدمة قبل فتح بلاغ">
      <img src="/images/help/getting-started/get-support-status.webp" alt="صفحة صحة خدمة كرزون تعرض حالة المكوّنات" />
    </Frame>
  </Step>
  <Step title="جهّز قبل التصعيد">
    أرفق أكبر قدر ممكن من التالي في أول رسالة:

    | ماذا | لماذا |
    | --- | --- |
    | **نطاق الحساب** (مثل `yourbrand.karzoun.chat`) | يحدد البيئة بسرعة |
    | **وقت التقريبي** للمشكلة (بتوقيتك أو UTC) | يطابق السجلات |
    | **الشاشة أو المسار** (مثل `/inbox` أو إعدادات القناة) | يوجّه التشخيص |
    | **خطوات إعادة الظهور** | يقلل الذهاب والعودة |
    | **لقطات شاشة أو تسجيل قصير** | يوضح رسالة الخطأ والواجهة |
    | **معرّف محادثة / حملة / أتمتة** إن وُجد | يختصر البحث الداخلي |

    {/* MEDIA: /images/help/getting-started/get-support-prepare.webp | مسودة بلاغ منظّمة: نطاق الحساب، الوقت، المسار، ومعرّف محادثة — بلا كلمات مرور */}
    <Frame caption="أول رسالة مكتملة تختصر الذهاب والعودة">
      <img src="/images/help/getting-started/get-support-prepare.webp" alt="عناصر بلاغ الدعم: النطاق والوقت والمسار والمعرّف" />
    </Frame>
  </Step>
  <Step title="تواصل مع الدعم">
    بعد التأكد أن المشكلة ليست عطلاً عاماً على [صحة الخدمة](https://status.karzoun.chat/):

    - افتح [تواصل معنا](https://karzoun.chat/contact) واذكر أنك عميل تشغيل / خدمة عملاء، مع العناصر من الجدول أعلاه.
    - مطوّر أو تكامل GraphQL / MCP / SDK؟ استخدم قناة المطوّرين من تبويب API في الوثائق — ليست نفس مسار دعم التشغيل.
  </Step>
</Steps>

<Tip>
لا ترسل كلمات مرور أو رموز تحقق أو مفاتيح API كاملة في البلاغ. إن لزم مفتاح للتشخيص، استخدم قناة آمنة يطلبها الدعم صراحة.
</Tip>

## أخطاء شائعة

| ما يحدث | الصواب |
| --- | --- |
| بلاغ مكرر أثناء عطل ظاهر على البوابة | انتظر تحديث [صحة الخدمة](https://status.karzoun.chat/) |
| رسالة بلا وقت ولا مسار | أرفق الجدول أعلاه في أول رسالة |
| خلط عطل واتساب ميتا بعطل كرزون | راجع [حالة واتساب للأعمال لدى ميتا](https://metastatus.com/whatsapp-business-api) لمشاكل القناة |

## الخطوة التالية

جهّزت البلاغ أو تأكدت أن العطل عام. بعد ذلك:

- إن كان الحساب يتأسس: [أول أسبوع للمسؤول](/ar/help-center/guides/getting-started/first-week-admin).
- للعودة إلى توجيه البداية: [نظرة عامة: البداية](/ar/help-center/guides/getting-started/overview).
- لإعداد الحساب بالترتيب: [الانطلاق السريع](/ar/help-center/guides/getting-started/quick-start).
