أسماء مقفلة في مركز المساعدة: **حساب كرزون**، **البريد الوارد**، **موظف** للبشر و**وكيل** للذكاء الاصطناعي فقط.

## ما تحتاجه في أيام الانطلاق

| المصطلح | المعنى |
| --- | --- |
| **حساب كرزون** | بيئة عمل الفريق — ليست «مساحة العمل». |
| **البريد الوارد** | `/inbox` لرسائل القنوات. مجموعة الأدلة: **خدمة العملاء**. |
| **القناة** | تكامل الوصول من `/channels`. |
| **القسم** | فريق تشغيل تُربَط به القنوات والموظفون. |
| **موظف** | عضو بشري. **وكيل** = ذكاء اصطناعي فقط. |
| **زكي / المساعد الذكي** | مساعد الموظفين في `/copilot` — ليس بوت واتساب للعملاء. |
| **الرد الآلي** | ترحيب وسلوك القناة من `/automations/channel-bots`. |
| **الحملات التسويقية** | في الواجهة عند النقر: **الرسائل الجماعية**. |

الجداول الكاملة: [مسرد المصطلحات](/ar/help-center/guides/getting-started/glossary).
