**الجمهور:** الجميع — نقطة الدخول اليومية بعد تسجيل الدخول (`/`).

الصفحة الرئيسية ليست تقريراً عميقاً؛ هي لوحة تشغيل سريعة: أين تقف اليوم، وما يحتاج تدخّلك، وكيف تتقدّم أنت وفريقك بالنقاط.

## مناطق الصفحة

من أعلى لأسفل تقريباً:

| المنطقة | ماذا تعرض |
| --- | --- |
| **الترحيب وحالة الوردية** | اسمك؛ حالة الحضور إن كان نظام الوقت مفعّلاً |
| **بطاقات المؤشرات** | ملخص سريع لأرقام يومك/فريقك حسب صلاحياتك |
| **يحتاج انتباهاً** | عناصر تستحق فتحاً فورياً (مثل محادثات معلّقة) |
| **إجراءات سريعة** | اختصارات لصفحات شائعة |
| **ويدجت المتصدرين** | نقاطك، ترتيبك، الفئات، الشارات، قائمة الفريق أو العالمية |
| **محادثاتي** | عيّنة من محادثاتك الأخيرة |
| **تقدّم التدريب** | المهمة التالية ونسبة الإنجاز — يفتح `/training` |

<Info>
**وسائط مطلوبة:** الصفحة الرئيسية بثلاثة أعمدة: يحتاج انتباهاً · إجراءات سريعة · ويدجت المتصدرين، مع ويدجت التدريب أسفل الصفحة.  
المسار المقترح: `/images/help/getting-started/home-dashboard-layout.webp`
</Info>

## ويدجت المتصدرين (لا صفحة مستقلة)

لا يوجد مسار `/leaderboard`. كل المنافسة تظهر هنا:

- **نقاطك** و**ترتيبك** داخل الفريق عند توفّر بيانات
- شريط لكل فئة: **السرعة** · **الجودة** · **الإنتاجية** · **التدريب** · **التفاعل**
- **شارات** مكتسبة من عتبات النقاط
- تبويبان: **المنافسة ضمن الفريق** و**المنافسة مع الشركات الأخرى**

التفاصيل: [النقاط والفئات](/ar/help-center/guides/training/points-and-categories) · [الشارات](/ar/help-center/guides/training/badges) · [فريق مقابل عالمي](/ar/help-center/guides/training/team-vs-global).

<Info>
**وسائط مطلوبة:** ويدجت المتصدرين مفتوحاً على تبويب الفريق مع شارات وفئات ظاهرة.  
المسار المقترح: `/images/help/getting-started/home-dashboard-leaderboard.webp`
</Info>

## ويدجت التدريب

يعرض مستواك (مبتدئ → مستكشف → لاعب فريق → مستخدم محترف) والمهمة التالية. النقر يفتح [مركز التدريب](/ar/help-center/guides/training/training-center). إن أخفيت التدريب من داخله، قد يختفي الويدجت حسب تفضيلاتك — أعد فتحه من قائمة المستخدم → **مركز التدريب**.

## ماذا لا تبحث عنه هنا؟

- تقارير عميقة → **الرؤى** (`/insights`)
- إعداد الفريق والفوترة → **الإعدادات**
- مسار تدريب كامل → `/training` لا الصفحة الرئيسية وحدها
