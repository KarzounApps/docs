من **الاجتماعات** (`/meetings`) تضغط **اجتماع جديد**، تملأ الأساسيات، ثم تختار كيف تريد رؤية مواعيدك لاحقاً من مبدّل العرض أعلى الشاشة.

## إنشاء اجتماع

### الأساسيات

1. افتح **الاجتماعات** واضغط **اجتماع جديد**.
2. أدخل **العنوان** (إلزامي).
3. حدّد **التاريخ والوقت**، أو فعّل **طوال اليوم**.
4. أضف **المشاركين** من تبويبات **الفريق** · **جهات الاتصال** · **بريد إلكتروني**.
5. احفظ بـ **إنشاء اجتماع**.

أنت كمنشئ تُضاف منظّماً عادةً بردّ حضور مقبول.

### خيارات إضافية

من **خيارات إضافية** اضبط عند الحاجة:

| الحقل | أمثلة الاستخدام |
| --- | --- |
| الوصف | سياق للمشاركين قبل اللقاء |
| الطريقة | حضوري · مكالمة فيديو · مكالمة هاتفية · مختلط |
| الموقع / رابط الاجتماع | عنوان مكان أو رابط انضمام يدوي |
| الغرفة | عند حضوري/مختلط — انظر [الغرف](/ar/help-center/guides/meetings/rooms) |
| النوع | داخلي · خارجي · مجلس · فردي · يومي · ورشة… |
| الأولوية | عاجل · مرتفع · متوسط · منخفض |
| الرؤية | عام / خاص (فلتر عرض؛ القائمة أصلاً لمشاركاتك) |
| التكرار | يومي / أسبوعي / شهري حسب الخيارات الظاهرة |
| مزامنة التقويم | إن رُبط [تقويم Google](/ar/help-center/guides/meetings/google-calendar) |

<Info>
**وسائط مطلوبة:** حوار الإنشاء مفتوح بالأساسيات، ثم موسّع بالخيارات الإضافية مع منتقي المشاركين.  
المسار المقترح: `/images/help/meetings/create-dialog.webp`  
**فيديو (مستحسن):** 30 ثانية إنشاء اجتماع بثلاثة مشاركين وحفظه.
</Info>

## حالات الاجتماع

| الحالة | المعنى التشغيلي |
| --- | --- |
| مجدول | لم يبدأ بعد |
| قيد التنفيذ | بدأ المنظّم اللقاء |
| مكتمل | انتهى |
| ملغي | أُلغي ولن يُعقد |

## ثمانية عروض

بدّل العرض من أعلى الشاشة حسب حاجتك:

| العرض | متى يفيد |
| --- | --- |
| الشهر | نظرة شهر كامل |
| الأسبوع | تداخل مواعيد الأسبوع |
| اليوم | جدول بالساعات لليوم |
| قائمة | سرد متسلسل |
| كانبان | بطاقات حسب الأيام |
| الخط الزمني | تداخل أفقي |
| جدول الأعمال | ملخص قادم مختصر |
| لوحة المعلومات | إحصائيات نشاط |

الشريط الجانبي داخل الصفحة يضم غالباً **التقويم** · **تصفية** · **القادمة**.

## بعد الإنشاء

افتح درج التفاصيل لإكمال **جدول الأعمال** و**الملاحظات** و**الإجراءات** ومتابعة RSVP. إن احتجت Meet تلقائياً لطريقة فيديو/مختلط، اربط التقويم أولاً.
