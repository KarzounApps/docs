عندما تريد دعوة الفريق أو العميل لموعد واضح — بعنوان ووقت ومشاركين — يصعب الاعتماد على رسائل متفرقة بلا تقويم مشترك.

توفّر **الاجتماعات** في كرزون (`/meetings`) حوار **اجتماع جديد** مع أساسيات وخيارات إضافية، ثم ثمانية عروض لرؤية مواعيدك لاحقاً.

يشرح هذا الدليل كيف تنشئ الاجتماع، تضبط الخيارات الإضافية، ومتى تبدّل العرض.

## قبل أن تبدأ

- أنت في **الاجتماعات** (`/meetings`) ولديك صلاحية إنشاء مواعيد إن طلبها الحساب.
- للغرف الحضورية راجع [الغرف](/ar/help-center/guides/meetings/rooms) مسبقاً. لـ Meet تلقائي راجع [تقويم Google](/ar/help-center/guides/meetings/google-calendar).

## الخطوات

<Steps>
  <Step title="افتح اجتماعاً جديداً واملأ الأساسيات">
    من **الاجتماعات** اضغط **اجتماع جديد**. أدخل **العنوان** (إلزامي)، حدّد **التاريخ والوقت** أو فعّل **طوال اليوم**، ثم أضف **المشاركين** من تبويبات **الفريق** · **جهات الاتصال** · **بريد إلكتروني**. احفظ بـ **إنشاء اجتماع**.

    أنت كمنشئ تُضاف منظّماً عادةً بردّ حضور مقبول.

    <Frame caption="حوار الإنشاء: أساسيات ثم خيارات إضافية">
      <img src="/images/help/meetings/create-dialog.webp" alt="حوار الإنشاء مفتوح بالأساسيات، ثم موسّع بالخيارات الإضافية مع منتقي المشاركين" />
    </Frame>
  </Step>
  <Step title="اضبط الخيارات الإضافية عند الحاجة">
    من **خيارات إضافية** عيّن ما يلزم:

    | الحقل | أمثلة الاستخدام |
    | --- | --- |
    | الوصف | سياق للمشاركين قبل اللقاء |
    | الطريقة | حضوري · مكالمة فيديو · مكالمة هاتفية · مختلط |
    | الموقع / رابط الاجتماع | عنوان مكان أو رابط انضمام يدوي |
    | الغرفة | عند حضوري/مختلط — انظر [الغرف](/ar/help-center/guides/meetings/rooms) |
    | النوع | داخلي · خارجي · مجلس · فردي · يومي · ورشة… |
    | الأولوية | عاجل · مرتفع · متوسط · منخفض |
    | الرؤية | عام / خاص (فلتر عرض؛ القائمة أصلاً لمشاركاتك) |
    | التكرار | يومي / أسبوعي / شهري حسب الخيارات الظاهرة |
    | مزامنة التقويم | إن رُبط [تقويم Google](/ar/help-center/guides/meetings/google-calendar) |

    {/* MEDIA: /images/help/meetings/create-options-expand-gif.webp | GIF 5ث: فتح خيارات إضافية → اختيار طريقة حضوري وربط غرفة */}
    <Frame caption="توسيع الخيارات الإضافية واختيار الطريقة">
      <img src="/images/help/meetings/create-options-expand-gif.webp" alt="فتح خيارات إضافية واختيار طريقة الاجتماع والغرفة" />
    </Frame>
  </Step>
  <Step title="بدّل العرض حسب حاجتك">
    من أعلى الشاشة اختر العرض المناسب:

    | العرض | متى يفيد |
    | --- | --- |
    | الشهر | نظرة شهر كامل |
    | الأسبوع | تداخل مواعيد الأسبوع |
    | اليوم | جدول بالساعات لليوم |
    | قائمة | سرد متسلسل |
    | كانبان | بطاقات حسب الأيام |
    | الخط الزمني | تداخل أفقي |
    | جدول الأعمال | ملخص قادم مختصر |
    | لوحة المعلومات | إحصائيات نشاط |

    الشريط الجانبي داخل الصفحة يضم غالباً **التقويم** · **تصفية** · **القادمة**.

    {/* MEDIA: /images/help/meetings/create-views-switch-gif.webp | GIF 5ث: التبديل بين كانبان وقائمة ويوم لنفس المواعيد */}

  </Step>

## حالات الاجتماع

| الحالة | المعنى التشغيلي |
| --- | --- |
| مجدول | لم يبدأ بعد |
| قيد التنفيذ | بدأ المنظّم اللقاء |
| مكتمل | انتهى |
| ملغي | أُلغي ولن يُعقد |

## بعد الإنشاء

افتح درج التفاصيل لإكمال **جدول الأعمال** و**الملاحظات** و**الإجراءات** ومتابعة RSVP — الدليل الكامل: [تفاصيل الاجتماع](/ar/help-center/guides/meetings/detail-drawer). إن احتجت Meet تلقائياً لطريقة فيديو/مختلط، اربط التقويم أولاً.

## الخطوة التالية

تعلّمت إنشاء الموعد وتبديل العرض. بعد ذلك:

- أكمل الأجندة وRSVP من [تفاصيل الاجتماع](/ar/help-center/guides/meetings/detail-drawer).
- إن كنت المنظّم لدورة كاملة: [مسار المنظّم](/ar/help-center/guides/meetings/path-organizer).
