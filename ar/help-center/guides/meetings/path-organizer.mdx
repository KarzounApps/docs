<Info>
**وسائط مطلوبة:** حوار «اجتماع جديد» مع مشاركين مختارين، ثم درج تفاصيل بأزرار بدء/إنهاء للمنظّم.  
المسار المقترح: `/images/help/meetings/path-organizer-create.webp`
</Info>

## دورة المنظّم

| الخطوة | الصفحة / الإجراء |
| --- | --- |
| أنشئ الموعد | **اجتماع جديد** — عنوان، وقت، مشاركون (فريق / جهات اتصال / بريد)، خيارات إضافية |
| تابع الردود | تبويب **المشاركون** وحالات RSVP |
| ابدأ اللقاء | عندما يحين الوقت: **بدء** → الحالة **قيد التنفيذ** |
| سجّل الحضور | لنفسك وللمشاركين عند الحاجة من تبويب **الحضور** |
| أنهِ أو ألغِ | **إنهاء** عند الاكتمال، أو **إلغاء** / **حذف** إن لزم (صلاحية المنظّم) |
| حوّل متابعة لعمل | من **الإجراءات** يمكن ربط عنصر بـ[مهمة](/ar/help-center/guides/tasks/task) إن ظهر في واجهتك |
