> **ملاحظة:** هذه الميزة حالياً قيد التطوير وقد تشهد تحديثات إضافية مستقبلاً.

يتيح لك **خادم MCP (Model Context Protocol)** في كرزون منح مساعدي الذكاء الاصطناعي (مثل Claude، Cursor، أو وكلاء الذكاء الاصطناعي الآخرين) وصولاً مباشراً إلى حسابك في كرزون.

من خلال هذا البروتوكول، يمكن للذكاء الاصطناعي قراءة بياناتك، عرض العملاء، إدارة المهام، إعداد خطافات الويب، والقيام بالعديد من العمليات الأخرى عبر اللغة الطبيعية.

![صفحة خادم MCP](/images/help/mcp-2279092/01-49d187f515dc.webp)

## ما يمكن للوكلاء فعله عبر MCP

يوفر خادم MCP وصولاً إلى أكثر من 75 أداة GraphQL، مقسمة إلى عدة مجالات:

- **جهات الاتصال و CRM:** جلب بيانات العملاء، الشركات، والعلامات (Tags).

- **المهام واللوحات:** إدارة المهام، إضافة مهام جديدة، والوصول للوحات المهام.

- **البريد الوارد والمحادثات:** قراءة المحادثات وإضافة رسائل إليها.

- **خطافات الويب:** قراءة وإضافة خطافات الويب.

- **قاعدة المعرفة:** البحث في قاعدة المعرفة وقراءة المقالات.

- **التطبيقات والمصادقة:** إدارة التطبيقات ورموز API.

## إعداد الاتصال

يوفر كرزون طريقتين لربط خادم MCP بمساعد الذكاء الاصطناعي الخاص بك: **محلي** أو **مستضاف**.

### الطريقة الأولى: الربط المحلي (Cursor / Claude Desktop)

تُستخدم هذه الطريقة إذا كنت تستخدم أدوات ذكاء اصطناعي مثبتة على جهازك الشخصي، مثل محرر الأكواد Cursor أو تطبيق Claude Desktop.

![إعداد MCP المحلي](/images/help/mcp-2279092/02-a4e57b94a9c1.webp)

**خطوات الربط المحلي:**

1. **إنشاء رمز API:** قم بإنشاء رمز API جديد من صفحة التطبيقات وانسخه (يظهر مرة واحدة فقط).

1. **تثبيت خادم MCP:** افتح سطر الأوامر (Terminal) في جهازك وشغل الأمر التالي (لا يحتاج لتثبيت عام بفضل `npx`):

   

```bash
   npx -y @karzounchat/mcp-server
   

```

1. **الإضافة إلى عميل MCP:** انسخ كود التكوين (JSON) الموجود في صفحة الإعداد، والصقه في ملف إعدادات MCP في Cursor أو Claude Desktop. لا تنسَ استبدال `<paste-app-token-from-/developer/apps>` برمز API الذي أنشأته في الخطوة الأولى.

مثال على التكوين:

```json
{
  "mcpServers": {
    "karzoun": {
      "command": "npx",
      "args": ["-y", "@karzounchat/mcp-server"],
      "env": {
        "KARZOUN_API_URL": "https://sales-d.api.karzoun.chat/graphql",
        "KARZOUN_APP_TOKEN": "رمز_API_الخاص_بك_هنا"
      }
    }
  }
}
```

### الطريقة الثانية: الربط المستضاف (SaaS / وكلاء سحابية )

تُستخدم هذه الطريقة إذا كنت تستخدم منصات ذكاء اصطناعي سحابية أو وكلاء (Agents) يعملون على خوادم خارجية (مثل منصات بناء الوكلاء).

![إعداد MCP المستضاف](/images/help/mcp-2279092/03-3dc92ef0e16d.webp)

**خطوات الربط المستضاف:**في هذه الحالة، لن تحتاج لتشغيل خادم محلي. بدلاً من ذلك، ستقوم بتوجيه وكيل الذكاء الاصطناعي للتخاطب مباشرة مع نقطة نهاية (Endpoint) خاصة بكرزون.

1. **نقطة النهاية (Endpoint):** استخدم الرابط التالي كـ URL لخادم MCP:

   

```
   https://sales-d.api.karzoun.chat/mcp
   

```

1. **ترويسة المصادقة (Header ):** يجب أن يرسل الوكيل السحابي رمز API في ترويسة الطلب بالشكل التالي:

   

```
   x-app-token: <your-app-token>
   

```

1. **مثال طلب Initialize:** في صفحة الإعداد، ستجد أمثلة جاهزة بـ cURL و BASH لكيفية بدء الاتصال (Initialize) مع الخادم السحابي باستخدام بروتوكول SSE (Server-Sent Events) أو HTTP العادي.

> **تحذير أمني:** لا تضع رموز التطبيق (API Tokens) في إعدادات MCP داخل المتصفح (Client-side) إذا كنت تبني تطبيق ويب، لتجنب تسريبها. استخدم دائماً MCP المستضاف من الخادم (Server-side) أو أتمتة خلفية.

## أمثلة عملية للربط

### مثال 1: الربط مع Claude Desktop

تطبيق Claude Desktop يدعم بروتوكول MCP بشكل مدمج، مما يتيح لك التحدث مع كرزون مباشرة من نافذة المحادثة.

**الخطوات:**

1. **أنشئ رمز API** من **المطور** > **التطبيقات** في كرزون وانسخه.

1. افتح تطبيق Claude Desktop على جهازك، ثم اذهب إلى:

- **macOS:** `Claude` > `Settings` > `Developer` > `Edit Config`
- **Windows:** `File` > `Settings` > `Developer` > `Edit Config`

1. سيفتح ملف `claude_desktop_config.json`، أضف إليه الكود التالي:

```json
{
  "mcpServers": {
    "karzoun": {
      "command": "npx",
      "args": ["-y", "@karzounchat/mcp-server"],
      "env": {
        "KARZOUN_API_URL": "https://sales-d.api.karzoun.chat/graphql",
        "KARZOUN_APP_TOKEN": "رمز_API_الخاص_بك_هنا"
      }
    }
  }
}
```

1. احفظ الملف وأعد تشغيل Claude Desktop.

1. ستظهر أيقونة 🔨 (أدوات ) في نافذة المحادثة تدل على أن كرزون متصل.

**أمثلة على ما يمكنك قوله لـ Claude بعد الربط:**

- _"اعرض لي آخر 10 محادثات في البريد الوارد"_

- _"ابحث عن العميل أحمد محمد وأخبرني بتفاصيله"_

- _"أنشئ مهمة جديدة بعنوان متابعة العميل رقم 123"_

---

### مثال 2: الربط مع Manus

منصة Manus تدعم ربط خوادم MCP الخارجية عبر إعدادات الموصلات (Connectors)، مما يتيح لوكيل Manus التفاعل مع بيانات كرزون مباشرة.

**الخطوات:**

1. **أنشئ رمز API** من **المطور** > **التطبيقات** في كرزون وانسخه.

1. في Manus، افتح إعدادات المشروع أو الجلسة واذهب إلى قسم **الموصلات (Connectors)**.

1. أضف موصل MCP جديد من نوع **Custom MCP** وأدخل البيانات التالية:

- **URL:** `https://sales-d.api.karzoun.chat/mcp`
- **Header:** `x-app-token: رمز_API_الخاص_بك_هنا`

1. احفظ الإعداد وسيتمكن وكيل Manus من الوصول إلى كرزون في المهام القادمة.

**أمثلة على ما يمكن لـ Manus فعله بعد الربط:**

- جلب قائمة العملاء وتحليلها تلقائياً.

- إنشاء تقارير بناءً على بيانات المحادثات.

- أتمتة إنشاء المهام أو تحديث بيانات جهات الاتصال.
