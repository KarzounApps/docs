---

ضمّن بكسل تتبع كرزون في موقعك لتحديد الزوّار ومزامنة بيانات العملاء مع مساحة عمل كرزون لديك.

## التضمين الأساسي

```html
<script>
  (function (w, d, s, l, i) {
    /* pixel bootstrap */
  })(window, document, "script", "dataLayer", "PIXEL_ID");
</script>
```

## الإعداد

| الإعداد         | الوصف                     |
| ----------------- | ---------------------------------- |
| `integrationId` | معرّف تكامل كرزون لديك     |
| `apiUrl`        | عنوان API للبوابة لمساحة عملك |
| `cdnUrl`        | شبكة CDN للأصول الثابتة                |

اضبط البكسل في **الإعدادات ← التكاملات** واستخدم المقتطف المُولَّد.

لتعيين بيانات العملاء المتقدّم، راجع توثيق البكسل في `packages/karzoun-pixel/docs/` في المستودع الأحادي.
