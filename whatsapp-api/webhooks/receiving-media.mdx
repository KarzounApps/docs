---
title: "Receiving media"
description: "Download images, documents, audio and video that customers send you."
---

An incoming media message carries a media ID, not the file:

```json
{
  "from": "966500000000",
  "id": "wamid.HBgM...",
  "timestamp": "1731916800",
  "type": "image",
  "image": {
    "id": "1037543291543636",
    "mime_type": "image/jpeg",
    "sha256": "e7b2…",
    "caption": "Damaged box"
  }
}
```

Download the file with your API key:

```bash
curl https://waba.karzoun.chat/1037543291543636/download \
  -H "Karzoun-API-Key: YOUR_API_KEY" \
  -o damaged-box.jpg
```

The response is the file with its original `Content-Type`.

<Tip>
  Download right away and store the file yourself. Meta keeps incoming media for a limited time.
</Tip>

`document`, `audio`, `video` and `sticker` messages work the same way: take `id` from the object named after the type.

To read the file's metadata (size, type, hash) without downloading it, call `GET /{media-id}`. See [Media](/whatsapp-api/messaging/media#retrieve).
