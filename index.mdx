## Try a request

```bash
curl -X POST 'https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql' \
  -H 'Content-Type: application/json' \
  -H 'x-app-token: YOUR_APP_TOKEN' \
  -d '{"query":"query { tags(page: 1, perPage: 3) { data { name } } }"}'
```

<Tip>
  Prefer a visual editor? Open the [GraphQL Playground](https://karzoun.chat/developer/playground) in your developer dashboard.
</Tip>
