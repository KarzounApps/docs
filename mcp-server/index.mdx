title: "MCP"
description: "Connect Cursor, Claude, or ChatGPT to your Karzoun workspace."
---

MCP lets an AI app call your Karzoun workspace: list customers, read the inbox, look up a WhatsApp template. Each tool is one public GraphQL operation. The tool name is the operation name.

Open **Developer → MCP setup** (`/developer/mcp-setup`) if you want the URL and config already filled in for your workspace.

## Pick your app

- **Cursor, VS Code, or Claude Desktop on your computer.** Follow [Cursor](/mcp-server/setup/cursor). [VS Code](/mcp-server/setup/vscode) and [Claude Desktop](/mcp-server/setup/claude-desktop) use the same program and a different config file. You paste an [API key](/developers/getting-started/authentication) into that file.
- **Claude.ai or ChatGPT.** Follow [Cloud apps](/mcp-server/setup/ai-connectors). Paste the MCP URL. The app signs you in. Do not paste a key.
- **A server you run.** Follow [HTTP MCP](/mcp-server/setup/hosted) and send `Authorization: Bearer` with an API key.

If the app does not need a language model, call [GraphQL](/developers/getting-started/quickstart) or [webhooks](/developers/guides/webhooks) directly.

## Start with a pack

A pack is a short tool list. `full` is every public operation and is a poor default.

| Pack | Give it to an agent that should |
| --- | --- |
| `customer-support` | Read the inbox, contacts, companies, and tags |
| `marketing` | Work with broadcasts, segments, forms, and products |
| `operations` | Work with tasks, team chat, and users |
| `whatsapp` | Work with WhatsApp messages, templates, and flows |
| `automations` | Read and edit automation flows |
| `integrations` | Read apps, webhooks, and MiniApps |
| `ai` | Search the knowledge base |
| `full` | See the entire public API |

On your computer, set `KARZOUN_MCP_PACK` to one of those ids. Over HTTP, call `/mcp/customer-support` instead of `/mcp`.

After it connects, ask: "Use Karzoun to list my first 5 tags." If the tool is missing or refused, see [Troubleshooting](/mcp-server/guides/troubleshooting).

## Local config

```json
{
  "mcpServers": {
    "karzoun-customer-support": {
      "command": "npx",
      "args": ["-y", "@karzounchat/mcp-server"],
      "env": {
        "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
        "KARZOUN_API_KEY": "kz_live_YOUR_API_KEY",
        "KARZOUN_MCP_PACK": "customer-support"
      }
    }
  }
}
```

| Variable | Required | What to put |
| --- | --- | --- |
| `KARZOUN_API_URL` | Yes | Your GraphQL URL |
| `KARZOUN_API_KEY` | Yes | The key from **Developer → API keys** |
| `KARZOUN_MCP_PACK` | No | A pack id. Defaults to `full` |
| `KARZOUN_MCP_FETCH_TIMEOUT_MS` | No | How long one GraphQL call may take. Default 30000 |
| `KARZOUN_MCP_MAX_RESPONSE_BYTES` | No | Largest tool reply. Default 524288 (512 KB) |

An old `KARZOUN_APP_TOKEN` is still read when `KARZOUN_API_KEY` is empty, until 31 March 2027. New setups should set the API key.

Hosted `/mcp` allows 120 POSTs a minute per key. `MCP_RATE_LIMIT_PER_MIN=0` on the gateway turns that off.
