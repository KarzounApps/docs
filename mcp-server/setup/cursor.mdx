---
title: "Cursor setup (stdio)"
description: "Run Karzoun MCP locally so Cursor's agent can call your workspace GraphQL API as tools."
---

Cursor runs a small local program that calls your workspace API. You need an [API key](/developers/getting-started/authentication) and your GraphQL URL, `https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql`.

## Configure MCP

<Steps>
  <Step title="Open MCP settings">
    **Cursor Settings → MCP → Add new global MCP server**

    Or edit `~/.cursor/mcp.json` / project `.cursor/mcp.json`.
  </Step>

  <Step title="Add the Karzoun server">
    ```json
    {
      "mcpServers": {
        "karzoun-customer-support": {
          "command": "npx",
          "args": ["-y", "@karzounchat/mcp-server"],
          "env": {
            "KARZOUN_API_URL": "https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql",
            "KARZOUN_API_KEY": "kz_live_YOUR_API_KEY",
            "KARZOUN_MCP_PACK": "customer-support"
          }
        }
      }
    }
    ```

    Replace `YOUR_SUBDOMAIN` and paste the API key from **Developer → API keys** (shown once).

    <Warning title="Keep the key out of git">
      Do not commit `mcp.json` if it contains a real key. Prefer an environment variable or Cursor's secret storage.
    </Warning>
  </Step>

  <Step title="Pick a pack">
    `KARZOUN_MCP_PACK` limits which public GraphQL tools the agent sees:

    | Pack | Good for |
    |------|----------|
    | `customer-support` | Inbox, contacts, companies, tags (recommended start) |
    | `marketing` | Broadcasts, segments, forms, products |
    | `whatsapp` | Templates, messaging, flows |
    | `automations` | Flows and nodes |
    | `full` | Entire public API (large — advanced) |

    Full table: [Hosted MCP → Packs](/mcp-server/setup/hosted#packs-tool-subsets).
  </Step>

  <Step title="Restart and verify">
    1. **Cursor Settings → MCP** — refresh the server
    2. Status should show **connected** with tools for your pack
    3. In chat: _"Use Karzoun to list my first 5 tags"_
  </Step>
</Steps>
