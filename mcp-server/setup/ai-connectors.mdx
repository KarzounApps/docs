Use this page when the AI app is on the internet, not on your laptop. Your URL is:

```
https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp/customer-support
```

`customer-support` is the tool pack. Drop it, or swap in another pack from the [MCP overview](/mcp-server), when you want a different list.

**Claude.ai and ChatGPT** sign you in. Paste the URL and jump to that section below. Do not paste an API key.

**Manus, remote Cursor, Claude Code, and your own server** can set a header. Send `Authorization: Bearer kz_live_…` with an [API key](/developers/getting-started/authentication). Never put that key in a browser extension or a shared chat.

**Developer → MCP setup** (`/developer/mcp-setup`) fills in the URL for your workspace.

Once it is connected, try:

- _"List my 10 most recently updated customers and summarize their tags."_
- _"Find open conversations that need a reply."_
- _"Search the knowledge base for return policy and draft a short customer reply."_
- _"List WhatsApp templates approved for my account."_
- _"Find the conversation with alice@example.com and summarize the last 5 messages."_

Ask the model to read before it changes anything. More prompts: [Agent patterns](/mcp-server/guides/agent-patterns). The operation names are in the [tool catalog](/mcp-server/tools/catalog).

## Claude.ai

Claude on the web supports **custom remote MCP connectors** (Settings → Connectors → Add custom connector).

<Steps>
  <Step title="Add the connector">
    1. Open [Claude Connectors](https://claude.ai/settings/connectors) (or **Admin → Connectors** on Team/Enterprise).
    2. Click **Add custom connector**.
    3. **Server URL:** `https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp/customer-support`
    4. Claude discovers Karzoun's authorization server. Sign in with your Karzoun account and approve the scopes. Do not paste an API key into this connector.
  </Step>

  <Step title="Enable in chat">
    Use the **+** menu in a conversation → **Connectors** → enable Karzoun for that chat.

    Test: _"Using Karzoun tools, run currentUser and list my first 5 tags."_
  </Step>
</Steps>

<Info title="Claude Desktop vs Claude.ai">
  **Claude Desktop** on your computer uses the [local setup](/mcp-server/setup/claude-desktop). Claude.ai uses this connector. Do not put the HTTPS URL in `claude_desktop_config.json`.
</Info>

## Manus

[Manus](https://manus.im/) supports **Custom MCP servers** over HTTP — a strong fit for hosted Karzoun because you can point at a public `/mcp` URL and supply credentials.

<Steps>
  <Step title="Open Custom MCP">
    **Settings → Integrations → Custom MCP** (or **+ Add custom MCP → Direct configuration**).
  </Step>

  <Step title="Enter server details">
    | Field              | Value                                                                                    |
    | ------------------ | ------------------------------------------------------------------------------------------ |
    | **Name**           | `Karzoun` (or your workspace name)                                                       |
    | **Transport**      | `HTTP` / Streamable HTTP                                                                 |
    | **Server URL**     | `https://{subdomain}.api.karzoun.chat/mcp`                                               |
    | **Authentication** | API key / Bearer — paste `kz_live_…`. If the UI has a custom header field, use `Authorization`. |

    If Manus sends `Authorization: Bearer` from a single API key field, paste the Karzoun API key there. No proxy.
  </Step>

  <Step title="Test and use">
    Manus verifies the server and lists discovered tools. Reference Karzoun in prompts:

    _"Pull my top 10 customers by last updated date and create a Manus doc summarizing their tags."_

    Official reference: [Manus custom MCP docs](https://manus.im/docs/integrations/custom-mcp).
  </Step>
</Steps>

## ChatGPT Apps and Connectors

OpenAI supports **remote MCP** through **Apps / Connectors** (Developer Mode in ChatGPT settings). ChatGPT connects from OpenAI's cloud — **local stdio does not work**.

<Steps>
  <Step title="Enable developer access">
    In ChatGPT: **Settings → Apps & Connectors** (or **Connectors → Advanced**) → enable **Developer mode** if available on your plan.
  </Step>

  <Step title="Add your MCP URL">
    Create a new app/connector and paste:

    ```
    https://{subdomain}.api.karzoun.chat/mcp
    ```

    Review discovered tools before enabling the app in conversations.
  </Step>
</Steps>

<Warning title="OAuth, not a pasted key">
  ChatGPT connectors sign in with **OAuth**. Paste the MCP URL, then sign in to Karzoun and approve the scopes. Do not paste an API key into this flow.

  Header-based clients ([Manus](#manus), [Cursor remote](#cursor-remote), [Claude Code](#claude-code), or your backend) send `Authorization: Bearer kz_live_…` instead.
</Warning>

## Cursor (remote)

For teams that prefer **not** to run `npx` locally, Cursor supports **remote MCP** via `url` + `headers` in `mcp.json`.

```json
{
  "mcpServers": {
    "karzoun-hosted": {
      "url": "https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp",
      "headers": {
        "Authorization": "Bearer ${env:KARZOUN_API_KEY}"
      }
    }
  }
}
```

Export `KARZOUN_API_KEY` in your shell profile (desktop apps may not load `.zshrc` — use system env or Cursor's supported secret patterns).

**Cursor Settings → MCP** should show **connected** with ~75 tools. Prefer [local stdio](/mcp-server/setup/cursor) for offline development; use **hosted** when `npx` is blocked or you want a single shared endpoint.

Docs: [Cursor MCP — remote servers](https://cursor.com/docs/mcp).

## Claude Code

[Claude Code](https://docs.anthropic.com/en/docs/claude-code) can register HTTP MCP servers from the CLI:

```bash
claude mcp add --transport http karzoun \
  https://YOUR_SUBDOMAIN.api.karzoun.chat/mcp \
  --header "Authorization: Bearer kz_live_YOUR_API_KEY"
```

Use a project `.mcp.json` for repo-scoped access. Revoke the key in **Developer → API keys** if the CLI config is shared.

## Build your own agent

Any stack that speaks **Streamable HTTP MCP** can call Karzoun:

```mermaid
flowchart LR
  User[User / trigger] --> Agent[Your agent runtime]
  Agent -->|POST /mcp + Authorization Bearer| Karzoun[Karzoun gateway]
  Karzoun --> GQL[GraphQL API]
```

Typical hosts: LangGraph, custom Node/Python workers, Zapier-style automations, internal Slack bots.

1. `POST initialize`
2. `POST tools/list` → discover operations
3. `POST tools/call` → execute with GraphQL-shaped arguments

Hosted MCP does not require an `mcp-session-id` between those calls.

Examples and curl: [Hosted MCP](/mcp-server/setup/hosted). Prompt design: [Agent patterns](/mcp-server/guides/agent-patterns).

## Scope tokens for safer agents

Before connecting a powerful client:

| Goal                    | Key scopes                          | Optional env                            |
| ------------------------ | ------------------------------------- | ------------------------------------------ |
| Read-only CRM assistant | Read customers, tags, companies     | `KARZOUN_MCP_TOOL_PREFIX` on stdio only |
| Support triage          | Conversations + knowledge base read | Narrow scopes on the key                 |
| Integration admin       | Webhooks write                      | A separate key, not the read-only one    |

Start with a **read-only** key, validate prompts, then issue a broader key if needed.

## Troubleshooting connectors

| Symptom                        | Likely cause                          | Fix                                           |
| -------------------------------- | ---------------------------------------- | ------------------------------------------------ |
| 401 Authorization required     | No API key or OAuth login                 | Send `Authorization: Bearer`, or finish consent |
| Tools empty / permission error | Key scopes too narrow                 | Widen scopes; test in the Playground          |
| Client cannot reach URL        | Private network / localhost           | Use public `*.api.karzoun.chat` only           |
| ChatGPT or Claude auth fails   | Connector URL is not the public MCP URL | Use `https://{subdomain}.api.karzoun.chat/mcp` and sign in |

More: [Troubleshooting](/mcp-server/guides/troubleshooting).
