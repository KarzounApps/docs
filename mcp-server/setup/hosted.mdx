Call Karzoun MCP over **Streamable HTTP** from your backend — or connect **cloud AI apps** (Claude, Manus, ChatGPT, remote Cursor) to the same endpoint.

**New:** Step-by-step connector guide → [AI app connectors](/mcp-server/setup/ai-connectors)

```
https://{subdomain}.api.karzoun.chat/mcp
https://{subdomain}.api.karzoun.chat/mcp/{pack}
```

<Warning title="Server-side only">
  Never call `/mcp` from browser JavaScript. The app token would be exposed to end users. Use your backend or a trusted worker.
</Warning>

## When to use hosted

| Use hosted                                     | Use stdio instead               |
| ---------------------------------------------- | -------------------------------- |
| Deployed AI agent on your infrastructure       | Local coding in Cursor / Claude |
| Cron or queue worker needs CRM tools           | One-off exploration             |
| Multi-tenant SaaS proxying per-customer tokens | Personal dev machine            |

## Authentication

Every request requires the same header as GraphQL:

```
x-app-token: YOUR_APP_TOKEN_JWT
```

Optional: `x-subdomain` when your gateway routes tenants by header.

## Packs (tool subsets)

Prefer a **pack** so agents get a focused tool list:

| Pack | URL |
|------|-----|
| Customer support | `/mcp/customer-support` |
| Marketing | `/mcp/marketing` |
| Operations | `/mcp/operations` |
| WhatsApp | `/mcp/whatsapp` |
| Automations | `/mcp/automations` |
| Integrations | `/mcp/integrations` |
| AI (knowledge base) | `/mcp/ai` |
| Full public API | `/mcp` or `/mcp/full` |

List packs:

```bash
curl -s 'https://YOUR.api.karzoun.chat/mcp/packs'
```

You can also pass `?pack=customer-support` or header `x-mcp-pack: customer-support` on `/mcp`.

## Transport

Hosted MCP is **stateless** Streamable HTTP (JSON responses). Official MCP clients still send `initialize` then `tools/list` / `tools/call` as separate POSTs — no sticky `mcp-session-id` is required across gateway pods.

## Initialize example

```bash
curl -s -X POST 'https://YOUR.api.karzoun.chat/mcp/customer-support' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'x-app-token: YOUR_TOKEN' \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {
      "protocolVersion": "2024-11-05",
      "capabilities": {},
      "clientInfo": { "name": "my-agent", "version": "1.0.0" }
    }
  }'
```

## List tools

```bash
curl -X POST 'https://YOUR.api.karzoun.chat/mcp/customer-support' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'x-app-token: YOUR_TOKEN' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}'
```

## Call a tool

```bash
curl -X POST 'https://YOUR.api.karzoun.chat/mcp/customer-support' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'x-app-token: YOUR_TOKEN' \
  -d '{
    "jsonrpc": "2.0",
    "id": 3,
    "method": "tools/call",
    "params": {
      "name": "customers",
      "arguments": { "page": 1, "perPage": 5 }
    }
  }'
```

## Architecture pattern

```mermaid
flowchart TB
  User[End user] --> App[Your app]
  App --> Agent[AI agent layer]
  Agent -->|x-app-token| MCP["Karzoun /mcp/:pack"]
  MCP --> GQL[GraphQL]
  Secrets[(Secrets manager)] -.-> Agent
```

Store tokens in a secrets manager; inject per tenant if you operate multi-tenant SaaS.

## Limits

- Same GraphQL permissions and rate behavior as direct API calls
- Hosted `/mcp` POSTs: default **120 req/min** per app token (`MCP_RATE_LIMIT_PER_MIN`)
- GraphQL fetch timeout: default **30s** (`KARZOUN_MCP_FETCH_TIMEOUT_MS`)
- Default **512 KB** tool response cap (configurable on self-hosted gateway mounts)
- See [Security](/mcp-server/setup/security) for rotation and scoping
