## Which one you want

Call **GraphQL** when your server needs data now. Use a **webhook** when you want Karzoun to tell you that something changed. Use **MCP** when an AI app should call the API. Use the **Dashboard SDK** when you are embedding a panel in the inbox. Use **MiniApps** when you are shipping a connector other people install.

## A call

```bash
curl -X POST 'https://YOUR_SUBDOMAIN.api.karzoun.chat/graphql' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer kz_live_YOUR_API_KEY' \
  -d '{"query":"query { tags(page: 1, perPage: 3) { data { name } pagination { totalCount } } }"}'
```

A successful response has a `data` object. A failed one has an `errors` array. See [Errors](/developers/guides/errors).

## Before you ship

- Keep the API key on your server. Never put it in browser JavaScript or a public repo.
- Check `X-Karzoun-Signature-256` on every webhook before you trust the body. See [Webhooks](/developers/guides/webhooks).
- Give the key only the scopes that job needs, such as `contacts:read`.
- Revoke the key in **Developer → API keys** when that person or integration goes away.
