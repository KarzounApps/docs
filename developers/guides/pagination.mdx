---
title: "Pagination"
description: "Read a Karzoun list one page at a time."
---

List queries such as `tags`, `customers`, and `conversations` take `page` and `perPage`. `page` starts at **1**. `tags` returns the first 20 rows when you leave both out. Other lists document their own default, so pass both whenever you care which page you get.

Ask for the `pagination` object and stop when `hasNextPage` is false.

```graphql
query {
  customers(page: 1, perPage: 20) {
    data {
      _id
      firstName
    }
    pagination {
      totalCount
      currentPage
      totalPages
      hasNextPage
      hasPreviousPage
    }
  }
}
```

Pass the next page as a variable rather than editing the query:

```json
{ "page": 2, "perPage": 20 }
```

```graphql
query Customers($page: Int, $perPage: Int) {
  customers(page: $page, perPage: $perPage) {
    data { _id firstName }
    pagination { currentPage hasNextPage }
  }
}
```

Keep `perPage` small. MCP throws away a tool result larger than 512 KB, and a huge page is slower for every client. Add a search or filter argument when the reference shows one, instead of paging through the whole workspace.
